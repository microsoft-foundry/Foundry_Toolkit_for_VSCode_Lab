# មូឌុល 7 - សេចក្តីសង្ខេប និង ជំហ៊ានបន្ទាប់

⏱️ ~5នាទី

**អបអរសាទរ!** អ្នកបានបង្កើត, សាកល្បង, ហើយ (បើលើផ្លូវ A) បានផ្សាភ្ជាប់ភ្នាក់ងារប្រាជ្ញាធិប្បាយដែលភ្ជាប់ដោយ Microsoft Foundry និង Foundry Toolkit សម្រាប់ VS Code។

## អ្វីដែលអ្នកបានបង្កើត

ភ្នាក់ងារ **"ពន្យល់ដូចជា ខ្ញុំជាអគ្គនាយក"** ដែល៖
- ទទួលរបាយការណ៍បច្ចេកទេសឧបត្តិហេតុឬការអាប់ដេតប្រតិបត្តិការតាមរយៈ HTTP (`POST /responses`)
- បម្លែងវាទៅជាសេចក្តីសង្ខេបភាសារងាយស្រួលសម្រាប់អគ្គនាយក
- អនុវត្តរចនាសម្ព័ន្ធលទ្ធផលនៅក្នុងទ្រង់ទ្រាយដែលបានរៀបចំ (អ្វីកើតឡើង / ផលប៉ះពាល់អាជីវកម្ម / ជំហ៊ានបន្ទាប់)
- បដិសេធសំណើផ្សេងទៀតដែលមិនទាក់ទង និងការបាយបញ្ចូលបញ្ជា
- ប្រតិបត្តិជាភ្នាក់ងារដែលមានសុវត្ថិភាពភ្ជាប់នៅក្នុង Microsoft Foundry Agent Service តាមផ្នែកកុងតឺន័រ

## ដំណាក់កាលសំអាតធនធាន (ជាជម្រើស)

ប្រសិនបើអ្នកចង់យកធនធាន Azure ដែលបានបង្កើត ក្នុងអំឡុងវគ្គសិក្សានេះចេញ៖

### ជម្រើស 1៖ លុបក្រុមធនធាន (លុបអ្វីគ្រប់យ៉ាង)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ជម្រើស 2៖ លុបភ្នាក់ងារភ្ជាប់តែប៉ុណ្ណោះ

1. បើក [ai.azure.com](https://ai.azure.com) → គម្រោងរបស់អ្នក → **Build** → **Agents**។
2. ចុចលើភ្នាក់ងាររបស់អ្នក → ចុច **Delete**។

### ជម្រើស 3៖ លុបការផ្សាភ្ជាប់ម៉ូដែល

1. នៅផ្នែក Foundry sidebar, ពង្រីកគម្រោងរបស់អ្នក → **Models**។
2. ចុច​ស្តាំលើការផ្សាភ្ជាប់ម៉ូដែល → **Delete**។

> **កំណត់ចំណាយ៖** ភ្នាក់ងារភ្ជាប់ មានតែចំណាយពេលដំណើរការ បើអ្នកបញ្ឈប់ឬលុបភ្នាក់ងារ នោះមិនមានចំណាយបន្ថែមទៀតទេ។ ការផ្សាភ្ជាប់ម៉ូដែលអាចមានចំណាយតិចតួចសម្រាប់សមត្ថភាពដែលបានរក្សាទុក - សូមលុបប្រសិនបើអ្នកបានបញ្ចប់។
