## អ្វីដែលអ្នកបានបង្កើត

មាស៊ិន **"ពន្យល់ដូចជា ខ្ញុំជាអ្នកគ្រប់គ្រង"** ដែល:
- ទទួលរបាយការណ៍បច្ចេកទេស ឬ ការអាប់ដែតប្រតិបត្តិការ តាមរយៈ HTTP (`POST /responses`)
- ប្រែអត្ថបទបច្ចេកទេសទៅជាសេចក្តីសង្ខេបភាសា ងាយស្រួលសម្រាប់អ្នកគ្រប់គ្រង
- អនុវត្តទ្រង់ទ្រាយលទ្ធផលដែលមានរចនាសម្ព័ន្ធ (អ្វីបានកើតឡើង / ផលប៉ះពាល់លើអាជីវកម្ម / ជំហានបន្ទាប់)
- បដិសេធសំណើមិនទាក់ទង និងការព្យាយាមបញ្ចូលបញ្ហារបស់ prompt injection
- ដំណើរការជាម៉ាស៊ីនមានផ្ទុកក្នុងបណ្ដុំ container នៅក្នុង Microsoft Foundry Agent Service

## គន្លឹះប្រធានបទដែលបានរៀន

| គន្លឹះ | អ្វីដែលអ្នកបានហ្វឹកហាត់ |
|---------|-------------------|
| **សំណុំរចនាសម្ព័ន្ធ Agent Framework** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` សៀងទំព័រ |
| **ជីវិត Agent មានផ្ទុក** | Scaffold → កំណត់រចនាសម្ព័ន្ធ → សាកល្បងក្នុងម៉ាស៊ីន​មូលដ្ឋាន → ដាក់ប្រតិបត្តិ → ពិនិត្យនៅពពក |
| **ការបង្កើត prompt សុវត្ថិភាព** | តួនាទី, ស្តាប់អ្នកទស្សនា, ទ្រង់ទ្រាយលទ្ធផល, ច្បាប់, ចរិតសុវត្ថិភាព, និង ឧទាហរណ៍ |

| **ព្រំដែនសុវត្ថិភាព** | ការការពារចំពោះការវាយប្រហារ prompt injection, គោរពតួនាទី, ការដោះស្រាយដោយម៉េត្រស្មើភាពវិជ្ជមានពីករណីកំណត់ |
| **ដំណើរការ Foundry Toolkit** | បង្កើតគម្រោង, ដាក់ឲ្យប្រើម៉ូឌែល, បង្កើត agent, Agent Inspector, ដាក់ប្រតិបត្តិអោយបានតែម្តង |

## សម្អាតធនធាន (ជាជម្រើស)

បើអ្នកចង់ដកធនធាន Azure ដែលបានបង្កើតក្នុងវគ្គសិក្សានេះ៖

### ជម្រើស 1: លុបក្រុមធនធាន (លុបអ្វីគ្រប់យ៉ាង)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ជម្រើស 2: លុប agent មានផ្ទុកតែ​មួយ

1. បើក [ai.azure.com](https://ai.azure.com) → គម្រោងរបស់អ្នក → **Build** → **Agents**។
2. ចុច agent របស់អ្នក → ចុច **Delete**។

### ជម្រើស 3: លុបការដាក់ប្រតិបត្តមូឌែល

1. នៅផ្នែករង Foundry, ពង្រីកគម្រោងរបស់អ្នក → **Models**។
2. ចុចស្ដាំលើការដាក់ប្រតិបត្តដល់ម៉ូឌែល → **Delete**។

> **សម្គាល់ថ្លៃថ្លា:** Agent មានផ្ទុកគ្រាន់តែមានថ្លៃពេលកំពុងដំណើរការ បើអ្នកបញ្ឈប់ឬលុប agent គ្មានថ្លៃបន្តទៀត។ ការដាក់ប្រតិបត្តម៉ូឌែលអាចមានថ្លៃតិចសម្រាប់ទំហំចាំបាច់ - សូមលុបហើយប្រសិនបើអ្នកបានបញ្ចប់។
