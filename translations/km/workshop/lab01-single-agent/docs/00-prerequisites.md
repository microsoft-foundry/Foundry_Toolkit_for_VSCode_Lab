> **ការមើលមុខនិងកំណត់កម្រិត៖** [ភ្នាក់ងារត្រូវដាក់ទីកន្លែង](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) កំពុងនៅក្នុង **ការមើលមុខសាធារណៈ** - មិនបានណែនាំសម្រាប់បន្ទុកការប្រតិបត្តិការផ្លូវការទេ។ សូមកត់សម្គាល់ដូចខាងក្រោម៖
> - **តំបន់គាំទ្រមានកំណត់** - សូមពិនិត្យ [ចំណុចផ្តល់សេវាតំបន់](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) មុនបង្កើតធនធាន។ ប្រសិនបើអ្នកជ្រើសតំបន់មិនគាំទ្រ អនុវត្តន៍នឹងបរាជ័យ។
> - កញ្ចប់ `agent-framework-foundry-hosting` គឺជាកំណែកំណត់មុន - API ប្រហែលជាខុសគ្នារវាងកំណែ។
> - កំណត់កម្រិតកំរិត៖ ភ្នាក់ងារត្រូវដាក់ទីកន្លែងគាំទ្រព្រីកូឡា 0–5 (រួមបញ្ចូលការកំណត់ទៅសូន្យ)។
> - លក្ខណៈខ្លះៗបង្ហាញនៅក្នុងសិក្ខាសាលានេះអាចផ្លាស់ប្តូរបន្ទាប់ពីសេវាកម្មឆ្លើយទៅរក GA។

## អ្វីដែលអ្នកនឹងបង្កើត

នៅក្នុងសិក្ខាសាលានេះ អ្នកនឹងបង្កើតភ្នាក់ងារ **"ពន្យល់បែបគេខ្ញុំជាអនុប្រធាន"** - ភ្នាក់ងារដំណើរការជាសេវាកម្ម AI ដែលយកបច្ចុប្បន្នភាពបច្ចេកទេសជាច្រើនហើយសរសេរវាឡើងជាសេចក្តីសង្ខេបជាភាសាអង់គ្លេសសាមញ្ញសម្រាប់អភិបាល។

```mermaid
flowchart LR
    A["🧑‍💻 You send a\ntechnical update"] --> B["🤖 Executive Summary\nAgent"]
    B --> C["📝 Plain-English\nexecutive summary"]
```

**ភ្នាក់ងារនេះប្រើ៖**
- **Microsoft Agent Framework** - សម្រាប់តុល្យភាពភ្នាក់ងារនិងរចនាសម្ព័ន្ធ
- **Foundry Toolkit សម្រាប់ VS Code** - សម្រាប់បង្កើតស៊ីស្ទឹម សាកល្បងក្នុងមូលដ្ឋាន និងបញ្ចេញ
- **ម៉ូដែល AI** (ឧ. `gpt-4.1-mini/gpt-5-mini`) - សម្រាប់បង្កើតសេចក្តីសង្ខេប

នៅចុងបញ្ចប់នៃមាតិកានេះ អ្នកនឹងបានភ្នាក់ងារដែលដំណើរការបាន ដែលអ្នកអាចសាកល្បងក្នុងមូលដ្ឋានតាមរយៈ Agent Inspector ហើយជាមិនមែនមានក៏អាចបញ្ចេញទៅពពក។

## ភ្នាក់ងារត្រូវដាក់ទីកន្លែង គឺអ្វី?

**ភ្នាក់ងារត្រូវដាក់ទីកន្លែង** គឺជាភ្នាក់ងារ AI ដែលដំណើរការជាសេវាកម្មគ្រប់គ្រងនៅ Microsoft Foundry។ ជំនួសការគ្រប់គ្រងផ្ទាល់ខ្លួន អ្នកបាច់បញ្ចូលកូដភ្នាក់ងាររបស់អ្នកនៅក្នុងធុងហើយ Foundry នឹងចាត់តាំងការពង្រីក ការចែកចាយ និងបង្ហាញវាតាមរយៈចំនុចចូល HTTP ស្តង់ដារ។

| គំនិត | មានន័យថា |
|---------|--------------|
| **ភ្នាក់ងារ** | កូដ Python របស់អ្នក ដែលទទួលសារ ពិនិត្យម៉ូដែល AI ហើយតបសំណើរដោយរចនាសម្ព័ន្ធ |
| **ត្រូវដាក់ទីកន្លែង** | Foundry ដំណើរការធុងរបស់អ្នក ដោយគ្មាន VM គ្មាន Kubernetes មិនចាំបាច់គ្រប់គ្រង |
| **ពិធីសាស្ត្រឆ្លើយតប** | API HTTP ស្តង់ដារ (`POST /responses`) ដែលអតិថិជនណាមួយអាចហៅដើម្បីតបស្នាមជាមួយភ្នាក់ងាររបស់អ្នក |
| **Agent Inspector** | UI សាកល្បងក្នុងមូលដ្ឋាន (បានបង្កើតក្នុង Foundry Toolkit) ដែលអនុញ្ញាតឲ្យអ្នកពិភាក្សាជាមួយភ្នាក់ងាររបស់អ្នកមុនពេលបញ្ចេញ |

នៅក្នុងសិក្ខាសាលានេះ អ្នកនឹងធ្វើពីសូន្យទៅភ្នាក់ងារត្រូវដាក់ទីកន្លែងពេញលេញ - ឬបញ្ឈប់នៅការសាកល្បងក្នុងមូលដ្ឋាន ប្រសិនបើអ្នកចូលចិត្ត។

## ផ្លូវទាំងអស់៖ ឧបករណ៍តម្រូវការ

ដំឡើងឧបករណ៍ទាំងអស់ខាងក្រោម។ បន្ទាប់ពីដំឡើង ពិនិត្យវាដោយបញ្ជារបញ្ជា as សាកល្បង។

| # | ឧបករណ៍ | កំណែ | ដំឡើង | ពិនិត្យ (លទ្ធផលរំពឹង) |
|---|------|---------|---------|---------------------------|
| 1 | **Visual Studio Code** | ថ្មីបំផុត | [code.visualstudio.com](https://code.visualstudio.com/) | បើកដោយគ្មានកំហុស |
| 2 | **Python** | 3.12 ឬខ្ពស់ជាង | [python.org/downloads](https://www.python.org/downloads/) | `python --version` $\rightarrow$ `Python 3.12.x` |
| 3 | **Foundry Toolkit សម្រាប់ VS Code** | ថ្មីបំផុត | Extension ID: `ms-windows-ai-studio.windows-ai-studio` | រូបតំណាង Foundry នៅ Activity Bar |
| 4 | **ពន្យល់ Python សម្រាប់ VS Code** | ថ្មីបំផុត | Extension ID: `ms-python.python` | បានដំឡើងនៅផ្នែក Extensions |

> [!TIP]
> **គន្លឹះជំនួយសម្រាប់ដំឡើង៖**
> - **ផ្លូវ Python (Windows):** ជ 항상 சரிபார்க்க **"បញ្ចូល Python ទៅ PATH"** នៅមុខកញ្ចប់ដំឡើង Python។ ដែលខ្វះ នៅក្នុងផ្ទាំងប្រតិបត្តិការរបស់អ្នក នឹងមិនអាចរកឃើញ `python` ទេ។
> - **កំណែ Python ច្រើនៗ៖** ប្រសិនបើអ្នកមាន Python 3.10 និង 3.12 នៅក្នុងម៉ាស៊ីនរបស់អ្នក ប្រើ `python3.12 -m venv .venv` ដើម្បីធានាថាគេកំពុងប្រើកំណែត្រឹមត្រូវសម្រាប់បរិយាកាស virtual របស់អ្នក។
> - **Docker WSL 2 (Windows):** នៅពេលដំឡើង Docker Desktop សូមជ្រើសបំរើបន្ទាន់ **WSL 2 backend** ។ Docker ជាមួយ Hyper-V យឺតជាង ហើយអាចបណ្តាលបញ្ហាក្នុងការកសាងកុងតឺនឺររបស់ Foundry។
> - **Docker មិនចាប់ផ្តើម?** រង់ចាំ 30–60 វិនាទី បន្ទាប់ពីបើក Docker Desktop។ បញ្ជារបញ្ជា `docker info` - ប្រសិនបើឃើញ "មិនអាចភ្ជាប់ទៅ Docker daemon" នោះ Docker កំពុងចាប់ផ្តើម។
> - **ផ្នែកបន្ថែម VS Code មិនដំណើរការទេ?** បន្ទាប់ពីដំឡើងផ្នែកបន្ថែម សូមផ្ទាំងវីនដូឡើងវិញ៖ `Ctrl+Shift+P` → `Developer: Reload Window`។

> **អ្នកប្រើ Windows៖** សូមពិនិត្យ **"បញ្ចូល Python ទៅ PATH"** នៅពេលដំឡើង Python។
