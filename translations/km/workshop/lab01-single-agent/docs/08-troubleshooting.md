# ម៉ូឌុល ៨ - ការដោះស្រាយបញ្ហា

ម៉ូឌុលនេះគឺជាមគ្គុទេសក៍យោងសម្រាប់បញ្ហាធម្មតា។ ជំរាបបត់វាទុក ហើយត្រឡប់មកវិញពេលដែលមានអ្វីមួយឆ្គង។

## ១. បញ្ហាសិទ្ធិ

### ១.១ អ្នកតំណាងមិនមានសិទ្ធិ `agents/write`

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**មូលហេតុដើម:** ខ្វះតួនាទី `Azure AI User` នៅកម្រិត **គម្រោង**។ នេះជាបញ្ហាដែលកើតឡើងចម្បងក្នុងវគ្គបង្រៀន។

**ដោះស្រាយ៖**
១. បើក [portal.azure.com](https://portal.azure.com)។
២. ស្វែងរកឈ្មោះ **គម្រោង** Foundry របស់អ្នក → ចុចលទ្ធផលដែលប្រភេទ **"Microsoft Foundry project"** (មិនមែនគណនីម្តាយទេ)។
៣. **ការត្រួតបញ្ជូល (IAM)** → **+ បន្ថែម** → **បន្ថែមតួនាទី**។
៤. តួនាទី៖ **Azure AI User** → បន្ទាប់។
៥. សមាជិក៖ ជ្រើសរើសអ្នក → ពិនិត្យ + ចាត់តំឡើង → ពិនិត្យ + ចាត់តំឡើង។
៦. **រង់ចាំ ១–២ នាទី** → ព្យាយាមម្តងទៀត។

> **ហេតុអ្វីបានជា Owner/Contributor មិនគ្រប់គ្រាន់:** តួនាទីទាំងនេះផ្តល់អំណាច *គ្រប់គ្រង* ប៉ុណ្ណោះ។ ប្រតិបត្តិការអ្នកតំណាងត្រូវការសិទ្ធិ `agents/write` ក្នុង *សកម្មភាពទិន្នន័យ* ដែលមានតែក្នុង `Azure AI User`, `Azure AI Developer` ឬ `Azure AI Owner` តែប៉ុណ្ណោះ។ សូមមើលឯកសារ [Foundry RBAC docs](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry)។

### ១.២ កំហុស `AuthorizationFailed` ពេលបង្កើត

**ដោះស្រាយ៖** ស្នើសុំអ្នកគ្រប់គ្រងឲ្យចាត់តួនាទី **Contributor** នៅលើក្រុមធនធាន ឬឲ្យពួកគេបង្កើតគម្រោងសម្រាប់អ្នក ហើយផ្តល់សិទ្ធិ **Azure AI User** នៅលើវា។

### ១.៣ បញ្ហា `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# រង់ចាំរហូតដល់ៈ "បានចុះបញ្ជី"
```

## ២. បញ្ហា Docker

> Docker គឺជា **ជម្រើសបន្ថែម**។ បញ្ហាទាំងនេះមានតែប្រសិនបើ Docker Desktop ត្រូវបានដំឡើង ហើយ extension ព្យាយាមបង្កើតនៅលើកុំព្យូទ័រស្នូល។

### ២.១ Docker daemon មិនដំណើរការ

**ដោះស្រាយ៖** ចាប់ផ្តើម Docker Desktop → រង់ចាំស្ថានភាព "កំពុងដំណើរការ" → ពិនិត្យជាមួយ `docker info` → ព្យាយាមម្តងទៀត។

### ២.២ ការសាងសង់បរាជ័យជាមួយបញ្ហាឧបនេះ

**ដោះស្រាយ៖** ពិនិត្យការសរសេរ `requirements.txt`, សាកល្បងជាលokalជាដំបូង៖ `pip install -r requirements.txt`។

### ២.៣ បទពិសោធន៍វេទិកា (Apple Silicon)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

## ៣. បញ្ហាសម្គាល់អត្តសញ្ញាណ

### ៣.១ ការបរាជ័យ `DefaultAzureCredential`

**ដោះស្រាយ (សាកល្បងតាមលំដាប់):**
១. `az login` (ចូលប្រើម្ដងទៀត)
២. `az account set --subscription "<id>"` (ជ្រើសរើស subscription ត្រឹមត្រូវ)
៣. VS Code → គណនី → ចាកចេញ → ចូលបញ្ចូលម្តងទៀត
៤. ពិនិត្យ៖ `az account get-access-token --resource https://cognitiveservices.azure.com`

### ៣.២ តូកិនដំណើរការបាននៅលើកុំព្យូទ័រផ្ទាល់ តែ មិនដំណើរការនៅលើម៉ាស៊ីនផ្សព្វផ្សាយ

**ការរំពឹងទុក៖** អ្នកតំណាងផ្សព្វផ្សាយប្រើអត្តសញ្ញាណ​ដែល​ស្វយ័តគ្រប់គ្រង​ដោយ​ប្រព័ន្ធ មិនមែនប្រើគណនីអ្នក។ ប្រសិនបើអgentបង្ហាញកំហុសសម្គាល់អត្តសញ្ញាណដូចខាងក្រោម៖
- ពិនិត្យថា `AZURE_AI_PROJECT_ENDPOINT` នៅក្នុង `agent.yaml` ត្រឹមត្រូវ
- ពិនិត្យថា អត្តសញ្ញាណគ្រប់គ្រងនៃគម្រោងមានសិទ្ធិចូលមើលម៉ូដែល

## ៤. បញ្ហាម៉ូដែល

### ៤.១ មិនរកបានការដាក់រចនាសម្ព័ន្ធម៉ូដែល

**ដោះស្រាយ៖** ឈ្មោះមានអក្សរធំតូចខុសគ្នា។ប្រៀបធៀប `.env` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` ជាមួយឈ្មោះត្រឹមត្រូវនៅមុខបញ្ចូល Foundry → Models។

### ៤.២ ឆ្លើយតបម៉ូដែលមិនគួរឲ្យជ្រាប

**ដោះស្រាយ៖** ពិនិត្យមើល `AGENT_INSTRUCTIONS` ក្នុង `main.py` (មិនត្រូវបម្រាល?) សាកល្បងម៉ូដែលដទៃ (ឧ. `gpt-4.1` ទល់នឹង `gpt-4.1-mini`)។

## ៥. បញ្ហាការដាក់ចេញ

### ៥.១ មិនអនុញ្ញាតឲ្យទាញ ACR

**ដោះស្រាយ៖** ចូល Azure Portal → Container Registry → Access control (IAM) → បន្ថែមតួនាទី **AcrPull** របស់អត្តសញ្ញាណគ្រប់គ្រងគម្រោង Foundry។

### ៥.២ អ្នកតំណាងបរាជ័យក្នុងការចាប់ផ្តើម (នៅតែ "Pending" ឬ "Failed")

ពិនិត្យកំណត់ហេតុកុងតេន័រ នៅក្នុងផ្នែកជំនួយ។ មូលហេតុទូទៅ៖

| សារ Log | ដោះស្រាយ |
|-------------|-----|
| `ModuleNotFoundError` | បន្ថែមកញ្ចប់បាត់ក្នុង `requirements.txt`, ដាក់ចេញម្ដងទៀត |
| `KeyError: 'AZURE_AI_PROJECT_ENDPOINT'` | បន្ថែមអថេរ env ទៅ `agent.yaml` ក្រោម `environment_variables` |
| `Address already in use` | ថែរក្សាឲ្យមានតែដំណើរការតែមួយភ្ជាប់ទៅ port 8088 |

### ៥.៣ ការដាក់ចេញពេលវេលាបិទ

**ដោះស្រាយ៖** ពិនិត្យការតភ្ជាប់អ៊ីនធឺណិត។ ការដាក់ចេញជាលំនៅដ្ឋានផ្តល់ទិន្នន័យច្រើនជាង ១០០MB។ ប្រសិនបើក្រោម proxy សូមកំណត់ proxy ក្នុង Docker Desktop។

| បញ្ហា | ដោះស្រាយ |
|-------|-----|

| ប្រភពធនធានមិនគ្រប់គ្រាន់ | Foundry Local ត្រូវការមemory ប្រហែល ៤GB ថ្មី។ បិទកម្មវិធីផ្សេងៗ។ |

### ៦.២ បញ្ហាម៉ូដែល Foundry Local

| បញ្ហា | ដោះស្រាយ |

| លទ្ធផលគុណភាពថៅ | សាកល្បងម៉ូដែលធំប្រសិនបើឧបករណ៍របស់អ្នកគាំទ្រ។ `phi-4-mini` គឺជាការសម្របសម្រួលល្អ។ |

## ៧. យោងយ៉ាងរហ័សៈ តួនាទី RBAC

| តួនាទី | កម្រិត | ផ្តល់សិទ្ធិ |
|------|-------|--------|
| **Azure AI User** | គម្រោង | សកម្មភាពទិន្នន័យ៖ `agents/write`, `agents/read` |
| **Azure AI Developer** | គម្រោង/គណនី | សកម្មភាពទិន្នន័យ + បង្កើតគម្រោង |
| **Azure AI Owner** | គណនី | 접근ពេញលេញ + គ្រប់គ្រងតួនាទី |
| **Contributor** | សុពកម្ម/ក្រុមធនធាន | សកម្មភាពគ្រប់គ្រងតែប៉ុណ្ណោះ (**គ្មាន** សកម្មភាពទិន្នន័យ) |
| **Owner** | សុពកម្ម/ក្រុមធនធាន | សកម្មភាពគ្រប់គ្រង + ការចាត់តំណែងតួនាទី (**គ្មាន** សកម្មភាពទិន្នន័យ) |
