## អ្វីដែលអ្នកបានបង្កើត

**កម្មវិធីវាយតម្លៃ Resume → Job Fit** - ជាចរន្តសហប្រតិបត្តិការអ្នកជាច្រើនដែលបានផ្ដល់សេវា ដែល៖
- ទទួលបានប្រវត្តិរូប + ពិពណ៌នាការងារតាមរយៈ HTTP (`POST /responses`)
- ប្រតិបត្តិការអ្នកជាពិសេសបួនរូបនៅក្នុងបណ្តោយជាលំដាប់ - អ្នកម្នាក់នីមួយៗផ្ញើទិន្នន័យដែលអ្នកបន្ទាប់ត្រូវការ
- ត្រឡប់លទ្ធផលពិន្ទុសមរម្យ (០–១០០ ជាមួយការបំបែក), បញ្ជីចំណេះដឹង និងរបាយការណ៍ចន្លោះសញ្ញាបត្រ និងផែនទីការសិក្សាផ្ទាល់ខ្លួនជាមួយតំណភ្ជាប់ Microsoft Learn ដើម្បីបង្កើតចន្លោះនីមួយៗ
- ហៅម៉ាស៊ីនមេ Microsoft Learn MCP (`https://learn.microsoft.com/api/mcp`) ដើម្បីទាញយកធនធានការសិក្សាផ្លូវការសម្រាប់ចន្លោះជំនាញដែលបានគណនា
- ប្រតិបត្តិជាអ្នកផ្ដល់សេវាអ្នកជាបំណែកតែមួយដែលបានធ្វើបែបកុងតឺន័រនៅក្នុង Microsoft Foundry Agent Service

## គំនិតសំខាន់ៗដែលបានរៀន

| គំនិត | អ្វីដែលអ្នកបានអនុវត្ត |
|---------|-------------------|
| **ការចាត់តាំងអ្នកជាច្រើនជារបៀបលំដាប់** | `WorkflowBuilder` បណ្តោយលំដាប់ជាមួយ `add_edge()` |
| **ជំនាញពិសេសរបស់អ្នក** | អ្នកជាពិសេសបួនរូបល្អជាងអ្នកម្នាក់ដែលមានគោលបំណងទូទៅ |
| **គំរូ Content Router** | ResumeParser ធ្វើជាអ្នកផ្ទេរទិន្នន័យ - វាអាចរក្សាអត្ថបទ JD នៅក្នុងផ្នែក `[JOB DESCRIPTION PASS-THROUGH]` ដើម្បីឲ្យអ្នកក្រោយអាចចូលដំណើរការ (ត្រូវការ ព្រោះ `context_mode="last_agent"` មានន័យថា តែ `start_executor` ចង់ឃើញសារប្រើប្រាស់ដើម) |
| **គំរូ Content Relay** | JD Agent ផ្ញើ `[PARSED RESUME PASS-THROUGH]` ឱ្យទៅមុខដូច្នេះ MatchingAgent ទទួលបានប្រវត្តិរូបទាំងពីរ; បំបែកការបង្ហោះសញ្ញាថតទន្លេ OR ដែលបណ្តាលមកពី graph fan-in |
| **ការបញ្ចូលឧបករណ៍ MCP** | `@tool` + `streamable_http_client` ហៅម៉ាស៊ីនមេ MCP ផ្លូវក្រៅ |
| **ជីវិតរបស់អ្នកផ្ដល់សេវា** | ការបង្កើត → ការកំណត់ → សាកល្បងក្នុងមូលដ្ឋាន → ដាក់បញ្ចូល → ផ្ទៀងផ្ទាត់ក្នុងពពក |
| **`context_mode="last_agent"`** | អ្នកប្រតិបត្តិផ្សេងៗគ្នាចង់ឃើញត្រឹមត្រូវលទ្ធផលអ្នកមួយជាទីមួយ |
| **ប្រតិបត្តិការ Foundry Toolkit** | វីហ្សាដចាប់ផ្ដើម, អ្នកត្រួតពិនិត្យAgent, អ្នកត្រួតពិនិត្យមើលចរន្ត, ដាក់បញ្ចូលក្នុងមួយចុច |

### គំនិតដើម្បីពង្រីកចរន្តការងារ

- **បន្ថែមអ្នកជាជម្រើសទី៥** - អ្នកបណ្តុះបណ្តាលសម្ភាសន៍ដែលបង្កើតសំណួរសម្ភាសន៍ដែលមានសក្តានុពលដោយផ្អែកលើរបាយការណ៍ចន្លោះ

- **ភ្ជាប់ទៅមូលដ្ឋានទិន្នន័យប្រវត្តិរូប** - ទាញយកប្រវត្តិរូបបេក្ខជនពីមូលដ្ឋានទិន្នន័យតាមរយៈ `@tool` ផ្ទាល់ខ្លួន
- **សាកល្បងម៉ូដែលផ្សេងៗ** - ប្រៀបធៀបគុណភាពនិងពេលយឺតនៃលទ្ធផល `gpt-4.1` និង `gpt-4.1-mini`

## សម្អាតធនធាន (ជាចិត្តរៀបចំ)

ប្រសិនបើអ្នកចង់ដកធនធាន Azure ដែលបានបង្កើតឡើងនៅពេលវគ្គបង្រៀននេះ៖

### ជម្រើស ១៖ លុបក្រុមធនធាន (លុបអ្វីគ្រប់យ៉ាង)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ជម្រើស ២៖ លុបគ្រាប់អេជិនផ្ដល់សេវា​តែមួយ

១. បើក [ai.azure.com](https://ai.azure.com) → គម្រោងរបស់អ្នក → **Build** → **Agents**។
២. ស្វែងរក **PersonalCareerCopilot** → ចុច **Delete**។

### ជម្រើស ៣៖ លុបការដាក់ម៉ូដែល

១. នៅផ្នែក Foundry sidebar, ពង្រីកគម្រោងរបស់អ្នក → **Models**។
២. ចុចស្ដាំលើការដាក់ម៉ូដែល → **Delete**។

> **កំណត់ចំណាំថ្លៃដើម:** អ្នកផ្ដល់សេវាផ្ទុកគ្រាប់តែប៉ុណ្ណោះដែលបង្កើតចំណាយពេលដំណើរការ។ ប្រសិនបើអ្នកបញ្ឈប់ឬលុបអ្នកផ្ដល់សេវា គ្មានចំណាយបន្ត។ ការដាក់ម៉ូដែលអាចបង្កើតការចំណាយតិចសម្រាប់សមត្ថភាពរក្សាទុក - សូមលុបនៅពេលអ្នកចប់រួច។
