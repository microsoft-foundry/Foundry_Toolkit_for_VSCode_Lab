## ផ្លូវការសិក្សាពេញលេញ

ឯកសារនេះនាំអ្នកឆ្លងកាត់ការសិក្សា សាកល្បង និងដាក់បង្ហាញ **វិថីការងារ multi-agent** ដែលវាយតម្លៃពីការចូលរួម Resume ទៅកាន់ការងារ ដោយប្រើប្រាស់ភ្នាក់ងារពិសេសបួនរូបដែលត្រូវបានគ្រប់គ្រងតាមរយៈ **WorkflowBuilder**។

> **លក្ខខណ្ឌមុន៖** សម្រេច [Lab 01 - Single Agent](../../lab01-single-agent/README.md) មុននឹងចាប់ផ្តើម Lab 02។
