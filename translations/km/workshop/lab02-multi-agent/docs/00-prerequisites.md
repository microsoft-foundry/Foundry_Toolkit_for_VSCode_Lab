## អ្វីដែលអ្នកនឹងសាងសង់

នៅក្នុងមន្ទីរពិសោធន៍នេះ អ្នកពង្រីកជំនាញភ្នាក់ងារតែមួយពី មន្ទីរពិសោធន៍ 01 ដើម្បីបង្កើត **សន្ទស្សន៍ភ្នាក់ងារច្រើន** - កម្មវិធី Resume → Job Fit Evaluator។

អ្នកលើកអត្ថបទ **ប្រវត្តិរូប** និង **ការពិពណ៌នាអំពីការងារ**។ ភ្នាក់ងាររៀងៗគ្នា ៤ នាក់ដំណើរការចូលប្រព័ន្ធតាមលំដាប់ បន្ទាប់មកផ្ដល់តម្លៃ៖
- ពិន្ទុសមរម្យ (0–100 ជាមួយការបែងចែកពិន្ទុ)
- បញ្ជីចន្លោះជំនាញ និងវិញ្ញាបនបត្រ
- ផ្លូវរៀនផ្ទាល់ខ្លួនជាមួយតំណភ្ជាប់បណ្តុះបណ្តាល Microsoft Learn ពិតប្រាកដសម្រាប់ចន្លោះនីមួយៗ

**សន្ទស្សន៍នេះប្រើប្រាស់៖**
- **ស៊ុមភ្នាក់ងាររបស់ Microsoft** - `WorkflowBuilder` សម្រាប់ការរៀបចំបណ្តោយបង្គោលតាមលំដាប់
- **Foundry Toolkit សម្រាប់ VS Code** - ជារចនាសម្ព័ន្ធ ការសាកល្បងនៅក្នុងស្រុក និងការចេញផ្សាយ
- **គំរូ AI** (ឧ. `gpt-4.1-mini`) - ប្រើសម្រាប់ភ្នាក់ងាររាល់សិបនាក់
- **ម៉ាស៊ីនមេ Microsoft Learn MCP** - ផ្ដល់តំណភ្ជាប់ធនធានសិក្សាពិតប្រាកដសម្រាប់ចន្លោះជំនាញ

## បញ្ជាក់ពី មន្ទីរពិសោធន៍ 01

មន្ទីរពិសោធន៍ 02 កសាងផ្ទាល់លើមន្ទីរពិសោធន៍ 01។ សូមបញ្ចប់ មន្ទីរពិសោធន៍ 01 ជាមុនសិនមុនពេលចាប់ផ្តើមនៅទីនេះ។

មិនបានធ្វើ មន្ទីរពិសោធន៍ 01 ទេមែនទេ? ចាប់ផ្តើមនៅទីនេះ៖ [មន្ទីរពិសោធន៍ 01 - ការណែនាំ](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ ផ្លូវ A - មេឃ Azure</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

ប្រសិនបើមានបញ្ហា ដំណើរការ `az login`។ បន្ទាប់មកផ្ទៀងផ្ទាត់នៅក្នុង VS Code:

1. `Ctrl+Shift+P` → វាយ **Foundry Toolkit** → បញ្ជាក់ែាច់បញ្ជាការបង្ហាញ។
2. ចុចរូបតំណាង **Foundry Toolkit** → គម្រោងរបស់អ្នក និងគំរូការចេញផ្សាយបង្ហាញ **ជោគជ័យ**។

![ស្វែងរកថាបន្ទះ Foundry Toolkit បង្ហាញគម្រោងនៅក្រោម My Resources ដោយមានខ្ទង់ជ្រើសរើស Switch project / Create project បើក](../../../../../translated_images/km/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** អ្នកបានចាត់តាំង **Foundry User** ក្នុង មន្ទីរពិសោធន៍ 01។ ប្រសិនបើចង់បំលែង សូមមើល [មន្ទីរពិសោធន៍ 01, មូឌុល 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac)។ តួនាទីនេះមានឈ្មោះមុនថា **Azure AI User** - មានការអនុញ្ញាតដូចគ្នា។

</details>

<details open>
<summary><strong>🅱️ ផ្លូវ B - Foundry Local</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

គេរំពឹងថា: `StatusCode: 200`។ ប្រសិនបើមិនបង្ហាញឡើយ សូមចាប់ផ្តើមឡើងវិញ Foundry Local ពីផ្នែក Foundry Toolkit sidebar។

> ការវិភាគទិន្នន័យទាំងអស់បើកនៅលើម៉ាស៊ីនរបស់អ្នក។ ការហៅទៅខាងក្រៅតែម្ដងគឺឧបករណ៍ MCP ទៅកាន់ `https://learn.microsoft.com/api/mcp`។

</details>
