## អ្វីដែលអ្នកនឹងសាងសង់

ក្នុងមន្ទីរបណ្តុះបណ្តាលនេះ អ្នកបានពង្រីកជំនាញភ្នាក់ងារតែមួយពីមន្ទីរបណ្តុះបណ្តាល 01 ដើម្បីបង្កើត **សេចក្តីជូនដំណឹងភ្នាក់ងារច្រើន** - អ្នកវាយតម្លៃឯកសារជResume → សមត្ថភាពការងារ។

អ្នកបិទបញ្ជូល **ប្រាប់ប្រវត្តិរូប** និង **លំអិតការងារ**។ ភ្នាក់ងារពិសេសបួននាក់ដំណើរការបញ្ចូលជាលំដាប់ តែបន្ទាប់មកបង្វិល:
- ពិន្ទុខាប់សមាសភាព (0–100 ជាមួយការបែងចែកពិន្ទុ)
- បញ្ជីចន្លោះជំនាញ និងសញ្ញាបត្រ
- ផ្លូវការសិក្សាប្រកបដោយផ្ទាល់ខ្លួនជាមួយតំណភ្ជាប់ Microsoft Learn ពិតប្រាកដសម្រាប់ចន្លោះនិមួយៗ

**កម្មវិធីនេះប្រើ៖**
- **ស៊ុមភ្នាក់ងារ Microsoft** - `WorkflowBuilder` សម្រាប់ការសម្របសម្រួលលំដាប់
- **ឧបករណ៍ Foundry សម្រាប់ VS Code** - សង់អ្នកជំនួយ សាកល្បងក្នុងតំបន់ បង្ហោះ
- **ម៉ូដែល AI** (ឧ. `gpt-4.1-mini`) - ប្រើដោយភ្នាក់ងារបួននាក់ទាំងអស់
- **ម៉ាស៊ីនមេ Microsoft Learn MCP** - ផ្តល់តំណធនធានសិក្សាពិតប្រាកដសម្រាប់ចន្លោះជំនាញនិមួយៗ
