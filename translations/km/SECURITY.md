## សន្តិសុខ

Microsoft យកចិត្តទុកដាក់យ៉ាងខ្លាំងចំពោះសន្តិសុខនៃផលិតផលនិងសេវាកម្មកម្មវិធីរបស់យើង ដែលរួមមាន
ឃ្លាំងកូដប្រភពទាំងអស់នៅក្នុងអង្គការជាក្រុម GitHub របស់យើង។

**សូមកុំរាយការណ៍បញ្ហាសន្តិសុខតាមរយៈបញ្ហាសាធារណៈក្នុង GitHub ។**

សម្រាប់ព័ត៌មានបច្ចុប្បន្នអំពីការរាយការណ៍សន្តិសុខ ទីតាំង ព័ត៌មានទំនាក់ទំនង និងគោលការណ៍,
សូមពិនិត្យមើលមគ្គុទេសក៍ចុងក្រោយសម្រាប់ឃ្លាំងនានារបស់ Microsoft ទីកន្លែង
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md)។
