# ਇਸ ਸੈਸ਼ਨ ਨੂੰ ਕਿਵੇਂ ਡਿਲਿਵਰ ਕਰਨਾ ਹੈ

ਇਸ ਸੈਸ਼ਨ ਨੂੰ ਡਿਲਿਵਰ ਕਰਨ ਲਈ ਧੰਨਵਾਦ!

ਵਰਕਸ਼ਾਪ ਡਿਲਿਵਰੀ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ, ਕਿਰਪਾ ਕਰਕੇ:

1. ਇਸ ਦਸਤਾਵੇਜ਼ ਅਤੇ ਸਾਰੇ ਸਾਮੱਗਰੀ ਨੂੰ ਪੂਰੀ ਤਰ੍ਹਾਂ ਪੜ੍ਹੋ।
2. ਸੈਸ਼ਨ ਡਿਲਿਵਰੀ ਦੀ ਰਿਕਾਰਡਿੰਗ ਅਤੇ ਵਰਕਸ਼ਾਪ ਦਾ ਐੰਡ-ਟੂ-ਐੰਡ ਵਾਕਥਰੂ ਵੇਖੋ।
3. ਦੋਹਾਂ ਹੈਂਡਸ-ਆਨ ਲੈੱਬਾਂ ਨੂੰ ਘੱਟੋ-ਘੱਟ ਇੱਕ ਵਾਰ ਆਪਣੇ ਮਸ਼ੀਨ 'ਤੇ ਪੂਰਾ ਕਰੋ ਇਸੋਂ ਪਹਿਲਾਂ ਕਿ ਸਮਾਗਮ ਸ਼ੁਰੂ ਹੋਵੇ।
4. ਆਪਣੇ Microsoft Foundry ਪ੍ਰੋਜੈਕਟ, ਮਾਡਲ ਡਿਪਲੋਇਮੈਂਟਾਂ ਅਤੇ ਕੋਟਾਸ ਨੂੰ ਵੇਰੀਫਾਈ ਕਰੋ।
5. ਜੇ ਕੁਝ ਸਪਸ਼ਟ ਨਾ ਹੋਵੇ ਤਾਂ ਮੈਨਟੇਨਰ ਨਾਲ ਸੰਪਰਕ ਕਰੋ।

### ਟਰੇਨਰ ਲਈ ਜ਼ਰੂਰੀਆ

ਡਿਲਿਵਰੀ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ, ਇਹ ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤੁਹਾਡੇ ਕੋਲ ਹੈ:

- ਇੱਕ **ਅਜ਼ੂਰ ਸਬਸਕ੍ਰਿਪਸ਼ਨ** ਜਿਸ ਵਿੱਚ ਸਰੋਤ ਬਣਾਉਣ ਦੀ ਅਨੁਮਤੀ ਹੈ (ਓਨਰ ਜਾਂ ਸਰੋਤ ਗਰੁੱਪ ਤੇ ਕੰਪONENTContributor)।
- ਇੱਕ **Microsoft Foundry ਪ੍ਰੋਜੈਕਟ** ਉਪਲਬਧ ਹੈ [ਉਹ ਖੇਤਰ ਜਿੱਥੇ ਹੋਸਟਡ ਏਜੰਟਸ ਸਮਰਥਿਤ ਹਨ](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability)।
- ਆਪਣੇ Foundry ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ **gpt-4.1** (ਜਾਂ **gpt-4.1-mini**) ਲਈ ਕੋਟਾ।
- ਹੇਠਾਂ ਦਿੱਤੇ ਟੂਲ ਇੰਸਟਾਲ ਹੋਣ:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Microsoft Foundry Toolkit extension](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (ਵਿਕਲਪੀ)
  - Python 3.10 ਜਾਂ ਉਸ ਤੋਂ ਬਾਅਦ ਦਾ ਵਰਜਨ

ਡਿਲਿਵਰੀ ਤੋਂ ਪਹਿਲਾਂ ਘੱਟੋ-ਘੱਟ ਇੱਕ ਵਾਰ [Hosted agents quickstart with `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) ਚਲਾਓ ਤਾਂ ਜੋ ਤੁਹਾਡੇ ਕੋਲ ਜਾਣਿਆ-ਪਛਾਣਿਆ Foundry ਪ੍ਰੋਜੈਕਟ, ਮਾਡਲ ਡਿਪਲੋਇਮੈਂਟ, ਅਤੇ ਅਜ਼ੂਰ ਕੰਟੇਨਰ ਰਜਿਸਟਰੀ ਹੋਵੇ, ਜੇ ਕੋਈ ਲਰਨਰ ਫਸ ਜਾਵੇ ਤਾਂ ਰੈਫਰ ਕਰਨ ਲਈ।

| ਡੈਮੋ              | ਲੈੱਬ    | ਫਾਇਲ                  | ਕੀ ਦਿਖਾਉਣਾ ਹੈ                                   |
|-------------------|---------|-----------------------|-----------------------------------------------|
| ਐਗਜ਼ੈਕਿਊਟਿਵ ਏਜੰਟ  | ਲੈੱਬ 01 | [`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent) | ਇੱਕ ਇਕਲੋਤਾ ਹੋਸਟਿਡ ਏਜੰਟ; ਤਕਨੀਕੀ ਜਾਰਗਨ ਨੂੰ ਐਗਜ਼ੈਕਿਊਟਿਵ ਸਮਰੀ ਵਿੱਚ ਤਰਜਮਾ ਕਰਨਾ |
| ਰੇਜ਼ਿਊਮ ਤੋਂ ਜੌਬ ਫਿਟ ਐਵਾਲੂਏਟਰ | ਲੈੱਬ 02 | [`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot) | 4-ਏਜੰਟ ਆਰਕਿਸਟ੍ਰੇਸ਼ਨ; ਰੇਜ਼ਿਊਮ-ਜੌਬ ਮਿਲਾਪ ਦਾ ਸਕੋਰ ਅਤੇ ਸਿਫਾਰਸ਼ ਤਿਆਰ ਕਰਨਾ |

### ਡੈਮੋ 1: ਐਗਜ਼ੈਕਿਊਟਿਵ ਏਜੰਟ

[`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent) ਵਿੱਚ ਇੱਕ ਸਵਤੰਤਰ ਏਜੰਟ। ਇਸਨੂੰ ਲੈੱਬ 01 ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ 10 ਮਿੰਟ ਦਾ ਡੈਮੋ ਵਜੋਂ ਵਰਤੋਂ।

1. ਖੋਲ੍ਹੋ [`workshop/lab01-single-agent/agent/main.py`](../../../workshop/lab01-single-agent/agent/main.py) ਅਤੇ ਏਜੰਟ ਦੀ ਪਰਿਭਾਸ਼ਾ (ਸਿਸਟਮ ਪ੍ਰੰਪਟ, ਮਾਡਲ, ਫਰੇਮਵਰਕ) ਦੇਖੋ।
2. `F5` ਦਬਾ ਕੇ **Agent Inspector** ਨੂੰ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਸ਼ੁਰੂ ਕਰੋ।
3. [README](../README.md#see-it-in-action) ਤੋਂ ਸੈਂਪਲ ਪ੍ਰੰਪਟ ਚਿਪਕਾਓ ਅਤੇ ਐਗਜ਼ੈਕਿਊਟਿਵ-ਸਮਰੀ ਜਵਾਬ ਦਿਖਾਓ।
4. ਦਿਖਾਓ [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) ਅਤੇ [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile) ਤਾਂ ਜੋ ਡਿਪਲੋਇਮੈਂਟ ਕਾਗਜ਼ਾਤ ਸਮਝ ਆ ਸਕਣ।
5. ਡਿਪਲੋਇਮੈਂਟ ਪ੍ਰਕਿਰਿਆ (Docker build, ACR push, hosted agent create) ਦਾ ਪ੍ਰਦਰਸ਼ਨ ਕਰੋ ਬਿਨਾਂ ਸਮਾਪਤੀ ਦੀ ਉਡੀਕ ਕੀਤੇ।

### ਡੈਮੋ 2: ਰੇਜ਼ਿਊਮ ਤੋਂ ਜੌਬ ਫਿਟ ਐਵਾਲੂਏਟਰ

[`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot) ਵਿੱਚ 4-ਏਜੰਟ ਵਰਕਫਲੋ। ਇਸਨੂੰ ਲੈੱਬ 02 ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ 10 ਮਿੰਟ ਦਾ ਡੈਮੋ ਵਜੋਂ ਵਰਤੋਂ।

1. ਖੋਲ੍ਹੋ [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) ਅਤੇ ਦਿਖਾਓ ਕਿ ਕਿਵੇਂ ਚਾਰ ਏਜੰਟ ਲੜੀਵਾਰ ਆਯੋਜਿਤ ਹਨ।
2. `F5` ਦਬਾ ਕੇ ਮਲਟੀ-ਏਜੰਟ ਵਰਕਫਲੋ ਲਈ **Agent Inspector** ਚਲਾਓ।
3. ਇੰਸਪੇਕਟਰ ਚੈਟ ਵਿੱਚ ਛੋਟਾ ਜੌਬ ਵੇਰਵਾ ਅਤੇ ਸੈਂਪਲ ਰੇਜ਼ਿਊਮ ਚਿਪਕਾਓ।
4. ਚਾਰ-ਏਜੰਟ ਪਾਈਪਲਾਈਨ: ਰੇਜ਼ਿਊਮ ਪਾਰਸਰ, ਜੌਬ ਲੋੜ ਕੱਡਣ ਵਾਲਾ, ਮਿਲਾਪ ਸਕੋਰ ਕਰਨ ਵਾਲਾ, ਅਤੇ ਸਿਫਾਰਸ਼ ਲਿਖਨ ਵਾਲਾ ਨੂੰ ਵੇਖਾਓ।
5. ਵੇਖਾਓ ਕਿ ਕਿਵੇਂ ਹਰ ਸਬ-ਏਜੰਟ ਦਾ ਆਉੱਟਪੁੱਟ ਅਗਲੇ ਏਜੰਟ ਦਾ ਸੰਦਰਭ ਬਣ ਜਾਂਦਾ ਹੈ, ਹੈਂਡਆਫ਼ ਪੈਟਰਨ ਨੂੰ ਉਜਾਗਰ ਕਰਦੇ ਹੋਏ।
6. ਦਿਖਾਓ [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) ਅਤੇ ਡੈਮੋ 1 ਤੋਂ ਸਿੰਗਲ-ਏਜੰਟ ਵਰਜਨ ਨਾਲ ਤੁਲਨਾ ਕਰੋ।

## ਡਿਲਿਵਰੀ ਸੁਝਾਵ

- **ਸ਼ੁਰੂ 'ਚ ਉਮੀਦਾਂ ਸੈੱਟ ਕਰੋ।** ਹੋਸਟਡ ਏਜੰਟਸ ਪੂਰੇ ਤੌਰ 'ਤੇ ਪ੍ਰੀਵਿਊ ਵਿੱਚ ਹਨ - ਖੇਤਰ ਦੀਆਂ ਸੀਮਾਵਾਂ ਅਤੇ ਕੋਟਾ ਦੀ ਪਹਿਲਾਂ ਜਾਣੂ ਕਰਵਾਉ ਕਿ ਕਿਵੇਂ ਲੈੱਬ ਵਿਚਕਾਰ ਲੋਕ ਹੈਰਾਨ ਨਾ ਹੋਣ।
- **ਪਹਿਲਾਂ ਜ਼ਰੂਰੀ ਕੰਮ ਚਲਾਓ।** ਦੋਹਾਂ ਲੈੱਬਾਂ ਵਿੱਚ ਇੱਕ `Validate prerequisites` VS Code ਟਾਸਕ ਹੈ - ਇਸਨੂੰ ਕੋਡ ਲੇਖਣ ਤੋਂ ਪਹਿਲਾਂ ਲੈੰਦੇ ਨੂੰ ਚਲਾਣਾ ਕਰਵਾਓ।
- **Agent Inspector ਹਮੇਸ਼ਾ ਦਿੱਖਦਾ ਰਹੇ।** ਬਹੁਤ ਸਾਰੇ "ਆਹਾ" ਪਲ ਉਹ ਲੋੜੀਂਦੇ ਹਨ ਜਦੋਂ ਲਰਨਰ ਲੋਕਲ `/responses` ਰਾਊਂਡ-ਟ੍ਰਿਪ ਚਮਕਦਾ ਵੇਖਦੇ ਹਨ।
- **ਇੱਕ ਬੈਕਅਪ ਪ੍ਰੋਜੈਕਟ ਰੱਖੋ।** ਜੇ ਕਿਸੇ ਲਰਨਰ ਦਾ Foundry ਪ੍ਰੋਜੈਕਟ ਕੋਟਾ ਦੀ ਸੀਮਾ 'ਤੇ ਪਹੁੰਚ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਡਿਪਲੋਇਮੈਂਟ ਕਦਮ ਲਈ ਇੱਕ ਪਹਿਲਾਂ ਤਿਆਰ ਕੀਤਾ ਪ੍ਰੋਜੈਕਟ ਸਾਂਝਾ ਕਰੋ ਕਿਸੇ ਕਮਰੇ ਨੂੰ ਰੋਕਣ ਦੀ ਥਾਂ।
- **ਹਾਜ਼ਰੀਆਂ ਨੂੰ ਜੋੜੋ।** ਲੈੱਬ 02 (ਮਲਟੀ-ਏਜੰਟ) ਉਸ ਵੇਲੇ ਕਾਫ਼ੀ ਆਸਾਨ ਹੁੰਦਾ ਹੈ ਜਦ ਲਰਨਰ ਆਪਣੇ ਸਾਥੀ ਨਾਲ ਵਰਕਫਲੋ ਬਾਰੇ ਗੱਲ ਕਰ ਸਕਦੇ ਹਨ।
- **ਡੌਕ ਮੋਡੀਊਲਜ਼ ਨੂੰ ਚੈੱਕਪੌਇੰਟ ਵਜੋਂ ਵਰਤੋ।** ਹਰ ਲੈੱਬ ਦਾ `docs/` ਫੋਲਡਰ 8 ਨੰਬਰ ਵਾਲੇ ਮੋਡੀਊਲਜ਼ ਵਿੱਚ ਵੰਡਿਆ ਹੈ - ਇਨ੍ਹਾਂ ਨੂੰ ਕੁਦਰਤੀ ਰੁਕਾਵਟ ਦੇ ਬਿੰਦੂ ਵਜੋਂ ਵਰਤੋ।
- **ਬੇਸ Docker ਇਮੇਜ਼ ਨੂੰ ਪਹਿਲਾਂ ਹੀ ਸਾਂਝੇ ਲੈੱਬ ਮਸ਼ੀਨਾਂ 'ਤੇ ਪুল ਕਰੋ** ਤਾਂ ਜੋ ਰਜਿਸਟਰੀ ਦਰ ਸੀਮਾਵਾਂ ਤੋਂ ਬਚਿਆ ਜਾ ਸਕੇ।

## ਇਸ ਸੈਸ਼ਨ ਨੂੰ ਕਸਟਮਾਈਜ਼ ਕਰਨਾ

ਤੁਸੀਂ ਆਪਣੀ ਦਰਸ਼ਕ ਲਈ ਵਰਕਸ਼ਾਪ ਨੂੰ ਅਨੁਕੂਲਿਤ ਕਰਨ ਦਾ ਸੁਆਗਤ ਹੈ। ਸਧਾਰਨ ਤਬਦੀਲੀਆਂ:

- **ਬੈਕਐਂਡ ਦਰਸ਼ਕ:** `agent.yaml`, Docker, ਅਤੇ ACR 'ਤੇ ਜ਼ਿਆਦਾ ਸਮਾਂ ਬਤੀਤ ਕਰੋ; ਪਲੇਗਰਾਊਂਡ ਡੈਮੋ ਨੂੰ ਕੱਟੋ।
- **ਨਾਗਰਿਕ-ਡਿਵੈਲਪਰ ਦਰਸ਼ਕ:** Foundry ਐਕਸਟੈਂਸ਼ਨ UI ਵਿੱਚ ਸਕੈਫੋਲਡਿੰਗ ਲਈ ਰਹੋ; CLI ਕਦਮ ਘਟਾਓ।
- **ਇਕਲੋਤਾ 60 ਮਿੰਟ ਸਲਾਟ:** ਸਿਰਫ ਇੰਟਰੋ, ਡੈਮੋ ਅਤੇ ਲੈਬ 01 ਦਿਓ।
- **ਸਿਰਫ ਵਰਕਸ਼ਾਪ (ਕੋਈ ਸਲਾਈਡ ਨਹੀਂ) ਫਾਰਮੈਟ:** ਦੋਹਾਂ ਲੈਬ READMEs ਖੋਲ੍ਹੋ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ ਪ੍ਰਮੁੱਖ ਸਕ੍ਰਿਪਟ ਵਜੋਂ ਵਰਤੋਂ।

ਜੇ ਤੁਸੀਂ ਲੈਬਜ਼ ਨੂੰ ਵਧਾਉਂਦੇ ਹੋ, ਕਿਰਪਾ ਕਰਕੇ ਬਦਲਾਅ PR ਰਾਹੀਂ ਵਾਪਸ ਦਿਓ ਤਾਂ ਜੋ ਹੋਰ ਟ੍ਰੇਨਰਾਂ ਨੂੰ ਲਾਭ ਹੋਵੇ।
