# ਮੋਡੀਊਲ 1 - ਆਰਕੀਟੈਕਚਰ ਨੂੰ ਸਮਝੋ

⏱️ ~5 ਮਿੰਟ

ਕੋਈ ਵੀ ਕੋਡ ਲਿਖਣ ਤੋਂ ਪਹਿਲਾਂ, ਇੱਥੇ ਤੁਹਾਡੇ ਬਣਾਏ ਜਾ ਰਹੇ ਵਿਸ਼ੇਸ਼ ਕਾਰਜ ਅਤੇ ਇਸਦਾ ਕੰਮ ਕਰਨ ਦਾ ਝਲਕ ਹੈ।

---

## ਤੁਸੀਂ ਜੋ ਬਣਾ ਰਹੇ ਹੋ

ਤੁਸੀਂ ਇੱਕ **ਰੀਜ਼ਿਊਮ** ਅਤੇ ਇੱਕ **ਨੌਕਰੀ ਦਾ ਵਰਣਨ** ਪੇਸਟ ਕਰਦੇ ਹੋ। ਕੰਮ ਦੀ ਪ੍ਰਕਿਰਿਆ ਇਹ ਮੁੜ ਦਿੰਦੀ ਹੈ:

- ਇੱਕ ਫਿੱਟ ਸਕੋਰ (0–100 ਅਤੇ ਇਸਦਾ ਵਿਸਥਾਰ)
- ਹੁਨਰ ਅਤੇ ਪ੍ਰਮਾਣਿਕਤਾ ਦੀਆਂ ਖ਼ਾਮੀਆਂ ਦੀ ਸੂਚੀ
- ਹਰ ਖ਼ਾਮੀ ਲਈ ਮਾਇਕਰੋਸਾਫਟ ਲਰਨ ਲਿੰਕਾਂ ਨਾਲ ਨਿੱਜੀ ਸਿੱਖਣ ਦਾ ਰੋਡਮੈਪ

---

## ਚਾਰ ਏਜੰਟ

ਇੱਕ ਏਜੰਟ ਜੋ ਇੱਕ ਵਾਰੀ ਵਿੱਚ ਪਾਰਸ, ਸਕੋਰ ਅਤੇ ਯੋਜ਼ਨਾ ਬਣਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਦਾ ਹੈ, ਅਕਸਰ ਜਲਦੀ ਕਰਦਾ ਹੈ ਅਤੇ ਥੋੜ੍ਹਾ ਨਤੀਜਾ ਦਿੰਦਾ ਹੈ। ਕੰਮ ਨੂੰ ਚਾਰ ਖ਼ਾਸ ਏਜੰਟਾਂ ਵਿੱਚ ਵੰਡਣ ਨਾਲ ਬਿਹਤਰ ਨਤੀਜੇ ਮਿਲਦੇ ਹਨ:

| ਏਜੰਟ | ਇਹ ਕੀ ਕਰਦਾ ਹੈ |
|-------|-------------|
| **ResumeParser** | ਰੀਜ਼ਿਊਮ ਨੂੰ ਪਾਰਸ ਕਰਦਾ ਹੈ; ਨੌਕਰੀ ਦਾ ਵਰਣਨ ਬਰਾਬਰ `[JOB DESCRIPTION PASS-THROUGH]` ਵਿੱਚ ਕਾਪੀ ਕਰਦਾ ਹੈ ਤਾ ਕਿ ਹੇਠਲੇ ਏਜੰਟਾਂ ਲਈ |
| **JobDescriptionAgent** | ਪਾਸ-ਥਰੂ ਤੋਂ JD ਦੀਆਂ ਲੋੜਾਂ ਕੱਢਦਾ ਹੈ; `[PARSED RESUME]` ਨੂੰ ਅੱਗੇ `[PARSED RESUME PASS-THROUGH]` ਵਜੋਂ ਭੇਜੇ |
| **MatchingAgent** | ਦੋਹਾਂ ਲੇਬਲ ਕੀਤੀਆਂ ਸੈਕਸ਼ਨਾਂ ਦੀ ਤੁਲਨਾ ਕਰਦਾ ਹੈ; ਇੱਕ 0-100 ਫਿੱਟ ਸਕੋਰ ਅਤੇ ਖ਼ਾਮੀ ਦੀ ਸੂਚੀ ਬਣਾਉਂਦਾ ਹੈ |
| **GapAnalyzer** | ਸਿੱਖਣ ਦਾ ਰੋਡਮੈਪ ਬਣਾਉਂਦਾ ਹੈ; ਹਰ ਖ਼ਾਮੀ ਲਈ ਮਾਇਕਰੋਸਾਫਟ ਲਰਨ ਵਿੱਚ ਖੋਜ ਕਰਦਾ ਹੈ |

## ਆਰਕੀਸਟਰੇਸ਼ਨ ਗ੍ਰਾਫ

ਕੰਮ ਦੀ ਪ੍ਰਕਿਰਿਆ ਇੱਕ **ਕ੍ਰਮਬੱਧ ਪਾਈਪਲਾਈਨ** ਹੈ - ਹਰ ਏਜੰਟ ਆਪਣਾ ਆਉਟਪੁੱਟ ਅੱਗਲੇ ਨੂੰ ਦਿੰਦਾ ਹੈ:

```mermaid

    D -- "ਫਿਟ ਰਿਪੋਰਟ + ਗੈਪਸ" --> E["ਗੈਪ ਵਿਸ਼ਲੇਸ਼ਕ + ਐਮਸੀਪੀ"]
```

1. **ResumeParser** ਵਰਤੋਂਕਾਰ ਇਨਪੁੱਟ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ, ਰੀਜ਼ਿਊਮ ਪਾਰਸ ਕਰਦਾ ਹੈ ਅਤੇ JD ਨੂੰ `[JOB DESCRIPTION PASS-THROUGH]` ਵਿੱਚ ਕਾਪੀ ਕਰਦਾ ਹੈ।
2. **JD ਏਜੰਟ** ਸੰਗਠਿਤ ਲੋੜਾਂ ਕੱਢਦਾ ਹੈ ਅਤੇ `[PARSED RESUME PASS-THROUGH]` ਅੱਗੇ ਭੇਜਦਾ ਹੈ।
3. **MatchingAgent** ਦੋਹਾਂ ਸੈਕਸ਼ਨ ਦੀ ਤੁਲਨਾ ਕਰਦਾ ਹੈ ਅਤੇ ਫਿੱਟ ਸਕੋਰ ਅਤੇ ਖ਼ਾਮੀਆਂ ਦੀ ਸੂਚੀ ਤਿਆਰ ਕਰਦਾ ਹੈ।
4. **GapAnalyzer** ਰੋਡਮੈਪ ਬਣਾਉਂਦਾ ਹੈ ਅਤੇ ਹਰ ਖ਼ਾਮੀ ਲਈ ਮਾਇਕਰੋਸਾਫਟ ਲਰਨ MCP ਟੂਲ ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ।

## ਇਹ ਕਿਵੇਂ ਕੋਡ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ

`main.py` ਵਿੱਚ, ਤੁਸੀਂ ਇਸ ਗ੍ਰਾਫ ਨੂੰ `WorkflowBuilder` ਨਾਲ ਵਰਨਨ ਕਰਦੇ ਹੋ:

```python
workflow_agent = (
    WorkflowBuilder(
        start_executor=resume_executor,       # ਯੂਜ਼ਰ ਇਨਪੁੱਟ ਪ੍ਰਾਪਤ ਕਰਨ ਵਾਲਾ ਪਹਿਲਾ ਏਜੰਟ
        output_executors=[gap_executor],      # ਆਖਰੀ ਏਜੰਟ - ਇਸਦੀ ਆਉਟਪੁੱਟ ਜਵਾਬ ਹੈ
    )
    .add_edge(resume_executor, jd_executor)       # ResumeParser → JD Agent
    .add_edge(jd_executor, matching_executor)     # JD Agent → MatchingAgent
    .add_edge(matching_executor, gap_executor)    # MatchingAgent → GapAnalyzer
    .build()
    .as_agent()
)
```

ਹਰ `Agent` ਨੂੰ `AgentExecutor` ਨਾਲ ਵਰੈਪ ਕੀਤਾ ਗਿਆ ਹੈ। `add_edge()` ਕਾਲਾਂ ਇੱਕ ਕੜੀ ਕ੍ਰਮਬੱਧ ਪਾਈਪਲਾਈਨ ਨੂੰ ਪਰਿਭਾਸ਼ਿਤ ਕਰਦੀਆਂ ਹਨ - ਹਰ ਏਜੰਟ ਸਿਰਫ਼ ਆਪਣਾ ਸਿੱਧਾ ਪਹਿਲਾ ਵਾਲਾ ਆਉਟਪੁੱਟ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ।

> `context_mode="last_agent"` ਦਾ ਮਤਲਬ ਹੈ ਹਰ ਐਕਜ਼ੀਕਿਊਟਰ ਸਿਰਫ਼ ਆਪਣੇ ਸਿੱਧੇ ਪਹਿਲੇ ਵਾਲੇ ਦਾ ਆਉਟਪੁੱਟ ਵੇਖਦਾ ਹੈ। ResumeParser ਅਤੇ JD ਏਜੰਟ ਲੇਬਲ ਕੀਤੀਆਂ ਸੈਕਸ਼ਨਾਂ ਵਿੱਚ ਡੇਟਾ ਅੱਗੇ ਭੇਜਦੇ ਹਨ ਤਾਂ ਕਿ ਹਰ ਹੇਠਲੇ ਏਜੰਟ ਕੋਲ ਬਿਲਕੁਲ ਉਹੀ ਚੀਜ਼ ਹੋਵੇ ਜੋ ਉਸਨੂੰ ਚਾਹੀਦੀ ਹੈ।

## MCP ਟੂਲ

GapAnalyzer ਕੋਲ ਇੱਕ ਟੂਲ ਹੈ: `search_microsoft_learn_for_plan`। ਇਹ `https://learn.microsoft.com/api/mcp` ਨਾਲ ਜੁੜਦਾ ਹੈ ਅਤੇ ਹਰ ਹੁਨਰ ਦੀ ਖ਼ਾਮੀ ਲਈ ਅਸਲੀ ਮਾਇਕਰੋਸਾਫਟ ਲਰਨ ਲਿੰਕਾਂ ਨੂੰ ਵਾਪਸ ਕਰਦਾ ਹੈ।

ਜਦੋਂ ਟੂਲ ਚੱਲਦਾ ਹੈ, ਤੁਸੀਂ ਇਹ ਲੌਗਜ਼ ਵੇਖੋਗੇ - ਸਾਰੇ ਅਪੇੱਖਿਤ:

```
GET  https://learn.microsoft.com/api/mcp → 405   ← connection probe, normal
POST https://learn.microsoft.com/api/mcp → 200   ← actual tool call
DELETE https://learn.microsoft.com/api/mcp → 405 ← cleanup probe, normal
```

ਸਿਰਫ਼ ਇਹੋ ਪਰਿਵਾਰ ਕਰੋ ਜੇ `POST` ਕਿਸੇ ਗਲਤੀ ਨੂੰ ਵਾਪਸ ਕਰੇ।
