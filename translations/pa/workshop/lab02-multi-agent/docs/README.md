# ਲੈਬ 02 - ਮਲਟੀ-ਏਜੰਟ ਵਰਕਫਲੋ: ਰਿਜ਼ਯੂਮ → ਨੌਕਰੀ ਫਿੱਟ ਮੁਲਾਂਕਣਕਾਰ

## ਪੂਰਾ ਸਿੱਖਣ ਮਾਰਗ

ਇਹ ਦਸਤਾਵੇਜ਼ ਤੁਹਾਨੂੰ ਇੱਕ **ਮਲਟੀ-ਏਜੰਟ ਵਰਕਫਲੋ** ਬਣਾਉਣ, ਟੈਸਟ ਕਰਨ ਅਤੇ ਤੈਨਾਤ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ ਜੋ ਚਾਰ ਵਿਸ਼ੇਸ਼ ਏਜੰਟਾਂ ਦੇ ਜ਼ਰੀਏ **WorkflowBuilder** ਦੇ ਤਹਿਤ ਰਿਜ਼ਯੂਮ-ਟੂ-ਨੌਕਰੀ ਫਿੱਟ ਦਾ ਮੁਲਾਂਕਣ ਕਰਦਾ ਹੈ।

> **ਪੂਰਵ-ਆਵਸ਼ਕਤਾ:** ਲੈਬ 02 ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ [ਲੈਬ 01 - ਸਿੰਗਲ ਏਜੰਟ](../../lab01-single-agent/README.md) ਪੂਰਾ ਕਰੋ।
