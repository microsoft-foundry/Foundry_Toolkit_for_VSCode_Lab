# ਮਾਡਿਊਲ 7 - ਖੇਡ-ਮੈਦਾਨ ਵਿਚ ਜਾਂਚ ਕਰੋ

⏱️ ~10 ਮਿੰਟ

ਇਸ ਮਾਡਿਊਲ ਵਿੱਚ, ਤੁਸੀਂ ਆਪਣੇ ਤੈਅ ਕੀਤੇ ਮਲਟੀ-ਏਜੰਟ ਵਰਕਫਲੋ ਨੂੰ VS ਕੋਡ ਅਤੇ Foundry ਪੋਰਟਲ ਵਿੱਚ ਟੈਸਟ ਕਰਦੇ ਹੋ, ਇਹ ਪੁਸ਼ਟੀ ਕਰਦੇ ਹੋ ਕਿ ਏਜੰਟ ਸਥਾਨਕ ਟੈਸਟਿੰਗ ਵਰਗਾ ਹੀ ਵਰਤਾਵ ਕਰਦਾ ਹੈ।

---

## ਤੈਅ ਕਰਨ ਤੋਂ ਬਾਅਦ ਫਿਰ ਟੈਸਟ ਕਿਉਂ ਕਰਨਾ ਚਾਹੀਦਾ ਹੈ?

ਹੋਸਟ ਕੀਤਾ ਮਾਹੌਲ ਕੁਝ ਅਹੰਕਾਰਪੂਰਕ ਤਰੀਕਿਆਂ ਵਿੱਚ ਸਥਾਨਕ ਤੋਂ ਵੱਖਰਾ ਹੁੰਦਾ ਹੈ:

| | ਸਥਾਨਕ | ਹੋਸਟ ਕੀਤਾ |
|--|-------|--------|
| **ਪਹਚਾਨ** | ਤੁਹਾਡਾ ਨਿੱਜੀ ਸਾਈਨ-ਇਨ (`DefaultAzureCredential`) | ਹਰ ਏਜੰਟ ਲਈ ਸਮਰਪਿਤ Entra ਪਹਚਾਨ (ਤੈਅ ਕਰਨ ਸਮੇਂ ਆਟੋ-ਪ੍ਰੋਵਿਜਨ ਕੀਤੀ) |
| **ਏਂਡਪਾਇੰਟ** | `http://localhost:8088/responses` | Foundry ਏਜੰਟ ਸਰਵਿਸ ਦੁਆਰਾ ਪ੍ਰਬੰਧਿਤ URL |
| **ਨੈੱਟਵਰਕ** | ਤੁਹਾਡੀ ਮਸ਼ੀਨ → Azure OpenAI + MCP | Azure ਬੈਕਬੋਨ (ਘੱਟ ਲੇਟੇਨਸੀ) |

ਕੋਈ ਖ਼ਰਾਬ ਕਰ ਰਹੀ env var, RBAC ਸਮੱਸਿਆ, ਜਾਂ ਬਲਾਕ ਕੀਤੀ MCP ਆਉਟਬਾਊਂਡ ਕਾਲ ਪਹਿਲਾਂ ਇੱਥੇ ਦਰਸਾਈ ਜਾਵੇਗੀ।

## ਵਿਕਲਪ A: VS ਕੋਡ ਖੇਡ-ਮੈਦਾਨ ਵਿਚ ਟੈਸਟ ਕਰੋ (ਪਹਿਲਾਂ ਸਿਫਾਰਸ਼ੀ)

### ਕਦਮ 1: ਆਪਣੇ ਹੋਸਟ ਕੀਤੇ ਏਜੰਟ ਤੱਕ ਜਾਓ

1. Activity Bar ਵਿੱਚ **Foundry Toolkit** ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
2. ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਫੈਲਾਓ → **Hosted Agents (Preview)** → ਆਪਣਾ ਏਜੰਟ ਲੱਭੋ।

![Foundry Toolkit sidebar showing Hosted Agents (Preview) with resume-job-fit-evaluator and its deployed versions](../../../../../translated_images/pa/06-foundry-sidebar-agent-status.a45994bfb5c21284.webp)

### ਕਦਮ 2: ਇੱਕ ਵਰਜ਼ਨ ਚੁਣੋ

1. ਏਜੰਟ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਆਪਣੇ ਵਰਜ਼ਨਾਂ ਨੂੰ ਵਧਾਉਣ ਲਈ।
2. `v1` 'ਤੇ ਕਲਿੱਕ ਕਰੋ → ਸਥਿਤੀ **ਸਰਗਰਮ** ਹੋਣ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ (sidebar ਵਿੱਚ "Running" ਜਾਂ "Started" ਦਿਖਾਈ ਦੇ ਸਕਦਾ ਹੈ - ਦੋਵੇਂ ਹੀ ਤਿਆਰ ਸਥਿਤੀ ਦਰਸਾਉਂਦੇ ਹਨ)।

### ਕਦਮ 3: ਖੇਡ-ਮੈਦਾਨ ਖੋਲ੍ਹੋ

1. **Playground** 'ਤੇ ਕਲਿੱਕ ਕਰੋ (ਜਾਂ ਵਰਜ਼ਨ 'ਤੇ ਰਾਈਟ-ਕਲਿੱਕ → **Open in Playground**).
2. VS ਕੋਡ ਟੈਬ ਵਿੱਚ ਚੈਟ ਵਿੰਡੋ ਖੁਲਵੇਗੀ।

### ਕਦਮ 4: ਆਪਣੇ ਸਥੂਲ ਟੈਸਟ ਚਲਾਓ

[Module 5](05-test-locally.md) ਤੋਂ ਉਹੀ 3 ਟੈਸਟ ਵਰਤੋ। ਹਰ ਸੁਨੇਹਾ ਖੇਡ-ਮੈਦਾਨ ਇਨਪੁੱਟ ਬਾਕਸ ਵਿੱਚ ਟਾਈਪ ਕਰੋ ਅਤੇ **Send** (ਜਾਂ **Enter**) ਦਬਾਓ।

#### ਟੈਸਟ 1 - ਪੂਰਾ ਰਿਜ਼ਯੂਮੇ + ਜੇਡੀ (ਮਿਆਰੀ ਫ਼ਲੋ)

Module 5, ਟੈਸਟ 1 (Jane Doe + Senior Cloud Engineer at Contoso Ltd) ਤੋਂ ਪੂਰਾ ਰਿਜ਼ਯੂਮੇ + ਜੇਡੀ ਪ੍ਰੰਪਟ ਪੇਸਟ ਕਰੋ।

**ਉਮੀਦ ਕੀਤੀ ਜਾਂਦੀ ਹੈ:**
- ਫਿਟ ਸਕੋਰ ਵਿੱਥ ਵਿਭਾਜਨ ਗਣਿਤ (100-ਅੰਕ ਸਕੇਲ)
- ਮੇਲ ਖਾਂਦੇ ਹੁਨਰਾਂ ਦਾ ਭਾਗ
- ਗੁਆਚੇ ਹੁਨਰਾਂ ਦਾ ਭਾਗ
- **ਹਰ ਗੁਆਚੇ ਹੁਨਰ ਲਈ ਇੱਕ ਗੈਪ ਕਾਰਡ** ਮਾਇਕ੍ਰੋਸਾਫਟ ਲਰਨ URLs ਦੇ ਨਾਲ
- ਸਿੱਖਣ ਵਾਲਾ ਰੋਡਮੈਪ ਟਾਈਮਲਾਈਨ ਸਮੇਤ

#### ਟੈਸਟ 2 - ਤੇਜ਼ ਛੋਟਾ ਟੈਸਟ (ਘੱਟੋ-ਘੱਟ ਇਨਪੁੱਟ)

```
RESUME: 3 years Python developer, knows Django and PostgreSQL, no cloud experience.

JOB: Cloud DevOps Engineer requiring AWS, Kubernetes, Terraform, CI/CD. 5 years needed.
```

**ਉਮੀਦ ਕੀਤੀ ਜਾਂਦੀ ਹੈ:**
- ਘੱਟ ਫਿਟ ਸਕੋਰ (< 40)
- ਇਮਾਨਦਾਰ ਅੰਕਲਨ ਸਟੇਜਡ ਸਿੱਖਣ ਦੇ ਰਸਤੇ ਨਾਲ
- ਕਈ ਗੈਪ ਕਾਰਡ (AWS, Kubernetes, Terraform, CI/CD, ਤਜ਼ਰਬੇ ਦਾ ਗੈਪ)

#### ਟੈਸਟ 3 - ਉੱਚ-ਫਿਟ ਉਮੀਦਵਾਰ

```
RESUME:
10 years Azure Cloud Architect. AZ-305 certified. Expert in AKS, Terraform, Azure DevOps, 
Azure Functions, Helm, Prometheus, Grafana, Python, Go. Led platform team of 8.

JOB:
Senior Cloud Engineer. Required: AKS, Terraform, Azure DevOps, Python. Preferred: Helm, Go.
5+ years experience. AZ-305 preferred.
```

**ਉਮੀਦ ਕੀਤੀ ਜਾਂਦੀ ਹੈ:**
- ਉੱਚ ਫਿਟ ਸਕੋਰ (≥ 80)
- ਇੰਟਰਵਿਊ ਤਈਆਰੀ ਅਤੇ ਪੋਲਿਸ਼ਿੰਗ 'ਤੇ ਧਿਆਨ
- ਕੁਝ ਜਾਂ ਕੋਈ ਵੀ ਗੈਪ ਕਾਰਡ ਨਹੀਂ
- ਤਈਆਰੀ 'ਤੇ ਕੇਂਦਰਿਤ ਛੋਟੀ ਟਾਈਮਲਾਈਨ

### ਕਦਮ 5: ਸਥਾਨਕ ਨਤੀਜਿਆਂ ਨਾਲ ਤੁਲਨਾ ਕਰੋ

ਆਪਣੇ ਨੋਟਸ ਜਾਂ Module 5 ਤੋਂ ਬ੍ਰਾਉਜ਼ਰ ਟੈਬ ਖੋਲ੍ਹੋ ਜਿੱਥੇ ਤੁਸੀਂ ਸਥਾਨਕ ਜਵਾਬ ਸੇਵ ਕੀਤੇ ਸਨ। ਹਰ ਟੈਸਟ ਲਈ:

- ਕੀ ਜਵਾਬ ਵਿੱਚ **ਉਹੀ ਸੰਰਚਨਾ** ਹੈ (ਫਿਟ ਸਕੋਰ, ਗੈਪ ਕਾਰਡ, ਰੋਡਮੈਪ)?
- ਕੀ ਇਹ **ਉਹੀ ਸਕੋਰਿੰਗ ਰੁਬਰਿਕ** ਨੂੰ ਫਾਲੋ ਕਰਦਾ ਹੈ (100-ਅੰਕ ਵਰਗੀ ਵਿਭਾਜਨ)?
- ਕੀ **ਮਾਇਕ੍ਰੋਸਾਫਟ ਲਰਨ URLs** ਅਜੇ ਵੀ ਗੈਪ ਕਾਰਡਾਂ ਵਿੱਚ ਮੌਜੂਦ ਹਨ?
- ਕੀ ਹਰ ਗੁਆਚੇ ਹੁਨਰ ਲਈ **ਇੱਕ ਗੈਪ ਕਾਰਡ** ਹੈ (ਛਾਂਟਿਆ ਨਹੀਂ ਗਿਆ)?

> **ਛੋਟੀਆਂ ਸ਼ਬਦ-ਵਾਰ ਫਰਕ ਸਧਾਰਨ ਹਨ** - ਮਾਡਲ ਗੈਰ-ਨਿਰਧਾਰਤਮਕ ਹੈ। ਸੰਰਚਨਾ, ਸਕੋਰਿੰਗ ਸਥਿਰਤਾ, ਅਤੇ MCP ਸੰਦ ਦੀ ਵਰਤੋਂ 'ਤੇ ਧਿਆਨ ਦਿਓ।

## ਵਿਕਲਪ B: Foundry ਪੋਰਟਲ ਵਿੱਚ ਟੈਸਟ ਕਰੋ

[Foundry Portal](https://ai.azure.com) ਇੱਕ ਵੈੱਬ-ਅਧਾਰਤ ਖੇਡ-ਮੈਦਾਨ ਮੁਹੱਈਆ ਕਰਵਾਉਂਦਾ ਹੈ ਜੋ ਸਾਥੀਆਂ ਜਾਂ ਸਟੇਕਹੋਲਡਰਾਂ ਨਾਲ ਸਾਂਝਾ ਕਰਨ ਲਈ ਲਾਭਕਾਰੀ ਹੈ।

### ਕਦਮ 1: Foundry ਪੋਰਟਲ ਖੋਲ੍ਹੋ

1. ਆਪਣਾ ਬ੍ਰਾਉਜ਼ਰ ਖੋਲ੍ਹੋ ਅਤੇ [https://ai.azure.com](https://ai.azure.com) 'ਤੇ ਜਾਓ।
2. ਉਸੇ Azure ਖਾਤੇ ਨਾਲ ਸਾਈਨ-ਇਨ ਕਰੋ ਜਿਸ ਨੂੰ ਤੁਸੀਂ ਸਾਰੀ ਵਰਕਸ਼ਾਪ ਵਿਚ ਵਰਤਿਆ ਹੈ।

### ਕਦਮ 2: ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਤੱਕ ਜਾਓ

1. ਹੋਮ ਪੇਜ਼ 'ਤੇ, ਖੱਬੀ ਸਾਈਡਬਾਰ 'ਤੇ **Recent projects** ਖੋਜੋ।
2. ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਦੇ ਨਾਮ (ਉਦਾਹਰਨ ਲਈ, `workshop-agents`) 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਜੇ ਨਹੀਂ ਦਿਖਾਈ ਦੇ ਰਿਹਾ, ਤਾਂ **All projects** 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਲੱਭੋ।

### ਕਦਮ 3: ਆਪਣੇ ਤੈਅ ਕੀਤੇ ਏਜੰਟ ਨੂੰ ਲੱਭੋ

1. ਪ੍ਰੋਜੈਕਟ ਖੱਬੇ ਨੈਵੀਗੇਸ਼ਨ ਵਿੱਚ, **Build** → **Agents** 'ਤੇ ਕਲਿੱਕ ਕਰੋ (ਜਾਂ **Agents** ਹਿੱਸਾ ਲੱਭੋ)।
2. ਤੁਹਾਨੂੰ ਏਜੰਟਾਂ ਦੀ ਸੂਚੀ ਦਿਖਾਈ ਦੇਵੇਗੀ। ਆਪਣੇ ਤੈਅ ਕੀਤੇ ਏਜੰਟ ਨੂੰ ਲੱਭੋ (ਉਦਾਹਰਨ ਲਈ, `resume-job-fit-evaluator`)।
3. ਏਜੰਟ ਦੇ ਨਾਮ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਇਸ ਦੀ ਵਿਸਥਾਰ ਪੰਨਾ ਖੋਲ੍ਹਣ ਲਈ।

### ਕਦਮ 4: ਖੇਡ-ਮੈਦਾਨ ਖੋਲ੍ਹੋ

1. ਏਜੰਟ ਵਿਸਥਾਰ ਪੰਨੇ 'ਤੇ, ਉੱਪਰ ਟੂਲਬਾਰ ਵੇਖੋ।
2. **Open in playground** (ਜਾਂ **Try in playground**) 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਚੈਟ ਇੰਟਰਫੇਸ ਖੁਲ ਜਾਵੇਗਾ।

### ਕਦਮ 5: ਉਹੀ ਸਥੂਲ ਟੈਸਟ ਚਲਾਓ

VS ਕੋਡ ਖੇਡ-ਮੈਦਾਨ ਭਾਗ ਵਿੱਚ ਉੱਪਰ ਦਿੱਤੇ ਸਾਰੇ 3 ਟੈਸਟ ਦੁਹਰਾਓ। ਹਰ ਜਵਾਬ ਦੀ ਤੁਲਨਾ ਦੋਹਾਂ ਸਥਾਨਕ ਨਤੀਜਿਆਂ (Module 5) ਅਤੇ VS ਕੋਡ ਖੇਡ ਮੈਦਾਨ ਨਤੀਜਿਆਂ (ਵਿਕਲਪ A ਉੱਪਰ) ਨਾਲ ਕਰੋ।
