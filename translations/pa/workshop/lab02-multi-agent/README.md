# ਲੈਬ 02 - ਬਹੁ-ਏਜੰਟ ਵਰਕਫਲੋ: ਰਿਜ਼ਿਊਮ → ਨੌਕਰੀ ਫਿੱਟ ਮੁਲਾਂਕਣਕਾਰ

## ਓਵਰਵਿਊ

ਇਸ ਹੱਥ-ਅਨ-ਲੈਬ ਵਿੱਚ, ਤੁਸੀਂ VS ਕੋਡ ਵਿੱਚ Foundry Toolkit ਦੀ ਵਰਤੋਂ ਨਾਲ ਇੱਕ **ਵਰਕਫਲੋ-ਪਹਿਲਾ ਬਹੁ-ਏਜੰਟ ਐਪ** ਬਣਾਉਂਦੇ ਹੋ ਅਤੇ ਇਸਨੂੰ Microsoft Foundry Agent Service 'ਤੇ ਡਿਪਲੋਇ ਕਰਦੇ ਹੋ।

**ਤੁਸੀਂ ਜੋ ਬਣਾਵੋਗੇ:** ਇੱਕ ਰਿਜ਼ਿਊਮ → ਨੌਕਰੀ ਫਿੱਟ ਮੁਲਾਂਕਣਕਾਰ ਜੋ ਰਿਜ਼ਿਊਮ ਅਤੇ ਨੌਕਰੀ ਦੇ ਵਰਣਨ ਨੂੰ ਪਾਰਸ ਕਰਦਾ ਹੈ, ਮੇਲ ਦਾ ਸਕੋਰ ਕਰਦਾ ਹੈ, ਅਤੇ Microsoft Learn ਸਰੋਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਇੱਕ ਵਿਅਕਤੀਗਤ ਸਿੱਖਿਆ ਯੋਜਨਾ ਤਿਆਰ ਕਰਦਾ ਹੈ।

**ਇਹ ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:**
1. ਯੂਜ਼ਰ ਰਿਜ਼ਿਊਮ ਅਤੇ ਨੌਕਰੀ ਦਾ ਵਰਣਨ ਪੇਸਟ ਕਰਦਾ ਹੈ।
2. **ResumeParser** ਰਿਜ਼ਿਊਮ ਨੂੰ ਪਾਰਸ ਕਰਦਾ ਹੈ ਅਤੇ ਨੌਕਰੀ ਦੇ ਵਰਣਨ ਨੂੰ ਸ਼ਾਬਦਿਕ ਤੌਰ 'ਤੇ `[JOB DESCRIPTION PASS-THROUGH]` ਸੈਕਸ਼ਨ ਵਿੱਚ ਕਾਪੀ ਕਰਦਾ ਹੈ।
3. **JD Agent** ਪਾਸ-ਥਰੂ ਤੋਂ ਸੰਰਚਿਤ ਮੰਗਾਂ ਨਿਕਾਲਦਾ ਹੈ, ਫਿਰ `[PARSED RESUME]` ਨੂੰ ਅੱਗੇ ਵਧਾ ਕੇ `[PARSED RESUME PASS-THROUGH]` ਵਜੋਂ ਰੇਲੇ ਕਰਦਾ ਹੈ।
4. **MatchingAgent** `[PARSED RESUME PASS-THROUGH]` ਨੂੰ `[JD REQUIREMENTS]` ਨਾਲ ਤੁਲਨਾ ਕਰਦਾ ਹੈ ਅਤੇ ਇਕ ਫਿੱਟ ਸਕੋਰ ਤਿਆਰ ਕਰਦਾ ਹੈ।
5. **GapAnalyzer** ਖ਼ਾਮੀਆਂ ਨੂੰ ਇੱਕ ਪ੍ਰਯੋਗੀ ਯੋਜਨਾ ਵਿੱਚ ਬਦਲਦਾ ਹੈ ਅਤੇ MCP ਰਾਹੀਂ ਅਸਲੀ Microsoft Learn ਲਿੰਕ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ।

## ਭਾਗ 2: ਵਰਕਫਲੋ ਬਣਾਓ ਅਤੇ ਟੈਸਟ ਕਰੋ

1. ਵਰਕਫਲੋ-ਅਧਾਰਿਤ ਪ੍ਰੋਜੈਕਟ ਬਣਾਉਣ ਲਈ Foundry Toolkit ਵਿਜ਼ਾਰਡ ਦੀ ਵਰਤੋਂ ਕਰੋ।
2. `PersonalCareerCopilot/main.py` ਤੋਂ ਪ੍ਰੰਪਟ ਬਲਾਕ ਅਤੇ ਵਰਕਫਲੋ ਗ੍ਰਾਫ ਨੂੰ ਆਪਣੇ ਵਰਕਸਪੇਸ ਵਿੱਚ ਕਾਪੀ ਕਰੋ।
3. Agent Inspector ਨਾਲ ਸਥਾਨੀ ਤੌਰ 'ਤੇ ਚਲਾਓ ਅਤੇ ਸਾਰੇ ਚਾਰ ਏਜੰਟਾਂ ਅਤੇ MCP ਟੂਲ ਦੀ ਜਾਂਚ ਕਰੋ।
4. ਸਥਾਨੀ ਟੈਸਟਿੰਗ ਪਾਸ ਹੋਣ 'ਤੇ ਹੋਸਟ ਕੀਤੇ ਏਜੰਟ ਨੂੰ Foundry 'ਤੇ ਡਿਪਲੋਇ ਕਰੋ।

## ਓਰਕੇਸਟਰੈਸ਼ਨ ਪੈਟਰਨ

ਲੈਬ 02 ਵਿੱਚ ਡਿਫੌਲਟ **fan-out → fan-in → ਕ੍ਰਮਵਾਰ** ਫਲੋ ਸ਼ਾਮਿਲ ਹੈ, ਅਤੇ ਡੌਕਸ ਵਿਚ ਵਿਕਲਪਿਕ ਓਰਕੇਸਟਰੈਸ਼ਨ ਪੈਟਰਨਾਂ ਵੀ ਵੇਖਾਏ ਗਏ ਹਨ ਜੋ ਪਰਖ ਲਈ ਹਨ।

- **ਬੋਝ ਵਾਲੇ ਸਹਿਮਤੀ ਨਾਲ Fan-out/Fan-in**
- **ਅਖੀਰੀ ਰੋਡਮੈਪ ਤੋਂ ਪਹਿਲਾਂ ਸਮੀਖਿਆਕਾਰ/ਆਲੋਚਕ ਪਾਸ**
- **ਫਿੱਟ ਸਕੋਰ ਅਤੇ ਗੈਰ-ਮੌਜੂਦ ਹੁਨਰਾਂ 'ਤੇ ਆਧਾਰਿਤ ਸਖਤ ਨਿਰਦੇਸ਼ਕ**
