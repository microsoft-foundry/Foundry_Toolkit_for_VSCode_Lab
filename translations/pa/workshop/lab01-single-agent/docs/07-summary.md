# ਮੋਡੀਊਲ 7 - ਸੰਖੇਪ ਅਤੇ ਅਗਲੇ ਕਦਮ

⏱️ ~5 ਮਿੰਟ

**ਵਧਾਈਆਂ!** ਤੁਸੀਂ Microsoft Foundry ਅਤੇ Foundry Toolkit for VS Code ਦਾ ਉਪਯੋਗ ਕਰਕੇ ਇੱਕ ਹੋਸਟ ਕੀਤਾ ਗਿਆ AI ਏਜੰਟ ਬਣਾਇਆ, ਟੈਸਟ ਕੀਤਾ, ਅਤੇ (ਜੇਕਰ ਰਾਹ A 'ਤੇ ਹੋ) ਤਾਇਨਾਤ ਕੀਤਾ।

---

## ਤੁਹਾਡੇ ਦੁਆਰਾ ਬਣਾਇਆ ਗਿਆ

ਇੱਕ **"ਜਿਵੇਂ ਕਿ ਮੈਂ ਇੱਕ ਐਗਜ਼ਿਕਿਊਟਿਵ ਹਾਂ, ਸਮਝਾਓ"** ਏਜੰਟ ਜੋ:
- HTTP (`POST /responses`) ਰਾਹੀਂ ਤਕਨੀਕੀ ਘਟਨਾ ਰਿਪੋਰਟਾਂ ਜਾਂ ਓਪਰੇਸ਼ਨਲ ਅਪਡੇਟ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ
- ਉਨ੍ਹਾਂ ਨੂੰ ਸਾਦਾ-ਭਾਸ਼ਾ ਐਗਜ਼ਿਕਿਊਟਿਵ ਸਾਰਾਂਸ਼ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ
- ਇੱਕ ਸੰਰਚਿਤ ਆਉਟਪੁੱਟ ਫਾਰਮੈਟ (ਕੀ ਹੋਇਆ / ਵਪਾਰ ਉੱਤੇ ਪ੍ਰਭਾਵ / ਅਗਲਾ ਕਦਮ) ਦਾ ਪਾਲਣ ਕਰਦਾ ਹੈ
- ਵਿਅਕਤੀਗਤ ਸਮਰਥਨ ਬਿਨਾਂ ਬਾਹਰਲੇ ਟੋਪਿਕ ਦੀਆਂ ਬੇਨਤੀਆਂ ਅਤੇ ਪ੍ਰੰਪਟ ਇੰਜੈਕਸ਼ਨ ਕੋਸ਼ਿਸ਼ਾਂ ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ
- Microsoft Foundry Agent Service ਵਿੱਚ ਕਨਟੇਨਰਾਈਜ਼ਡ ਹੋਸਟ ਕੀਤਾ ਗਿਆ ਏਜੰਟ ਵਜੋਂ ਚੱਲਦਾ ਹੈ

## ਮੁੱਖ ਧਾਰਾਵਾਂ ਸਿੱਖੀਆਂ ਗਈਆਂ

| ਧਾਰਨਾ | ਤੁਸੀਂ ਕੀ ਅਭਿਆਸ ਕੀਤਾ |
|---------|-------------------|
| **ਏਜੰਟ ਫਰੇਮਵਰਕ ਵਾਸਤੁਕਲਾ** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` ਪਾਈਪਲਾਈਨ |
| **ਹੋਸਟ ਕੀਤਾ ਗਿਆ ਏਜੰਟ ਜੀਵਨਚੱਕਰ** | ਸਕੈਫੋਲਡ → ਸੰਰਚਿਤ ਕਰੋ → ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਟੈਸਟ ਕਰੋ → ਤਾਇਨਾਤ ਕਰੋ → ਕਲਾਉਡ 'ਚ ਸਚੇਤ ਕਰੋ |
| **ਸਿਸਟਮ ਪ੍ਰੰਪਟ ਇੰਜੀਨੀਅਰਿੰਗ** | ਭੂਮਿਕਾ, ਦਰਸ਼ਕ, ਆਉਟਪੁੱਟ ਫਾਰਮੈਟ, ਨਿਯਮ, ਸੁਰੱਖਿਆ ਸੀਮਾਵਾਂ, ਅਤੇ ਉਦਾਹਰਣਾਂ |

| **ਸੁਰੱਖਿਆ ਸੀਮਾਵਾਂ** | ਪ੍ਰੰਪਟ ਇੰਜੈਕਸ਼ਨ ਰੋਧ, ਭੂਮਿਕਾ ਪਾਲਣਾ, ਐਜੰਟ ਦੀ ਸੁਚੱਜੀ ਸੰਭਾਲ |

### ਆਪਣੇ ਏਜੰਟ ਨੂੰ ਵਧਾਉਣ ਲਈ ਵਿਚਾਰ

- **ਮਿਤੀ ਸੰਦ ਸ਼ਾਮਿਲ ਕਰੋ** - ਏਜੰਟ ਨੂੰ ਸਾਰਾਂਸ਼ ਵਿੱਚ "ਅੱਜ ਤੱਕ" ਸੰਦਰਭ ਸ਼ਾਮਿਲ ਕਰਨ ਦਿਓ
- **ਇੱਕ ਘਟਨਾ ਡੇਟਾਬੇਸ ਨਾਲ ਜੁੜੋ** - ਸੰਦ ਫੰਕਸ਼ਨ ਰਾਹੀਂ ਅਸਲੀ ਘਟਨਾ ਵੇਰਵੇ ਖਿੱਚੋ
- **ਇੱਕ Bing ਗ੍ਰਾਊਂਡਿੰਗ ਸੰਦ ਸ਼ਾਮਿਲ ਕਰੋ** - ਵਾਧੂ ਸੰਦਰਭ ਲਈ ਨਵੀਂ ਖਬਰਾਂ ਨੂੰ ਖੋਜਣ ਦਿਓ
- **ਵੱਖ-ਵੱਖ ਮਾਡਲਾਂ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ** - `gpt-4.1` ਅਤੇ `gpt-4.1-mini` ਆਉਟਪੁੱਟ ਗੁਣਵੱਤਾ ਦੀ ਤੁਲਨਾ ਕਰੋ
- **Foundry ਨਾਲ ਮੁਲਿਆਂਕਣ ਕਰੋ** - ਆਪੇਮਾਪੀ ਤੇ ਏਜੰਟ ਗੁਣਵੱਤਾ ਮਾਪਣ ਲਈ ਮੁਲਿਆਂਕਰਨ ਫੀਚਰ ਦੀ ਵਰਤੋਂ ਕਰੋ

### ਰਾਹ B ਵਰਤੋਂਕਾਰਾਂ ਲਈ: ਕਲਾਉਡ ਤਾਇਨਾਤੀ ਨੂੰ ਅਪਗ੍ਰੇਡ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਕਲਾਉਡ 'ਤੇ ਤਾਇਨਾਤੀ ਲਈ ਤਿਆਰ ਹੋਵੋਗੇ:
1. ਇੱਕ Azure ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪ੍ਰਾਪਤ ਕਰੋ ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [ਮੋਡੀਊਲ 01, ਸੈਟਅਪ](01-setup.md#step-2-set-up-based-on-your-access) ਪੂਰਾ ਕਰੋ (ਪ੍ਰੋਜੈਕਟ ਬਣਾਓ, ਮਾਡਲ ਤਾਇਨਾਤ ਕਰੋ, RBAC ਨਿਰਧਾਰਤ ਕਰੋ)
3. ਆਪਣੇ `.env` ਨੂੰ Foundry ਪ੍ਰੋਜੈਕਟ ਏਂਡਪੋਇੰਟ ਅਤੇ ਮਾਡਲ ਤਾਇਨਾਤੀ ਨਾਮ ਨਾਲ ਅਪਡੇਟ ਕਰੋ
4. [ਮੋਡੀਊਲ 05 - Foundry ‘ਤੇ ਤਾਇਨਾਤੀ](05-deploy-to-foundry.md) ਤੋਂ ਜਾਰੀ ਰੱਖੋ

## ਸਰੋਤਾਂ ਨੂੰ ਸਾਫ਼ ਕਰੋ (ਵਿਕਲਪਤ)

ਜੇਕਰ ਤੁਸੀਂ ਇਸ ਵਰਕਸ਼ਾਪ ਦੇ ਦੌਰਾਨ ਬਣਾਏ ਗਏ Azure ਸਰੋਤਾਂ ਨੂੰ ਹਟਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ:

### ਵਿਕਲਪ 1: ਰਿਸੋਰਸ ਗਰੁੱਪ ਨੂੰ ਮਿਟਾਓ (ਸਭ ਕੁਝ ਮਿਟਾਉਂਦਾ ਹੈ)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ਵਿਕਲਪ 2: ਸਿਰਫ਼ ਹੋਸਟ ਕੀਤਾ ਏਜੰਟ ਹਟਾਓ

1. [ai.azure.com](https://ai.azure.com) ਖੋਲ੍ਹੋ → ਆਪਣਾ ਪ੍ਰੋਜੈਕਟ → **ਬਿਲਡ** → **ਏਜੰਟਸ**।
2. ਆਪਣੇ ਏਜੰਟ ਤੇ ਕਲਿਕ ਕਰੋ → **ਹਟਾਓ** 'ਤੇ ਕਲਿਕ ਕਰੋ।

### ਵਿਕਲਪ 3: ਮਾਡਲ ਤਾਇਨਾਤੀ ਹਟਾਓ

1. Foundry ਸਾਈਡਬਾਰ ਵਿੱਚ ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਵਿਸਥਾਰਿਤ ਕਰੋ → **ਮਾਡਲਸ**।
2. ਮਾਡਲ ਤਾਇਨਾਤੀ ਤੇ ਸੱਜਾ-ਕਲਿਕ ਕਰੋ → **ਹਟਾਓ**।

> **ਲਾਗਤ ਨੋਟ:** ਹੋਸਟ ਕੀਤੇ ਏਜੰਟ ਤਦ ਹੀ ਖਰਚ ਲਗਦੇ ਹਨ ਜਦੋਂ ਉਹ ਚੱਲ ਰਹੇ ਹੁੰਦੇ ਹਨ। ਜੇ ਤੁਸੀਂ ਏਜੰਟ ਨੂੰ ਰੋਕਦੇ ਜਾਂ ਮਿਟਾਉਂਦੇ ਹੋ, ਤਾਂ ਕੋਈ ਚਲਦੀ ਹੋਈ ਖਰਚ ਨਹੀਂ ਹੁੰਦੀ। ਮਾਡਲ ਤਾਇਨਾਤੀ ਲਈ ਸੁਰੱਖਿਅਤ ਸਮਰੱਥਾ ਲਈ ਥੋੜ੍ਹੀ ਜਿਹੀ ਖਰਚ ਆ ਸਕਦੀ ਹੈ - ਜੇ ਤੁਸੀਂ ਮੁਕੰਮਲ ਹੋ ਚੁੱਕੇ ਹੋ ਤਾਂ ਇਸਨੂੰ ਮਿਟਾ ਦਿਓ।
