# ਮਾਡਿਊਲ 5 - Foundry ਏਜੰਟ ਸਰਵਿਸ ਵਿੱਚ ਡਿਪਲੌਏ ਕਰੋ

⏱️ ~10 ਮਿੰਟ

> ⚠️ **ਪਾਥ ਬੀ ਉਪਭੋਗਤਾਵਾਂ:** ਇਸ ਮਾਡਿਊਲ ਲਈ Foundry ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਲੋੜੀਂਦਾ ਹੈ। ਜੇਕਰ ਤੁਸੀਂ Foundry Local ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ [ਮਾਡਿਊਲ 07 - ਸੰਖੇਪ](07-summary.md) ਨੂੰ ਛੱਡ ਦੇਵੋ। ਤੁਸੀਂ ਸਫਲਤਾਪੂਰਵਕ ਲੋਕਲ ਵਿਕਾਸ ਵਰਕਫਲੋ ਪੂਰਾ ਕਰ ਲਿਆ ਹੈ!

ਇਸ ਮਾਡਿਊਲ ਵਿੱਚ, ਤੁਸੀਂ ਆਪਣੇ ਲੋਕਲ-ਟੈਸਟ ਕੀਤੇ ਏਜੰਟ ਨੂੰ Microsoft Foundry 'ਚ ਇੱਕ **Hosted Agent** ਵਜੋਂ ਡਿਪਲੌਏ ਕਰਦੇ ਹੋ। ਡਿਪਲੌਏਮੈਂਟ ਇੱਕ ਕੰਟੇਨਰ ਇਮੇਜ ਬਣਾਉਂਦਾ ਹੈ, ਇਸ ਨੂੰ Azure Container Registry ਵਿੱਚ ਧੱਕਦਾ ਹੈ, ਅਤੇ Foundry ਦੀ ਪ੍ਰਬੰਧਿਤ ਢਾਂਚਾ ਵਿੱਚ ਏਜੰਟ ਨੂੰ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।

## ਕਦਮ 1: ਤਾਇਨਾਤੀ ਸ਼ੁਰੂ ਕਰੋ

ਜੇ ਏਜੰਟ ਇੰਸਪੈਕਟਰ ਖੁਲਾ ਹੋਇਆ ਹੈ (ਟੈਸਟਿੰਗ ਤੋਂ):

1. `Ctrl+Shift+P` ਦਬਾਓ → **Foundry Toolkit: Deploy Hosted Agent**.

## ਕਦਮ 3: ਤਾਇਨਾਤੀ ਕਰੋ ਅਤੇ ਨਿਗਰਾਨੀ ਕਰੋ

1. **Deploy** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
2. **Output** ਪੈਨਲ ਨੂੰ ਵੇਖੋ (ਡ੍ਰੌਪਡਾਊਨ ਵਿਚੋਂ **Microsoft Foundry** ਚੁਣੋ)।
3. ਤਾਇਨਾਤੀ ਇਹਨਾਂ ਚਰਨਾਂ ਵਿਚੋਂ ਲੰਘਦੀ ਹੈ:
   - **Docker build** - ਤੁਹਾਡੇ Dockerfile ਤੋਂ ਕੰਟੇਨਰ ਬਣਾਉਂਦਾ ਹੈ
   - **Docker push** - ਚਿੱਤਰ ਨੂੰ ACR ‘ਤੇ ਧੱਕਦਾ ਹੈ (ਪਹਿਲੀ ਵਾਰੀ 1–3 ਮਿੰਟ)
   - **Agent registration** - Foundry ਵਿੱਚ ਹੋਸਟਡ ਏਜੰਟ ਬਣਾਉਂਦਾ ਹੈ
   - **Container start** - ਸਿਸਟਮ-ਪ੍ਰਬੰਧਿਤ ਪਹਚਾਣ ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ

4. ਜਦੋਂ ਸਮਾਪਤ ਹੋ ਜਾਵੇ, ਇਕ ਸੂਚਨਾ ਆਉਂਦੀ ਹੈ:
   > **executive-summary-agent ਸਫਲਤਾਪੂਰਵਕ ਤਾਇਨਾਤੀ ਹੋ ਗਿਆ ਹੈ।** `View logs` `Run agent`

5. ਏਜੰਟ ਪਲੇਗਰਾਉਂਡ ਖੋਲ੍ਹਣ ਲਈ **Run agent** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

![Deployment success showing Agent Playground with Running status](../../../../../translated_images/pa/05-deployed-asset.b59e6a5eef31c0b1.webp)
