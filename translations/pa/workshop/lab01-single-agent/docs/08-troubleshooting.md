# ਮਾਡਿਊਲ 8 - ਸਮੱਸਿਆ ਸੂਧਾਰਨ

ਇਹ ਮਾਡਿਊਲ ਆਮ ਸਮੱਸਿਆਵਾਂ ਲਈ ਇੱਕ ਸੰਦਰਭ ਗਾਈਡ ਹੈ। ਇਸ ਨੂੰ ਬੁਕਮਾਰਕ ਕਰੋ ਅਤੇ ਜਦੋਂ ਕੁਝ ਗਲਤ ਹੋਵੇ ਤਾਂ ਵਾਪਸ ਆਓ।

---

## 1. ਅਨੁਮਤੀ ਤ੍ਰੁੱਟੀਆਂ

### 1.1 `agents/write` ਅਨੁਮਤੀ ਅਸਵੀਕਾਰ

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**ਮੂਲ ਕਾਰਨ:** **ਪ੍ਰਾਜੈਕਟ** ਇਸਤਰ 'ਤੇ `Azure AI User` ਰੋਲ ਗੁਆਂਢਾ ਹੈ। ਇਹ #1 ਵਰਕਸ਼ਾਪ ਦੀ ਗਲਤੀ ਹੈ।

**ਠੀਕ ਕਰਨ ਲਈ:**
1. [portal.azure.com](https://portal.azure.com) ਖੋਲ੍ਹੋ।
2. ਆਪਣੀ Foundry **ਪ੍ਰਾਜੈਕਟ** ਦਾ ਨਾਂ ਖੋਜੋ → **"Microsoft Foundry project"** ਕਿਸਮ ਦਾ ਨਤੀਜਾ ਤੇ ਕਲਿੱਕ ਕਰੋ (ਮਾਤਰ ਮਾਪਿਆ ਖਾਤਾ ਨਹੀਂ)।
3. **ਪਹੁੰਚ ਨਿਯੰਤ੍ਰਣ (IAM)** → **+ ਜੋੜੋ** → **ਰੋਲ ਅਸਾਈਨਮੈਂਟ ਜੋੜੋ**।
4. ਰੋਲ: **Azure AI User** → ਅੱਗੇ ਵਧੋ।
5. ਮੈਂਬਰ: ਖੁਦ ਨੂੰ ਚੁਣੋ → ਸਮੀਖਿਆ + ਅਸਾਈਨ ਕਰੋ → ਸਮੀਖਿਆ + ਅਸਾਈਨ ਕਰੋ।
6. **1–2 ਮਿੰਟ ਉਡੀਕੋ** → ਦੁਬਾਰਾ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

> **ਕਿਉਂ Owner/Contributor ਕਾਫ਼ੀ ਨਹੀਂ:** ਇਹ ਰੋਲ ਸਿਰਫ *ਪ੍ਰਬੰਧਨ* ਕਿਰਿਆਵਾਂ ਦਿੰਦੇ ਹਨ। ਏਜੰਟ ਓਪਰੇਸ਼ਨਾਂ ਲਈ `agents/write` *ਡਾਟਾ ਕਿਰਿਆ* ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ, ਜੋ ਸਿਰਫ `Azure AI User`, `Azure AI Developer`, ਜਾਂ `Azure AI Owner` ਵਿੱਚ ਮਿਲਦੀ ਹੈ। ਵੇਖੋ [Foundry RBAC docs](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry)।

### 1.2 ਪ੍ਰੋਵਿਜ਼ਨਿੰਗ ਦੌਰਾਨ `AuthorizationFailed`

**ਠੀਕ ਕਰਨ ਲਈ:** ਆਪਣੇ ਐਡਮਿਨ ਨੂੰ ਕਹੋ ਕਿ ਰਿਸੋਰਸ ਗਰੁੱਪ 'ਤੇ **Contributor** ਦਿਓ, ਜਾਂ ਉਹ ਤੁਹਾਡੇ ਲਈ ਪ੍ਰਾਜੈਕਟ ਬਣਾਵੇ ਅਤੇ ਤੁਹਾਨੂੰ **Azure AI User** ਦੇਵੇ।

### 1.3 `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# ਇੰਤਜ਼ਾਰ ਕਰੋ ਜਦ ਤੱਕ: "ਰਜਿਸਟਰਡ"
```

## 2. ਡੋ커 ਦੀਆਂ ਗਲਤੀਆਂ

> ਡੋਕਰ **ਵਿਕਲਪਿਕ** ਹੈ। ਇਹ ਸਿਰਫ਼ ਉਸ ਸਮੇਂ ਲਾਗੂ ਹੁੰਦਾ ਹੈ ਜੇ ਡੋਕਰ ਡੈਸਕਟਾਪ ਇੰਸਟਾਲ ਹੈ ਅਤੇ ਐਕਸਟੈਂਸ਼ਨ ਸਥਾਨਕ ਬਿਲਡ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਦਾ ਹੈ।

### 2.1 ਡੋकर ਡੀਮਨ ਚੱਲ ਨਹੀਂ ਰਿਹਾ

**ਠੀਕ ਕਰਨ ਲਈ:** ਡੋਕਰ ਡੈਸਕਟਾਪ ਸ਼ੁਰੂ ਕਰੋ → "ਚੱਲ ਰਿਹਾ" ਦਰਜਾ ਆਉਣ ਦੀ ਉਡੀਕ ਕਰੋ → `docker info` ਨਾਲ ਜਾਂਚ ਕਰੋ → ਦੁਬਾਰਾ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

### 2.2 ਡਿਪੈਂਡੇਂਸੀ ਦੀਆਂ ਗਲਤੀਆਂ ਨਾਲ ਬਿਲਡ ਫੇਲ

**ਠੀਕ ਕਰਨ ਲਈ:** `requirements.txt` ਦੀ ਸਪੈਲਿੰਗ ਦੀ ਜਾਂਚ ਕਰੋ, ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਪਹਿਲਾਂ ਟੈਸਟ ਕਰੋ: `pip install -r requirements.txt`।

### 2.3 ਪਲੇਟਫਾਰਮ ਅਸਮਤੋਲ (ਐਪਲ ਸਿਲਿਕਾਨ)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

## 3. ਪ੍ਰਮਾਣਿਕਤਾ ਦੀਆਂ ਗਲਤੀਆਂ

### 3.1 `DefaultAzureCredential` ਫੇਲ

**ਠੀਕ ਕਰਨ ਲਈ (ਕ੍ਰਮ ਵਿੱਚ ਕੋਸ਼ਿਸ਼ ਕਰੋ):**
1. `az login` (ਮੁੜ ਪ੍ਰਮਾਣਿਕਤਾ ਕਰੋ)
2. `az account set --subscription "<id>"` (ਸਹੀ ਸਬਸਕ੍ਰਿਪਸ਼ਨ)
3. VS ਕੋਡ → ਖਾਤੇ → ਸਾਈਨ ਆਉਟ → ਮੁੜ ਸਾਈਨ ਇਨ
4. ਜਾਂਚ ਕਰੋ: `az account get-access-token --resource https://cognitiveservices.azure.com`

### 3.2 ਟੋਕਨ ਸਥਾਨਕ ਕੰਮ ਕਰਦਾ ਹੈ ਪਰ ਹੋਸਟਡ ਨਹੀਂ

**ਉਮੀਦ ਹੈ:** ਹੋਸਟਡ ਏਜੰਟ ਸਿਸਟਮ ਪ੍ਰਬੰਧਿਤ ਪਰਚੇ ਨਾਲ ਵਰਤੋਂ ਕਰਦੇ ਹਨ, ਤੁਹਾਡੇ ਪ੍ਰਮਾਣ ਪੱਤਰ ਨਾਲ ਨਹੀਂ। ਜੇ ਹੋਸਟਡ ਏਜੰਟ ਪ੍ਰਮਾਣੀਕਤਾ ਦੀਆਂ ਗਲਤੀਆਂ ਮਿਲਦੀਆਂ ਹਨ:
- `agent.yaml` ਵਿੱਚ `AZURE_AI_PROJECT_ENDPOINT` ਦੀ ਜਾਂਚ ਕਰੋ ਕਿ ਠੀਕ ਹੈ
- ਪ੍ਰਾਜੈਕਟ ਦੀ ਪ੍ਰਬੰਧਿਤ ਪਰਚੇ ਕੋਲ ਮਾਡਲ ਐਕਸੈਸ ਹੈ ਜਾਂ ਨਹੀਂ

## 4. ਮਾਡਲ ਦੀਆਂ ਗਲਤੀਆਂ

### 4.1 ਮਾਡਲ ਨਾਲ ਪ੍ਰਦਾਨਗੀ ਨਹੀਂ ਮਿਲੀ

**ਠੀਕ ਕਰਨ ਲਈ:** ਨਾਂ **ਕੇਸ-ਸੰਵੇਦਨਸ਼ੀਲ** ਹੈ। `.env` ਵਿਚ `AZURE_AI_MODEL_DEPLOYMENT_NAME` ਨੂੰ Foundry ਸਾਈਡਬਾਰ → ਮਾਡਲ ਵਿੱਚ ਸਹੀ ਨਾਮ ਨਾਲ ਤੁਲਨਾ ਕਰੋ।

### 4.2 ਅਣਅਪੇक्षित ਮਾਡਲ ਆਉਟਪੁਟ

**ਠੀਕ ਕਰਨ ਲਈ:** `main.py` ਵਿੱਚ `AGENT_INSTRUCTIONS` ਦੀ ਸਮੀਖਿਆ ਕਰੋ (ਕੀ ਕੱਟਿਆ ਨਹੀਂ?). ਵੱਖਰਾ ਮਾਡਲ ਕੋਸ਼ਿਸ਼ ਕਰੋ (`gpt-4.1` ਵਿਰੁੱਧ `gpt-4.1-mini`)।

## 5. ਪ੍ਰਦਾਨਗੀ ਦੀਆਂ ਗਲਤੀਆਂ

### 5.1 ACR ਪਲ ਅਨੁਮਤਿ ਨਹੀਂ ਹੈ

**ਠੀਕ ਕਰਨ ਲਈ:** Azure ਪੋਰਟਲ → ਕੰਟੇਨਰ ਰਜਿਸਟਰੀ → ਪਹੁੰਚ ਨਿਯੰਤ੍ਰਣ (IAM) → Foundry ਪ੍ਰਾਜੈਕਟ ਦੀ ਪ੍ਰਬੰਧਿਤ ਪਰਚੇ ਨੂੰ **AcrPull** ਰੋਲ ਜੋੜੋ।

### 5.2 ਏਜੰਟ ਸ਼ੁਰੂ ਕਰਨ ਵਿਚ ਅਸਫਲ (ਹਮੇਸ਼ਾ "Pending" ਜਾਂ "Failed" ਰਹਿੰਦਾ)

ਸਾਈਡਬਾਰ ਵਿੱਚ ਕੰਟੇਨਰ ਲੌਗਜ਼ ਚੈੱਕ ਕਰੋ। ਆਮ ਕਾਰਣ:

| ਲੌਗ ਸੁਨੇਹਾ | ਠੀਕ ਕਰਨ ਦਾ ਤਰੀਕਾ |
|-------------|-----|
| `ModuleNotFoundError` | `requirements.txt` ਵਿੱਚ ਗੁੰਮ ਸਾਜ਼ ਉੰਮੀਦ ਵਧਾਓ, ਮੁੜ ਪ੍ਰਦਾਨਗੀ ਕਰੋ |
| `KeyError: 'AZURE_AI_PROJECT_ENDPOINT'` | `agent.yaml` ਵਿੱਚ `environment_variables` ਹੇਠ(env var) ਸ਼ਾਮਲ ਕਰੋ |
| `Address already in use` | ਇਹ ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਸਿਰਫ ਇੱਕ ਪ੍ਰਕਿਰਿਆ ਪੋਰਟ 8088 ਬਾਂਧੇ |

### 5.3 ਪ੍ਰਦਾਨਗੀ ਸਮਾਂ-ਮਿਆਦ ਪੂਰੀ ਹੋ ਗਈ

**ਠੀਕ ਕਰਨ ਲਈ:** ਇੰਟਰਨੈੱਟ ਕਨੈਕਸ਼ਨ ਦੀ ਜਾਂਚ ਕਰੋ। ਪਹਿਲੀ ਵਾਰ ਪ੍ਰਦਾਨਗੀ ਵੱਡਾ >100MB ਭੇਜਦੀ ਹੈ। ਕੋਈ ਪ੍ਰਾਕਸੀ ਪਿੱਛੇ? ਡੋਕਰ ਡੈਸਕਟਾਪ ਪ੍ਰਾਕਸੀ ਸੈਟਿੰਗਸ ਸੈੱਟ ਕਰੋ।

## 6. ਪਾਥ B - Foundry ਲੋਕਲ

### 6.1 Foundry ਲੋਕਲ ਸ਼ੁਰੂ ਨਹੀਂ ਹੁੰਦਾ

| ਸਮੱਸਿਆ | ਠੀਕ ਕਰਨ ਦਾ ਤਰੀਕਾ |
|-------|-----|
| `foundry: command not found` | ਦੁਬਾਰਾ ਇੰਸਟਾਲ ਕਰੋ: `winget install Microsoft.FoundryLocal` |
| ਕਾਫ਼ੀ ਸਰੋਤ ਨਹੀਂ | Foundry Local ਨੂੰ ~4GB RAM ਖਾਲੀ ਚਾਹੀਦੀ ਹੈ। ਹੋਰ ਐਪ ਬੰਦ ਕਰੋ। |
| ਮਾਡਲ ਡਾਊਨਲੋਡ ਫੇਲ | ਡਿਸਕ ਖੇਤਰ ਦੀ ਜਾਂਚ ਕਰੋ (ਮਾਡਲ 2–8 GB ਹਨ)। ਦੁਬਾਰਾ ਕੋਸ਼ਿਸ਼ ਕਰੋ: `foundry local models pull <name>` |

### 6.2 Foundry ਲੋਕਲ ਮਾਡਲ ਦੀਆਂ ਗਲਤੀਆਂ

| ਸਮੱਸਿਆ | ਠੀਕ ਕਰਨ ਦਾ ਤਰੀਕਾ |
|-------|-----|
| ਹੌਲੀ ਜਵਾਬ | ਉਮੀਦ ਕੀਤੀ ਜਾਂਦੀ - ਲੋਕਲ ਮਾਡਲ CPU 'ਤੇ ਚੱਲਦੇ ਹਨ ਜੇਕਰ ਤੁਹਾਡੇ ਕੋਲ GPU ਨਹੀਂ। ਧੀਰਜ ਧਰੋ। |
| ਖਰਾਬ ਗੁਣਵੱਤਾ ਵਾਲਾ ਆਉਟਪੁਟ | ਜੇ ਤੁਹਾਡੇ ਹਾਰਡਵੇਅਰ ਦੀ ਇਜਾਜ਼ਤ ਹੈ ਤਾਂ ਵੱਡਾ ਮਾਡਲ ਕੋਸ਼ਿਸ਼ ਕਰੋ। `phi-4-mini` ਵਧੀਆ ਸੰਤੁਲਨ ਹੈ। |
| ਕਨੈਕਸ਼ਨ ਨਾ-ਪਸੰਦ ਕੀਤਾ | ਜਾਂਚ ਕਰੋ ਕਿ Foundry Local ਚੱਲ ਰਿਹਾ ਹੈ: `foundry local status`। ਜਰੂਰਤ ਪੈਣ ਤੇ ਮੁੜ ਸ਼ੁਰੂ ਕਰੋ। |

## 7. ਤੇਜ਼ ਸੰਦਰਭ: RBAC ਰੋਲ

| ਰੋਲ | ਸੀਮਾ | ਆਗਿਆਵਾਂ |
|------|-------|--------|
| **Azure AI User** | ਪ੍ਰਾਜੈਕਟ | ਡਾਟਾ ਕਿਰਿਆਵਾਂ: `agents/write`, `agents/read` |
| **Azure AI Developer** | ਪ੍ਰਾਜੈਕਟ/ਖਾਤਾ | ਡਾਟਾ ਕਿਰਿਆਵਾਂ + ਪ੍ਰਾਜੈਕਟ ਬਣਾਉਣਾ |
| **Azure AI Owner** | ਖਾਤਾ | ਪੂਰੀ ਪਹੁੰਚ + ਰੋਲ ਪ੍ਰਬੰਧਨ |
| **Contributor** | ਸਬਸਕ੍ਰਿਪਸ਼ਨ/ਰਿਸੋਰਸ ਗਰੁੱਪ | ਸਿਰਫ ਪ੍ਰਬੰਧਨ ਕਿਰਿਆਵਾਂ (**ਕੋਈ** ਡਾਟਾ ਕਿਰਿਆਵਾਂ ਨਹੀਂ) |
| **Owner** | ਸਬਸਕ੍ਰਿਪਸ਼ਨ/ਰਿਸੋਰਸ ਗਰੁੱਪ | ਪ੍ਰਬੰਧਨ + ਰੋਲ ਅਸਾਈਨਮੈਂਟ (**ਕੋਈ** ਡਾਟਾ ਕਿਰਿਆਵਾਂ ਨਹੀਂ) |
