## Безопасность

Microsoft серьезно относится к безопасности наших программных продуктов и сервисов, включая
все репозитории исходного кода в наших организациях GitHub.

**Пожалуйста, не сообщайте о проблемах безопасности через публичные вопросы на GitHub.**

Для получения информации о сообщениях о безопасности, местонахождении, контактных данных и политиках,
пожалуйста, ознакомьтесь с последними рекомендациями для репозиториев Microsoft по адресу
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
