## Как создавать проблемы и получать помощь  

Этот проект использует GitHub Issues для отслеживания ошибок и запросов на функции. Пожалуйста, ищите существующие 
проблемы перед созданием новых, чтобы избежать дублирования. Для новых проблем создавайте новое Issue с вашим багом или 
запросом на функцию.
