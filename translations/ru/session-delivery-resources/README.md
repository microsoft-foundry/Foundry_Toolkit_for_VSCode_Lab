# Как провести эту сессию

Спасибо за проведение этой сессии!

Перед проведением мастер-класса, пожалуйста:

1. Внимательно прочитайте этот документ и все входящие в него ресурсы целиком.
2. Посмотрите запись проведения сессии и полный обзор мастер-класса.
3. Пройдитесь по обоим практическим занятиям целиком на своей машине **хотя бы один раз** до мероприятия.
4. Проверьте ваш проект Microsoft Foundry, развертывания моделей и квоты.
5. Свяжитесь с куратором, если что-то не понятно.

## Начало работы

В этом мастер-классе разработчики научатся создавать, тестировать и разворачивать AI-агентов в **Microsoft Foundry Agent Service** в виде **хостируемых агентов** полностью из VS Code, используя расширение **Microsoft Foundry Toolkit**.

Мастер-класс разделён на несколько частей: слайды, **2 живые демонстрации** и **2 практических задания**.

### Требования к ведущему

Перед проведением убедитесь, что у вас есть:

- **Подписка Azure** с разрешениями создавать ресурсы (Владелец или Участник группы ресурсов).
- Доступ к **проекту Microsoft Foundry** в [регионе, поддерживающем хостируемых агентов](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability).
- Квота на **gpt-4.1** (или **gpt-4.1-mini**) в вашем проекте Foundry.
- Установленные следующие инструменты:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Расширение Microsoft Foundry Toolkit](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (Необязательно)
  - Python 3.10 или выше

Запустите [быстрый старт с хостируемыми агентами через `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) хотя бы один раз до проведения, чтобы иметь проверенный проект Foundry, развертывание модели и реестр контейнеров Azure в резерве, если у участника возникнут трудности.

## Демонстрации

В ходе проведения включены две живые демонстрации. Выделите на каждую по 10 минут.

| Демо | Лабораторная работа | Файлы | Что показать |
|------|--------------------|-------|------------|
| Executive Agent | Лаб 01 | [`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent) | Один хостируемый агент; перевод технического языка в исполнительное резюме |
| Resume to Job Fit Evaluator | Лаб 02 | [`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot) | Оркестрация 4 агентов; оценка соответствия резюме вакансии и генерация рекомендаций |

### Демо 1: Executive Agent

Отдельный агент в [`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent). Используйте как 10-минутное демо перед Лаб 01.

1. Откройте [`workshop/lab01-single-agent/agent/main.py`](../../../workshop/lab01-single-agent/agent/main.py) и пройдитесь по определению агента (системный промпт, модель, фреймворк).
2. Нажмите `F5` для запуска **Agent Inspector** локально.
3. Вставьте пример промпта из [README](../README.md#see-it-in-action) и покажите ответ с исполнительным резюме.
4. Продемонстрируйте [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) и [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile), чтобы объяснить артефакты развертывания.
5. Покажите поток развертывания (сборка Docker, пуш в ACR, создание хостируемого агента) без ожидания завершения.

### Демо 2: Resume to Job Fit Evaluator

4-агентный рабочий процесс в [`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot). Используйте как 10-минутное демо перед Лаб 02.

1. Откройте [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) и покажите, как четыре агента связаны в последовательную оркестрацию.
2. Нажмите `F5` для запуска **Agent Inspector** для мультиагентного рабочего процесса.
3. Вставьте короткое описание вакансии и пример резюме в чат инспектора.
4. Пройдитесь по пайплайну из четырёх агентов: парсер резюме, извлекатель требований к вакансии, оценщик соответствия, и писатель рекомендаций.
5. Обратите внимание, как вывод каждого субагента становится контекстом для следующего агента, выделив паттерн передачи.
6. Покажите [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) для сравнения с одиночным агентом из Демо 1.

## Советы по проведению

- **Устанавливайте ожидания заранее.** Хостируемые агенты находятся на стадии превью - сразу обозначьте ограничения по регионам и квоты, чтобы участники не были удивлены посреди лаборатории.
- **Сначала запустите задачу проверки требований.** В обеих лабораторных включена задача VS Code `Validate prerequisites` - пусть участники выполнят её до начала работы с кодом.
- **Держите Agent Inspector открытым.** Большинство «ага!» моментов происходят, когда участники видят, как локальный эндпойнт `/responses` оживает.
- **Имейте запасной проект.** Если у участника возникнет проблема с квотой в проекте Foundry, поделитесь заранее подготовленным проектом для шага развертывания, чтобы избежать блокировки всей группы.
- **Объединяйте участников в пары.** Лаб 02 (мультиагентный) заметно проще, если можно обсудить последовательность с партнёром.
- **Используйте модули документации как контрольные точки.** Папка `docs/` каждой лабораторной разделена на 8 нумерованных модулей — используйте их для естественных пауз.
- **Предварительно загрузите базовый Docker-образ** на общих машинах, чтобы избежать ограничений по скорости в реестре.

## Решение проблем во время проведения

| Симптом                                      | Что попробовать в первую очередь                                                                             |
|---------------------------------------------|-------------------------------------------------------------------------------------------------------------|
| Agent Inspector не может подключиться       | Проверьте, что порт `8088` свободен, и задача `Run Lab01 HTTP Server` / `Run Lab02 HTTP Server` запущена.   |
| Отладчик не подключается                     | Проверьте, что порт `5679` свободен; перезапустите VS Code, если `debugpy` уже занят этим портом.           |
| Ошибка авторизации при `azd up`              | Выполните `az login` и `azd auth login`, убедитесь, что выбран правильный тенант.                            |
| Развертывание зависло на пуше в ACR          | Проверьте, что Docker Desktop запущен и у пользователя есть право `AcrPush` на реестр.                      |
| Модель возвращает 404 / deployment-not-found  | Имя развертывания модели в `agent.yaml` должно совпадать с развертыванием в проекте Foundry.                 |

| Хост-агент застрял на этапе `Provisioning` | Проверьте, что регион проекта [поддерживает хост-агентов](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) и что квота доступна. |
| Плейграунд возвращает 401                   | Повторно аутентифицируйте расширение Foundry из панели активности VS Code.                              |

Для более детальных инструкций каждый лабораторный курс содержит собственный документ `08-troubleshooting.md` - направьте учащихся туда:

- Лабораторная 01: [`workshop/lab01-single-agent/docs/08-troubleshooting.md`](../workshop/lab01-single-agent/docs/08-troubleshooting.md)
- Лабораторная 02: [`workshop/lab02-multi-agent/docs/08-troubleshooting.md`](../workshop/lab02-multi-agent/docs/08-troubleshooting.md)

## Настройка данной сессии

Вы можете адаптировать воркшоп под свою аудиторию. Частые варианты:

- **Аудитория бэкенд-разработчиков:** уделите больше времени `agent.yaml`, Docker и ACR; упростите демонстрацию в плейграунде.
- **Аудитория гражданских разработчиков:** оставайтесь в UI расширения Foundry для создания каркаса; сократите шаги CLI.
- **Однопоточный слот на 60 минут:** проведите только вводную часть, демонстрацию и Лабораторную 01.
- **Формат только воркшоп (без слайдов):** откройте оба README лабораторий и используйте их как основной сценарий.

Если вы расширяете лаборатории, пожалуйста, внесите изменения через PR, чтобы другие тренеры могли ими воспользоваться.
