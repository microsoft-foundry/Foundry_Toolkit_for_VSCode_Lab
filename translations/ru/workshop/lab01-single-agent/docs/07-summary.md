## Что вы создали

Агент **"Объясни как руководителю"**, который:
- Получает технические отчёты о инцидентах или операционные обновления через HTTP (`POST /responses`)
- Переводит их в понятные руководителю исполнительные резюме
- Соблюдает структурированный формат вывода (Что произошло / Влияние на бизнес / Следующий шаг)
- Отказывает в выполнении запросов вне темы и попытках внедрения подсказок
- Запускается как контейнеризованный размещённый агент в Microsoft Foundry Agent Service

### Идеи для расширения вашего агента

- **Добавьте инструмент даты** - Позвольте агенту включать контекст "на сегодняшний день" в резюме
- **Подключитесь к базе инцидентов** - Получайте реальные данные об инцидентах через функцию инструмента
- **Добавьте инструмент Bing для поиска обоснования** - Позвольте агенту искать последние новости для дополнительного контекста
- **Попробуйте разные модели** - Сравните качество вывода `gpt-4.1` и `gpt-4.1-mini`
- **Оцените с Foundry** - Используйте функцию Evaluations для измерения качества агента в масштабе

## Очистка ресурсов (по желанию)

Если вы хотите удалить ресурсы Azure, созданные во время этого обучения:

### Вариант 1: Удалить группу ресурсов (удалит всё)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### Вариант 2: Удалить только размещённого агента

1. Откройте [ai.azure.com](https://ai.azure.com) → ваш проект → **Build** → **Agents**.
2. Кликните по вашему агенту → нажмите **Delete**.

### Вариант 3: Удалить развертывание модели

1. В боковой панели Foundry разверните ваш проект → **Models**.
2. Кликните правой кнопкой по развертыванию модели → **Delete**.

> **Примечание о стоимости:** За размещённых агентов оплата взимается только при работе. Если остановить или удалить агента, оплата прекращается. За развертывание модели может взиматься небольшая плата за зарезервированную мощность – удалите, если больше не нужно.
