# Лабораторная 02 - Мультиагентный рабочий процесс: Оценка соответствия резюме вакансии

## Обзор

В этой практической лабораторной работе вы создадите **мультиагентное приложение, ориентированное на рабочие процессы**, используя Foundry Toolkit в VS Code и развернете его в Microsoft Foundry Agent Service.

**Что вы создадите:** оценщик соответствия резюме вакансии, который парсит резюме и описание вакансии, оценивает совпадение и создает персонализированную дорожную карту обучения с использованием ресурсов Microsoft Learn.

---

## Архитектура

```mermaid
flowchart TD
    A["Ввод пользователя"] --> B["Парсер резюме"]
    B -->|"[РАСПАРСЕННОЕ РЕЗЮМЕ] + [ПРОПУСК ОПИСАНИЯ ВАКАНСИИ]"| C["Агент описания вакансии"]
    C -->|"[ТРЕБОВАНИЯ ВАКАНСИИ] + [ПРОПУСК РАСПАРСЕННОГО РЕЗЮМЕ]"| D["Агент сопоставления"]
    D -->|отчет о соответствии + пробелы| E["Анализатор пробелов + Microsoft Learn MCP"]
    E -->|балл соответствия + дорожная карта| F["Вывод"]

    style A fill:#4A90D9,color:#fff
    style B fill:#7B68EE,color:#fff
    style C fill:#7B68EE,color:#fff
    style D fill:#E67E22,color:#fff
    style E fill:#27AE60,color:#fff
    style F fill:#4A90D9,color:#fff
```

**Как это работает:**
1. Пользователь вставляет резюме и описание вакансии.
2. **ResumeParser** парсит резюме и копирует описание вакансии дословно в раздел `[ПРОХОД ЗА ОПИСАНИЕМ ВАКАНСИИ]`.
3. **JD Agent** извлекает структурированные требования из проходного раздела, затем передает `[РАСПАРСЕННОЕ РЕЗЮМЕ]` дальше как `[ПРОХОД РАСПАРСЕННОГО РЕЗЮМЕ]`.
4. **MatchingAgent** сравнивает `[ПРОХОД РАСПАРСЕННОГО РЕЗЮМЕ]` с `[ТРЕБОВАНИЯМИ ВАКАНСИИ]` и выдает оценку соответствия.
5. **GapAnalyzer** превращает пробелы в практическую дорожную карту и получает реальные ссылки Microsoft Learn через MCP.

## Часть 2: Построение и тестирование рабочего процесса

1. Используйте мастер Foundry Toolkit для создания проекта, основанного на рабочем процессе.
2. Скопируйте блоки подсказок и граф рабочего процесса из `PersonalCareerCopilot/main.py` в ваше рабочее пространство.
3. Запустите локально с помощью Agent Inspector и проверьте всех четырех агентов и инструмент MCP.
4. Разверните размещенного агента на Foundry после успешного локального тестирования.
