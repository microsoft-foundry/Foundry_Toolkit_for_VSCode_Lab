## Что вы построите

В этой лабораторной работе вы расширите навыки одного агента из Лабораторной работы 01, чтобы создать **многоагентный рабочий процесс** — Резюме → Оценщик соответствия вакансии.

Вы вставляете **резюме** и **описание вакансии**. Четыре специализированных агента последовательно обрабатывают ввод, затем возвращают:
- Оценку соответствия (0–100 с разбиением по баллам)
- Список недостающих навыков и сертификатов
- Персонализированную дорожную карту обучения с реальными ссылками Microsoft Learn для каждого недостатка

**В рабочем процессе используются:**
- **Microsoft Agent Framework** — `WorkflowBuilder` для последовательной организации пайплайна
- **Foundry Toolkit для VS Code** — создание каркаса, локальное тестирование, развертывание
- **Модель искусственного интеллекта** (например, `gpt-4.1-mini`) — используется всеми четырьмя агентами
- **Сервер Microsoft Learn MCP** — предоставляет реальные ссылки на обучающие материалы для каждой недостающей компетенции
