## Что вы создадите

В этой лабораторной работе вы расширяете навыки одного агента из Лаба 01 для создания **многоагентного рабочего процесса** — оценщика соответствия резюме и вакансии.

Вы вставляете **резюме** и **описание вакансии**. Четыре специализированных агента обрабатывают ввод последовательно, после чего возвращают:
- Оценку соответствия (0–100 с разбором по критериям)
- Список пробелов в навыках и сертификатах
- Персонализированную дорожную карту обучения с реальными ссылками на Microsoft Learn для каждого пробела

**Рабочий процесс использует:**
- **Microsoft Agent Framework** — `WorkflowBuilder` для последовательной оркестрации конвейера
- **Foundry Toolkit для VS Code** — структура, локальное тестирование, развертывание
- **AI-модель** (например, `gpt-4.1-mini`) — используется всеми четырьмя агентами
- **Сервер Microsoft Learn MCP** — предоставляет реальные ссылки на обучающие ресурсы для каждого пробела в навыках
