## Что вы создали

**Resume → Job Fit Evaluator** — многоагентный размещённый рабочий процесс, который:
- Получает резюме + описание вакансии по HTTP (`POST /responses`)
- Запускает четыре специализированных агента в последовательной цепочке — каждый агент передаёт данные, необходимые следующему
- Возвращает оценку соответствия (0–100 с подробным разбором), список недостатков навыков и сертификатов, а также персональный план обучения с реальными ссылками Microsoft Learn для каждого пробела
- Обращается к серверу Microsoft Learn MCP (`https://learn.microsoft.com/api/mcp`) для получения официальных учебных ресурсов по каждому обнаруженному пробелу в навыках
- Работает как один контейнеризированный размещённый агент в Microsoft Foundry Agent Service

## Основные изученные концепции

| Концепция | Что вы практиковали |
|---------|-------------------|
| **Многоагентная оркестровка** | `WorkflowBuilder` последовательная цепочка с `add_edge()` |
| **Специализация агентов** | Четыре сфокусированных агента превосходят одного универсального агента |
| **Паттерн Content Router** | ResumeParser одновременно выступает маршрутизатором — он сохраняет текст описания вакансии в разделе `[JOB DESCRIPTION PASS-THROUGH]`, чтобы последующие агенты могли его получить (требуется, потому что `context_mode="last_agent"` означает, что только `start_executor` видит исходное сообщение пользователя) |
| **Паттерн Content Relay** | JD Agent пересылает `[PARSED RESUME PASS-THROUGH]` дальше, чтобы MatchingAgent получил оба профиля; избегает двойного триггера с ИЛИ-семантикой, который вызывают графы слияния |
| **Интеграция с MCP инструментом** | `@tool` + `streamable_http_client` вызов внешнего MCP сервера |
| **Жизненный цикл размещённого агента** | Создание → Настройка → Локальное тестирование → Развёртывание → Проверка в облаке |
| **`context_mode="last_agent"`** | Каждый исполнитель видит только вывод своего непосредственного предшественника |
| **Рабочий процесс Foundry Toolkit** | Мастер создания, Agent Inspector, Workflow Visualizer, развертывание в один клик |

### Идеи для расширения этого рабочего процесса

- **Добавить 5-го агента** — Коуч по собеседованию, генерирующий вероятные вопросы на основе отчёта о пробелах
- **Добавить инструмент Bing для обогащения информации** — Позволить JD Agent искать похожие вакансии для расширения требований
- **Подключить базу данных резюме** — Извлекать профили кандидатов из базы через кастомный `@tool`
- **Попробовать разные модели** — Сравнить качество и скорость вывода `gpt-4.1` и `gpt-4.1-mini`
- **Оценить с помощью Foundry** — Использовать функцию Evaluations для оценки отчётов соответствия по эталонным данным

## Очистка ресурсов (по желанию)

Если хотите удалить ресурсы Azure, созданные в процессе этой лабораторной работы:

### Вариант 1: Удалить группу ресурсов (удалит все)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### Вариант 2: Удалить только размещённого агента

1. Откройте [ai.azure.com](https://ai.azure.com) → ваш проект → **Создание** → **Агенты**.
2. Найдите **PersonalCareerCopilot** → нажмите **Удалить**.

### Вариант 3: Удалить развёртывание модели

1. В боковой панели Foundry разверните ваш проект → **Модели**.
2. Щёлкните правой кнопкой по развёртыванию модели → **Удалить**.

> **Примечание по стоимости:** Размещённые агенты платят только за время работы. Если вы остановите или удалите агента, дальнейшая плата не взимается. Развёртывание модели может нести небольшую плату за зарезервированную ёмкость — удалите его, если работа завершена.
