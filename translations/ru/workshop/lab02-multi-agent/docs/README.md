# Лабораторная работа 02 - Многоагентный рабочий процесс: Оценка соответствия резюме вакансии

## Полный учебный путь

В этой документации показано, как создавать, тестировать и развёртывать **многоагентный рабочий процесс**, который оценивает соответствие резюме вакансии с помощью четырёх специализированных агентов, управляемых через **WorkflowBuilder**.

> **Требование:** Завершите [Лабораторную работу 01 - Один агент](../../lab01-single-agent/README.md) перед началом Лабораторной работы 02.
