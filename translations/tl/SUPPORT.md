**MAY-ARI NG REPO**: Nais mo ba ng Customer Service & Support (CSS) na suporta para sa produktong/proyektong ito?

- **Walang suporta mula sa CSS:** Punan ang template na ito ng impormasyon kung paano magsumite ng mga isyu at humingi ng tulong.
- **Oo, may suporta mula sa CSS:** Punan ang intake form sa [aka.ms/onboardsupport](https://aka.ms/onboardsupport). Makikipagtulungan at tutulungan ka ng CSS upang matukoy ang mga susunod na hakbang.
- **Hindi sigurado?** Punan ang intake na para bang ang sagot ay "Oo". Tutulungan ka ng CSS na magdesisyon.

*Pagkatapos ay tanggalin ang unang pamagat na ito mula sa SUPPORT.MD file bago ilathala ang iyong repo.*

# Suporta

## Paano magsampa ng mga isyu at humingi ng tulong  

Ginagamit ng proyektong ito ang GitHub Issues para subaybayan ang mga bug at kahilingan ng tampok. Mangyaring hanapin muna ang mga umiiral na 
isyu bago mag-file ng mga bagong isyu upang maiwasan ang pag-uulit. Para sa mga bagong isyu, isumite ang iyong bug o 
kahilingan ng tampok bilang bagong Issue.

Para sa tulong at mga tanong tungkol sa paggamit ng proyektong ito, mangyaring **TAGAPAGPANATILI NG REPO: ILAGAY DITO ANG MGA INSTRUKSYON 
PARA SA PAANO MAKIPAG-UGNAY SA MGA MAY-ARI NG REPO O KOMUNIDAD PARA SA TULONG. MAARING ITO AY STACK OVERFLOW TAG O IBA PANG 
CHANNEL. SAAN MO TUTULUNGAN ANG MGA TAO?**.

## Patakaran sa Suporta ng Microsoft  

Ang suporta para sa **PROYEKTONG o PRODUKTO** na ito ay limitado sa mga mapagkukunang nakalista sa itaas.
