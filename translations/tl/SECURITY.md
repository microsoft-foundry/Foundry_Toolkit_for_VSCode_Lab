## Seguridad

Tinitiyak ng Microsoft ang seguridad ng aming mga software na produkto at serbisyo, kabilang na
ang lahat ng source code na repositoryo sa aming mga GitHub na organisasyon.

**Mangyaring huwag mag-ulat ng mga kahinaan sa seguridad sa pamamagitan ng pampublikong mga isyu sa GitHub.**

Para sa impormasyon sa pag-uulat ng seguridad, mga lokasyon, impormasyon sa pakikipag-ugnayan, at mga polisiya,
mangyaring tingnan ang pinakabagong patnubay para sa mga Microsoft repositoryo sa
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
