# מודול 7 - סיכום והצעדים הבאים

⏱️ ~5 דקות

**ברכות!** בנית, בדקת, ואם בנתיב א', פרסת סוכן בינה מלאכותית מתארח באמצעות Microsoft Foundry ו-Foundry Toolkit עבור VS Code.

---

## מה שבנית

סוכן **"הסבר כאילו אני מנהל בכיר"** ש:
- מקבל דוחות תאונות טכניות או עדכונים תפעוליים דרך HTTP (`POST /responses`)
- מתרגם אותם לסיכומים בשפה פשוטה למנהלים בכירים
- עוקב אחרי פורמט פלט מובנה (מה קרה / השפעה עסקית / הצעד הבא)
- דוחה בקשות לא קשורות וניסיונות הזרקת פקודות
- פועל כסוכן מתארח בתור קונטיינר בשירות סוכני Foundry של מיקרוסופט

---

## מושגים מרכזיים שלמדת

| מושג | מה התאמנת עליו |
|---------|-------------------|
| **ארכיטקטורת Agent Framework** | צינור `FoundryChatClient` → `Agent` → `ResponsesHostServer` |
| **מחזור חיים של סוכן מתארח** | תבנית → קונפיגורציה → בדיקה מקומית → פריסה → אימות בענן |
| **הנדסת פקודת מערכת** | תפקיד, קהל יעד, פורמט פלט, חוקים, מגבלות בטיחות ודוגמאות |
| **הבדלים בין מקומי למתארח** | זהות (אישורים אישיים מול זהות מנוהלת), נקודת קצה, נתיב רשת |
| **גבולות בטיחות** | הגנה מפני הזרקת פקודות, ציות לתפקיד, טיפול עדין במקרים מיוחדים |
| **זרימת עבודה של Foundry Toolkit** | יצירת פרויקט, פריסת מודל, יצירת סוכן, Agent Inspector, פריסה בלחיצה אחת |

### רעיונות להרחבת הסוכן שלך

- **הוסף כלי תאריך** - אפשר לסוכן לכלול הקשר "נכון להיום" בסיכומים
- **חיבור למסד נתונים של תקלות** - שלוף פרטים אמתיים על תקלות דרך פונקציית כלי
- **הוסף כלי עיגון מבינג** - אפשר לסוכן לחפש חדשות אחרונות להקשר נוסף
- **נסה מודלים שונים** - השווה איכות פלט בין `gpt-4.1` ל-`gpt-4.1-mini`
- **הערכה עם Foundry** - השתמש בפיצ'ר ההערכות למדידת איכות הסוכן בקנה מידה

### למשתמשי נתיב ב': שדרגו לפריסת ענן

כשאתה מוכן לפרוס לענן:
1. קבל מנוי Azure ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. השלם את [מודול 01, ההתקנה](01-setup.md#step-2-set-up-based-on-your-access) (צור פרויקט, פרוס מודל, הענק הרשאות RBAC)
3. עדכן את קובץ `.env` עם נקודת הקצה של פרויקט Foundry ושם פריסת המודל
4. המשך מ-[מודול 05 - פריסה ל-Foundry](05-deploy-to-foundry.md)

## ניקוי משאבים (אופציונלי)

אם ברצונך להסיר את משאבי Azure שנוצרו במהלך הסדנה:

### אפשרות 1: מחק את קבוצת המשאבים (מוחק הכל)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### אפשרות 2: מחק רק את הסוכן המתארח

1. פתח את [ai.azure.com](https://ai.azure.com) → הפרויקט שלך → **Build** → **Agents**.
2. לחץ על הסוכן שלך → לחץ על **Delete**.

### אפשרות 3: מחק את פריסת המודל

1. בסרגל הצדדי של Foundry, פתח את הפרויקט שלך → **Models**.
2. לחץ ימני על פריסת המודל → **Delete**.

> **הערת עלות:** סוכנים מתארחים גובים עלות רק בזמן ריצה. אם תעצור או תמחק את הסוכן, אין חיוב מתמשך. פריסת המודל עשויה לגבות עלות קטנה עבור קיבולת שמורה - מחק אותה אם סיימת.
