# מעבדה 02 - זרימת עבודה רב-סוכנים: הערכת התאמת קורות חיים למשרה

## מסלול הלמידה המלא

תיעוד זה מדריך אותך בבניית, בדיקה ופריסה של **זרימת עבודה רב-סוכנים** שמעריכה התאמת קורות חיים למשרה באמצעות ארבעה סוכנים מתמחים המנוהלים דרך **WorkflowBuilder**.

> **דרישה מוקדמת:** יש להשלים את [מעבדה 01 - סוכן יחיד](../../lab01-single-agent/README.md) לפני תחילת מעבדה 02.
