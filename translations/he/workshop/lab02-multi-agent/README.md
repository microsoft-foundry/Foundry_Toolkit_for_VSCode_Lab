# מעבדה 02 - זרימת עבודה מולטי-סוכן: מעריך התאמת קורות חיים למשרה

## סקירה כללית

במעבדה המעשית הזו, תבנו **אפליקציית מולטי-סוכן שממוקדת בזרימת העבודה** תוך שימוש ב-Foundry Toolkit ב-VS Code ותפרסמו אותה לשירות Microsoft Foundry Agent.

**מה שתבנו:** מעריך התאמת קורות חיים למשרה שמנתח קורות חיים ותיאור משרה, מדרג את ההתאמה ומייצר מפת דרכים לימודית מותאמת אישית תוך שימוש במשאבי Microsoft Learn.

---

## ארכיטקטורה

```mermaid
flowchart TD
    A["קלט משתמש"] --> B["מפענח קורות חיים"]
    B -->|"[קורות חיים מפוענחות] + [תיאור משרה במעבר]"| C["סוכן תיאור משרה"]
    C -->|"[דרישות תיאור משרה] + [קורות חיים מפוענחות במעבר]"| D["סוכן התאמה"]
    D -->|דוח התאמה + פערים| E["מנתח פערים + Microsoft Learn MCP"]
    E -->|ציון התאמה + מפת דרכים| F["פלט"]

    style A fill:#4A90D9,color:#fff
    style B fill:#7B68EE,color:#fff
    style C fill:#7B68EE,color:#fff
    style D fill:#E67E22,color:#fff
    style E fill:#27AE60,color:#fff
    style F fill:#4A90D9,color:#fff
```

**איך זה עובד:**
1. המשתמש מדביק קורות חיים ותיאור משרה.
2. **ResumeParser** מנתח את קורות החיים ומעתיק את תיאור המשרה במלואו לסעיף `[JOB DESCRIPTION PASS-THROUGH]`.
3. **JD Agent** מפיק דרישות מבניות מתוך התוכן המועבר, ואז מעביר את `[PARSED RESUME]` הלאה בתור `[PARSED RESUME PASS-THROUGH]`.
4. **MatchingAgent** משווה בין `[PARSED RESUME PASS-THROUGH]` ל-`[JD REQUIREMENTS]` ומפיק ציון התאמה.
5. **GapAnalyzer** ממיר את הפערים למפת דרכים מעשית ומביא קישורים אמיתיים מ-Microsoft Learn באמצעות MCP.

## חלק 2: בנה ובדוק את זרימת העבודה

1. השתמש באשף Foundry Toolkit כדי ליצור קונסטרוקציה לפרויקט מבוסס זרימת עבודה.
2. העתק את קטעי השאילתות וגרף זרימת העבודה מהקובץ `PersonalCareerCopilot/main.py` אל סביבת העבודה שלך.
3. הרץ באופן מקומי עם Agent Inspector ואמת את כל ארבעת הסוכנים בתוספת כלי MCP.
4. פרסם את הסוכן המאוחסן ל-Foundry לאחר שהבדיקות המקומיות עוברות בהצלחה.
