# စမ်းသပ်ချက် ၀၂ - မလ်တီ-အေးဂျင့် အလုပ်လုပ်စဉ်: ကိုယ်ရေးရာဇဝင် → အလုပ် သင့်တော်မှု ဆန်းစစ်သူ

## လုံးဝ လေ့လာသင်ယူမှု လမ်းကြောင်း

ဒီစာတမ်းက သင့်ကို နည်းပညာအထူးပြု အေးဂျင့်လေးယောက်နဲ့ **WorkflowBuilder** အသုံးပြုပြီး ကိုယ်ရေးရာဇဝင်နှင့် အလုပ်အကိုင်သင့်တော်မှုကို တူညီအောင် စစ်ဆေးပေးသည့် **မလ်တီ-အေးဂျင့် အလုပ်လုပ်စဉ်** တည်ဆောက်၊ စမ်းသပ်၊ ဖြန့်ချိ တဲ့နည်းလမ်းကို လမ်းပြပေးမှာ ဖြစ်ပါတယ်။

> **လိုအပ်ချက်:** စမ်းသပ်ချက် ၀၁ - တစ်ခုတည်း အေးဂျင့် ([Lab 01 - Single Agent](../../lab01-single-agent/README.md)) ကို စမ်းသပ်ချက် ၀၂ စတင်မလုပ်ခင် အပြီးသတ်ပါ။
