# စမ်းသပ်မှု 02 - မျိုးစုံအေဂျင့် လုပ်ငန်းစဉ်: ရုပ်သိမ်းစာတမ်း → အလုပ်နဲ့ ကိုက်ညီမှု အကဲဖြတ်သူ

## မျိုးမှာနားလည်မှု

ဤ လက်တွေ့လက်တွေ့လုပ်ငန်းတွင် Foundry Toolkit ကို VS Code မှာအသုံးပြု၍ **workflow-first multi-agent app** တစ်ခု တည်ဆောက်ပြီး Microsoft Foundry Agent Service သို့ ဖြန့်ချိသည်။

**သင်တည်ဆောက်မည့်အရာ:** ရုပ်သိမ်းစာတမ်းနှင့် အလုပ်ဖော်ပြချက်ကို ဖတ်ရှုကာ ကိုက်ညီမှုအကဲဖြတ်ချက်ပေးပြီး Microsoft Learn အရင်းအမြစ်များကို အသုံးပြုပြီး ကိုယ်ပိုင်သင်ယူမှုလမ်းပြမြေပုံကို ထုတ်ပေးသော Resume → Job Fit Evaluator ဖြစ်သည်။

---

## ဖွဲ့စည်းပုံ


**လုပ်ဆောင်ပုံ:**
1. အသုံးပြုသူသည် ရုပ်သိမ်းစာတမ်းနှင့် အလုပ်ဖော်ပြချက်ကို ကပ်ထည့်သည်။
2. **ResumeParser** သည် ရုပ်သိမ်းစာတမ်းကို ဖတ်ရှုပြီး JD ကိုပေါင်းတည် `[JOB DESCRIPTION PASS-THROUGH]` အပိုင်းအဖြစ် မူလတည်းကအစ ကူးယူသွားသည်။
3. **JD Agent** သည် pass-through ထဲမှ ဖွဲ့စည်းထားသော လိုအပ်ချက်များကို ခွဲခြမ်းစိတ်ဖြာပြီး `[PARSED RESUME]` ကို `[PARSED RESUME PASS-THROUGH]` အဖြစ် ရှေ့ဆက် လွှဲပြောင်းသည်။
4. **MatchingAgent** သည် `[PARSED RESUME PASS-THROUGH]` နှင့် `[JD REQUIREMENTS]` ကို ယှဉ်ပြိုင်ကာ ကိုက်ညီမှုအဆင့်အတန်း ထုတ်ပေးသည်။
5. **GapAnalyzer** သည် တွေ့ရှိ gaps များကို လက်တွေ့ကောင်းမွန်သော လမ်းပြမြေပုံများပြုလုပ်ပြီး MCP ကနေ Microsoft Learn လင့်ခ်များကို ရယူသည်။

## အပိုင်း ၂: လုပ်ငန်းစဉ်ကို တည်ဆောက်ပြီး စမ်းသပ်ပါ

1. Foundry Toolkit wizard ကို အသုံးပြုပြီး workflow-based project ကို စတင်ဖန်တီးပါ။
2. `PersonalCareerCopilot/main.py` မှ prompt blocks နှင့် workflow graph များကို မိမိလုပ်ငန်းဗဟိုသို့ ကူးယူထည့်သွင်းပါ။
3. Agent Inspector နှင့် နှစ်ခြိုက်၍ သတ်မှတ်ထားသော agent လေးဆယ်နှင့် MCP ကိရိယာတို့ကို ဒေသခံမှာ စမ်းသပ်ပါ။
4. ဒေသခံ စမ်းသပ်မှု အောင်မြင်လျှင် hosted agent ကို Foundry သို့ ဖြန့်ချိပါ။

## စီမံခန့်ခွဲမှု ပုံစံများ

Lab 02 တွင် မူရင်း **fan-out → fan-in → စဉ်ဆက်ဖြစ်စဉ်** အစဉ်အဆက်ထဲကပါရှိပြီး စာရွက်များတွင် စမ်းသပ်မှုအတွက် အခြား စီမံခန့်ခွဲမှု ပုံစံများကိုလည်း ဖော်ပြထားသည်။

- **အလေးချိန်ထည့်ထားသော fan-out/fan-in consensus**
- **နိဂုံးထုတ်မတိုင်မီ ပြန်လည်သုံးသပ်သူ/တိုက်ခိုက်သူ လမ်းကြောင်း**
- **ကိုက်ညီမှုဆိုင်ရာ စံနှုန်းနှင့် ပျောက်ကွယ်နေသောကျွမ်းကျင်မှုများအပေါ် မူတည်သော အခြေအနေ router**
