# Module 7 - အနှစ်ချုပ်နှင့် နောက်တစ်ဆင့်များ

⏱️ ~၅ မိနစ်

**ဂုဏ်ယူပါတယ်!** သင်သည် Microsoft Foundry နှင့် Foundry Toolkit for VS Code ကို အသုံးပြု၍ မိမိ၏ hosted AI ကိုယ်စားလှယ်တစ်ဦးကို တည်ဆောက်၊ စမ်းသပ်၊ (Path A မှာဖြစ်ပါက) ဖြန့်ချိပြီးဖြစ်ပါသည်။

---

## သင်တည်ဆောက်ခဲ့သည်။

**"ငါသည် အမှုဆောင်အရာရှိတစ်ဦးအဖြစ် ရှင်းပြပါ"** ကိုယ်စားလှယ်တစ်ဦးသည်-
- တက္ကနစ် အရေးပေါ် အစီရင်ခံစာများ သို့မဟုတ် လည်ပတ်မှုအချက်အလက်များကို HTTP ( `POST /responses` ) မှတဆင့် လက်ခံတင်ပြသည်
- ၎င်းများအား ရိုးရှင်းသော ဘာသာစကားဖြင့် အမှုဆောင်အရေးအကြောင်းအရာအကျဉ်းများအဖြစ် ဘာသာပြန်သည်
- တိကျသည့် ပုံစံဖြင့် ထုတ်ပေးသည် (ဘာဖြစ်ပျက်ခဲ့သည် / စီးပွားရေးသက်ရောက်မှု / နောက်တစ်ဆင့်)
- မလိုလားအပ်သော တောင်းဆိုချက်များနှင့် prompt injection ကြိုးပမ်းမှုများကို ငြင်းဆိုသည်
- Microsoft Foundry Agent Service တွင် container အတွင်း hosted ကိုယ်စားလှယ်အဖြစ် တည်ဆောင်ထားသည်

---

## သင်လေ့လာသင့်သော အဓိက အၾကောင်းအရာများ

| အကြောင်းအရာ | သင်လေ့ကျင့်ခဲ့သည် |
|---------|-------------------|
| **ကိုယ်စားလှယ် ဖရိမ်ဝါခ် ဒီဇိုင်း** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` လမ်းကြောင်း |
| **Hosted ကိုယ်စားလှယ်၏ အသက်တမ်း** | စတင်ခြင်း → ဆက်တင်ပြင်ဆင်ခြင်း → ဒေသတွင်း စမ်းသပ်ခြင်း → ဖြန့်ချိခြင်း → မိုးလုံလေလုံတွင် အတည်ပြုခြင်း |
| **စနစ် prompt စီမံချက်** | သရုပ်တစ်ခု၊ ပရိသတ်၊ ထုတ်ပေးမှု ပုံစံ၊ စည်းကမ်းများ၊ လုံခြုံရေး ကန့်သတ်ချက်များနှင့် နမူနာများ |
| **ဒေသတွင်း vs. hosted ကွဲပြားချက်များ** | ကိုယ်ပိုင်အချက်အလက် (ပုဂ္ဂိုလ်ရေး လက်မှတ် vs. စီမံထိန်းချုပ်ထားသော အတည်ပြုချက်), endpoint, ကွန်ယက်လမ်းကြောင်း |
| **လုံခြုံရေးနယ်နိမိတ်များ** | prompt injection ကာကွယ်မှု၊ သရုပ်ဆောင်မှုလိုက်နာမှု၊ အကွာအဝေးကိစ္စများကို ရိုးရှင်းသနည်းဖြင့် ကိုင်တွယ်မှု |
| **Foundry Toolkit လုပ်ငန်းစဉ်** | စီမံကိန်း ဖန်တီးခြင်း၊ မော်ဒယ် ဖြန့်ချိခြင်း၊ ကိုယ်စားလှယ် scaffold လုပ်ခြင်း၊ Agent Inspector, တစ်ချက်တည်း ဖြန့်ချိခြင်း |

## သင်ပြီးမြောက်ထားသော အလုပ်များ

### လမ်းကြောင်း A (Foundry subscription)

- [x] Foundry Toolkit ကို စတင်ဖြင့် Foundry စီမံကိန်းကို မော်ဒယ်ဖြန့်ချပ်ပြီး ဖန်တီးခြင်း
- [x] auto-generated စီမံကိန်း ဖွဲ့စည်းပုံဖြင့် hosted ကိုယ်စားလှယ် scaffold လုပ်ခြင်း
- [x] လုံခြုံရေးစည်းကမ်းများပါရှိသော ကျွမ်းကျင်သော agent သတ်မှတ်ချက်များရေးသားခြင်း
- [x] ဒေသတွင်းတွင် ၃ ခုသော လုပ်ဆောင်ချက် အခြေအနေများဖြင့် စမ်းသပ်ခြင်း (Agent Inspector)
- [x] Foundry Agent Service (containerized) အတွက် ဖြန့်ချိ ပြီးခြင်း
- [x] မိုးလုံလေလုံ စမ်းသပ်မှု ၄ ခုဖြင့် အတည်ပြုခြင်း

### လမ်းကြောင်း B (Foundry Local)

- [x] ဒေသတွင်း မော်ဒယ် endpoint ဖြင့် Foundry Toolkit စတင်ဖြင့် ထားရှိခြင်း
- [x] hosted ကိုယ်စားလှယ် စီမံကိန်း scaffold လုပ်ခြင်း
- [x] လုံခြုံရေး စည်းကမ်းများပါရှိသော အသေးစိတ် agent သတ်မှတ်ချက်များရေးသားခြင်း
- [x] ဒေသတွင်းတွင် လုပ်ဆောင်ချက် အခြေအနေ ၃ ခုဖြင့် စမ်းသပ်ခြင်း
- [x] မိုးလုံလေလုံ အရင်းအမြစ် မလိုအပ်ဘဲ ကိုယ်စားလှယ် သဘောထားမှန်ကန်မှုအား အတည်ပြုခြင်း

### ကိုယ်စားလှယ်ကို တိုးချဲ့ရန် အကြံပြုချက်များ

- **နေ့ရက်ကိရိယာတစ်ခု ထည့်ပါ** - ကိုယ်စားလှယ်အား "ယနေ့အခြေအနေ" ကို မူလအကြောင်းအရာများထဲ ပြသရန် ခွင့်ပြုပါ
- **အရေးပေါ်ဖြစ်ရပ် ဒေတာဘေ့စ်နှင့် ချိတ်ဆက်ပါ** - tool function ဖြင့် အရေးပေါ်အချက်အလက်များကို ဆွဲထုတ်ပါ
- **Bing အခြေခံကိရိယာ ထည့်ပါ** - အပိုကျသည့်သတင်းအချက်အလက်စုံရ သဘောထားရန် ကိုယ်စားလှယ်အားခွင့်ပြုပါ
- **မော်ဒယ်အမျိုးမျိုး စမ်းသပ်ကြည့်ပါ** - `gpt-4.1` နှင့် `gpt-4.1-mini` ထုတ်လွှင့်မှု အရည်အသွေးကို နှိုင်းယှဉ်ပါ
- **Foundry ဖြင့် အကဲဖြတ်ပါ** - Evaluations အင်္ဂါရပ်ကို အသုံးပြု၍ ကိုယ်စားလှယ် အရည်အသွေးအတိုင်းအတာဖြင့် တိုင်းတာပါ

### လမ်းကြောင်း B အသုံးပြုသူများအတွက် - မိုးလုံလေလုံ ဖြန့်ချိခြင်းသို့ မြှင့်တင်ပါ

မိုးလုံလေလုံ ထဲသို့ ဖြန့်ချိရန် အသင့်ရှိလာသောအခါ -
1. Azure subscription တစ်ခု ရယူပါ ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [Module 01, Setup](01-setup.md#step-2-set-up-based-on-your-access) ပြီးစီးပါ (စီမံကိန်းဖန်တီး၊ မော်ဒယ်ဖြန့်ချိ၊ RBAC ခန့်သတ်)
3. ကိုယ့်၏ `.env` ဖိုင်တွင် Foundry စီမံကိန်း endpoint နှင့် မော်ဒယ် ဖြန့်ချိမှု အမည်များ အပ်ဒိတ်လုပ်ပါ
4. [Module 05 - Deploy to Foundry](05-deploy-to-foundry.md) မှ ဆက်လက်လုပ်ဆောင်ပါ

## အရင်းအမြစ်များ သန့်ရှင်းခြင်း (ရွေးချယ်လို့ရသည်)

သင် ဒီလုပ်ငန်းရဲ့ အတွင်း ဆောက်လုပ်ထားသော Azure အရင်းအမြစ်များကို ဖျက်လိုပါက -

### ရွေးချယ်စရာ ၁ - resource group ကို ဖျက်ပါ (အားလုံးဖျက်မည်)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ရွေးချယ်စရာ ၂ - hosted ကိုယ်စားလှယ်သာ ဖျက်ပါ

1. [ai.azure.com](https://ai.azure.com) ကိုဖွင့် → ကိုယ့်စီမံကိန်း → **Build** → **Agents** ကိုသွားပါ။
2. ကိုယ်စားလှယ်ကိုနှိပ် → **ဖျက်ရန်** ကိုနှိပ်ပါ။

### ရွေးချယ်စရာ ၃ - မော်ဒယ် ဖြန့်ချိမှုကို ဖျက်ပါ

1. Foundry sidebar တွင် ကိုယ့်စီမံကိန်း ကို ကျယ်ပြန့်မြှင့်တင်ပါ → **Models** ကိုရွေးပါ။
2. မော်ဒယ်ဖြန့်ချိမှုကိုညာကလစ် → **ဖျက်ရန်** ကိုနှိပ်ပါ။

> **ကုန်ကျစရိတ်မှတ်ချက်**: Hosted ကိုယ်စားလှယ်များသည် လည်ပတ်နေချိန်မှသာ ကုန်ကျစရိတ်ရှိသည်။ သို့မဟုတ် ကိုယ်စားလှယ်ကို ပိတ်သိမ်း သို့မဟုတ် ဖျက်လျှင် ဆက်လက်ကောက်ခံမှု မရှိတော့ပါ။ မော်ဒယ် ဖြန့်ချိမှုသည် သတ်မှတ်ထားသော စွမ်းရည်အတွက် သေးငယ်သော လိုအပ်မှုဘက်ကို ကောက်ခံနိုင်သည် - သင်ပြီးသွားတယ်ဆိုလျှင် ဖျက်ပါ။
