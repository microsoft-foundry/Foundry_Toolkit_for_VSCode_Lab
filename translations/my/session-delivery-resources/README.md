# ဒီအစီအစဉ်ကို မည်သို့ပေးပို့မည်နည်း

ဒီအစီအစဉ်ကို ပေးပို့မှုအတွက် ကျေးဇူးတင်ပါသည်!

အလုပ်ရုံအစီအစဉ်ကို ပေးပို့မီ ကျေးဇူးပြု၍ -

1. ဤစာတမ်းနှင့် ထည့်သွင်းထားသော မြမ်းမံစာရင်းအားလုံးကို ပြည့်စုံစွာ ဖတ်ရှုပါ။
2. အစီအစဉ် ပေးပို့မှုမှတ်တမ်းနှင့် အလုပ်ရုံအစီအစဉ် အဆုံးမှ အဆုံးသိုင်းလမ်းညွှန်ဖွင့်ပွဲကို ကြည့်ရှုပါ။
3. လက်တွေ့လေ့ကျင့်ဆောင်ရွက်မှု နှစ်ရပ်ကို သင်၏စက်ပေါ်တွင် **အနည်းဆုံး တစ်ကြိမ်** လုံး လိုက်လံလုပ်ပါ။
4. သင်၏ Microsoft Foundry project၊ မော်ဒယ်များအဖွင့်နှင့် ကွတ်တာများကို အတည်ပြုပါ။
5. မည်သည့်အရာမဆို မသေချာပါက ထိန်းသိမ်းသူထံ ဆက်သွယ်ပါ။

### သင်ကြားသူအတွက် မတိုင်မီ လိုအပ်ချက်များ

ပေးပို့ရန်မတိုင်မီ သင်တွင် ရှိစေရမည့် အရာများမှာ -

- ရင်းမြစ်ဖန်တီးခွင့်ပါ ပိုင်ရှင် ဒါမှမဟုတ် contributor အဖြစ် **Azure subscription** တစ်ခု။
- [hosted agents ကိုထောက်ပံ့သော ဒေသ](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) တွင်ရှိသော **Microsoft Foundry project** အတွက် ဝင်ခွင့်။
- သင်၏ Foundry project တွင် **gpt-4.1** (သို့) **gpt-4.1-mini** အတွက် ကွတ်တာ။
- အောက်ဖော်ပြပါ ကိရိယာများ တပ်ဆင်ပြီးဖြစ်ရမည်။
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Microsoft Foundry Toolkit extension](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (စိတ်ကြိုက်)
  - Python 3.10 သို့မဟုတ် နောက်ထပ်ဗားရှင်း

[Hosted agents quickstart with `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) ကို တစ်ကြိမ် အနည်းဆုံး လုပ်ပြီးနောက် ပေးပို့ပါက လေ့လာသူမည်သူမဆို တိုးတက်မှုအဆင်မပြေပါက ရည်ညွှန်းရန် ရင်းမြစ်၊ မော်ဒယ် ဖန်တီးခွင့် နှင့် Azure Container Registry တစ်ခု ဖြစ်မြောက်ထားရမည်။

1. [`workshop/lab01-single-agent/agent/main.py`](../../../workshop/lab01-single-agent/agent/main.py) ကို ဖွင့်ပြီး agent ကို အညွှန်းချက်များ (system prompt, model, framework) နှင့် နီးစပ်စွာ ရှင်းပြပါ။
2. `F5` ကိုနှိပ်ပြီး **Agent Inspector** ကို ဒေသတွင်းတွင် စတင်ပါ။
3. [README](../README.md#see-it-in-action) မှ နမူနာ prompt ကို ကော်ပီကာနှင့် သိမ်းပြီး executive-summary ဖြေကြားမှုကို ပြပါ။
4. [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) နှင့် [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile) ကို ပြပါပြီး ဖြန့်ချိမှု artefacts များကို ရှင်းပြပါ။
5. ဖြန့်ချိမှု လုပ်ငန်းစဉ်ကို (Docker build, ACR push, hosted agent ဖန်တီးခြင်း) ပြုလုပ်ပြီးလည်း အပြီးသတ်အတွက် မစောင့်ဆိုင်းပါနှင့်။

### ပြသမှု ၂: Resume to Job Fit Evaluator

[`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot) တွင် ၄-agent Workflow တစ်ခု။ Lab 02 မတိုင်မီ ၁၀ မိနစ် ဒေမိုအဖြစ် အသုံးပြုပါ။

1. [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) ကို ဖွင့်ပြီး agent ၄ ဦးကို စဉ်လိုက် အလှည့်အပြောင်း ပြုလုပ်သော စနစ်လမ်းကြောင်းနှင့် ရေးဆွဲထားသည်ကို ပြပါ။
2. `F5` ကိုနှိပ်ပြီး မတူညီသော agent များအတွက် **Agent Inspector** ကို စတင်ပါ။
3. Inspector chat တွင် အလုပ်အညွှန်းတိုတစ်ခုနှင့် နမူနာ ရုပ်ပုံတင်ပြချက် တစ်ခုကို ပေးပို့ပါ။
4. လူကြီးagent လေးခု၏ လုပ်ငန်းစဉ်အားလုံးကို လမ်းလျှောက်ပြပါ: ရုပ်ပုံတင်မည့် resume parser, အလုပ်လိုအပ်ချက် အစိတ်အပိုင်း extractor, ကိုက်ညီမှုစာရင်း scorer, အကြံပြုချက်ရေးသူ။
5. ခွဲခြမ်းသုံးသပ်ချက် sub-agent တစ်ခုချင်းစီ၏ output သည် နောက်တစ် agent ၏ context ဖြစ်တယ်ဟု ဖော်ပြပြီး handoff ပုံစံကို ညွှန်ပြပါ။
6. [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) ကို ပြပါ။ Demo 1မှ single-agent agent.yaml နှင့် နှိုင်းယှဉ်ပါ။

## ပေးပို့မှုပြုစေမှု အကြံပြုချက်များ

- **မျှော်မှန်းချက်များကို မကြာမီ ထားပါ။** Hosted agents များ သည် ပြသမှုဆိုင်ရာဖြစ်ပြီး ဒေသကန့်သတ်ချက်နှင့် ကွတ်တာများကို အစမှာ ဖော်ပြပါ၊ သို့မဟုတ် လေ့ကျင့်မှုပွဲအလယ်တွင် မထင်မှတ်ထားသောအတိုင်း မဖြစ်ပေါ်ပါစေနိုင်ပါ။
- **လိုအပ်မှုများ စစ်ဆေးခြင်း အဓိကလုပ်ဆောင်သော ပထမဆုံးအနေဖြင့် ပြုလုပ်ပါ။** လှုပ်ရှားလက်တွေ့ လေ့ကျင့်မှု နှစ်ခုစလုံးတွင် `Validate prerequisites` VS Code task တခုပါဝင်သည်- စတင် မည်သည့်ကုဒ်ရေးမီ ၎င်းကို အသုံးပြုခြင်း။
- **Agent Inspector ကို ဖော်ပြထားပါ။** အများစုသော "aha" အချိန်များသည် သင်ယူသူများ ဒေသတွင်း `/responses` များ၏ round-trip မီးပုံရိပ်များကို မြင်တွေ့သောအခါ ဖြစ်ပေါ်သည်။
- **backup project တစ်ခု ထားပါ။** အကယ်၍ သင်ယူသူတစ်ဦး၏ Foundry project တွင် ကွတ်တာ ပြဿနာရှိပါက ဖြန့်ချိမှုအဆင့်တွင် အခန်းအားတားဆီးခြင်းမှ သတိထားပြီး အလျင်တစ်ချက်အတွက် ကြိုတင် ဖန်တီးထားသော project ကို မျှဝေပါ။
- **လေ့လာသူများအား တွဲဖက်ပါ။** Lab 02 (multi-agent) ကို လေ့လာသူများစကားပြောနိုင်စေရန် နှစ်တွဲလျှောက်ခြင်းသည် တကယ်ပေါက်ကွာပါတယ်။
- **စာရွက်စာတမ်း modules များကို စစ်ဆေးခန်း အနေဖြင့် အသုံးပြုပါ။** လက်တွေ့လေ့ကျင့်မှုတိုင်းတွင် `docs/` ဖိုလ်ဒါတွင် ၈ ခုသော နံပါတ်ထားသော modules ပါပြီး၊ အဲဒီ modules များမှာ သာမာန်နေရာထိုင်ခုံ အဖြစ်အသုံးဝင်သည်။
- **shared lab စက် machines တို့တွင် base Docker ရုပ်ပုံကို ရှေ့ဆွဲပြီး ပြီးမြောက်မှုစောင့်ဆိုင်းမှုများကို ရှောင်ရှားပါ။**

## ဤအစည်းအဝေးကို စိတ်ကြိုက်ပြင်ဆင်ခြင်း

သင်သည် သင်ပွဲကို သင့်ရည်ရွယ်သော ပရိသတ်အတွက် အဆင်ပြေအောင် ပြင်ဆင်နိုင်သည်။ ပုံမှန်မတူညီချက်များမှာ -

- **Backend ပရိသတ်များ:** `agent.yaml`, Docker နှင့် ACR များတွင် အချိန်ပို အသုံးပြုပါ; playground demo ကို အတိုချုံးလုပ်ပါ။
- **ပြည်သူ့ဖန်တီးသူများ (Citizen-developer) ပရိသတ်များ:** scaffolding အတွက် Foundry extension UI တွင် နေပြီး CLI ခြေလှမ်းများ များကို လျော့နည်းပါ။
- **Single-track 60-minute အစီအစဉ်:** only ဝင်ရောက်စာတမ်း, demo, နှင့် Lab 01 ကို ပို့စ်ပါ။
- **Workshop သာ (slides မပါ) ပုံစံ:** lab READMEs နှစ်ခု လုံးကို ဖွင့်ပြီး မူပိုင်စာသားအဖြစ် အသုံးပြုပါ။

lab များကို တိုးချဲ့ပါက အပြောင်းအလဲများကို PR မှတင်ပြီး အခြားသင်ကြားသူများအတွက် အကျိုးရှိပါစေ။
