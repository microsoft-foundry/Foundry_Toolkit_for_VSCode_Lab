## လုံခြုံရေး

Microsoft သည် ကျွန်တော်တို့၏ဆော့ဖ်ဝဲထုတ်ကုန်များနှင့် ဝန်ဆောင်မှုများ၏လုံခြုံရေးကို ဂရုစိုက်ပါသည်၊ ၎င်းတွင် ကျွန်တော်တို့ GitHub အဖွဲ့အစည်းများရှိ မူရင်းကုဒ်သိုလှောင်ထားသောအရင်းအမြစ်များအားလုံးပါဝင်သည်။




ကျေးဇူးပြု၍ Microsoft repository များအတွက် နောက်ဆုံးလမ်းညွှန်မှုများကို
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md) တွင် စစ်ဆေးပါ။
