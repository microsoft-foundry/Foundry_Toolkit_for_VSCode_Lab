# Модул 7 - Резюме и следващи стъпки

⏱️ ~5 мин

**Поздравления!** Вие изградихте, тествахте и (ако сте на Път А) разположихте хостван AI агент с помощта на Microsoft Foundry и Foundry Toolkit за VS Code.

---

## Какво изградихте

Един **„Обясни ми като на изпълнителен директор“** агент, който:
- Получава технически доклади за инциденти или оперативни актуализации чрез HTTP (`POST /responses`)
- Превежда ги на прост език в изпълнителни резюмета
- Следва структурирана изходна форма (Какво се случи / Бизнес въздействие / Следваща стъпка)
- Отхвърля заявки извън темата и опити за подмяна на подсказки
- Работи като контейнеризиран хостван агент в Microsoft Foundry Agent Service

---

## Ключови концепции, които научихте

| Концепция | Какво практикувахте |
|---------|-------------------|
| **Архитектура на Agent Framework** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` pipeline |
| **Жизнен цикъл на хостван агент** | Scaffold → Конфигуриране → Локално тестване → Поставяне → Проверка в облака |
| **Инженеринг на системни подсказки** | Роля, аудитория, изходен формат, правила, ограничения за безопасност и примери |
| **Разлики между локален и хостван** | Идентичност (личен идентификатор срещу управлявана идентичност), крайна точка, мрежов път |
| **Граници на безопасността** | Защита срещу подмяна на подсказки, спазване на ролята, коректна обработка на крайни случаи |
| **Работен процес с Foundry Toolkit** | Създаване на проект, разполагане на модел, scaffold на агент, Agent Inspector, пускане с един клик |

### Идеи за разширяване на вашия агент

- **Добавете инструмент за дата** - Позволете на агента да включва контекст „към днешна дата“ в резюметата
- **Свържете се с база данни за инциденти** - Извличайте реални инциденти чрез функция на инструмента
- **Добавете инструмент за търсене в Bing** - Позволете на агента да търси последни новини за допълнителен контекст
- **Опитайте различни модели** - Сравнете качеството на изхода на `gpt-4.1` срещу `gpt-4.1-mini`
- **Оценете с Foundry** - Използвайте функцията за оценки, за да измерите качеството на агента в мащаб

## Изчистване на ресурси (по избор)

Ако искате да премахнете ресурсите в Azure, създадени по време на този курс:

### Опция 1: Изтрийте групата ресурси (премахва всичко)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### Опция 2: Изтрийте само хоствания агент

1. Отворете [ai.azure.com](https://ai.azure.com) → вашия проект → **Build** → **Agents**.
2. Кликнете на вашия агент → кликнете **Delete**.

### Опция 3: Изтрийте разполагането на модел

1. В страничната лента на Foundry разширете вашия проект → **Models**.
2. Десен бутон на разполагането на модела → **Delete**.

> **Бележка за разходите:** Хостваните агенти начисляват разходи само когато работят. Ако спрете или изтриете агента, няма текущи такси. Разполагането на модела може да доведе до малка такса за резервиране на капацитет - изтрийте го, ако сте приключили.
