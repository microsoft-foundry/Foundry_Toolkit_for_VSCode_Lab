# Лаборатория 02 - Многоагентен работен процес: Оценка на съвместимост резюме → работа

## Пълен учебен път

Тази документация ви превежда през процеса на изграждане, тестване и внедряване на **многоагентен работен процес**, който оценява съвместимостта между резюме и работа чрез четири специализирани агента, координирани чрез **WorkflowBuilder**.

> **Изискване:** Завършете [Лаборатория 01 - Един агент](../../lab01-single-agent/README.md) преди да започнете Лаборатория 02.
