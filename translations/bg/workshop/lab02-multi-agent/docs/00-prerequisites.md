## Какво ще изградите

В тази лабораторна работа разширявате уменията на един агент от Лаб 01, за да изградите **многокраен работен поток** - Оценител на съвпадението на автобиографията с работата.

Вмъквате **автобиография** и **описание на работата**. Четири специализирани агенти обработват входа последователно и след това връщат:
- Оценка на съвпадението (0–100 с разбивка на оценките)
- Списък на пропуснати умения и сертификати
- Персонализиран учебен път със реални връзки към Microsoft Learn за всяка пропусната област

**Работният поток използва:**
- **Microsoft Agent Framework** - `WorkflowBuilder` за последователно оркестриране на поточна линия
- **Foundry Toolkit за VS Code** - скелет, локално тестване, разгръщане
- **Модел за изкуствен интелект** (например, `gpt-4.1-mini`) - използван от всички четири агенти
- **Microsoft Learn MCP сървър** - предоставя реални връзки към учебни ресурси за всяка пропусната умение
