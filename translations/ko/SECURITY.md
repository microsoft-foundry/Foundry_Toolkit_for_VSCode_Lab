## 보안

Microsoft는 우리 소프트웨어 제품과 서비스의 보안을 매우 중요하게 생각하며,
여기에는 우리 GitHub 조직 내의 모든 소스 코드 저장소가 포함됩니다.

**보안 취약점을 공개 GitHub 이슈를 통해 신고하지 마십시오.**

보안 신고 정보, 위치, 연락처 정보, 정책 등에 대해서는,
Microsoft 저장소에 대한 최신 안내를
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md)에서 확인해 주시기 바랍니다.
