# मॉड्यूल 8 - समस्या निवारण

यह मॉड्यूल सामान्य समस्याओं के लिए एक संदर्भ गाइड है। इसे बुकमार्क करें और जब कुछ गलत हो जाए तो वापिस आएं।

---

## 1. अनुमति त्रुटियां

### 1.1 `agents/write` अनुमति अस्वीकृत

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**मूल कारण:** **प्रोजेक्ट** स्तर पर `Azure AI User` भूमिका गायब है। यह कार्यशाला की #1 त्रुटि है।

**समाधान:**
1. [portal.azure.com](https://portal.azure.com) खोलें।
2. अपने Foundry **प्रोजेक्ट** नाम के लिए खोजें → परिणाम पर क्लिक करें जिसका प्रकार **"Microsoft Foundry project"** हो (मूल खाते पर नहीं)।
3. **Access control (IAM)** → **+ Add** → **Add role assignment**।
4. भूमिका: **Azure AI User** → आगे।
5. सदस्य: स्वयं चुनें → समीक्षा + असाइन करें → समीक्षा + असाइन करें।
6. **1–2 मिनट प्रतीक्षा करें** → पुनः प्रयास करें।

> **क्यों Owner/Contributor पर्याप्त नहीं है:** ये भूमिकाएँ केवल *प्रबंधन* क्रियाएँ देती हैं। एजेंट संचालन के लिए `agents/write` *डेटा क्रिया* आवश्यक है, जो केवल `Azure AI User`, `Azure AI Developer`, या `Azure AI Owner` में होती है। देखें [Foundry RBAC docs](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry)।

### 1.2 प्रावधान के दौरान `AuthorizationFailed`

**समाधान:** अपने एडमिन से संसाधन समूह पर **Contributor** असाइन करने को कहें, या वे आपके लिए प्रोजेक्ट बनाएं और आपको इस पर **Azure AI User** प्रदान करें।

### 1.3 `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# प्रतीक्षा करें जब तक: "पंजीकृत"
```

## 2. Docker त्रुटियां

> Docker **वैकल्पिक** है। ये केवल लागू होती हैं अगर Docker Desktop इंस्टॉल है और एक्सटेंशन स्थानीय बिल्ड करता है।

### 2.1 Docker डेमॉन नहीं चल रहा

**समाधान:** Docker Desktop शुरू करें → "running" स्थिति का इंतजार करें → `docker info` से सत्यापित करें → पुनः प्रयास करें।

### 2.2 निर्भरता त्रुटियों के साथ बिल्ड असफल

**समाधान:** `requirements.txt` वर्तनी जांचें, पहले स्थानीय रूप से परीक्षण करें: `pip install -r requirements.txt`।

### 2.3 प्लेटफ़ॉर्म असंगति (Apple Silicon)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

## 3. प्रमाणीकरण त्रुटियां

### 3.1 `DefaultAzureCredential` विफल

**समाधान (क्रम में प्रयास करें):**
1. `az login` (पुनः प्रमाणीकरण)
2. `az account set --subscription "<id>"` (सही सदस्यता)
3. VS Code → Accounts → Sign Out → पुनः Sign In करें
4. सत्यापित करें: `az account get-access-token --resource https://cognitiveservices.azure.com`

### 3.2 टोकन स्थानीय रूप से काम करता है लेकिन होस्टेड नहीं

**उम्मीद:** होस्टेड एजेंट सिस्टम-प्रबंधित पहचान का उपयोग करते हैं, आपके क्रेडेंशियल नहीं। यदि होस्टेड एजेंट को प्रमाणीकरण त्रुटियाँ मिलती हैं:
- `agent.yaml` में `AZURE_AI_PROJECT_ENDPOINT` सही है यह जांचें
- जांचें कि प्रोजेक्ट की प्रबंधित पहचान को मॉडल एक्सेस है

## 4. मॉडल त्रुटियां

### 4.1 मॉडल डिप्लॉयमेंट नहीं मिला

**समाधान:** नाम **केस-संवेदी** है। `.env` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` को Foundry साइडबार → Models में सटीक नाम से मिलाएं।

### 4.2 अप्रत्याशित मॉडल आउटपुट

**समाधान:** `main.py` में `AGENT_INSTRUCTIONS` समीक्षा करें (क्या ट्रंकेटेड नहीं है?)। अलग मॉडल आज़माएं (`gpt-4.1` बनाम `gpt-4.1-mini`)।

---

## 5. डिप्लॉयमेंट त्रुटियां

### 5.1 ACR पुल अनधिकृत

**समाधान:** Azure Portal → Container Registry → Access control (IAM) → Foundry प्रोजेक्ट की प्रबंधित पहचान को **AcrPull** भूमिका जोड़ें।

### 5.2 एजेंट शुरू होने में विफल (रहता है "Pending" या "Failed")

साइडबार में कंटेनर लॉग्स जांचें। सामान्य कारण:

| लॉग संदेश | समाधान |
|-------------|-----|
| `ModuleNotFoundError` | `requirements.txt` में गायब पैकेज जोड़ें, पुनः डिप्लॉय करें |
| `KeyError: 'AZURE_AI_PROJECT_ENDPOINT'` | `agent.yaml` में `environment_variables` के तहत env var जोड़ें |
| `Address already in use` | सुनिश्चित करें कि केवल एक प्रक्रिया पोर्ट 8088 से बाइंड हो |

### 5.3 डिप्लॉयमेंट समय समाप्त हो जाता है

**समाधान:** इंटरनेट कनेक्शन जांचें। पहला डिप्लॉयमेंट >100MB भेजता है। प्रॉक्सी के पीछे? Docker Desktop प्रॉक्सी सेटिंग्स कॉन्फ़िगर करें।

## 6. पथ बी - Foundry लोकल

### 6.1 Foundry लोकल शुरू नहीं होगा

| समस्या | समाधान |
|-------|-----|
| `foundry: command not found` | पुनः इंस्टॉल करें: `winget install Microsoft.FoundryLocal` |
| अपर्याप्त संसाधन | Foundry Local को ~4GB RAM खाली चाहिए। अन्य ऐप बंद करें। |
| मॉडल डाउनलोड विफल | डिस्क स्थान देखें (मॉडल 2–8 GB हैं)। पुनः प्रयास करें: `foundry local models pull <name>` |

### 6.2 Foundry लोकल मॉडल त्रुटियां

| समस्या | समाधान |
|-------|-----|
| धीमी प्रतिक्रियाएं | अपेक्षित - लोकल मॉडल CPU पर चलते हैं जब तक कि आपके पास GPU न हो। धैर्य रखें। |
| कम गुणवत्ता आउटपुट | यदि आपका हार्डवेयर अनुमति देता है तो बड़ा मॉडल आज़माएं। `phi-4-mini` अच्छा संतुलन है। |
| कनेक्शन अस्वीकृत | पुष्टि करें कि Foundry Local चल रहा है: `foundry local status`। जरूरत हो तो पुनः चालू करें। |

## 7. त्वरित संदर्भ: RBAC भूमिकाएं

| भूमिका | क्षेत्र | प्रदान करता है |
|------|-------|--------|
| **Azure AI User** | प्रोजेक्ट | डेटा क्रियाएँ: `agents/write`, `agents/read` |
| **Azure AI Developer** | प्रोजेक्ट/अकाउंट | डेटा क्रियाएँ + प्रोजेक्ट निर्माण |
| **Azure AI Owner** | अकाउंट | पूर्ण पहुंच + भूमिका प्रबंधन |
| **Contributor** | सदस्यता/आरजी | केवल प्रबंधन क्रियाएँ (**कोई** डेटा क्रियाएँ नहीं) |
| **Owner** | सदस्यता/आरजी | प्रबंधन + भूमिका असाइनमेंट (**कोई** डेटा क्रियाएँ नहीं) |
