# मॉड्यूल 7 - सारांश और अगले कदम

⏱️ ~5 मिनट

**बधाई हो!** आपने Microsoft Foundry और Foundry Toolkit for VS Code का उपयोग करके एक होस्ट किए गए AI एजेंट का निर्माण, परीक्षण किया है और (अगर पथ A पर हैं) तैनात भी किया है।

---

## आपने क्या बनाया

एक **"एक्जीक्यूटिव की तरह समझाएं"** एजेंट जो:
- तकनीकी घटना रिपोर्ट या परिचालन अपडेट HTTP (`POST /responses`) के माध्यम से प्राप्त करता है
- उन्हें सरल भाषा में कार्यकारी सारांश में अनुवादित करता है
- एक संरचित आउटपुट प्रारूप का पालन करता है (क्या हुआ / व्यवसाय पर प्रभाव / अगला कदम)
- विषय-विहीन अनुरोधों और प्रॉम्प्ट इंजेक्शन प्रयासों को अस्वीकार करता है
- Microsoft Foundry Agent सेवा में कंटेनराइज्ड होस्टेड एजेंट के रूप में चलता है

---

## मुख्य अवधारणाएँ जो सीखी गईं

| अवधारणा | आपने क्या अभ्यास किया |
|---------|-------------------|
| **एजेंट फ्रेमवर्क आर्किटेक्चर** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` पाइपलाइन |
| **होस्टेड एजेंट जीवनचक्र** | Scaffold → Configure → स्थानीय परीक्षण → तैनात करें → क्लाउड में सत्यापित करें |
| **सिस्टम प्रॉम्प्ट इंजीनियरिंग** | भूमिका, दर्शक, आउटपुट प्रारूप, नियम, सुरक्षा बाधाएं, और उदाहरण |
| **स्थानीय बनाम होस्टेड अंतर** | पहचान (व्यक्तिगत क्रेडेंशियल बनाम प्रबंधित पहचान), एंडपॉइंट, नेटवर्क पथ |
| **सुरक्षा सीमाएं** | प्रॉम्प्ट इंजेक्शन रक्षा, भूमिका पालन, किनारे मामलों को सहजता से संभालना |
| **Foundry Toolkit कार्यप्रवाह** | परियोजना निर्माण, मॉडल तैनाती, एजेंट स्कैफ़ोल्डिंग, एजेंट इंस्पेक्टर, एक-क्लिक तैनाती |

### अपने एजेंट को बढ़ाने के विचार

- **एक तारीख टूल जोड़ें** - एजेंट को "आज के अनुसार" संदर्भ सारांशों में शामिल करने दें
- **एक घटना डेटाबेस से कनेक्ट करें** - एक टूल फ़ंक्शन के माध्यम से वास्तविक घटना विवरण निकालें
- **एक बिंग ग्राउंडिंग टूल जोड़ें** - एजेंट को अतिरिक्त संदर्भ के लिए हाल की खबरें खोजने दें
- **विभिन्न मॉडल आज़माएं** - `gpt-4.1` बनाम `gpt-4.1-mini` आउटपुट गुणवत्ता की तुलना करें
- **Foundry के साथ मूल्यांकन करें** - एजेंट गुणवत्ता को पैमाने पर मापने के लिए Evaluations फीचर का उपयोग करें

### पथ B उपयोगकर्ताओं के लिए: क्लाउड तैनाती पर अपग्रेड करें

जब आप क्लाउड पर तैनात करने के लिए तैयार हों:
1. एक Azure सदस्यता प्राप्त करें ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [मॉड्यूल 01, सेटअप](01-setup.md#step-2-set-up-based-on-your-access) पूरा करें (परियोजना बनाएं, मॉडल तैनात करें, RBAC असाइन करें)
3. अपने `.env` को Foundry परियोजना एंडपॉइंट और मॉडल तैनाती नाम के साथ अपडेट करें
4. [मॉड्यूल 05 - Foundry पर तैनात करें](05-deploy-to-foundry.md) से जारी रखें

## संसाधनों को साफ करें (वैकल्पिक)

यदि आप इस कार्यशाला के दौरान बनाए गए Azure संसाधनों को हटाना चाहते हैं:

### विकल्प 1: रिसोर्स ग्रुप हटाएं (सब कुछ हटा देता है)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### विकल्प 2: केवल होस्टेड एजेंट को हटाएं

1. [ai.azure.com](https://ai.azure.com) खोलें → अपनी परियोजना → **Build** → **Agents**।
2. अपने एजेंट पर क्लिक करें → **Delete** पर क्लिक करें।

### विकल्प 3: मॉडल तैनाती हटाएं

1. Foundry साइडबार में, अपनी परियोजना फैलाएं → **Models**।
2. मॉडल तैनाती पर राइट-क्लिक करें → **Delete**।

> **लागत नोट:** होस्टेड एजेंट केवल चलने पर लागत लगाते हैं। यदि आप एजेंट को रोकते हैं या हटा देते हैं, तो कोई लगातार शुल्क नहीं है। मॉडल तैनाती में आरक्षित क्षमता के लिए थोड़ा शुल्क लग सकता है - यदि आपका काम समाप्त हो गया है तो इसे हटा दें।
