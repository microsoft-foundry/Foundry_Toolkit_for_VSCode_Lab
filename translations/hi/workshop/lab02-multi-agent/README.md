# लॅब 02 - मल्टी-एजेंट वर्कफ़्लो: रिज़्यूमे → नौकरी उपयुक्तता मूल्यांकनकर्ता

## अवलोकन

इस व्यावहारिक प्रयोगशाला में, आप VS कोड में Foundry Toolkit का उपयोग करके एक **वर्कफ़्लो-प्रथम मल्टी-एजेंट ऐप** बनाएंगे और इसे Microsoft Foundry Agent Service में तैनात करेंगे।

**आप क्या बनाएंगे:** एक रिज़्यूमे → नौकरी उपयुक्तता मूल्यांकनकर्ता जो रिज़्यूमे और नौकरी विवरण को पार्स करता है, मेल का स्कोर करता है, और Microsoft Learn संसाधनों का उपयोग करके एक व्यक्तिगत लर्निंग रोडमैप बनाता है।

**यह कैसे काम करता है:**
1. उपयोगकर्ता एक रिज़्यूमे और नौकरी विवरण पेस्ट करता है।
2. **ResumeParser** रिज़्यूमे को पार्स करता है और नौकरी विवरण को बिल्कुल वैसे ही `[JOB DESCRIPTION PASS-THROUGH]` सेक्शन में कॉपी करता है।
3. **JD Agent** पास-थ्रू से संरचित आवश्यकताएँ निकालता है, फिर `[PARSED RESUME]` को आगे `[PARSED RESUME PASS-THROUGH]` के रूप में भेजता है।
4. **MatchingAgent** `[PARSED RESUME PASS-THROUGH]` की तुलना `[JD REQUIREMENTS]` से करता है और उपयुक्तता स्कोर बनाता है।
5. **GapAnalyzer** अंतराल को व्यावहारिक रोडमैप में बदलता है और MCP के माध्यम से वास्तविक Microsoft Learn लिंक प्राप्त करता है।

## भाग 2: वर्कफ़्लो बनाएं और परीक्षण करें

1. Foundry Toolkit विज़ार्ड का उपयोग करके वर्कफ़्लो-आधारित प्रोजेक्ट स्कैफोल्ड करें।
2. `PersonalCareerCopilot/main.py` से प्रॉम्प्ट ब्लॉक्स और वर्कफ़्लो ग्राफ़ को कॉपी करके अपने कार्यक्षेत्र में चिपकाएं।
3. एजेंट इंस्पेक्टर के साथ स्थानीय रूप से चलाएं और सभी चार एजेंट्स के साथ-साथ MCP टूल सत्यापित करें।
4. स्थानीय परीक्षण सफल होने पर होस्टेड एजेंट को Foundry पर तैनात करें।
