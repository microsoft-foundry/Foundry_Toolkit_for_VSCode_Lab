## सुरक्षा

माइक्रोसॉफ्ट हमारे सॉफ़्टवेयर उत्पादों और सेवाओं की सुरक्षा को गंभीरता से लेता है, जिसमें
हमारे GitHub संगठनों में सभी स्रोत कोड भंडार शामिल हैं।

**कृपया सार्वजनिक GitHub मुद्दों के माध्यम से सुरक्षा कमजोरियों की सूचना न दें।**

सुरक्षा रिपोर्टिंग जानकारी, स्थान, संपर्क जानकारी, और नीतियों के लिए,
कृपया Microsoft रिपॉजिटरीज के नवीनतम निर्देशों की समीक्षा करें
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md) पर।
