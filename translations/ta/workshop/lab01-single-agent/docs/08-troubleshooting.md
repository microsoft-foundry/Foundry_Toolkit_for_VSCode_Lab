# தொகுதி 8 - பிழைகள் தீர்வு

இந்த தொகுதி பொதுவான பிரச்சனைகள் பற்றி ஒரு குறிப்புரை வழிகாட்டி ஆகும். தவறு ஏற்பட்டால் இதை புத்தகமிடவும், திரும்பவும் பின்பற்றவும்.

---

## 1. அனுமதி பிழைகள்

### 1.1 `agents/write` அனுமதி மறுக்கப்பட்டது

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**மூல காரணம்:** **திட்டம்** நிலை மட்டத்தில் `Azure AI User` பதிவேட்டுக்குரிய பங்கு இல்லை. இது #1 பயிற்சி பிழை ஆகும்.

**திருத்தம்:**
1. [portal.azure.com](https://portal.azure.com) திறக்கவும்.
2. உங்கள் Foundry **திட்டம்** பெயரை தேடவும் → **"Microsoft Foundry project"** வகை முடிவை சொடுக்கவும் (தந்தை கணக்கு இல்லை).
3. **அணுகல் கட்டுப்பாடு (IAM)** → **+ சேர்** → **பங்கு ஒதுக்கீடு சேர்**.
4. பங்கு: **Azure AI User** → அடுத்து.
5. உறுப்பினர்கள்: தங்களை தேர்ந்தெடுக்கவும் → மதிப்பாய்வுசெய் + ஒதுக்கீடு → மதிப்பாய்வுசெய் + ஒதுக்கீடு.
6. **1–2 நிமிடங்கள் காத்திருக்கவும்** → மீண்டும் முயற்சி செய்யவும்.

> **ஏன் Owner/Contributor போதாது:** இவை *மேலாண்மை* நடவடிக்கைகள் மட்டுமே வழங்குகின்றன. முகவர் செயல்பாடுகள் `agents/write` *தரவு நடவடிக்கை* தேவை, இது `Azure AI User`, `Azure AI Developer`, அல்லது `Azure AI Owner` இல் மட்டுமே உள்ளது. காட்டு [Foundry RBAC ஆவணங்கள்](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry).

### 1.2 `AuthorizationFailed` வழங்கும் போது

**திருத்தம்:** உங்கள் நிர்வாகியிடம் வளக்குழுவில் **Contributor** பணியை ஒதுக்குமாறு கேளுங்கள், அல்லது அவர் உங்களுக்காக திட்டத்தை உருவாக்கி அதில் **Azure AI User** அளிக்கவும்.

### 1.3 `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# காத்திருக்கவும்: "பதிவுசெய்யப்பட்டது"
```

## 2. Docker பிழைகள்

> Docker **காக ஆகும்**. இவை Docker Desktop நிறுவப்பட்டு நீட்சிக் கட்டுமானம் முயற்சிக்கும் போது மட்டும் பொருந்தும்.

### 2.1 Docker daemon இயங்கவில்லை

**திருத்தம்:** Docker Desktop தொடங்கவும் → "இயங்கி 있음" நிலையை காத்திருங்கள் → `docker info` மூலம் சரிபார்க்கவும் → மீண்டும் முயற்சி செய்யவும்.

### 2.2 கட்டமைப்பு சார்பு பிழைகள்

**திருத்தம்:** `requirements.txt` எழுத்துப்பிழைகளை சரிபார்க்கவும், முதலில் உள்ளூராக சோதனை செய்யவும்: `pip install -r requirements.txt`.

### 2.3 தள பொருத்தமின்மை (ஆப்பிள் சிலிகான்)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

## 3. அங்கீகார பிழைகள்

### 3.1 `DefaultAzureCredential` தோல்வி

**திருத்தம் (ஆரம்பத்தில் முயற்சி செய்யவும்):**
1. `az login` (மறு அங்கீகாரம்)
2. `az account set --subscription "<id>"` (சரியான சந்தா)
3. VS Code → கணக்குகள் → வெளியேறு → மீண்டும் உள்நுழைவும்
4. சரிபார்க்கவும்: `az account get-access-token --resource https://cognitiveservices.azure.com`

### 3.2 டோக்கன் உள்ளூரில் வேலை செய்கிறது ஆனால் ஹோஸ்ட் செய்யப்படவில்லை

**எதிர்பார்ப்பு:** ஹோஸ்ட் செயலிகள் கணினி நிர்வகிக்கப்பட்ட அடையாளத்தைப் பயன்படுத்துகின்றன, உங்கள் அங்கீகாரம் அல்ல. ஹோஸ்ட் செயலி அங்கீகார பிழைகள் பெற்றால்:
- `agent.yaml` இல் `AZURE_AI_PROJECT_ENDPOINT` சரியானதா என்று சரிபார்க்கவும்
- திட்டத்தின் நிர்வகிக்கப்பட்ட அடையாளத்துக்கு மாதிரி அனுமதி இருக்கிறதா என்று பார்

## 4. மாதிரி பிழைகள்

### 4.1 மாதிரி орналுத்தல் கிடைக்கவில்லை

**திருத்தம்:** பெயர் **தலைப்பு/காணொளி உணர்த்தல்** உள்ளது. `.env` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` ஐ Foundry பக்கவிளக்கத்தில் உள்ள Models உடன் ஒப்பிடவும்.

### 4.2 எதிர்பாராத மாதிரி வெளியீடு

**திருத்தம்:** `main.py` இல் `AGENT_INSTRUCTIONS` ஐ மதிப்பாய்வு செய்யவும் (அகற்றப்பட்டதல்லவா?). வேறு மாதிரியை முயற்சி செய்யவும் (`gpt-4.1` மற்றும் `gpt-4.1-mini`).

## 5. орналுத்தல் பிழைகள்

### 5.1 ACR இழுப்பு அனுமதி மறுக்கப்பட்டது

**திருத்தம்:** Azure Portal → Container Registry → அணுகல் கட்டுப்பாடு (IAM) → Foundry திட்டத்தின் நிர்வகிக்கப்பட்ட அடையாளத்திற்கு **AcrPull** பங்கு சேர்க்கவும்.

### 5.2 முகவர் துவங்க தோல்வி (எப்போதும் "பேண்டிங்" அல்லது "தோல்வி" உள்ளிருந்து )

பக்கவிளக்கத்தில் உள்ள கப்பல் பதிவுகளை சரிபார்க்கவும். பொதுவான காரணங்கள்:

| பதிவுச் செய்தி | திருத்தம் |
|-------------|-----|
| `ModuleNotFoundError` | `requirements.txt` இல் குறைந்த தொகுதியைச் சேர்க்கவும், மீண்டும் தொகுக்கவும் |
| `KeyError: 'AZURE_AI_PROJECT_ENDPOINT'` | `agent.yaml` இல் `environment_variables` உட்பட எண் மாறியைச் சேர்க்கவும் |
| `Address already in use` | 8088 போர்ட்டுக்கு ஒரு செயலி மட்டுமே பிணைக்கப்பட்டிருக்க வேண்டும் சோதிக்கவும் |

### 5.3 орналுத்தல் நேரம் முடிவடைகிறது

**திருத்தம்:** இன்டெர்நெட் இணைப்பைச் சரிபார்க்கவும். முதலாவது இடம் 100MB-ஐ மீறுகிறது. ஒரு பிரதிநிதி பின்னணி உள்ளதா? Docker Desktop பிரதிநிதி அமைப்புகளை அமைக்கவும்.

## 6. பாதை B - Foundry உள்ளூர்

### 6.1 Foundry உள்ளூர் துவங்கவில்லை

| பிரச்சனை | திருத்தம் |
|-------|-----|
| `foundry: command not found` | மீண்டும் நிறுவவும்: `winget install Microsoft.FoundryLocal` |
| போதுமான வளங்கள் இல்லை | Foundry உள்ளூர் சுமார் 4GB RAM இலவசம் தேவை. மற்ற பயன்பாடுகளை மூடு. |
| மாதிரி பதிவேற்று தோல்வி | வட்டு இடத்தைச் சரிபார்க்கவும் (மாதிரிகள் 2–8 GB). மீண்டும் முயற்சி செய்யவும்: `foundry local models pull <name>` |

### 6.2 Foundry உள்ளூர் மாதிரி பிழைகள்

| பிரச்சனை | திருத்தம் |
|-------|-----|
| மெதுவான பதில்கள் | எதிர்பார்க்கப்பட்டது - உள்ளூர் மாதிரிகள் CPUல் இயங்கும், உங்களுக்கு GPU இல்லையெனில். பொறுமையாக இரு. |
| தரமின்றி வெளியீடு | உங்கள் உற்பவியுடன் பெரிய மாதிரியை முயற்சி செய்யவும். `phi-4-mini` நல்ல சமநிலை. |
| இணைப்பு மறுக்கப்பட்டது | Foundry உள்ளூர் இயங்குவதாக உறுதி செய்யவும்: `foundry local status`. தேவையானால் மீண்டும் துவங்கவும். |

## 7. விரைவு குறிப்புரை: RBAC பங்குகள்

| பங்கு | பரப்பளம் | வழங்குகிறது |
|------|-------|--------|
| **Azure AI User** | திட்டம் | தரவு நடவடிக்கைகள்: `agents/write`, `agents/read` |
| **Azure AI Developer** | திட்டம்/கணக்கு | தரவு நடவடிக்கைகள் + திட்ட உருவாக்கம் |
| **Azure AI Owner** | கணக்கு | முழு அணுகல் + பங்கு நிர்வாகம் |
| **Contributor** | சந்தா/ஆர்ஜி | மேலாண்மை நடவடிக்கைகள் மட்டும் (**தரவு நடவடிக்கைகள் இல்லை**) |
| **Owner** | சந்தா/ஆர்ஜி | மேலாண்மை + பங்கு ஒதுக்கீடு (**தரவு நடவடிக்கைகள் இல்லை**) |
