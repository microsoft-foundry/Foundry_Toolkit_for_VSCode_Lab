# Module 7 - சுருக்கம் மற்றும் அடுத்த படிகள்

⏱️ ~5 நிமிடங்கள்

**வாழ்த்துக்கள்!** நீங்கள் Microsoft Foundry மற்றும் Foundry Toolkit for VS Code பயன்படுத்தி ஒரு ஹோஸ்ட் செய்யப்பட்ட AI முகவரியை உருவாக்கி, சோதித்து, (பாதை A இல் இருந்தால்) நியமித்துவிட்டீர்கள்.

---

## நீங்கள் உருவாக்கியது என்ன

ஒரு **"நான் நிர்வாகி போல விளக்குகிறேன்"** முகவர், அது:
- தொழில்நுட்ப நிகழ்வு அறிக்கைகள் அல்லது செயல்பாட்டு புதுப்பிப்புகளை HTTP வழியாக பெறுகிறது (`POST /responses`)
- அவற்றை எளிய மொழி நிர்வாக சுருக்கங்களாக மொழிபெயர்க்கிறது
- கட்டமைக்கப்பட்ட வெளியீட்டு வடிவத்தை பின்பற்றுகிறது (என்ன நடந்தது / வணிக தாக்கம் / அடுத்த படி)
- தலைப்பிற்கு வெளியான கோரிக்கைகள் மற்றும் ப்ராம்ட் ஊக்கங்களை மறுக்கிறது
- Microsoft Foundry Agent Service இல் கன்டெய்னரை பயன்படுத்தி ஹோஸ்ட் செய்யப்பட்ட முகவராக இயங்குகிறது

---

## முக்கியக் கருத்துக்கள்

| கருத்து | நீங்கள் பயிற்சி பெற்றது |
|---------|--------------------|
| **முகவர் கட்டமைப்பு வடிவமைப்பு** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` குழாய் |
| **ஹோஸ்ட் முகவர் வாழ்க்கைசுழற்சி** | Scaffold → அமைக்க → உள்ளூர் சோதனை → நியமிக்க → மேகத்தில் சரிபார்க்க |
| **கட்டமைப்பு ப்ராம்ட் பொறியியல்** | வேடிக்கை, பார்வையாளர், வெளியீட்டு வடிவம், விதிகள், பாதுகாப்பு வரம்புகள் மற்றும் உதாரணங்கள் |
| **உள்ளூர் மற்றும் ஹோஸ்ட் வேறுபாடுகள்** | அடையாளம் (தனிப்பட்ட அடையாளம் மற்றும் பராமரிக்கப்பட்ட அடையாளம்), முடிவுத்தளம், நெட்வொர்க் பாதை |
| **பாதுகாப்பு எல்லைகள்** | ப்ராம்ட் ஊக்கிகள் பாதுகாப்பு, வேடிக்கை பின்பற்றுதல், நுட்பமான நிலைகளை மென்மையாக கையாள்தல் |
| **Foundry Toolkit பணிவழி** | திட்ட உருவாக்கம், மாதிரியை நியமித்தல், முகவர் ஸ்காஃபோல்டிங், முகவர் இன்ஸ்பெக்டர், ஒரே கிளிக் மூலம் நியமனம் |

### உங்கள் முகவரை விரிவுபடுத்தக் கருத்துக்கள்

- **தேதி கருவி சேர்க்கவும்** - "இன்று வரை" என்பதைக் கொண்டு சுருக்கங்களில் முகவரைச் சேர்க்க விடுமாறு செய்யவும்
- **ஒரு நிகழ்வு தரவுத்தளத்தை இணைக்கவும்** - கருவி செயல்பாட்டின் மூலம் உண்மையான நிகழ்வு விவரங்களை ஈட்டி
- **பிங் அடித்தள கருவி சேர்க்கவும்** - கூடுதல் சூழ்நிலையில் சமீபத்திய செய்திகளை முகவர் தேட விடுமாறு செய்யவும்
- **விநியோகிக்கப்பட்ட வகைகளை முயற்சிக்கவும்** - `gpt-4.1` மற்றும் `gpt-4.1-mini` வெளியீட்டு தரத்தை ஒப்பிடவும்
- **Foundry உடன் மதிப்பீடு செய்யவும்** - முகவர் தரத்தை பரிமாணத்தில் அளக்க மதிப்பீடுகள் அம்சத்தை பயன்படுத்தவும்

### பாதை B பயனாளிகளுக்கு: மேக நியமனத்திற்கு மேம்படுத்தவும்

நீங்கள் மேகத்தில் நியமிக்கத் தயாராக உள்ளபோது:
1. ஒரு Azure சந்தாவை பெறவும் ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [Module 01, அமைப்பு](01-setup.md#step-2-set-up-based-on-your-access) முழுமையாக செய்யவும் (திட்டம் உருவாக்கவும், மாடல் நியமிக்கவும், RBAC ஒதுக்கவும்)
3. உங்கள் `.env` கோப்பை Foundry திட்ட முடிவுத்தளம் மற்றும் மாடல் நியமிப்பு பெயரால் புதுப்பிக்கவும்
4. [Module 05 - Foundryக்கு நியமிக்க](05-deploy-to-foundry.md) இடத்தில் இருந்து தொடரவும்

## வளங்களை சுத்தப்படுத்தவும் (விருப்பமானது)

இந்தப் பயிற்சிக்குழுவின் போது உருவாக்கப்பட்ட Azure வளங்களை நீக்க விரும்பினால்:

### விருப்பம் 1: வளக் குழுவை அழிக்கவும் (எல்லாவற்றையும் நீக்குகிறது)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### விருப்பம் 2: ஹோஸ்ட் செய்யப்பட்ட முகவரையே அழிக்கவும்

1. [ai.azure.com](https://ai.azure.com) → உங்கள் திட்டம் → **Build** → **Agents** என்பதை திறக்கவும்.
2. உங்கள் முகவரியை கிளிக் செய்து → **Delete** அழிய விடவும்.

### விருப்பம் 3: மாடல் நியமிப்பை அழிக்கவும்

1. Foundry பக்கத்தருகில் உங்கள் திட்டத்தை விரிவாக்கவும் → **Models**.
2. மாடல் நியமிப்பை வலது கிளிக் செய்து → **Delete** செய்யவும்.

> **செலவு குறிப்புரை:** ஹோஸ்ட் செய்யப்பட்ட முகவர்கள் இயக்கும் பொழுதே செலவு ஏற்படுகிறது. நீங்கள் முகவரியை நிறுத்தவோ அல்லது அழிக்கவோ செய்தால் தொடர்ச்சியான கட்டணம் இல்லை. மாடல் நியமிப்பு ஒதுக்கப்பட்ட திறனுக்காக சற்று கட்டணம் ஏற்படக்கூடும் - நீங்கள் முடிந்தால் அதனை நீக்கவும்.
