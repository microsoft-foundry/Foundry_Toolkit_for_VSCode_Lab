# Module 9 - சுருக்கம் மற்றும் அடுத்த படிகள்

⏱️ ~5 நிமிடம்

**வாழ்த்து!** நீங்கள் Microsoft Foundry மற்றும் Foundry Toolkit for VS Code பயன்படுத்தி ஒரு பன்முக செயல் திட்டத்தை உருவாக்கி, சோதித்து, (பாதை A இல் இருந்தால்) வெளியிட்டுள்ளீர்.

---

## நீங்கள் உருவாக்கியது

**Resume → வேலை பொருந்துதன்மை மதிப்பாய்வாளர்** - ஒரு பன்முக செயல் திட்டம், அது:
- HTTP (`POST /responses`) மூலம் ஒரு resumes மற்றும் வேலை விளக்கமாக அடைகிறது
- ஒவ்வொரு செயல் காரரும் அடுத்தவருக்கு தரவை வழங்கும் வகையில் நான்கு சிறப்பு செயல் காரர்கள் தொடர்ச்சியான குழாயில் இயங்குகிறார்கள்
- பொருத்தப்பெண் (0–100 உடன் விரிவாக்கம்), திறன் மற்றும் சான்றிதழ் குறைபாடுகள் பட்டியல், மற்றும் ஒவ்வொரு குறைபாடுக்கும் உண்மையான Microsoft Learn இணைப்புகளுடன் தனிப்பட்ட கற்றல் வழிகாட்டி வழங்குகிறது
- ஒவ்வொரு கண்டறியப்பட்ட திறன் குறைபாட்டுக்கும் அதிகாரப்பூர்வ கற்றல் வளங்களை பெற Microsoft Learn MCP சேவையகத்தை (`https://learn.microsoft.com/api/mcp`) அழைக்கிறது
- Microsoft Foundry Agent சேவையகத்தில் ஒரு ஒற்றை கன்டெய்னரை அடிப்படையாக்கி இயங்கும்

## முக்கியக் கருத்துக்கள் கற்றுக்கொண்டவை

| கருத்து | நீங்கள் பயிற்சி பெற்றது |
|---------|-------------------|
| **பன்முக செயல் ஒருங்கிணைப்பு** | `WorkflowBuilder` தொடர்ச்சி குழாயுடன் `add_edge()` |
| **செயல் காரர் சிறப்புறுதி** | நான்கு கவனமான செயல் காரர்கள் ஒரு பொது நோக்க செயல் காரரை விட சிறந்தது |
| **உள்ளடக்க வழிப்படுத்தி மாதிரி** | ResumeParser ஒரு வழிப்படுத்தி என இரட்டை பங்கு வகிக்கிறது - அது JD உரையை `[JOB DESCRIPTION PASS-THROUGH]` பகுதியிலூடு பாதுகாக்கிறது, ஆகவே கீழ்க்காணும் செயல் காரர்கள் அதை அணுக முடியும் (`context_mode="last_agent"` என்பதனால், `start_executor` மட்டுமே பயன்பாட்டாளரின் அசல் செய்தியை காண்கிறது என்பதால் இது அவசியம்) |
| **உள்ளடக்க ஒப்படைப்பு மாதிரி** | JD Agent `[PARSED RESUME PASS-THROUGH]` ஐ முன் அனுப்புகிறது, ஆகவே MatchingAgent இரு hồḷ Private மட்டும் பெறுகிறது; fan-in வரைபடங்கள் விளைவிக்கும் OR-அர்த்த உணர்வு இரட்டைத் தூண்டுதலை தவிர்க்கிறது |
| **MCP கருவி ஒருங்கிணைப்பு** | `@tool` + `streamable_http_client` மூலம் வெளி MCP சேவையகத்தை அழைத்தல் |
| **ப도ர்ந்துள்ள செயல் காரர் வாழ்நாள்** | Scaffold → கட்டமைப்பு → உள்ளூரில் சோதனை → வெளியீடு → மேகத்தில் உறுதி |
| **`context_mode="last_agent"`** | ஒவ்வொரு செய்வான் தன் நேரடி முன்னோடியின் வெளியீட்டை மட்டுமே காண்கிறது |
| **Foundry Toolkit செயல் திட்டம்** | Scaffold wizard, Agent Inspector, Workflow Visualizer, ஒரு கிளிக் வெளியீடு |

### இந்த செயல்முறையை விரிவுப்படுத்த சில யோசனைகள்

- **ஐந்தாவது செயல் காரரை சேர்க்கவும்** - குறைபாடு அறிக்கைக்கு அடிப்படையாகக் கொண்டு சாத்தியமான நேர்காணல் கேள்விகளை உருவாக்கும் நேர்காணல் பயிற்சியாளர்
- **Bing நிலை கருவியை சேர்க்கவும்** - JD Agent வேலைவாய்ப்பு அறிவிக்கப்பட்டுள்ளவற்றை தேடி தேவைகளை மேம்படுத்த அனுமதிக்கவும்
- **ஒரு ரெசுமே தரவுத்தளத்தை இணைக்கவும்** - தனிப்பயன் `@tool` மூலம் பட்டியலிடப்பட்ட வேட்பாளர் சுயவிவரங்களை பெறவும்
- **வேறுபட்ட மாதிரிகளை முயற்சிக்கவும்** - `gpt-4.1` மற்றும் `gpt-4.1-mini` வெளியீட்டு தரம் மற்றும் தாமதத்தை ஒப்பிடுங்கள்
- **Foundry உடன் மதிப்பீடு செய்யவும்** - மதிப்பீடு அம்சத்தை பயன்படுத்தி பொருத்த அறிக்கைகளை பொன்மதி தரவு தொகுப்புடன் மதிப்பிடுங்கள்

### பாதை B பயனர்களுக்கு: மேக வெளியீட்டிற்கு மேம்படுத்தவும்

மேகத்தில் வெளியிட தயார் என்றால்:
1. Azure சந்தாவை பெறுங்கள் ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [Lab 01, Module 01](../../lab01-single-agent/docs/01-setup.md) முடிக்கவும் (திட்டம் உருவாக்கவும், மாதிரியை வெளியிடவும், RBAC ஒதுக்கவும்)
3. உங்கள் `.env` கோப்பில் Foundry திட்ட முடிவுநிலை மற்றும் மாதிரி வெளியீட்டுப் பெயரை புதுப்பிக்கவும்
4. [Module 06 - Deploy to Foundry](06-deploy-to-foundry.md) தொடங்கவும்

## வளங்களை சுத்தம் செய்யவும் (விருப்பமானது)

இந்த ப றயன்பாட்டின் போது உருவாக்கப்பட்ட Azure வளங்களை நீக்க விரும்பினால்:

### விருப்பம் 1: வளக் குழுவை நீக்கவும் (எல்லாவற்றையும் நீக்கும்)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### விருப்பம் 2: செய்யப்பட்ட செயல் காரரை மட்டும் நீக்கவும்

1. [ai.azure.com](https://ai.azure.com) → உங்கள் திட்டம் → **Build** → **Agents** என்பதை திறக்கவும்.
2. **PersonalCareerCopilot** ஐ கண்டுபிடித்து → **Delete** கிளிக் செய்யவும்.

### விருப்பம் 3: மாதிரி வெளியீட்டை நீக்கவும்

1. Foundry பக்கப்பட்டியில், உங்கள் திட்டத்தை விரிவுபடுத்தவும் → **Models**.
2. மாதிரியை வலது கிளிக் செய்து → **Delete** செய்யவும்.

> **செலவு குறிப்பாக:** கட்டப்படும் செயல் காரர்கள் இயங்கும்போது மட்டுமே செலவு ஏற்படும். நீங்கள் செயல் காரரை நிறுத்தவோ அல்லது நீக்கவோ செய்தால் தொடர்ந்த கட்டணம் இல்லாது. மாதிரி வெளியீடு பாதுகாக்கப்பட்ட திறனுக்காக சிறிய கட்டணத்தை ஏற்படுத்தலாம் - முடிந்தவுடன் அதை நீக்கவும்.
