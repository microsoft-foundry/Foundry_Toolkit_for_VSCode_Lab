# Module 7 - விளையாட்டு майதானத்தில்ச் சரிபார்க்கவும்

⏱️ ~10 நிமிடங்கள்

இந்த மொடியூலில், நீங்கள் உங்கள் வெளியிடப்பட்ட பல முகவர்கள் செயலாக்கத்தை VS Code மற்றும் Foundry போர்டலில் பரிட்சை செய்து, முகவர் உள்ளூரில் செய்த பரிட்சைகளுடன் ஒத்துப்போவதைக் உறுதி செய்வீர்கள்.

---

## வெளியிட்டு பிறகு மீண்டும் பரிட்சை செய்ய ஏன்?

ஹோஸ்டான சூழல் உள்ளூரிலிருந்து சில முக்கியமான விதங்களில் வேறுபடுகிறது:

| | உள்ளூர் | ஹோஸ்டான |
|--|-------|--------|
| **அடையாளம்** | உங்கள் தனிப்பட்ட உள்நுழைவு (`DefaultAzureCredential`) | முகவர் தேவைப்படுகிறபோது தானாக உருவாக்கப்படும் தனித்த Entra அடையாளம் |
| **இறுதிப்புள்ளி** | `http://localhost:8088/responses` | Foundry Agent Service மேலாண்மை URL |
| **நெட்வொர்க்** | உங்கள் இயந்திரம் → Azure OpenAI + MCP | Azure பின்புற வலைப்பின்னல் (குறைந்த தாமதம்) |

தவறான சுற்றுப்பாதை மாறிலி, RBAC சிக்கல், அல்லது தடைசெய்யப்பட்ட MCP வெளியே அழைப்பு முதலில் இங்கே தான் தெரிய வரும்.

---

## விருப்பம் A: VS Code விளையாட்டு майதானத்தில் பரிட்சை செய்ய (முதலில் பரிந்துரைக்கப்படுகிறது)

### படி 1: உங்கள் ஹோஸ்டான முகவர்க்கு செல்லவும்

1. செயல்பாட்டுப் பட்டியில் **Foundry Toolkit** ஐ கிளிக் செய்யவும்.
2. உங்கள் திட்டத்தை விரிப்பாக்கவும் → **Hosted Agents (Preview)** → உங்கள் முகவர்க்கு தேடவும்.

![Foundry Toolkit sidebar showing Hosted Agents (Preview) with resume-job-fit-evaluator and its deployed versions](../../../../../translated_images/ta/06-foundry-sidebar-agent-status.a45994bfb5c21284.webp)

### படி 2: ஒரு பதிப்பைத் தேர்ந்தெடுக்கவும்

1. முகவரைக் கிளிக் செய்து அதன் பதிப்புகளை விரிப்பாக்கவும்.
2. `v1` ஐ கிளிக் செய்து நிலை **செயலில் உள்ளது** என உறுதிசெய்யவும் (சைட்பார் "Running" அல்லது "Started" என காட்டலாம் - இரண்டும் ஒரே தயாரான நிலையில் உள்ளதை குறிக்கிறது).

### படி 3: விளையாட்டு майதானத்தைத் திறக்கவும்

1. **Playground** ஐ கிளிக் செய்யவும் (அல்லது பதிப்பை வலது கிளிக் செய்து → **Open in Playground** ஐத் தேர்ந்தெடுக்கவும்).
2. VS Code தாவலில் ஒரு உரையாடல் சாளரம் திறக்கும்.

### படி 4: உங்கள் சுடுகாடு பரிட்சைகளை இயக்கவும்

[Module 5](05-test-locally.md) இல் உள்ள அதே 3 பரிட்சைகளை பயன்படுத்தவும். ஒவ்வொரு செய்தியையும் விளையாட்டு майதான உள்ளீடு பெட்டியில் தட்டச்சு செய்து **Send** (அல்லது **Enter**) அழுத்தவும்.

#### பரிட்சி 1 - முழு இரும்பு + வேலை விளக்கம் (பொதுவான ஓட்டம்)

Module 5, Test 1 இல் இருந்து முழு இரும்பு + வேலை விளக்கம் சகித்தலை ஒட்டிவைக்கவும் (ஜேன் டோ + Contoso Ltd இல் மூத்த கிளவுட் இன்ஜினியர்).

**எதிர்பார்க்கப்படுகிறது:**
- உட்க_fit மதிப்பெண் உட்பட விரிவான கணக்கீடு (100 புள்ளி அளவுகோல்)
- பொருந்தும் திறன்கள் பகுதி
- காணாமல் போன திறன்கள் பகுதி
- **எல்லா காணாமல் போன திறன் ஒன்றிற்கும் ஒரு நெடுவரிசை அட்டை** Microsoft Learn URL-களுடன்
- கற்றல் பாதை காலத்துடன்

#### பரிட்சி 2 - விரைவு குறுஞ்சோதனை (குறைந்த உள்ளீடு)

```
RESUME: 3 years Python developer, knows Django and PostgreSQL, no cloud experience.

JOB: Cloud DevOps Engineer requiring AWS, Kubernetes, Terraform, CI/CD. 5 years needed.
```

**எதிர்பார்க்கப்படுகிறது:**
- குறைந்த உட்க_fit மதிப்பெண் (< 40)
- நேர்மையான மதிப்பீடு மற்றும் கட்டப்படுத்தப்பட்ட கற்றல் பாதை
- பன்முக நெடுவரிசை அட்டைகள் (AWS, Kubernetes, Terraform, CI/CD, அனுபவத்திலுள்ள இடைவெளி)

#### பரிட்சி 3 - உயர் உட்க_fit ஆம் வேட்பாளர்

```
RESUME:
10 years Azure Cloud Architect. AZ-305 certified. Expert in AKS, Terraform, Azure DevOps, 
Azure Functions, Helm, Prometheus, Grafana, Python, Go. Led platform team of 8.

JOB:
Senior Cloud Engineer. Required: AKS, Terraform, Azure DevOps, Python. Preferred: Helm, Go.
5+ years experience. AZ-305 preferred.
```

**எதிர்பார்க்கப்படுகிறது:**
- உயர் உட்க_fit மதிப்பெண் (≥ 80)
- நேர்காணல் தயாரிப்பு மற்றும் கோலமாக்கலுக்கு கவனம்
- சில அல்லது எந்த நெடுவரிசை அட்டைகளும் இல்லை
- குறுகிய காலக்கெடு தயாரிப்புக்கு கவனம் செலுத்தியது

### படி 5: உள்ளூரில் முடிவுகளுடன் ஒப்பிடுக

Module 5 இல் நீங்கள் சேமித்த உங்கள் குறிப்பு அல்லது உலாவி தாவலைத் திறக்கவும். ஒவ்வொரு பரிட்சைக்கும்:

- பதில் **அதே கட்டமைப்பை** கொண்டதா (உட்க_fit மதிப்பெண், நெடுவரிசை அட்டைகள், கற்றல் பாதை)?
- **அதே மதிப்பீட்டு விதிமுறையை** பின்பற்றுகிறதா (100 புள்ளி விரிவாக்கம்)?
- **Microsoft Learn URL-கள்** இன்னும் நெடுவரிசை அட்டைபடைகளில் உள்ளதா?
- **ஒவ்வொரு காணாமல் போன திறனுக்கும் ஒரு நெடுவரிசை அட்டை** உள்ளதா (குறுக்கப்பட்டதல்ல)?

> **சிறு சொற்பொருள் வேறுபாடுகள் சாதாரணம்** - முறைபடுத்தாத மாடல். கட்டமைப்பு, மதிப்பீட்டு ஒருங்கிணைப்பு மற்றும் MCP கருவி பயன்பாட்டில் கவனம் செலுத்தவும்.

## விருப்பம் B: Foundry போர்டலில் பரிட்சை செய்ய

[Foundry Portal](https://ai.azure.com) இணையதள அடிப்படையிலான விளையாட்டு майதானம், குழுவினரோடு அல்லது பங்குதாரர்களோடு பகிர்வதற்கு உதவிக்கரமாக உள்ளது.

### படி 1: Foundry போர்டலை திறக்கவும்

1. உங்கள் உலாவியை திறந்து [https://ai.azure.com](https://ai.azure.com) என்ற முகவரிக்கு செல்லவும்.
2. ஒரே Azure கணக்கில் உள்நுழைக, நீங்கள் முழு பணி வகுப்புக்கும் பயன்படுத்திவருகிறீர்கள்.

### படி 2: உங்கள் திட்டத்திற்குச் செல்லவும்

1. முகப்பு பக்கத்தில், இடது பக்க பட்டியில் **Recent projects** ஐ தேடவும்.
2. உங்கள் திட்டப் பெயரை கிளிக் செய்யவும் (உதாரணம்: `workshop-agents`).
3. காணவில்லை என்றால், **All projects** கிளிக் செய்து தேடவும்.

### படி 3: வெளியிடப்பட்ட உங்கள் முகவரைக் கண்டறியவும்

1. திட்டத்தின் இடது வழிசெலுத்தலில் **Build** → **Agents** ஐ கிளிக் செய்யவும் (அல்லது **Agents** பகுதியைத் தேடவும்).
2. முகவர்களின் பட்டியலைப் பார்க்க முடியும். உங்கள் வெளியிடப்பட்ட முகவரைக் கண்டறியவும் (உதா: `resume-job-fit-evaluator`).
3. முகவர் பெயரை கிளிக் செய்து அதன் விரிவான பக்கத்தைத் திறக்கவும்.

### படி 4: விளையாட்டைத் திறக்கவும்

1. முகவர் விரிவான பக்கத்தில் மேற்கே உள்ள கருவியா பட்டியலைப் பாருங்கள்.
2. **Open in playground** (அல்லது **Try in playground**) ஐ கிளிக் செய்யவும்.
3. உரையாடல் இடைமுகம் திறக்கும்.

### படி 5: அதே சுடுகாடு பரிட்சைகளை இயக்கவும்

மேலே குறிப்பிட்ட VS Code விளையாட்டு майதான பகுதியில் உள்ள அனைத்து 3 பரிட்சைகளையும் மீண்டும் செய்யவும். ஒவ்வொரு பதிலையில் உள்ளூரில் செய்யப்பட்ட முடிவுகளுடன் (Module 5) மற்றும் VS Code விளையாட்டு майதான முடிவுகளுடன் (மேலே விருப்பம் A) ஒப்பிடவும்.

| 2 | **மதிப்பீட்டு ஒருமித்த தன்மை** | உட்க_fit மதிப்பெண் 100 புள்ளி அளவுகோலைப் பயன்படுத்தி விரிவான கணக்கீடு செய்கிறது | |
| 3 | **இடைவெளி அட்டை முழுமைத்தன்மை** | ஒவ்வொரு காணாமல் போன திறனுக்கும் ஒரு அட்டை (குறுக்கப்படாத அல்லது இணைக்கப்படாத) | |
| 4 | **MCP கருவி ஒருங்கிணைப்பு** | இடைவெளி அட்டைகள் உண்மையான Microsoft Learn URL-களைக் கொண்டுள்ளன | |
| 5 | **கட்டமைப்பு ஒருமித்த தன்மை** | வெளியீட்டு கட்டமைப்பு உள்ளூர் மற்றும் ஹோஸ்டான இயக்கங்களுக்கிடையில் பொருந்துகின்றது | |
| 6 | **பதிலளிப்பு நேரம்** | முழு மதிப்பீட்டுக்கு ஹோஸ்டான முகவர் 2 நிமிடங்களில் பதில் அளிக்கிறது | |
| 7 | **பிழைகள் இல்லை** | HTTP 500 பிழைகள், நேரம் முடிவுகள், அல்லது காலியாக்கப்பட்ட பதில்கள் இல்லை | |

> "கடந்து சென்றது" என்பது குறைந்தது ஒரு விளையாட்டு майதானத்தில் (VS Code அல்லது போர்டல்) உள்ள 3 சுடுகாடு பரிட்சைகளுக்கான 7 அளவுகோல்களின் அனைத்தும் பூர்த்தி செய்யப்பட்டுள்ளதை குறிக்கிறது.

## விளையாட்டு майதான சிக்கல் தீர்க்கும் உதவிக்குறிப்புகள்

| அறிகுறி | சாத்தியமான காரணம் | சரி செய்யும் வழி |
|---------|-------------|-----|
| விளையாட்டு майதானம் ஏற்றமுடியவில்லை | கன்டெய்னர் `active` நிலையில் இல்லை | [Module 6](06-deploy-to-foundry.md) திரும்ப சென்று, வெளியீட்டு நிலையை சரிபார்க்கவும். `creating` நிலையில் இருந்தால் காத்திருங்கள் |
| முகவர் காலியான பதிலைத் தருகிறது | மாடல் வெளியீடு பெயர் பொருந்தவில்லை | `agent.yaml` → `environment_variables` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` உங்கள் வெளியிடப்பட்ட மாடலுடன் பொருந்துகிறதா என்று சரிபார்க்கவும் |
| முகவர் பிழை செய்தி தருகிறது | [RBAC](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry) அனுமதி இல்லாமல் இருக்கிறது | திட்ட வரம்பில் **[Foundry User](https://aka.ms/foundry-ext-project-role)** (முன்பு Azure AI User) நியமிக்கவும் |
| இடைவெளி அட்டைகளில் Microsoft Learn URL-கள் இல்லை | MCP வெளியே செல்ல முடிவது தடைசெய்யப்பட்டது அல்லது MCP சேவையகம் கிடைக்கவில்லை | கன்டெய்னர் `learn.microsoft.com`-ஐ அணுகக்கூடியதா என்று சரிபார்க்கவும். விவரங்களுக்கு [Module 8](08-troubleshooting.md) பார்க்கவும் |
| ஒரே இடைவெளி அட்டை மட்டும் (அகற்றப்பட்டது) | GapAnalyzer нұсқаулықத்தில் "CRITICAL" பகுதி இல்லை | [Module 3, படி 2.4](03-configure-agents.md) மீண்டும் பார்க்கவும் |
| உட்க_fit மதிப்பெண் உள்ளூரைப்போல வெவ்வேறு | வேறு மாடல் அல்லது வழிமுறைகள் வெளியிடப்பட்டுள்ளன | `agent.yaml` சுற்றுப்பாதை மாறிலிகள் உள்ளூர் `.env` உடன் ஒப்பிடவும். தேவையாயின் மீண்டும் வெளியிடவும் |
| போர்டலில் "முகவர் காணப்படவில்லை" | வெளியீடு இன்னும் பரவுகிற அல்லது தோல்வியடைந்துள்ளது | 2 நிமிடம் காத்திருங்கள், புதுப்பிக்கவும். இன்னும் காணவில்லை என்றால் [Module 6](06-deploy-to-foundry.md) இருந்து மீண்டும் வெளியிடவும் |

- [ ] ஒவ்வொரு காணாமல் போன திறனுக்கும் ஒரு இடைவெளி அட்டை (குறுக்கப்படாமல்தான்)

- [ ] சரிபார்ப்பு மதிப்பீடு அட்டவணை முடிக்கப்பட்டது (அனைத்து 7 அளவுகோலும் கடந்து சென்றன)
