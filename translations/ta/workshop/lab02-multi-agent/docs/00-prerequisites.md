⏱️ ~10 நிமிடம்

> [!WARNING]
> **முன்னோட்டம் மற்றும் வரம்புகள்:** [Hosted Agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) தற்போது **பொதுச்செயல்முறை முன்னோட்டத்தில்** உள்ளது - உற்பத்தி பணிகளுக்கு பரிந்துரைக்கப்படவில்லை. இந்த பணிமன்றத்தில் காணப்படும் சில அம்சங்கள் சேவை GA நோக்கி நகரும்போது மாறக்கூடும்.

## நீங்கள் உருவாக்கப்போவது

இந்த ஆய்வகம், Lab 01–இல் இருந்து ஒரு-ஏஜென்ட் திறன்களை விரிவுபடுத்தி, **பல-ஏஜென்ட் வேலைநடவடிக்கை** உருவாக்குகிறது - Resume → வேலைப் பொருத்த மதிப்பாய்வாளர்.

நீங்கள் ஒரு **சுயவிவரம்** மற்றும் ஒரு **வேலை விவரம்** ஒட்டுவீர்கள். நான்கு நிபுணத்துவமிக்க ஏஜென்ட்கள் உள்ளீட்டை தொடர் முறையில் செயல்படுத்தி, பிறகு திரும்ப அளிக்கும்:
- பொருத்த மதிப்பு (0–100 மதிப்பீட்டு பிரிவுடன்)
- திறன் மற்றும் சான்றிதழ் குறியீட்டு பட்டியல்
- ஒவ்வொரு குறைக்கான Microsoft Learn இணைப்புகளுடன் தனிப்பயன் கற்றல் பயண வரைபடம்

**வேலைநடவடிக்கை பயன்படுத்துகிறது:**
- **Microsoft Agent Framework** - தொடர் குழாய் ஒருங்கிணைப்பிற்கு `WorkflowBuilder`
- **Foundry Toolkit for VS Code** - மேடமைப்பு, உள்ளூரில் சோதனை, நிலைநிறுத்தல்
- **ஒரு AI மாதிரி** (எ.கா., `gpt-4.1-mini`) - அனைத்து நான்கு ஏஜென்ட்களும் பயன்படுத்தும்
- **Microsoft Learn MCP சேவையகம்** - ஒவ்வொரு திறன் குறைக்குமான உண்மையான கற்றல் வள இணைப்புகளை வழங்குகிறது

## Lab 01 சரிபார்ப்பு

Lab 02 நேரடியாக Lab 01–இல் கட்டப்பட்டுள்ளது. இங்கு தொடங்குவதற்கு முன் Lab 01–ஐ முதலில் முடிக்கவும்.

Lab 01 இன்னும் செயத்தியுள்ளீர்களா? இங்கிருந்து தொடங்கவும்: [Lab 01 - அறிமுகம்](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ பாதை A - Azure மேகம்</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

தோல்வியடைவின் போது, `az login` இயக்கவும். பிறகு VS Code இல் சரிபார்க்கவும்:

1. `Ctrl+Shift+P` → **Foundry Toolkit** எனத் type செய்யவும் → கட்டளைகள் தோன்றுவதை உறுதிசெய்க.
2. **Foundry Toolkit** ஐகானை கிளிக் செய்யவும் → உங்கள் திட்டம் மற்றும் நிலைநிறுத்தப்பட்ட மாதிரி **வெற்றி** எனக் காண்பிக்கப்படும்.

![Foundry Toolkit sidebar showing MY RESOURCES section with the project switcher modal open](../../../../../translated_images/ta/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** நீங்கள் Lab 01–இல் **Foundry பயனர்** என பணிவகுப்பு செய்துள்ளீர்கள். மீண்டும் பணிவகுப்பு செய்ய வேண்டுமானால், [Lab 01, தொகுதி 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac) பார்க்கவும். உரிமை முன்பு **Azure AI பயனர்** என அழைக்கப்பட்டது - அதே அனுமதிகள்.

</details>

<details open>
<summary><strong>🅱️ பாதை B - Foundry உள்ளூர்</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

எதிர்பார்க்கப்படுகிறது: `StatusCode: 200`. இல்லையெனில், Foundry Toolkit sidebar–இல் இருந்து Foundry உள்ளூரை மீண்டும் தொடங்கவும்.

> அனைத்து கூற்று உங்கள் இயந்திரத்தில் இயங்கும். மட்டுமல்ல MCP கருவி மூலம் `https://learn.microsoft.com/api/mcp` க்கு வெளியே செல்வது.

</details>
