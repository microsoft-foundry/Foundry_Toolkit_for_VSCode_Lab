⏱️ ~10 நிமிடம்

> [!WARNING]
> **முன்னூட்டமும் வரம்புகளும்:** [Hosted Agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) தற்போது **பொது முன்னூட்டத்தில்** உள்ளன - உற்பத்தி வேலைப்பதிவுகளுக்கு பரிந்துரைக்கப்படவில்லை. இந்த பயிற்சி நிலையத்தில் காண்பிக்கப்பட்ட சில அம்சங்கள் சேவை GA நோக்கி நகரும்போது மாற்றப்படலாம்.

## நீங்கள் உருவாக்கப்போகும் விஷயம்

இந்த ஆய்வகத்தில், நீங்கள் Lab 01 இல் இருந்த ஒரே முகவரின் திறன்களை விரிவுபடுத்தி **பல முகவர் பணியூடாகம்** உருவாக்குகிறீர்கள் - ரெஸ்யூம் → வேலை பொருத்தம் மதிப்பாய்வாளி.

நீங்கள் ஒரு **ரெஸ்யூமை** மற்றும் ஒரு **வேலை விளக்கக்குறிப்பை** நகலெடுத்து ஒட்டுகிறீர்கள். நான்கு சிறப்பு முகவர்கள் வரிசையாக உள்ளீட்டை செயலாக்கி, பின்னர் திருப்பி விடுகிறார்கள்:
- பொருத்த மதிப்பெண் (0–100 scoring பகுப்புடன்)
- திறன் மற்றும் சான்றிதழ் குறைபாடுகளின் பட்டியல்
- ஒவ்வொரு குறைபாடுக்கும் Microsoft Learn இல் இருந்து உண்மையான கற்றல் வள இணைப்புகளுடன் தனிப்பயன் கற்றல் திட்டம்

**இந்த பணியூடாகம் பயன்படுத்துகிறது:**
- **Microsoft Agent Framework** - வரிசையாக பைப்ப்லைன் ஒருங்கிணைப்புக்கான `WorkflowBuilder`
- **Foundry Toolkit for VS Code** - கண்காணிப்பு, உள்ளூரில் சோதனை, நிரல்படுத்தல்
- **ஒரு AI மாதிரியானது** (எ.கா., `gpt-4.1-mini`) - நான்கு முகவர்களும் பயன்படுத்தும் 
- **Microsoft Learn MCP சேவையகம்** - ஒவ்வொரு திறன் குறைபாடுக்கும் உண்மையான கற்றல் வள இணைப்புகளை வழங்குகிறது

## Lab 01 சரிபார்ப்பு

Lab 02 நேரடியாக Lab 01 இல் அடிப்படையாகக் கொண்டுள்ளது. இங்கே தொடங்குவதற்கு முன் Lab 01 முடிக்கவும்.

இன்னும் Lab 01 செய்யவில்லை என்றால்? இங்கே தொடங்குங்கள்: [Lab 01 - அறிமுகம்](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ பாதை A - Azure மேகம்</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

இது தோல்வியடைந்தால், `az login` இயக்கவும். பின்னர் VS Code இல் சரிபார்க்கவும்:

1. `Ctrl+Shift+P` → **Foundry Toolkit** என தட்டச்சு செய்யவும் → கட்டளைகள் தோன்றுவதை உறுதிசெய்யவும்.
2. **Foundry Toolkit** ஐ கிளிக் செய்யவும் → உங்கள் திட்டம் மற்றும் நிரல்படுத்தப்பட்ட மாதிரி **வெற்றி** எனக் காண்பிக்கும்.

![Foundry Toolkit sidebar showing the project under My Resources, with the Switch project / Create project picker open](../../../../../translated_images/ta/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** நீங்கள் Lab 01 இல் **Foundry User** ஆக நியமித்துள்ளீர்கள். மறுபடியும் நியமிக்க வேண்டுமானால், [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac) ஐ பார்க்கவும். முன்பு இந்த உரிமை **Azure AI User** என்று அழைக்கப்படுவதாக இருந்தது - ஒன்றே உரிமைகள்.

</details>

<details open>
<summary><strong>🅱️ பாதை B - Foundry உள்ளூர்</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

எதிர்பார்க்கப்படுகிறது: `StatusCode: 200`. இல்லையெனில், Foundry Toolkit பக்கசாளரை மறுதொடக்கம் செய்து Foundry உள்ளூரை மீண்டும் தொடங்கவும்.

> அனைத்து பிரிக்கப்படும் செயல்கள் உங்கள் இயந்திரத்தில் நடைபெறுகின்றன. ஒரே வெளியே செல்லும் அழைப்பு MCP கருவி மூலம் `https://learn.microsoft.com/api/mcp` க்கு தான்.

</details>
