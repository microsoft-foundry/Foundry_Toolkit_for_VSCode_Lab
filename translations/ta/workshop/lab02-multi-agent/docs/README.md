# ஆய்வு 02 - பன்முக முகவர்க்குழு செயல்திட்டம்: தொடரியல் → வேலை பொருத்த மதிப்பாய்வாளர்

## முழுமையான கற்றல் பாதை

இந்த ஆவணம் உங்களுக்கு **பன்முக முகவர்க்குழு செயல்திட்டம்** ஒன்றை உருவாக்கி, சோதித்து, மற்றும் பராமரிக்க வழிகாட்டுகிறது, இது நான்கு சிறப்பு முகவர்களை ஒருங்கிணைக்கும் மூலம் **WorkflowBuilder** உதவியுடன் தொடரியல்-வேலை பொருத்தத்தை மதிப்பாய்க்கிறது.

> **முன்னோக்கி:** ஆய்வு 02 பூங்காவைத் தொடங்க முன்னர் [ஆய்வு 01 - ஒற்றை முகவர்](../../lab01-single-agent/README.md)நீங்கள் முடித்திருப்பது அவசியம்.
