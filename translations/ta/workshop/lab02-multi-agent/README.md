# ஆய்வு 02 - பன்முக முகவர் பணியோட்டம்: கே_resume → பணியிட பொருத்த மதிப்பீட்டாளர்

## பார்வை

இந்த செயன்முறை ஆய்வில், நீங்கள் VS Code இல் Foundry Toolkit ஐ பயன்படுத்தி **பணியோட்டம் முதன்மையான பன்முக முகவர் பயன்பாட்டை** உருவாக்கி அதை Microsoft Foundry Agent சேவைக்கு பதியப்போகிறீர்கள்.

**நீங்கள் உருவாக்கப்போகிரது:** ஒரு கே_resume → பணியிட பொருத்த மதிப்பீட்டாளர், அது கே_resume மற்றும் பணியிட விளக்கத்தை பகுப்பாய்வு செய்து, பொருந்துதலை மதிப்பிட்டு, Microsoft Learn வளங்களை பயன்படுத்தி தனிப்பயன் கல்வி திட்டத்தை உருவாக்கும்.

**இது எப்படி வேலை செய்கிறது:**
1. பயனர் ஒரு கே_resume மற்றும் பணியிட விளக்கத்தை ஒட்டுகிறார்.
2. **ResumeParser** கே_resume ஐ பகுப்பாய்வு செய்து, பணியிட விளக்கத்தை அசல் வடிவில் `[JOB DESCRIPTION PASS-THROUGH]` பகுதியில் நகலெடுக்கிறது.
3. **JD Agent** கடத்தலிலிருந்து கட்டமைக்கப்பட்ட தேவைகளை பெற்று, அடுத்து `[PARSED RESUME]` ஐ  `[PARSED RESUME PASS-THROUGH]` ஆக அனுப்புகிறது.
4. **MatchingAgent** `[PARSED RESUME PASS-THROUGH]` மற்றும் `[JD REQUIREMENTS]` ஐ ஒப்பிட்டு பொருத்த மதிப்பெண்களை உருவாக்குகிறது.
5. **GapAnalyzer** குறைகளை நடைமுறைத் திட்டமாக மாற்றி, MCP மூலம் உண்மையான Microsoft Learn இணைப்புகளை பெறுகிறது.

## பகுதி 2: பணியோட்டத்தை கட்டி சோதனை செய்யவும்

1. Foundry Toolkit விஞ்ஞானியை பயன்படுத்தி பணியோட்ட அடிப்படையிலான திட்டத்தை உருவாக்கவும்.
2. `PersonalCareerCopilot/main.py` இன் ப்ராம்ட் தொகுதிகளை மற்றும் பணியோட்ட வரைபடத்தை உங்கள் வேலைப் பகுதியில் நகலெடுக்கவும்.
3. உள்ளூர் முறையில் Agent Inspector கொண்டு இயக்கு மற்றும் நான்கு முகவர்களும் MCP கருவி சரியாக வேலை செய்கிறதா என்பதை உறுதிப்படுத்தவும்.
4. உள்ளூர்வமாக சோதித்தவுடன் Foundry இல் ஹோஸ்ட் செய்யப்பட்ட முகவரைப் பிரசாரம் செய்யவும்.

## ஒருங்கிணைப்பு மாதிரிகள்

ஆய்வு 02 இல் இயல்புநிலை **வெளியேறு → உள்ளேறு → முறையே** பணி நீக்கம் உள்ளது, மேலும் ஆவணங்களில் பரிசோதனைக்கு விருப்பமான மாற்று ஒருங்கிணைப்பு மாதிரிகளும் குறிக்கப்பட்டுள்ளன.

- **அளவோடுவுகை உள்ள வெளியில்/உள்ளேறு உடன் கட்டாய ஒப்புதல்**
- **இறுதி திட்டத்திற்கு முன்னர் விமர்சகர்/அறிக்கையாளர் காலப்பிரிவு**
- **பொருத்த மதிப்பெண் மற்றும் குறைவான திறன்கள் அடிப்படையில் நிபந்தனை வழிமாற்றி**

[docs/04-orchestration-patterns.md](docs/04-orchestration-patterns.md) ஐ பார்க்கவும்.
