# இந்த அமர்வை எவ்வாறு வழங்குவது

இந்த அமர்வை வழங்குவதற்கு நன்றி!

பணிமனை வழங்குவதற்கு முன்னரே, தயவுசெய்து:

1. இந்த ஆவணத்தையும் உள்ளடக்கிய அனைத்து வளங்களையும் முழுமையாகப் படியுங்கள்.
2. அமர்வு வழங்கல் பதிவை மற்றும் பணிமனை முழுமையான நடைமுறையையும் பாருங்கள்.
3. நிகழ்வுக்கு முன்பு இரு கைபாடவும் உங்கள் இயந்திரத்தில் **குறைந்தது ஒருமுறை** முழுமையாகச் செய்து பார்வையிடுங்கள்.
4. உங்கள் Microsoft Foundry திட்டம், மாதிரி வழங்கல்கள் மற்றும் கட்டளைகளை சரிபார்க்கவும்.
5. ஏதாவது தெளிவாக இல்லையெனில் பராமரிப்பவரை அணுகவும்.

### பயிற்சியாளர் முன்னிலை

நீங்கள் வழங்குவதற்கு முன், கீழ்கண்டவை உள்ளனவா என்பதை உறுதிப்படுத்திக்கொள்ளவும்:

- வளங்களை உருவாக்க அனுமதி கொண்ட **Azure சந்தா** (Owner அல்லது Contributor ஆக ஒரு வள குழுவில்).
- [ஹோஸ்ட் செய்யப்பட்ட முகவர்களுக்கு ஆதரவான பிரதேசம்](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability)இல் உள்ள **Microsoft Foundry திட்டம்**.
- உங்கள் Foundry திட்டத்தில் **gpt-4.1** (அல்லது **gpt-4.1-mini**) க்கான கட்டளையுண்டா என்பதை சரிபார்க்கவும்.
- கீழ்க்கண்ட கருவிகளும் நிறுவப்பட்டுள்ளன:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Microsoft Foundry Toolkit விரிவெடுப்பு](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (விருப்பப்படி)
  - Python 3.10 அல்லது அதற்கு மேல்

உங்கள் சரியான Foundry திட்டம், மாதிரி வழங்கல், மற்றும் Azure Container Registry இருப்பதை உறுதி செய்ய [Hosted agents quickstart with `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) ஐ குறைந்தது ஒருமுறை இயக்கி பாருங்கள்.

4. [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) மற்றும் [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile) கொண்டு வழங்கல் சொத்துக்களை விளக்கவும்.
5. வழங்கல் நடைமுறையை (Docker கட்டமைப்பு, ACR தள்ளுதல், hosted agent உருவாக்கம்) முழுமையாக இல்லாமல் செய்கின்றபோது விளக்கவும்.

### டெமோ 2: Resume to Job Fit Evaluator

[`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot)இல் 4-முகவர் பணிமுறை. கைபாடு 02க்கு முன் 10 நிமிட டெமோவாக பயன்படுத்தவும்.

1. [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) திறந்து நான்கு முகவர்கள் தொடர் ஒருங்கிணைப்பில் எப்படி இணைக்கப்படுகிறார்கள் என்பதைக் காண்பியுங்கள்.
2. பல-முகவர் பணிமுறைக்காக **Agent Inspector**ஐ இயக்க `F5` அழுத்தவும்.
3. Inspector உரையாடலில் ஒரு சிறிய வேலை விவரிப்பு மற்றும் மாதிரி வாழ்க்கை வரலாறு ஒட்டவும்.
4. நான்கு-முகவர் குழாய்வழி: வாழ்க்கை வரலாறு பகுப்பாய்வாளர், வேலை தேவைகள் எடுப்பவர், பொருத்த மதிப்பீட்டாளர், பரிந்துரை எழுத்துவர் ஆகியவற்றை விளக்கி நடைபரவுங்கள்.
5. ஒவ்வொரு துணை-முகவரின் வெளியீடு அடுத்த முகவரின் சூழ்நிலையாக எவ்வாறு மாறுகிறது என்று, ஒப்படைக்கும் முறையை வலியுறுத்தி குறிப்பிட்டு விழிப்பூட்டுங்கள்.
6. ஒற்றை முகவர் டெமோ 1-னை ஒப்பிடும் வகையில் [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) காண்பியுங்கள்.

## வழங்கும் குறிப்புகள்

- **முன்பே எதிர்பார்ப்புகளை அமைக்கவும்.** Hosted முகவர்கள் முன்நிலைவில் உள்ளன - பிரதேச வரம்புகள் மற்றும் கட்டளைகளை முன்னிலையிலேயே கூறி, பங்கேற்பாளர்கள் கைபாட்டில் அதிர்ச்சியடைவதை தவிர்க்கவும்.
- **முன்பணிகளினைப் முதலில் இயக்கவும்.** இரு கைபாடுகளும் `Validate prerequisites` என்ற VS Code பணியை வழங்குகின்றன - இதை பங்கேற்பாளர்கள் குறைந்தது ஒரு முறை எந்த குறியீடியும் எழுதப்படுவதற்கு முன்னர் இயக்க வேண்டும்.
- **Agent Inspector எப்போதும் தெரியுமாறு வைக்கவும்.** பெரும்பாலான "ஆஹா" நிமிடங்கள் உள்ளூர் `/responses` தொடர்பு விளக்குக்கள் பகுத்தாய்வு ஆகும்போது ஏற்படுகின்றன.
- **மறுசீரமைக்க பட்ட திட்டத்தை வைத்திருங்கள்.** ஒருவன் quota பிரச்சனையில் சிக்கினால், வழங்கல் படிக்கு முன் முன்னதாகProvision செய்யப்பட்ட திட்டத்தை பகிர்ந்து, அறையைக் தடுப்பதை தவிர்க்கவும்.
- **பங்கேற்பாளர்களை ஜோடி செய்யப்பட்டுப் பாருங்கள்.** கைகாட்டும் 02 (பல முகவர்) பணிமுறை, பேச்சு ஆராய்ச்சியுடன் எளிமையாக நடைபெறும்.
- **ஆவண தொகுதிகளை சரிபார்ப்புக் கடந்தமாக்கமாக்க பயன்படுத்தவும்.** ஒவ்வொரு கைபாடின் `docs/` கோப்பகம் 8 எண் செய்யப்பட்ட தொகுதிகளாக பிரிக்கப்பட்டுள்ளது - அவற்றைக் குறிப்பிடவும்.
- **பொதுவான ஆய்வறை கணினிகளில் அடிப்படையான Docker படத்தை முன்பே இறக்குமதி செய்யவும்** பதிவேற்ற அளவுக் கட்டுப்பாடுகளைத் தவிர்க்க.
