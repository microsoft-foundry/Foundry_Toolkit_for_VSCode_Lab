## பாதுகாப்பு

மைக்ரோசாஃப்ட் எங்கள் மென்பொருள் தயாரிப்புகளும் சேவைகளும் பாதுகாப்பை மிகுந்த முக்கியத்துவத்துடன் எடுத்துக் கொள்கிறது,
அதில் எங்கள் GitHub அமைப்புகளில் உள்ள அனைத்து மூலக் குறியீட்டு சேமிப்பகங்களும் அடங்கும்.

**பொதுவான GitHub பிரச்சினைகள் மூலம் பாதுகாப்பு பலவீனங்களை பகிர வேண்டாம்.**

பாதுகாப்பு அறிக்கைகள், இடங்கள், தொடர்பு தகவல் மற்றும் கொள்கைகள் குறித்து,
தயவுசெய்து மைக்ரோசாஃப்ட் சேமிப்பகங்களுக்கான சமீபத்திய வழிகாட்டுதலைப் பாருங்கள்
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
