# உதவி

## சிக்கல்களை பதிவு செய்வது மற்றும் உதவி பெறுவது எப்படி  

இந்த திட்டம் பிழைகள் மற்றும் அம்ச கோரிக்கைகள் கண்காணிக்க GitHub Issues ஐ பயன்படுத்துகிறது. 
புதிதாக சிக்கல் பதிவு செய்வதற்கு முன் இத்துடன் உள்ள சிக்கல்களை தேடவும், நகல்களைத் தவிர்க்க. புதிய சிக்கல்கள் 
பிழை அல்லது அம்ச கோரிக்கையை புதிய சிக்கலாக பதிவு செய்யவும்.

இந்த திட்டத்தை பயன்படுத்துவதற்கான உதவி மற்றும் கேள்விகளுக்கு, **ரெப்போ பராமரிப்பாளர்: இங்கு ரெப்போ உரிமையாளர்கள் அல்லது சமூகத்துடன் தொடர்பு கொள்ள வழிமுறைகளைச் சேர்க்கவும். அது ஒரு Stack Overflow குறிச்சொல் அல்லது வேறு சேனல் இருக்கலாம். நீங்கள் எங்கு மக்களுக்கு உதவப்போகிறீர்கள்?**.
