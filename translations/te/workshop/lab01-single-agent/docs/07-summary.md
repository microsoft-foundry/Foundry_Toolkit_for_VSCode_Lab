# మాడ్యూల్ 7 - సారాంశం & తదుపరి చర్యలు

⏱️ ~5 నిమిషాలు

**అభినందనలు!** మీరు Microsoft Foundry మరియు Foundry Toolkit for VS Code ఉపయోగించి హోస్టెడ్ AI ఏజెంట్ను నిర్మించి, పరీక్షించి, (పాత్ A లో ఉంటే) డిప్లాయ్ చేసారు.

---

## మీరు నిర్మించినది

ఒక **"నేను ఎగ్జిక్యుటివ్ లాగా వివరిస్తున్నాను"** ఏజెంట్ ఇది:
- టెక్నికల్ ఇన్సిడెంట్ నివేదికలు లేదా ఆపరేషనల్ అప్‌డేట్లు HTTP ద్వారా అందుకుంటుంది (`POST /responses`)
- వాటిని సరళమైన భాషలో ఎగ్జిక్యుటివ్ సారాంశాలలోకి అనువదిస్తుంది
- ఒక నిర్మిత అవుట్‌పుట్ ఫార్మాట్ అనుసరిస్తుంది (ఏం జరిగింది / వ్యాపార ప్రభావం / తదుపరి చర్య)
- ఆఫ్-టాపిక్ అభ్యర్థనలు మరియు ప్రాంప్ట్ ఇంజెక్షన్ ప్రయత్నాలను నిరాకరిస్తుంది
- Microsoft Foundry Agent Service లో కంటైనరైజ్డ్ హోస్టెడ్ ఏజెంట్ను ఓడిస్తుంది

---

## మీరు నేర్చుకున్న ప్రధాన భావనలూ

| భావన | మీరు అభ్యసించినది |
|---------|-------------------|
| **ఏజెంట్ ఫ్రేమ్‌వర్క్ నిర్మాణం** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` పైప్‌లైన్ |
| **హోస్టెడ్ ఏజెంట్ లైఫ్‌సైకిల్** | స్కాఫోల్డ్ → కాన్ఫిగర్ → స్థానికంగా పరీక్షించు → డిప్లాయ్ చేయు → క్లౌడ్‌లో నిర్ధారించు |
| **సిస్టమ్ ప్రాంప్ట్ ఇంజినీరింగ్** | పాత్ర, ప్రేక్షకులు, అవుట్‌పుట్ ఫార్మాట్, నియమాలు, భద్రతా పరిమితులు మరియు ఉదాహరణలు |
| **లోకల్ వర్సెస్ హోస్టెడ్ తేడాలు** | గుర్తింపు (వ్యక్తిగత క్రెడెన్షియల్ వర్సెస్ మేనేజ్డ్ ఐడెంటిటీ), ఎండ్‌పాయింట్, నెట్‌వర్క్ తారాగతి |
| **భద్రతా సరిహద్దులు** | ప్రాంప్ట్ ఇంజెక్షన్ రక్షణ, పాత్ర అనుసరణ, అతి తుప్రత పరిస్థితుల సంతృప్తికర చికిత్స |
| **Foundry Toolkit వర్క్‌ఫ్లో** | ప్రాజెక్ట్ సృష్టి, మోడల్ డిప్లాయ్‌మెంట్, ఏజెంట్ స్కాఫోల్డింగ్, ఏజెంట్ ఇన్స్పెక్టర్, ఒక క్లిక్ డిప్లాయ్ |

### మీ ఏజెంట్‌ను విస్తరించడానికి ఆలోచనలు

- **తేదీ టూల్ జోడించండి** - ఏజెంట్ సారాంశాలలో "ఈ రోజు నుండి" నేపథ్యాన్ని చేర్చనివ్వండి
- **ఒక ఇన్సిడెంట్ డేటాబేస్‌కు కనెక్ట్ అవ్వండి** - టూల్ ఫంక్షన్ ద్వారా వాస్తవ ఇన్సిడెంట్ వివరాలను పొందండి
- **Bing గ్రౌండింగ్ టూల్ జోడించండి** - అదనపు సందర్భానికి తాజా వార్తలను ఏజెంట్ చూడనివ్వండి
- **విభిన్న మోడల్స్ ప్రయత్నించండి** - `gpt-4.1` మరియు `gpt-4.1-mini` అవుట్‌పుట్ నాణ్యతను తులనాచేయండి
- **Foundryతో మదించు** - ఏజెంట్ నాణ్యతను స్కేలులో కొలవడానికి ఎవాల్యుయేషన్స్ ఫీచర్ ఉపయోగించండి

### పాత్ B వినియోగదారులు: క్లౌడ్ డిప్లాయ్‌మెంట్‌కు అభివృద్ధి చేయండి

మీరు క్లౌడ్‌కు డిప్లాయ్ చేయడానికి సిద్ధంగా ఉన్నప్పుడు:
1. Azure సబ్‌స్క్రిప్షన్ పొందండి ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [మాడ్యూల్ 01, సెటప్](01-setup.md#step-2-set-up-based-on-your-access) పూర్తి చేయండి (ప్రాజెక్ట్ సృష్టించండి, మోడల్ డిప్లాయ్ చేయండి, RBAC నియామకం చేయండి)
3. మీ `.env` లో Foundry ప్రాజెక్ట్ ఎండ్‌పాయింట్ మరియు మోడల్ డిప్లాయ్‌మెంట్ పేరు నవీకరించండి
4. [మాడ్యూల్ 05 - Foundry కు డిప్లాయ్](05-deploy-to-foundry.md) నుండి కొనసాగండి

## వనరులను శుభ్రపరచండి (ఐచ్ఛికం)

ఈ వర్క్షాప్ సమయంలో మీరు సృష్టించిన Azure వనరులను తీసివేయాలనుకుంటే:

### ఎంపిక 1: రిసోర్స్ గ్రూప్‌ను తొలగించండి (ప్రతి چیزను తొలగిస్తుంది)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ఎంపిక 2: కేవలం హోస్టెడ్ ఏజెంట్‌ను తొలగించండి

1. [ai.azure.com](https://ai.azure.com) → మీ ప్రాజెక్ట్ → **Build** → **Agents** ను తెరవండి.
2. మీ ఏజెంట్ పై క్లిక్ చేసి → **Delete** పై క్లిక్ చేయండి.

### ఎంపిక 3: మోడల్ డిప్లాయ్‌మెంట్‌ను తొలగించండి

1. Foundry సైడ్‌బార్‌లో మీరు ప్రాజెక్ట్ విస్తరించి → **Models** ని ఎంచుకోండి.
2. మోడల్ డిప్లాయ్‌మెంట్ పై రైట్ క్లిక్ చేసి → **Delete** ఎంచుకోండి.

> **ఖర్చు గమనిక:** హోస్టెడ్ ఏజెంట్లు నడుస్తున్నప్పుడు మాత్రమే చార్జీలు కలిగి ఉంటాయి. మీరు ఏజెంట్‌ను నిలిపివేయడం లేదా తొలగించడం అయితే ఏదైనా కొనసాగించే చార్జీలు ఉండవు. మోడల్ డిప్లాయ్‌మెంట్ కొరకు రిజర్వ్ చేసిన కెపాసిటీకి చిన్న చార్జీ ఉండవచ్చు - మీరు పని పూర్తి చేసాక దీన్ని తొలగించండి.
