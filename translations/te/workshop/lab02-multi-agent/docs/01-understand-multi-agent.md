# మాడ్యూల్ 1 - వాస్తవకట్టును అర్థం చేసుకోవడం

⏱️ ~5 నిమిషాలు

ఏ కోడ్ రాయకముందు, మీరు ఏం నిర్మిస్తున్నారో మరియు అది ఎలా పని చేస్తుందో ఒక తక్షణ అవలోకనం.

---

## మీరు నిర్మిస్తున్నది

మీరు ఒక **రిజ్యూమే** మరియు ఒక **జాబ్ వివరణ** పేస్ట్ చేస్తున్నారు. వర్క్‌ఫ్లో తిరిగి ఇస్తుంది:

- ఒక సరిపోయే స్కోరు (0-100తో విభజన సహా)
- నైపుణ్యాలు మరియు సర్టిఫికేషన్ గాప్ల జాబితా
- ప్రతి గాప్ కోసం Microsoft Learn లింకులతో ఒక వ్యక్తిగత కోర్సు మార్గం

---

## నాలుగు ఏజెంట్లు

ఒకే ఏజెంట్ ఒకేసారి పూర్తిగా విశ్లేషించేందుకు, స్కోరు ఇవ్వడానికి, మరియు ప్రణాళిక రూపొందించేందుకు ప్రయత్నిస్తే సాధారణంగా త్వరగా పని చేసి సగముఖ ఫలితాన్ని ఇస్తుంది. పని నాలుగు ప్రత్యేక ఏజెంట్లుగా విభజించడం మెరుగైన ఫలితాలను ఇస్తుంది:

| ఏజెంట్ | దాని పని |
|-------|-------------|
| **ResumeParser** | రిజ్యూమేను విశ్లేషిస్తుంది; జాబ్ వివరణను జాగ్రత్తగా `[JOB DESCRIPTION PASS-THROUGH]` లో కాపీ చేస్తుంది తదుపరి ఏజెంట్లు ఉపయోగించుకునేందుకు |
| **JobDescriptionAgent** | పాస్-తురూ నుండి JD అవసరాలను పొందుతుంది; `[PARSED RESUME]` ను `[PARSED RESUME PASS-THROUGH]` గా ముందుకు భేజేస్తుంది |
| **MatchingAgent** | రెండు లేబుల్ చేసిన విభాగాలను పోల్చుతుంది; 0-100 సరిపోయే స్కోరు మరియు గాప్ జాబితా ఇస్తుంది |
| **GapAnalyzer** | ఒక అభ్యాస మార్గం నిర్మిస్తుంది; Microsoft Learn లో ప్రతి గాప్ కోసం శోధిస్తుంది |

## ఆర్కেস্ট్రేషన్ గ్రాఫ్

వర్క్‌ఫ్లో ఒక **క్రమబద్ధమైన పైప్‌లైన్** - ప్రతి ఏజెంట్ తన అవుట్పుట్ ను తదుపరి ఏజెంట్ కు ఇస్తుంది:

```mermaid
flowchart LR
    A["వినియోగదారు ఇన్‌పుట్"] --> B["రిస్యుమే పార్సర్"]
    B -- "పార్స్ చేయబడిన రిస్యుమే + JD రీలే" --> C["జాబ్ వివరణ ఏజెంట్"]
    C -- "JD అవసరాలు + రిస్యుమే రీలే" --> D["లెక్కింపు ఏజెంట్"]
    D -- "సరిపోలే వివరాలు + గ్యాప్స్" --> E["గ్యాప్ అనాలైజర్ + MCP"]
    E --> F["చివరి అవుట్పుట్"]
```

1. **ResumeParser** యూజర్ ఇన్‌పుట్ అందుకుంటుంది, రిజ్యూమేను విశ్లేషిస్తుంది, JD ను `[JOB DESCRIPTION PASS-THROUGH]` లో కాపీ చేస్తుంది.
2. **JD ఏజెంట్** నిర్మిత అవసరాలను వెలికి తీయడం మరియు `[PARSED RESUME PASS-THROUGH]` ను ముందుకు పంపడం.
3. **MatchingAgent** రెండు విభాగాలను పోల్చి సరిపోయే స్కోరు మరియు గాప్ జాబితాను ఉత్పత్తి చేస్తుంది.
4. **GapAnalyzer** మార్గసూచిని తయారుచేసి ప్రతి గాప్ కోసం Microsoft Learn MCP టూల్‌ను పిలుస్తుంది.

## దీన్ని కోడ్‌కు ఎలా మ్యాప్ చేయాలి

`main.py` లో, మీరు ఈ గ్రాఫ్‌ను `WorkflowBuilder` తో వర్ణిస్తారు:

```python
workflow_agent = (
    WorkflowBuilder(
        start_executor=resume_executor,       # వినియోగదారు ఇన్‌పుట్ పొందే మొదటి ఏజెంట్
        output_executors=[gap_executor],      # చివరి ఏజెంట్ - దాని అవుట్పుట్ ప్రతిస్పందన
    )
    .add_edge(resume_executor, jd_executor)       # ResumeParser → JD ఏజెంట్
    .add_edge(jd_executor, matching_executor)     # JD ఏజెంట్ → మాచ్ చేయు ఏజెంట్
    .add_edge(matching_executor, gap_executor)    # మాచ్ చేయు ఏజెంట్ → గ్యాప్ విశ్లేషకుడు
    .build()
    .as_agent()
)
```

ప్రతి `Agent`ని `AgentExecutor` లో చుట్టి ఉంటారు. `add_edge()` కాల్స్ క్రమబద్ధమైన పైప్‌లైన్‌ను నిర్వచిస్తాయి - ప్రతి ఏజెంట్ తన నేర ప్రత్యర్థి అవుట్పుట్ మాత్రమే అందుకుంటుంది.

> `context_mode="last_agent"` అంటే ప్రతి ఎగ్జిక్యూటర్ కేవలం తన ప్రత్యక్ష మున్స్ ఏజెంట్ అవుట్పుట్‌ను మాత్రమే చూస్తుంది. ResumeParser మరియు JD ఏజెంట్లు లేబుల్ చేసిన విభాగాలలో డేటా ముందుకు పంపుతాయి కాబట్టి ప్రతి తర్వాతి ఏజెంట్ అవసరమైన దాన్ని తప్పకుండా పొందుతుంది.

## MCP టూల్

GapAnalyzer దగ్గర ఒకే ఒక టూల్ ఉంది: `search_microsoft_learn_for_plan`. ఇది `https://learn.microsoft.com/api/mcp`తో కనెక్ట్ అయి ప్రతి నైపుణ్య గాప్ కోసం నిజమైన Microsoft Learn లింకులను ఇస్తుంది.

టూల్ నడుస్తున్నప్పుడు మీరు ఈ లాగ్‌లు చూస్తారు - ఇవన్నీ ఆశించినవి:

```
GET  https://learn.microsoft.com/api/mcp → 405   ← connection probe, normal
POST https://learn.microsoft.com/api/mcp → 200   ← actual tool call
DELETE https://learn.microsoft.com/api/mcp → 405 ← cleanup probe, normal
```

`POST` లో ఎలాంటి లోపం వస్తే ఆ విషయం మాత్రమే జాగ్రత్తగా చూడాలి.
