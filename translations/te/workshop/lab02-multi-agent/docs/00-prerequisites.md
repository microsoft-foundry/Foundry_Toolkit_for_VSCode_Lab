## మీరు తయారు చేసేది

ఈ ప్రయోగంలో, మీరు Lab 01 నుండి సింగిల్-ఏజెంట్ నిపుణతలను విస్తరించి **బహుఎజెంట్ వర్క్‌ఫ్లో** - రిజ్యూమ్ → జాబ్ ఫిట్ ఈవాల్యుటర్‌ను నిర్మిస్తారు.

మీరు ఒక **రిజ్యూమ్** మరియు ఒక **జాబ్ వివరణ** ను పేస్ట్ చేస్తారు. నల్గురు ప్రత్యేక ఏజెంట్లు సీక్వెన్షియల్‌గా ఇన్‌పుట్‌ను ప్రాసెస్ చేసి, తర్వాత ఈవి ఇస్తారు:
- ఒక ఫిట్ స్కోరు (0–100తో స్కోరింగ్ విభజన)
- ఒక నైపుణ్యం మరియు సర్టిఫికేషన్ గ్యాప్ జాబితా
- ప్రతి గ్యాప్ కి నిజమైన Microsoft Learn లింకులను కలిగిన వ్యక్తిగత శిక్షణ రోడ్‌మ్యాప్

**వర్క్‌ఫ్లోలో ఉపయోగించే:**
- **Microsoft Agent Framework** - `WorkflowBuilder` సీక్వెన్షియల్ పైప్‌లైన్ ఆర్కెస్ట్రేషన్ కోసం
- **Foundry Toolkit for VS Code** - స్కాఫోల్డ్, స్థానికంగా టెస్ట్ చేయండి, డిప్లాయ్ చేయండి
- **ఒక AI మోడల్** (ఉదా., `gpt-4.1-mini`) - అన్ని నల్గురు ఏజెంట్లు ఉపయోగిస్తారు
- **Microsoft Learn MCP సర్వర్** - ప్రతి నైపుణ్యం గ్యాప్ కోసం నిజమైన శిక్షణ వనరుల లింకులు అందిస్తుంది

