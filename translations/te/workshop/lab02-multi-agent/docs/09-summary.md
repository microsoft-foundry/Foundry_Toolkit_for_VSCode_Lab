# మాడ్యూల్ 9 - సారాంశం & తర్వాతి దశలు

⏱️ సుమారు 5 నిమిషాలు

**అభినందనలు!** మీరు Microsoft Foundry మరియు Foundry Toolkit for VS Code ఉపయోగించి బహుళ ఏజెంట్ వర్క్‌ఫ్లోను నిర్మించి, పరీక్షించి, (Path Aపై ఉంటే) అమర్చారు.

---

## మీరు నిర్మించినది

**Resume → Job Fit Evaluator** - ఒక బహుళ ఏజెంట్ ఆధారిత వర్క్‌ఫ్లో ఇది:
- HTTP ద్వారా రిజ్యూమే + ఉద్యోగ వివరణను సేకరిస్తుంది (`POST /responses`)
- నాలుగు ప్రత్యేక ఏజెంట్లను పరమ పరంపరగా నడిపిస్తుంది - ప్రతి ఏజెంట్ తర్వాతి ఏజెంట్ అవసరమైన డేటాను అందిస్తుంది
- ఒక సరిపోలిక స్కోర్ (0–100 విభాగాలతో), నెపథ్య మరియు సర్టిఫికేషన్ లోపాల జాబితా, ప్రతి లోపానికి అనుకూల వ్యక్తిగత అభ్యసన మార్గదర్శకం Microsoft Learn లింకులతో కలిగి ఉంటుంది
- Microsoft Learn MCP సర్వర్ (`https://learn.microsoft.com/api/mcp`)ని పిలిచి ప్రతి గుర్తింపు నెపథ్య లోపానికి అధికారిక అధ్యయన వనరులను తీసుకొంటుంది
- Microsoft Foundry ఏజెంట్ సర్వీస్‌లో ఒకే కంటైనర్‌లో హోస్ట్ అయిన ఏజెంట్‌గా పని చేస్తుంది

## మీరు నేర్చుకున్న ముఖ్య కాన్సెప్ట్లు

| కాన్సెప్టు | మీరు సాధించినది |
|---------|-------------------|
| **బహుళ ఏజెంట్ ఆర్కెస్ట్రేషన్** | `WorkflowBuilder` పరంపర pipelineతో `add_edge()` |
| **ఏజెంట్ ప్రత్యేకత** | నాలుగు ప్రత్యేక ఏజెంట్లు ఒక సాధారణ ఏజెంట్ కన్నా మెరుగైన ఫలితాలు ఇస్తాయి |
| **కంటెంట్ రౌటర్ ప్యాటర్న్** | ResumeParser ఒక రౌటర్ విధిగా ఉంటుంది - JD టెక్స్ట్‌ను `[JOB DESCRIPTION PASS-THROUGH]` సెక్షన్లో ఉంచి డౌన్స్ట్రిమ్ ఏజెంట్లు అందుకోగలుగుతాయి (`context_mode="last_agent"` కారణంగా కేవలం `start_executor`కి మాత్రమే ముసాయిదా సందేశం కనిపిస్తుంది) |
| **కంటెంట్ రీలే ప్యాటర్న్** | JD ఏజెంట్ `[PARSED RESUME PASS-THROUGH]` ని ముందుకు రీలే చేస్తుంది, అందువల్ల MatchingAgent కి రెండింటి సమాచారాలు అందుతాయి; OR-సెమాంటిక్స్ డబుల్-ట్రిగ్గర్ నుంచి తప్పిస్తుంది |
| **MCP టూల్ ఇంటిగ్రేషన్** | `@tool` + `streamable_http_client` తో బాహ్య MCP సర్వర్ వెళ్లటం |
| **హోస్టెడ్ ఏజెంట్ లైఫ్‌సైకిల్** | Scaffold → కన్ఫిగర్ → స్థానికంగా పరీక్షించు → అమర్చు → క్లౌడ్ లో ధృవీకరించు |
| **`context_mode="last_agent"`** | ప్రతి ఎగ్జిక్యూటర్ తన ప్రత్యక్ష పూర్వీకుడి ఉత్పత్తిని మాత్రమే చూడగలుగుతుంది |
| **Foundry Toolkit వర్క్‌ఫ్లో** | Scaffold విज़ార్డ్, ఏజెంట్ ఇన్స్పెక్టర్, వర్క్‌ఫ్లో విజువలైజర్, ఒక క్లిక్ డిప్లాయ్ |

### ఈ వర్క్‌ఫ్లోతో విస్తరించడానికి ఆలోచనలు

- **5వ ఏజెంట్ జోడించండి** - లోపాల నివేదిక ఆధారంగా అంతర్వ్యాకల్పిక ప్రశ్నలను సృష్టించే ఇంటర్వ్యూ కోచ్
- **Bing గ్రౌండింగ్ టూల్ జోడించండి** - JD Agent ఒకే ఉద్యోగం పబ్లిషింగ్‌లను వెతుకుతుండగా అవసరాలను సమృద్ధిగా చేయండి
- **రిజ్యూమే డేటాబేస్‌కు కనెక్ట్ అవ్వండి** - కస్టమ్ `@tool` ద్వారా అభ్యర్థుల ప్రొఫైళ్లను తీసుకోండి
- **విభిన్న మోడల్స్ ప్రయత్నించండి** - `gpt-4.1` vs. `gpt-4.1-mini` అవుట్‌పుట్ నాణ్యత మరియు ఆలస్యం తులన జరపండి
- **Foundryతో అంచనా వేయండి** - అంచనాల ఫీచర్ ఉపయోగించి సరిపోలిక నివేదికలు స్వర్ణ డేటాసెట్ తో స్కోరు చేయండి

### పాథ్ B వినియోగదారుల కోసం: క్లౌడ్ అమరికకు అప్‌గ్రేడ్ చేయండి

మీరు క్లౌడ్‌కి అమర్చేందుకు సిద్ధంగా ఉన్నప్పుడు:
1. Azure సబ్స్‌క్రిప్షన్ పొందండి ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [ల్యాబ్ 01, మాడ్యూల్ 01](../../lab01-single-agent/docs/01-setup.md) పూర్తి చేసుకోండి (ప్రాజెక్ట్ సృష్టించండి, మోడల్ అమర్చండి, RBAC కేటాయించండి)
3. మీ `.env`ని Foundry ప్రాజెక్ట్ ఎండ్‌పాయింట్ మరియు మోడల్ అమరిక పేరుతో అప్‌డేట్ చేయండి
4. [Module 06 - Deploy to Foundry](06-deploy-to-foundry.md) నుండి కొనసాగండి

## వనరులను శుభ్రపరచండి (ఐచ్ఛికం)

మీరు ఈ వర్క్‌షాప్‌లో సృష్టించిన Azure వనరులను తొలగించాలని ఉంటే:

### ఎంపిక 1: రిసోర్స్ గ్రూప్‌ను తొలగించండి (అన్నీ తొలగిస్తుంది)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ఎంపిక 2: హోస్టెడ్ ఏజెంట్‌ను మాత్రమే తొలగించండి

1. [ai.azure.com](https://ai.azure.com) → మీ ప్రాజెక్ట్ → **Build** → **Agents** ను తెరవండి.
2. **PersonalCareerCopilot** ని కనుగొని **Delete** పై క్లిక్ చేయండి.

### ఎంపిక 3: మోడల్ అమరికను తొలగించండి

1. Foundry సైడ్‌బార్‌లో మీ ప్రాజెక్ట్‌ను విస్తరించండి → **Models**.
2. మోడల్ అమరికపై రైట్-క్లిక్ చేసి → **Delete** ఎంచుకోండి.

> **ఖర్చు గమనిక:** హోస్టెడ్ ఏజెంట్లు నడుస్తున్న సమయంలో మాత్రమే ఖర్చు ఉంటాయి. ఏజెంట్ నిలిపివేస్తే లేదా తొలగిస్తే, ఎటువంటి కొనసాగింపు ఛార్జీలు ఉండవు. మోడల్ అమరికకు రిజర్వ్ చేసిన సామర్థ్యం కొరకు కొద్దిరోజుల ఛార్జీ వచ్చే అవకాశం ఉంది - మీరు ముగించాక దాన్ని కూడా తొలగించండి.
