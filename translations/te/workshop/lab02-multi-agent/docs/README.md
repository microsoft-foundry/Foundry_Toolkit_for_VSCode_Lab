# ప్రయోగశాల 02 - బహుళ-ఏజెంట్ పనితీరు: రెజ్యూమే → ఉద్యోగ సరిపోయే విలక్షణకర్త

## పూర్తి శిక్షణ మార్గం

ఈ డాక్యుమెంటేషన్ మా మల్టీ-ఏజెంట్ వర్క్‌ఫ్లోను నిర్మించడం, పరీక్షించడం, మరియు నియమించడాన్ని చూపిస్తుంది, ఇది నాలుగు ప్రత్యేక ఏజెంట్లు ద్వారా రెజ్యూమే-ఉద్యోగ సరిపోయే విలువను అంచనా వేస్తుంది, అవి **WorkflowBuilder** ద్వారా సమర్ధంగా పర్యవేక్షించబడతాయి.

> **ఆవశ్యకమైంది:** ప్రయోగశాల 02 ప్రారంభించే ముందు [ప్రయోగశాల 01 - ఒక ఏజెంట్](../../lab01-single-agent/README.md) పూర్తి చేయండి.
