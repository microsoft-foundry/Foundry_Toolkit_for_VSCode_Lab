# ల్యాబ్ 02 - బహుళ-ఏజెంట్ వర్క్‌ఫ్లో: రిజ్యూమ్ → ఉద్యోగ సరిపోయే నిర్ధారకుడు

## అవలోకనం

ఈ హ్యాండ్స్-ఆన్ ల్యాబ్‌లో, మీరు VS కోడ్‌లో ఫౌండ్రీ టూల్కిట్ ఉపయోగించి **వర్క్‌ఫ్లో-ఫస్ట్ బహుళ-ఏజెంట్ యాప్**‌ని నిర్మించి, దాన్ని మైక్రోసాఫ్ట్ ఫౌండ్రీ ఏజెంట్ సర్వీస్‌కు పంపిణీ చేస్తారు.

**మీరు నిర్మించేది:** ఒక రిజ్యూమ్ → ఉద్యోగ సరిపోయే నిర్థారకుడు, ఇది రిజ్యూమ్ మరియు ఉద్యోగ వివరణని విశ్లేషించి, సరిపోకును స్కోర్ చేసి, మైక్రోసాఫ్ట్ లెర్న్ వనరులతో వ్యక్తిగతీకరించిన అభ్యాస మార్గదర్శకం తయారు చేస్తుంది.

**ఇది ఎలా పనిచేస్తుంది:**
1. వినియోగదారు రిజ్యూమ్ మరియు ఉద్యోగ వివరణను పేస్ట్ చేస్తాడు.
2. **ResumeParser** రిజ్యూమ్‌ను విశ్లేషించి ఉద్యోగ వివరణను మార్పు లేని రూపంలో `[JOB DESCRIPTION PASS-THROUGH]` విభాగంలో కాపీ చేస్తుంది.
3. **JD Agent** పాస్-త్రమ్ నుంచి నిర్మిత డేటా అవసరాలను తీసుకుని, `[PARSED RESUME]`ని `[PARSED RESUME PASS-THROUGH]`గా ముందుకు పంపుతుంది.
4. **MatchingAgent** `[PARSED RESUME PASS-THROUGH]` మరియు `[JD REQUIREMENTS]`తో సరిపోల్చి ఫిట్ స్కోర్ తయారు చేస్తుంది.
5. **GapAnalyzer** లోపాలను ప్రాక్టికల్ మార్గదర్శకంగా మార్చి MCP ద్వారా ఒరిజినల్ మైక్రోసాఫ్ట్ లెర్న్ లింకులను తీసుకుని వస్తుంది.

## భాగం 2: వర్క్‌ఫ్లోని నిర్మించి పరీక్షించండి

1. ఫౌండ్రీ టూల్కిట్ విజార్డ్ను ఉపయోగించి వర్క్‌ఫ్లో ఆధారిత ప్రాజెక్టును స్కాఫోల్డ్ చేయండి.
2. `PersonalCareerCopilot/main.py` నుండి ప్రాంప్ట్ బ్లాక్స్ మరియు వర్క్‌ఫ్లో గ్రాఫ్‌ను మీ వర్క్‌స్పేస్‌లో కాపీ చేయండి.
3. ఏజెంట్ ఇన్‌స్పెక్టర్‌తో స్థానికంగా రన్ చేసి నాలుగు ఏజెంట్లు మరియు MCP టూల్‌ను ధృవీకరించండి.
4. స్థానిక పరీక్షల విజయవంతమైనప్పుడు హోస్టెడ్ ఏజెంటును ఫౌండ్రీకు పంపండి.

## సమన్వయ నమూనాలు

ల్యాబ్ 02 డీఫాల్ట్ **ఫ్యాన్-అవుట్ → ఫ్యాన్-ఇన్ → వరుస** ప్రవాహాన్ని కలిగి ఉంది, మరియు డాక్యుమెంట్స్ ప్రయోగాత్మకత కోసం ప్రత్యామ్నాయ సమన్వయ నమూనాలను కూడా వివరిస్తాయి.
