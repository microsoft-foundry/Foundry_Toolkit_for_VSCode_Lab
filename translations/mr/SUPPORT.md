# समर्थन

## समस्या कशा नोंदवायच्या आणि मदत कशी मिळवायची  

हा प्रकल्प बग्स आणि फिचर विनंत्या ट्रॅक करण्यासाठी GitHub Issues वापरतो. कृपया नवीन समस्या नोंदवण्याआधी आधीच्या 
समस्यांची तपासणी करा जेणेकरून पुनरावृत्ती टाळता येतील. नवीन समस्या असल्यास, तुमचा बग किंवा 
फिचर विनंती नवीन Issues म्हणून नोंदवा.

या प्रकल्पाचा वापर कसा करायचा याबद्दल मदत किंवा प्रश्न असल्यास, कृपया **रिपॉजिटरी देखभाल करणारा: येथे सूचनांचा समावेश करा 
ज्याद्वारे रिपॉजिटरी मालक किंवा समुदायाशी संपर्क साधायचा आहे. हे Stack Overflow टॅग किंवा दुसरी
माध्यम असू शकते. तुम्ही लोकांना कुठे मदत करणार आहात?**.
