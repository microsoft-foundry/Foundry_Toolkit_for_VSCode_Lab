# विभाग 7 - सारांश आणि पुढील पावले

⏱️ ~5 मिनिटे

**अभिनंदन!** तुम्ही Microsoft Foundry आणि Foundry Toolkit for VS Code वापरून एक होस्टेड AI एजंट तयार केला, तपासला आणि (जर पाथ A वर असाल तर) तैनात केला आहे.

---

## तुम्ही काय तयार केले

एक **"Explain Like I'm an Executive"** एजंट जो:
- तांत्रिक घटनेच्या अहवाल किंवा ऑपरेशनल अपडेट HTTP (`POST /responses`) द्वारे प्राप्त करतो
- त्यांना सोप्या भाषेतील कार्यकारी सारांशांमध्ये भाषांतरित करतो
- एक संरचित आउटपुट फॉर्मॅटचा अवलंब करतो (काय घडले / व्यवसायावर परिणाम / पुढील पाऊल)
- ऑफ-टॉपिक विनंत्या आणि प्रॉम्प्ट इंजेक्शन प्रयत्न नाकारतो
- Microsoft Foundry Agent Service मध्ये कंटेनरायझड होस्टेड एजंट म्हणून चालतो

| संकल्पना | तुम्ही काय सराव केला |
|---------|-------------------|

| **होस्टेड एजंट जीवनचक्र** | Scaffold → कॉन्फिगर करा → स्थानिक तपासणी → तैनात करा → क्लाऊड मध्ये पडताळणी करा |
| **सिस्टम प्रॉम्प्ट अभियांत्रिकी** | भूमिका, प्रेक्षक, आउटपुट फॉर्मॅट, नियम, सुरक्षितता मर्यादा, आणि उदाहरणे |
| **स्थानिक विरुद्ध होस्टेड फरक** | ओळख (वैयक्तिक प्रमाणपत्र विरुद्ध व्यवस्थापित ओळख), एंडपॉइंट, नेटवर्क मार्ग |
| **सुरक्षितता सीमा** | प्रॉम्प्ट इंजेक्शन संरक्षण, भूमिका पाळणे, सर्वाधिक प्रकरणे सौम्य हाताळणी |
| **Foundry Toolkit कार्यप्रवाह** | प्रोजेक्ट तयार करणे, मॉडेल तैनात करणे, एजंट स्कॅफोल्डिंग, Agent Inspector, एक-क्लिक तैनाती |

### तुमच्या एजंटला विस्तृत करण्यासाठी कल्पना

- **डेट टूल जोडा** - एजंटला सारांशांमध्ये "आज तारखेपर्यंत" संदर्भ समाविष्ट करण्याची परवानगी द्या
- **इन्सिडेंट डेटाबेसशी कनेक्ट करा** - टूल फंक्शनद्वारे खरी घटना तपशील मिळवा
- **Bing ग्राउंडिंग टूल जोडा** - एजंटला अतिरिक्त संदर्भासाठी अलीकडच्या बातम्या पाहण्याची परवानगी द्या
- **वेगवेगळे मॉडेल वापरून पहा** - `gpt-4.1` विरुद्ध `gpt-4.1-mini` आउटपुट गुणवत्ता तुलना करा
- **Foundry सोबत मूल्यांकन करा** - एजंट गुणवत्ता मोठ्या प्रमाणावर मोजण्यासाठी Evaluations वैशिष्ट्य वापरा

### पाथ B वापरकर्त्यांसाठी: क्लाऊड तैनातीसाठी अपग्रेड करा

जेव्हा तुम्ही क्लाऊडमध्ये तैनात करण्यास तयार असाल:
1. Azure सबस्क्रिप्शन मिळवा ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [Module 01, सेटअप](01-setup.md#step-2-set-up-based-on-your-access) पूर्ण करा (प्रोजेक्ट तयार करा, मॉडेल तैनात करा, RBAC लागू करा)
3. तुमचा `.env` Foundry प्रोजेक्ट एंडपॉइंट आणि मॉडेल तैनाती नावाने अद्ययावत करा
4. [Module 05 - Foundry मध्ये तैनात करा](05-deploy-to-foundry.md) मधून सुरू ठेवा

## संसाधने स्वच्छ करा (ऐच्छिक)

जर तुम्हाला या कार्यशाळेदरम्यान तयार केलेली Azure संसाधने काढून टाकायची असतील तर:

### पर्याय 1: रिसोर्स ग्रुप हटवा (सर्व काही काढून टाकतो)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### पर्याय 2: फक्त होस्टेड एजंट हटवा

1. [ai.azure.com](https://ai.azure.com) उघडा → तुमचा प्रोजेक्ट → **Build** → **Agents**.
2. तुमचा एजंट क्लिक करा → **Delete** क्लिक करा.

### पर्याय 3: मॉडेल तैनाती हटवा

1. Foundry साइडबारमध्ये तुमचा प्रोजेक्ट विस्तार करा → **Models**.
2. मॉडेल तैनातीवर राइट-क्लिक करा → **Delete**.

> **खर्च नोट:** होस्टेड एजंट चालू असतानाच खर्च करतात. तुम्ही एजंट थांबलात किंवा हटवलात तर चालू शुल्क नाही. मॉडेल तैनातीसाठी राखीव क्षमता साठी लहान शुल्क लागू शकतो - पूर्ण झाल्यावर तो हटवा.
