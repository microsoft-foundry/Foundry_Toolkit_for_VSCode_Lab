# मॉड्यूल 8 - समस्या निवारण

हा मॉड्यूल सामान्य समस्या यासाठी संदर्भ मार्गदर्शक आहे. त्यास बुकमार्क करा आणि काहीतरी चुकीचे झाल्यास परत या.

---

## 1. परवानगी त्रुटी

### 1.1 `agents/write` परवानगी नाकारली

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**मुळ कारण:** **प्रोजेक्ट** पातळीवर `Azure AI User` भूमिका नाही. हा #1 कार्यशाळेतील त्रुटी आहे.

**ठिक करा:**
1. [portal.azure.com](https://portal.azure.com) उघडा.
2. तुमच्या Foundry **प्रोजेक्ट** नावासाठी शोधा → **"Microsoft Foundry project"** प्रकाराच्या निकालावर क्लिक करा (पालक खाते नाही).
3. **Access control (IAM)** → **+ Add** → **Add role assignment**.
4. भूमिका: **Azure AI User** → पुढे.
5. सदस्य: स्वतःची निवड करा → पुनरावलोकन + नियुक्त करा → पुनरावलोकन + नियुक्त करा.
6. **1–2 मिनिटे प्रतीक्षा करा** → पुन्हा प्रयत्न करा.

> **का Owner/Contributor पुरेसे नाही:** या भूमिका *व्यवस्थापन* क्रिया फक्त देतात. एजंट ऑपरेशन्ससाठी `agents/write` *डेटा क्रिया* आवश्यक आहे, जी फक्त `Azure AI User`, `Azure AI Developer`, किंवा `Azure AI Owner` मध्ये आहे. पहा [Foundry RBAC docs](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry).

### 1.2 provisioning दरम्यान `AuthorizationFailed`

**ठिक करा:** तुमच्या अ‍ॅडमिनला संसाधन समूहावर **Contributor** नियुक्त करण्यास विचारा, किंवा ते तुम्हाला प्रोजेक्ट तयार करून त्यावर **Azure AI User** द्या.

### 1.3 `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# थांबा जोपर्यंत: "नोंदणीकृत"
```

## 2. डॉकर त्रुटी

> डॉकर **ऐच्छिक** आहे. हे फक्त तेव्हाच लागू होतात जेव्हा डॉकर डेस्कटॉप इंस्टॉल केलेले आहे आणि विस्तार स्थानीय बिल्ड करण्याचा प्रयत्न करतो.

### 2.1 डॉकर डेमन चालू नाही

**ठिक करा:** Docker Desktop सुरू करा → "running" स्थितीसाठी प्रतीक्षा करा → `docker info` ने तपासा → पुन्हा प्रयत्न करा.

### 2.2 अवलंबित्व त्रुटींसह बिल्ड अयशस्वी

**ठिक करा:** `requirements.txt` ची स्पेलिंग तपासा, प्रथम स्थानिकरीतीने तपासा: `pip install -r requirements.txt`.

### 2.3 प्लॅटफॉर्म जुळणी नाही (Apple Silicon)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

## 3. प्रमाणन त्रुटी

### 3.1 `DefaultAzureCredential` अयशस्वी

**ठिक करा (क्रमाने प्रयत्न करा):**
1. `az login` (पुन्हा प्रमाणीकरण करा)
2. `az account set --subscription "<id>"` (बरोबर सदस्यता)
3. VS Code → खाते → साइन आउट → पुन्हा साइन इन करा
4. तपासा: `az account get-access-token --resource https://cognitiveservices.azure.com`

### 3.2 टोकन स्थानिकरित्या कार्य करते पण होस्टेडवर नाही

**अपेक्षित:** होस्टेड एजंट्स सिस्टम-व्यवस्थीत ओळख वापरतात, तुमचा प्रमाणपत्र नाही. होस्टेड एजंटला प्रमाणीकरण त्रुटी आल्या तर:
- `agent.yaml` मधील `AZURE_AI_PROJECT_ENDPOINT` बरोबर आहे का तपासा
- प्रोजेक्टची व्यवस्थीत ओळख मॉडेल प्रवेशासाठी आहे का तपासा

## 4. मॉडेल त्रुटी

### 4.1 मॉडेल वितरण सापडले नाही

**ठिक करा:** नाव **केस-संवेदनशील** आहे. `.env` मधील `AZURE_AI_MODEL_DEPLOYMENT_NAME` ला Foundry साइडबार → मॉडेल्स मधील नेमाशी तुळना करा.

### 4.2 अनपेक्षित मॉडेल आउटपुट

**ठिक करा:** `main.py` मधील `AGENT_INSTRUCTIONS` पुनरावलोकन करा (कापलेले नाही का?). वेगळे मॉडेल वापरून पहा (`gpt-4.1` विरुद्ध `gpt-4.1-mini`).

---

## 5. वितरण त्रुटी

### 5.1 ACR पुल अपरमिश्रित

**ठिक करा:** Azure Portal → Container Registry → Access control (IAM) → Foundry प्रोजेक्टच्या व्यवस्थीत ओळखीला **AcrPull** भूमिका जोडा.

### 5.2 एजंट सुरू होऊ शकत नाही (अडलेला "Pending" किंवा "Failed" मध्ये)

साइडबारमधील कंटेनर लॉग तपासा. सामान्य कारणे:

| लॉग संदेश | ठिक करा |
|-------------|-----|
| `ModuleNotFoundError` | गहाळ पॅकेज `requirements.txt` मध्ये जोडा, पुनर्वितरित करा |
| `KeyError: 'AZURE_AI_PROJECT_ENDPOINT'` | `agent.yaml` मध्ये `environment_variables` अंतर्गत env var जोडा |
| `Address already in use` | एकापेक्षा जास्त प्रक्रिया पोर्ट 8088 वापरत नाही याची खात्री करा |

### 5.3 वितरण वेळ समाप्त

**ठिक करा:** इंटरनेट कनेक्शन तपासा. पहिल्या वितरणामध्ये >100MB पाठवले जाते. प्रॉक्सीमागे आहेत का? Docker Desktop च्या प्रॉक्सी सेटिंग्ज सानुकूल करा.

## 6. पथ B - Foundry लोकल

### 6.1 Foundry लोकल सुरू होत नाही

| समस्या | ठिक करा |
|-------|-----|
| `foundry: command not found` | पुन्हा स्थापित करा: `winget install Microsoft.FoundryLocal` |
| अपुरी संसाधने | Foundry Local कडे ~4GB RAM मोकळी असणे आवश्यक. इतर अ‍ॅप बंद करा. |
| मॉडेल डाउनलोड अयशस्वी | डिस्क जागा तपासा (मॉडेल्स 2–8 GB आहेत). पुन्हा प्रयत्न करा: `foundry local models pull <name>` |

### 6.2 Foundry लोकल मॉडेल त्रुटी

| समस्या | ठिक करा |
|-------|-----|
| हळू प्रतिसाद | अपेक्षित - लोकल मॉडेल्स CPU वर चालतात जोपर्यंत GPU नाही. धीर धरा. |
| खराब गुणवत्ता आउटपुट | तुमच्या हार्डवेअरला परवानगी असल्यास मोठे मॉडेल वापरून पहा. `phi-4-mini` चांगला संतुलन आहे. |
| कनेक्शन नाकारले | Foundry Local चालू आहे का तपासा: `foundry local status`. गरज असल्यास पुनरारंभ करा. |

## 7. वेगवान संदर्भ: RBAC भूमिका

| भूमिका | व्याप्ती | पुरवठा करतो |
|------|-------|--------|
| **Azure AI User** | प्रोजेक्ट | डेटा क्रिया: `agents/write`, `agents/read` |
| **Azure AI Developer** | प्रोजेक्ट/खाते | डेटा क्रिया + प्रोजेक्ट निर्मिती |
| **Azure AI Owner** | खाते | पूर्ण प्रवेश + भूमिका व्यवस्थापन |
| **Contributor** | सदस्यता/आरजी | फक्त व्यवस्थापन क्रिया (**कोणतीही नाही** डेटा क्रिया) |
| **Owner** | सदस्यता/आरजी | व्यवस्थापन + भूमिका नियुक्ती (**कोणतीही नाही** डेटा क्रिया) |
