# लॅब ०२ - बहु-एजंट वर्कफ्लो: रेज्युमे → नोकरी फिट मूल्यांकनकर्ता

## पूर्ण शिक्षण मार्ग

ही कागदपत्रे तुम्हाला चार विशेष एजंट्स वापरून रेज्युमे-ते-नोकरी फिट मूल्यांकन करणारे **बहु-एजंट वर्कफ्लो** तयार करणे, चाचणी करणे आणि तैनात करणे शिकवते, जे **WorkflowBuilder** च्या माध्यमातून संघटित केले आहे.

> **पूर्वअट:** लॅब ०२ सुरू करण्यापूर्वी [लॅब ०१ - सिंगल एजंट](../../lab01-single-agent/README.md) पूर्ण करा.
