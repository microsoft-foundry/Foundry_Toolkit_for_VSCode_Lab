## तुम्ही काय तयार करणार आहात

या लॅबमध्ये, तुम्ही लॅब 01 मधील सिंगल-एजंट कौशल्ये वाढवून एक **मल्टी-एजंट वर्कफ्लो** तयार करता - रिझ्युमे → नोकरीसाठी योग्यता मूल्यांकन.

तुम्ही एक **रिझ्युमे** आणि एक **नोकरीचे वर्णन** पेस्ट करता. चार विशेष एजंट्स क्रमाने इनपुट प्रक्रिया करतात आणि नंतर परत करतात:
- एक फिट स्कोअर (0–100 सह स्कोअरिंग ब्रेकडाउन)
- कौशल्य आणि प्रमाणपत्रातील फरकांची यादी
- प्रत्येक फरकासाठी वास्तविक Microsoft Learn लिंकसह वैयक्तिकृत शैक्षणिक रोडमॅप

**वर्कफ्लो वापरतो:**
- **Microsoft Agent Framework** - `WorkflowBuilder` साठी अनुक्रमित पाइपलाइन संयोजन
- **Foundry Toolkit for VS Code** - स्कॅफोल्ड, स्थानिक चाचणी, वितरण
- **एक AI मॉडेल** (उदा., `gpt-4.1-mini`) - सर्व चार एजंट्स द्वारे वापरले जाते
- **Microsoft Learn MCP सर्व्हर** - प्रत्येक कौशल्य फरकासाठी वास्तविक शिकण्याचे स्त्रोत लिंक प्रदान करतो

## लॅब 01 तपासणी

लॅब 02 थेट लॅब 01 वर आधारित आहे. येथे सुरुवात करण्यापूर्वी लॅब 01 पूर्ण करा.

अजून लॅब 01 केला नाही? येथे सुरू करा: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ मार्ग A - Azure क्लाउड</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

जर हे अपयशी ठरले, तर `az login` चालवा. नंतर VS Code मध्ये तपासा:

1. `Ctrl+Shift+P` → "**Foundry Toolkit**" टाइप करा → कमांड दिसत असल्याची पुष्टी करा.
2. "**Foundry Toolkit**" चिन्हावर क्लिक करा → तुमचा प्रोजेक्ट आणि तैनात मॉडेल **यशस्वी** दाखवते.

![Foundry Toolkit साइडबार ज्यात MY RESOURCES विभाग प्रोजेक्ट स्विचर मोडाल उघडलेला आहे](../../../../../translated_images/mr/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** तुम्ही लॅब 01 मध्ये **Foundry User** नियुक्त केला होता. पुन्हा नियुक्त करण्याची गरज असल्यास, पहा [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac). भूमिका पूर्वी **Azure AI User** नावाची होती - त्याच परवानग्या.

</details>

<details open>
<summary><strong>🅱️ मार्ग B - Foundry स्थानिक</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

अपेक्षित: `StatusCode: 200`. नसल्यास, Foundry Toolkit साइडबारमधून Foundry स्थानिक पुनःप्रारंभ करा.

> सर्व अनुमान तुमच्या मशीनवर चालतात. एकमेव बाह्य कॉल MCP टूल पासून `https://learn.microsoft.com/api/mcp` आहे.

</details>
