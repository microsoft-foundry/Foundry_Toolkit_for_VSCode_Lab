# लॅब ०२ - मल्टि-एजंट वर्कफ्लो: रेज्युमे → नोकरीसाठी योग्यतेचे मूल्यमापन

## आढावा

या हँड्स-ऑन लॅबमध्ये, तुम्ही VS कोडमधील Foundry Toolkit वापरून **वर्कफ्लो-प्रथम मल्टि-एजंट अ‍ॅप** तयार करून ते Microsoft Foundry Agent Service वर तैनात कराल.

**तुम्ही जे तयार कराल:** एक रेज्युमे → नोकरी योग्यतेचे मूल्यांकन करणारा अ‍ॅप जो रेज्युमे आणि नोकरीचे वर्णन पार्स करतो, जुळणीचे गुणांकन करतो, आणि Microsoft Learn स्रोतांचा वापर करून वैयक्तिकृत शिकण्याचा रोडमॅप तयार करतो.

**हे कसे कार्य करते:**
1. वापरकर्ता रेज्युमे आणि नोकरीचे वर्णन पेस्ट करतो.
2. **ResumeParser** रेज्युमे पार्स करतो आणि JD नेमके `[JOB DESCRIPTION PASS-THROUGH]` विभागात कॉपी करतो.
3. **JD Agent** पास-थ्रू मधून संरचित आवश्यकता काढतो, त्यानंतर `[PARSED RESUME]` पुढे `[PARSED RESUME PASS-THROUGH]` म्हणून पाठवतो.
4. **MatchingAgent** `[PARSED RESUME PASS-THROUGH]` आणि `[JD REQUIREMENTS]` यांची तुलना करतो आणि फिट स्कोर तयार करतो.
5. **GapAnalyzer** गॅप्सना प्रॅक्टिकल रोडमॅपमध्ये रूपांतरित करतो आणि MCP च्या माध्यमातून खऱ्या Microsoft Learn दुव्यांसाठी शोध घेतो.

## भाग २: वर्कफ्लो तयार करा आणि तपासा

1. Foundry Toolkit विजार्डचा वापर करून वर्कफ्लो-आधारित प्रोजेक्ट स्कॅफोल्ड करा.
2. `PersonalCareerCopilot/main.py` मधील प्रॉम्प्ट ब्लॉक्स आणि वर्कफ्लो ग्राफ तुमच्या कार्यक्षेत्रात कॉपी करा.
3. एजंट इन्स्पेक्टरसह स्थानिकपणे चालवा आणि सर्व चार एजंट्स आणि MCP टूलची पडताळणी करा.
4. स्थानिक तपासणी पास झाल्यावर होस्टेड एजंट Foundry वर तैनात करा.

## समन्वय नमुने (Orchestration patterns)

लॅब ०२ मध्ये डीफॉल्ट **fan-out → fan-in → अनुक्रमिक** प्रवाह आहे, आणि दस्तऐवजांमध्ये प्रयोगांसाठी पर्यायी समन्वय नमुन्यांचे वर्णन देखील आहे.

- **भारित सहमतीसह Fan-out/Fan-in**
- **अंतिम रोडमॅपपूर्वी पुनरावलोकनकर्ता/टिका करणारा पास**
- **योग्यतेचा गुणांकन आणि गहाळ कौशल्यांवर आधारित अटीसंबंधी राउटर**

पहा [docs/04-orchestration-patterns.md](docs/04-orchestration-patterns.md).
