# ماڈیول 0 - تعارف

⏱️ ~10 منٹ

> [!WARNING]
> **پریویو اور حدود:** [ہوسٹڈ ایجنٹس](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) اس وقت **عوامی پریویو** میں ہیں - پیداوار والے کاموں کے لیے سفارش نہیں کی جاتی۔ درج ذیل باتوں کا خیال رکھیں:
> - **مدد یافتہ علاقے محدود ہیں** - وسائل بنانے سے پہلے [ریجن دستیابی](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) چیک کریں۔ اگر آپ غیر معاون ریجن منتخب کرتے ہیں، تو تعیناتی ناکام ہو جائے گی۔
> - `azure-ai-agentserver-agentframework` پیکیج پری ریلیز ہے - APIs ورژنز کے درمیان تبدیل ہو سکتے ہیں۔
> - اسکیل کی حدود: ہوسٹڈ ایجنٹس 0-5 نقول (ریپلیکا) کی حمایت کرتے ہیں (اسکیل ٹو زیرو سمیت)۔
> - اس ورکشاپ میں دکھائی گئی کچھ خصوصیات GA کی طرف بڑھنے کے دوران تبدیل ہو سکتی ہیں۔

## آپ کیا بنائیں گے

اس ورکشاپ میں، آپ ایک **"ایگزیکٹو کی طرح وضاحت کریں"** ایجنٹ بنائیں گے - ایک ہوسٹڈ اے آئی ایجنٹ جو پیچیدہ تکنیکی اپ ڈیٹس کو سادہ انگریزی ایگزیکٹو خلاصے میں دوبارہ لکھتا ہے۔

```mermaid
flowchart LR
    A["🧑‍💻 آپ ایک\nتکنیکی اپ ڈیٹ بھیجتے ہیں"] --> B["🤖 ایگزیکٹو سمری\nایجنٹ"]
    B --> C["📝 سادہ انگریزی\nایگزیکٹو سمری"]
```

**ایجنٹ استعمال کرتا ہے:**
- **مائیکروسافٹ ایجنٹ فریم ورک** - ایجنٹ کے منطق اور ساخت کے لیے
- **فاؤنڈری ٹول کٹ برائے VS کوڈ** - اسکافولڈنگ، مقامی ٹیسٹنگ، اور تعیناتی کے لیے
- **ایک AI ماڈل** (مثلاً `gpt-4.1-mini/gpt-5-mini`) - خلاصے بنانے کے لیے

اس لیب کے اختتام تک، آپ کے پاس ایک کام کرنے والا ایجنٹ ہوگا جسے آپ ایجنٹ انسپیکٹر کے ذریعے مقامی طور پر ٹیسٹ کر سکتے ہیں، اور خواہش کے مطابق کلاؤڈ پر تعینات کر سکتے ہیں۔

---

## ہوسٹڈ ایجنٹس کیا ہیں؟

ایک **ہوسٹڈ ایجنٹ** ایک AI ایجنٹ ہے جو مائیکروسافٹ فاؤنڈری میں ایک مینیجڈ سروس کے طور پر چلتا ہے۔ اپنی انفراسٹرکچر کو خود مینیج کرنے کے بجائے، آپ اپنا ایجنٹ کوڈ کنٹینر میں پیک کرتے ہیں اور فاؤنڈری اسکیلنگ، ہوسٹنگ، اور اسے ایک معیاری HTTP اینڈ پوائنٹ کے ذریعے ایکسپوز کرنے کا انتظام کرتا ہے۔

| تصور | اس کا مطلب |
|---------|--------------|
| **ایجنٹ** | آپ کا پائتھن کوڈ جو صارف کا پیغام وصول کرتا ہے، AI ماڈل کو کال کرتا ہے، اور ساختی جواب دیتا ہے |
| **ہوسٹڈ** | فاؤنڈری آپ کے کنٹینر کو چلانی ہے - کوئی VM، کوئی Kubernetes، کوئی انفراسٹرکچر مینجمنٹ نہیں |
| **جواب دینے کا پروٹوکول** | ایک معیاری HTTP API (`POST /responses`) جسے کوئی بھی کلائنٹ آپ کے ایجنٹ کے ساتھ تعامل کے لیے کال کر سکتا ہے |
| **ایجنٹ انسپیکٹر** | ایک مقامی ٹیسٹنگ یو آئی (فاؤنڈری ٹول کٹ میں شامل) جو آپ کو تعیناتی سے پہلے اپنے ایجنٹ سے بات چیت کرنے دیتا ہے |

اس ورکشاپ میں، آپ زیرو سے مکمل ہوسٹڈ ایجنٹ تک جائیں گے - یا اگر چاہیں تو صرف مقامی ٹیسٹنگ پر ہی رک سکتے ہیں۔

## تمام راستے: ضروری آلات

نیچے دیے گئے ہر آلے کو انسٹال کریں۔ انسٹال کرنے کے بعد، چیک کمانڈ چلا کر اس کی کارکردگی کی تصدیق کریں۔

| # | آلہ | ورژن | انسٹال کریں | تصدیق (متوقع نتیجہ) |
|---|------|---------|---------|---------------------------|
| 1 | **ویژول اسٹوڈیو کوڈ** | تازہ ترین | [code.visualstudio.com](https://code.visualstudio.com/) | بغیر غلطی کھلتا ہے |
| 2 | **پائتھن** | 3.12 یا اس سے زیادہ| [python.org/downloads](https://www.python.org/downloads/) | `python --version` $\rightarrow$ `Python 3.12.x` |
| 3 | **فاؤنڈری ٹول کٹ برائے VS کوڈ** | تازہ ترین | ایکسٹینشن ID: `ms-windows-ai-studio.windows-ai-studio` | سرگرمی بار میں فاؤنڈری آئیکون |
| 4 | **پائتھن ایکسٹینشن برائے VS کوڈ** | تازہ ترین | ایکسٹینشن ID: `ms-python.python` | ایکسٹینشنز پینل میں انسٹال شدہ |

> [!TIP]
> **انسٹالیشن کے لیے پرو ٹپس:**
> - **پائتھن PATH (ونڈوز):** ہمیشہ پائتھن انسٹالر کی پہلی اسکرین پر **"Add Python to PATH"** کو چیک کریں۔ اس کے بغیر، `python` آپ کے ٹرمینل میں تسلیم نہیں کیا جائے گا۔
> - **کئی پائتھن ورژنز:** اگر آپ کے پاس Python 3.10 اور 3.12 دونوں انسٹال ہیں، تو `python3.12 -m venv .venv` استعمال کریں تاکہ صحیح ورژن آپ کے ورچوئل ماحول میں استعمال ہو۔
> - **ڈوکر WSL 2 (ونڈوز):** ڈوکر ڈیسک ٹاپ انسٹالیشن کے دوران، یقینی بنائیں کہ **WSL 2 بیک اینڈ** منتخب ہے۔ Hyper-V کے ساتھ ڈوکر سست ہوتا ہے اور فاؤنڈری کنٹینر بلڈز میں مسائل پیدا کر سکتا ہے۔
> - **ڈوکر شروع نہیں ہو رہا؟** ڈوکر ڈیسک ٹاپ لانچ کرنے کے بعد 30-60 سیکنڈ انتظار کریں۔ `docker info` چلائیں - اگر آپ کو "Cannot connect to the Docker daemon" نظر آتا ہے، تو ڈوکر ابھی بھی شروع ہو رہا ہے۔
> - **VS کوڈ ایکسٹینشنز لوڈ نہیں ہو رہی؟** ایکسٹینشنز انسٹال کرنے کے بعد ونڈو کو دوبارہ لوڈ کریں: `Ctrl+Shift+P` → `Developer: Reload Window`.

> **ونڈوز صارفین:** پائتھن انسٹالیشن کے دوران **"Add Python to PATH"** کو چیک کریں۔
