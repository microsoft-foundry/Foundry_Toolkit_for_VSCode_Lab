# ماڈیول 8 - مسائل کا حل

یہ ماڈیول عمومی مسائل کے لیے ایک حوالہ گائیڈ ہے۔ اس کا بُک مارک بنائیں اور جب کچھ غلط ہو تو یہاں واپس آئیں۔

---

## 1. اجازت کی غلطیاں

### 1.1 `agents/write` اجازت رد

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**بنیادی وجہ:** `Azure AI User` کردار کی کمی **پروجیکٹ** سطح پر۔ یہ ورکشاپ کی سب سے عام غلطی ہے۔

**حل:**
1. کھولیں [portal.azure.com](https://portal.azure.com).
2. اپنے Foundry **پروجیکٹ** کا نام تلاش کریں → **"Microsoft Foundry project"** قسم کے نتیجے پر کلک کریں (والد اکاؤنٹ پر نہیں)۔
3. **Access control (IAM)** → **+ Add** → **Add role assignment**۔
4. کردار: **Azure AI User** → اگلا۔
5. ممبرز: خود منتخب کریں → جائزہ لیں + تفویض کریں → جائزہ لیں + تفویض کریں۔
6. **1-2 منٹ انتظار کریں** → دوبارہ کوشش کریں۔

> **کیوں Owner/Contributor کافی نہیں ہیں:** یہ کردار صرف *انتظامی* کارروائیاں دیتے ہیں۔ ایجنٹ کی کارروائیوں کے لیے `agents/write` *ڈیٹا ایکشن* کی ضرورت ہے، جو صرف `Azure AI User`، `Azure AI Developer`، یا `Azure AI Owner` میں ہوتا ہے۔ دیکھیں [Foundry RBAC docs](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry)۔

### 1.2 `AuthorizationFailed` پروویژننگ کے دوران

**حل:** اپنے ایڈمن سے کہیں کہ ریسورس گروپ پر **Contributor** مقرر کرے، یا وہ آپ کے لیے پروجیکٹ بنائیں اور آپ کو اس پر **Azure AI User** دیں۔

### 1.3 `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# انتظار کریں جب تک: "رجسٹرڈ"
```

---

## 2. ڈاکر کی غلطیاں

> ڈاکر **اختیاری** ہے۔ یہ صرف اس صورت میں لاگو ہوتے ہیں جب ڈاکر ڈیسک ٹاپ انسٹال ہو اور ایکسٹینشن لوکل بلڈ کی کوشش کرے۔

### 2.1 ڈاکر ڈیمان چل نہیں رہا

**حل:** ڈاکر ڈیسک ٹاپ شروع کریں → "running" اسٹیٹس کا انتظار کریں → `docker info` سے تصدیق کریں → دوبارہ کوشش کریں۔

### 2.2 انحصاری کی غلطیوں کے باعث بلڈ ناکام

**حل:** `requirements.txt` کی ہجے چیک کریں، پہلے لوکل ٹیسٹ کریں: `pip install -r requirements.txt`۔

### 2.3 پلیٹ فارم کا میل نہ کھانا (ایپل سلیکن)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

---

## 3. توثیق کی غلطیاں

### 3.1 `DefaultAzureCredential` ناکام ہو گیا

**حل (ترتیب سے آزمائیں):**
1. `az login` (دوبارہ تصدیق)
2. `az account set --subscription "<id>"` (صحیح سبسکرپشن)
3. VS Code → Accounts → Sign Out → دوبارہ سائن ان کریں
4. تصدیق کریں: `az account get-access-token --resource https://cognitiveservices.azure.com`

### 3.2 ٹوکن لوکل کام کرتا ہے مگر ہوسٹڈ نہیں

**متوقع:** ہوسٹڈ ایجنٹس سسٹم مینجڈ آئیڈینٹی استعمال کرتے ہیں، آپ کی کریڈینشل نہیں۔ اگر ہوسٹڈ ایجنٹ کو آتھ کی غلطیاں آئیں:
- چیک کریں `AZURE_AI_PROJECT_ENDPOINT` `agent.yaml` میں صحیح ہے
- تصدیق کریں کہ پروجیکٹ کی مینجڈ آئیڈینٹی کو ماڈل تک رسائی حاصل ہے

---

## 4. ماڈل کی غلطیاں

### 4.1 ماڈل تعیناتی نہیں ملی

**حل:** نام **حساس ہوتا ہے۔** `.env` میں `AZURE_AI_MODEL_DEPLOYMENT_NAME` کا موازنہ Foundry کی سائڈبار میں Models کے عین نام سے کریں۔

### 4.2 غیر متوقع ماڈل آؤٹ پٹ

**حل:** `main.py` میں `AGENT_INSTRUCTIONS` کا جائزہ لیں (کیا کٹ نہیں ہوئے؟)۔ مختلف ماڈل آزمائیں (`gpt-4.1` بمقابلہ `gpt-4.1-mini`)۔

---

## 5. تعیناتی کی غلطیاں

### 5.1 ACR پل غیر مجاز

**حل:** Azure Portal → Container Registry → Access control (IAM) → Foundry پروجیکٹ کی مینجڈ آئیڈینٹی کو **AcrPull** رول دیں۔

### 5.2 ایجنٹ شروع نہیں ہوتا (ہمیشہ "Pending" یا "Failed" رہتا ہے)

سائڈبار میں کنٹینر کے لوگ چیک کریں۔ عام وجوہات:

| لاگ پیغام | حل |
|-------------|-----|
| `ModuleNotFoundError` | `requirements.txt` میں گم شدہ پیکج شامل کریں، دوبارہ تعینات کریں |
| `KeyError: 'AZURE_AI_PROJECT_ENDPOINT'` | `agent.yaml` میں `environment_variables` کے تحت env var شامل کریں |
| `Address already in use` | یقینی بنائیں کہ صرف ایک پراسیس پورٹ 8088 پر بند ہو |

### 5.3 تعیناتی کا وقت ختم ہو گیا

**حل:** انٹرنیٹ کنکشن چیک کریں۔ پہلی تعیناتی میں >100MB بھیجا جاتا ہے۔ پراکسی کے پیچھے ہیں؟ ڈاکر ڈیسک ٹاپ پراکسی سیٹنگز ترتیب دیں۔

---

## 6. راستہ ب - Foundry لوکل

### 6.1 Foundry لوکل شروع نہیں ہوتا

| مسئلہ | حل |
|-------|-----|
| `foundry: command not found` | دوبارہ انسٹال کریں: `winget install Microsoft.FoundryLocal` |
| وسائل ناکافی | Foundry Local کو تقریباً 4GB RAM خالی چاہیے۔ دیگر ایپس بند کریں۔ |
| ماڈل ڈاؤن لوڈ ناکام | ڈسک اسپیس چیک کریں (ماڈل 2-8 GB ہوتے ہیں)۔ دوبارہ کوشش: `foundry local models pull <name>` |

### 6.2 Foundry لوکل ماڈل کی غلطیاں

| مسئلہ | حل |
|-------|-----|
| سست ردعمل | متوقع ہے - لوکل ماڈلز CPU پر چلتے ہیں جب تک کہ آپ کے پاس GPU نہ ہو۔ صبر کریں۔ |
| ناقص معیار کا آؤٹ پٹ | اگر آپ کے ہارڈویئر کی اجازت ہو تو بڑا ماڈل آزمائیں۔ `phi-4-mini` اچھا توازن ہے۔ |
| کنکشن مسترد | تصدیق کریں کہ Foundry Local چل رہا ہے: `foundry local status`۔ ضرورت پر دوبارہ شروع کریں۔ |

---

## 7. فوری حوالہ: RBAC کردار

| کردار | دائرہ کار | دیتی ہے |
|------|-------|--------|
| **Azure AI User** | پروجیکٹ | ڈیٹا ایکشنز: `agents/write`, `agents/read` |
| **Azure AI Developer** | پروجیکٹ/اکاؤنٹ | ڈیٹا ایکشنز + پروجیکٹ تخلیق |
| **Azure AI Owner** | اکاؤنٹ | مکمل رسائی + رول مینجمنٹ |
| **Contributor** | سبسکرپشن/RG | صرف انتظامی کارروائیاں (**کوئی** ڈیٹا ایکشن نہیں) |
| **Owner** | سبسکرپشن/RG | انتظام + رول تفویض (**کوئی** ڈیٹا ایکشن نہیں) |
