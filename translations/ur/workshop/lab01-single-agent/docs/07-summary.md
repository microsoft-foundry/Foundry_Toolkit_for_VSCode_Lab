# ماڈیول 7 - خلاصہ اور اگلے اقدامات

⏱️ ~5 منٹ

**مبارک ہو!** آپ نے Microsoft Foundry اور Foundry Toolkit برائے VS Code استعمال کرتے ہوئے ایک ہوسٹڈ AI ایجنٹ بنایا، جانچا، اور (اگر راستہ A پر ہیں) تعینات کیا ہے۔

---

## آپ نے کیا بنایا

ایک **"ایگزیکٹو کی طرح وضاحت کریں"** ایجنٹ جو:
- تکنیکی واقعہ رپورٹس یا آپریشنل اپڈیٹس HTTP (`POST /responses`) کے ذریعے وصول کرتا ہے
- انہیں آسان زبان میں ایگزیکٹو خلاصوں میں ترجمہ کرتا ہے
- ایک ساختہ آؤٹ پٹ فارمیٹ کی پیروی کرتا ہے (کیا ہوا / کاروباری اثر / اگلا اقدام)
- غیر متعلقہ درخواستوں اور پرامپٹ انجیکشن کوششوں کو مسترد کرتا ہے
- Microsoft Foundry Agent Service میں کنٹینرائزڈ ہوسٹڈ ایجنٹ کے طور پر چلتا ہے

---

## اہم تصورات جو سیکھے

| تصور | آپ نے کیا مشق کی |
|---------|-------------------|
| **ایجنٹ فریم ورک کی ساخت** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` پائپ لائن |
| **ہوسٹڈ ایجنٹ کا لائف سائیکل** | اسکیفولڈ → ترتیب دیں → مقامی طور پر جانچیں → تعینات کریں → کلاؤڈ میں تصدیق کریں |
| **سسٹم پرامپٹ انجینئرنگ** | کردار، سامعین، آؤٹ پٹ فارمیٹ، قواعد، حفاظتی پابندیاں، اور مثالیں |
| **مقامی اور ہوسٹڈ میں فرق** | شناخت (ذاتی اسناد بمقابلہ منظم شناخت)، اینڈپوائنٹ، نیٹ ورک راستہ |
| **حفاظتی حدود** | پرامپٹ انجیکشن دفاع، کردار کی پابندی، کنارے کے معاملات کی موزوں ہینڈلنگ |
| **Foundry Toolkit ورک فلو** | پروجیکٹ کی تخلیق، ماڈل کی تعیناتی، ایجنٹ اسکیفولڈنگ، ایجنٹ انسپکٹر، ایک کلک تعیناتی |

### اپنے ایجنٹ کو بڑھانے کے خیالات

- **تاریخ کا ٹول شامل کریں** - ایجنٹ کو "آج کی تاریخ کے لحاظ سے" سیاق و سباق شامل کرنے دیں
- **ایک واقعہ ڈیٹا بیس سے منسلک کریں** - ایک ٹول فنکشن کے ذریعے حقیقی واقعہ کی تفصیلات نکالیں
- **ایک Bing گراؤنڈنگ ٹول شامل کریں** - ایجنٹ کو اضافی سیاق و سباق کے لیے حالیہ خبروں کی تلاش کرنے دیں
- **مختلف ماڈلز آزمائیں** - `gpt-4.1` بمقابلہ `gpt-4.1-mini` آؤٹ پٹ معیار کا موازنہ کریں
- **Foundry کے ساتھ جائزہ لیں** - ایجنٹ کے معیار کو پیمانے پر ناپنے کے لیے Evaluations فیچر استعمال کریں

### راستہ B کے صارفین کے لیے: کلاؤڈ تعیناتی میں اپ گریڈ کریں

جب آپ کلاؤڈ میں تعینات کرنے کے لیے تیار ہوں:
1. Azure سبسکرپشن حاصل کریں ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [ماڈیول 01، سیٹ اپ](01-setup.md#step-2-set-up-based-on-your-access) مکمل کریں (پروجیکٹ بنائیں، ماڈل تعینات کریں، RBAC تفویض کریں)
3. اپنے `.env` کو Foundry پروجیکٹ اینڈپوائنٹ اور ماڈل تعیناتی کے نام سے اپ ڈیٹ کریں
4. [ماڈیول 05 - Foundry میں تعینات کریں](05-deploy-to-foundry.md) سے جاری رکھیں

## وسائل کی صفائی (اختیاری)

اگر آپ اس ورکشاپ کے دوران بنائے گئے Azure وسائل کو ہٹانا چاہتے ہیں:

### آپشن 1: ریسورس گروپ حذف کریں (سب کچھ ہٹا دیتا ہے)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### آپشن 2: صرف ہوسٹڈ ایجنٹ کو حذف کریں

1. کھولیں [ai.azure.com](https://ai.azure.com) → اپنا پروجیکٹ → **Build** → **Agents**.
2. اپنے ایجنٹ پر کلک کریں → **Delete** پر کلک کریں۔

### آپشن 3: ماڈل تعیناتی حذف کریں

1. Foundry سائڈبار میں اپنے پروجیکٹ کو بڑھائیں → **Models**.
2. ماڈل تعیناتی پر رائٹ کلک کریں → **Delete**.

> **لاگت کا نوٹ:** ہوسٹڈ ایجنٹس صرف چلنے پر لاگت آتی ہے۔ اگر آپ ایجنٹ کو روک دیں یا حذف کر دیں، تو کوئی مسلسل چارج نہیں ہوتا۔ ماڈل تعیناتی ممکنہ طور پر مختص گنجائش کے لیے معمولی چارج لگا سکتی ہے - اگر آپ ختم ہو چکے ہیں تو اسے حذف کر دیں۔
