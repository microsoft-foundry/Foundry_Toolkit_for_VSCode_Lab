# لیب 02 - ملٹی ایجنٹ ورک فلو: ریزیومے → جاب فٹ ایولیویٹر

## جائزہ

اس عملی لیب میں، آپ VS کوڈ میں Foundry Toolkit استعمال کرتے ہوئے ایک **ورک فلو-اول ملٹی ایجنٹ ایپ** بنائیں گے اور اسے Microsoft Foundry Agent Service پر تعینات کریں گے۔

**جو آپ بنائیں گے:** ریزیومے → جاب فٹ ایولیویٹر جو ریزیومے اور جاب کی تفصیل کو پارس کرتا ہے، میچ کا اسکور دیتا ہے، اور Microsoft Learn وسائل استعمال کرتے ہوئے ایک ذاتی نوعیت کا لرننگ روڈ میپ تیار کرتا ہے۔

---

    C -->|"[جی ڈی کی ضروریات] + [تجزیہ شدہ ریزیومے پاس تھرو]"| D["میچنگ ایجنٹ"]

**یہ کیسے کام کرتا ہے:**
1. صارف ریزیومے اور جاب کی تفصیل پیسٹ کرتا ہے۔
2. **ResumeParser** ریزیومے کو پارس کرتا ہے اور جاب ڈسکرپشن کو بالکل ویسا ہی `[JOB DESCRIPTION PASS-THROUGH]` سیکشن میں کاپی کرتا ہے۔
3. **JD Agent** پاس تھرو سے ساختی تقاضے نکالتا ہے، پھر `[PARSED RESUME]` کو آگے `[PARSED RESUME PASS-THROUGH]` کے طور پر بھیجتا ہے۔
4. **MatchingAgent** `[PARSED RESUME PASS-THROUGH]` اور `[JD REQUIREMENTS]` کا موازنہ کرتا ہے اور فٹ اسکور پیدا کرتا ہے۔
5. **GapAnalyzer** خلا کو ایک عملی روڈ میپ میں بدلتا ہے اور MCP کے ذریعے Microsoft Learn کے حقیقی روابط لاتا ہے۔

## حصہ 2: ورک فلو بنائیں اور آزمائیں

1. Foundry Toolkit وزرڈ استعمال کریں تاکہ ورک فلو پر مبنی پروجیکٹ کی تشکیل کریں۔
2. `PersonalCareerCopilot/main.py` سے پرامپٹ بلاکس اور ورک فلو گراف کو اپنے ورک اسپیس میں کاپی کریں۔
3. ایجنٹ انسپکٹر کے ساتھ مقامی طور پر چلائیں اور تمام چار ایجنٹس کے ساتھ MCP ٹول کی تصدیق کریں۔
4. جب مقامی ٹیسٹنگ کامیاب ہو جائے تو ہوسٹڈ ایجنٹ کو Foundry پر تعینات کریں۔

## ہم آہنگی کے نمونے
