## آپ کیا بنائیں گے

اس لیب میں، آپ لیب 01 کی سنگل ایجنٹ مہارتوں کو بڑھاتے ہوئے ایک **کثیر ایجنٹ ورک فلو** بنائیں گے - ریزیومے → جاب فٹ ایولیویٹر۔

آپ ایک **ریزیومے** اور ایک **جاب ڈسکرپشن** چسپاں کرتے ہیں۔ چار ماہر ایجنٹ ان پٹ کو متواتر پروسیس کرتے ہیں، پھر یہ واپس کرتے ہیں:
- فٹ اسکور (0–100 ایک اسکورنگ بریک ڈاؤن کے ساتھ)
- مہارت اور سرٹیفیکیشن کی کمی کی فہرست
- ہر کمی کے لئے مائیکروسافٹ لرن کے حقیقی لنکس کے ساتھ ایک شخصی سیکھنے کا روڈ میپ

**ورک فلو استعمال کرتا ہے:**
- **Microsoft Agent Framework** - `WorkflowBuilder` برائے متواتر پائپ لائن آرکسٹریشن
- **Foundry Toolkit for VS Code** - اسکیفولڈ، مقامی طور پر ٹیسٹ کریں، تعینات کریں
- **ایک AI ماڈل** (مثلاً `gpt-4.1-mini`) - چاروں ایجنٹس استعمال کرتے ہیں
- **Microsoft Learn MCP سرور** - ہر مہارت کی کمی کے لئے حقیقی سیکھنے کے وسائل کے لنکس فراہم کرتا ہے

## لیب 01 چیک

لیب 02 براہ راست لیب 01 پر تعمیر ہے۔ یہاں شروع کرنے سے پہلے لیب 01 مکمل کریں۔

کیا آپ نے ابھی تک لیب 01 نہیں کی؟ یہاں سے شروع کریں: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ راستہ A - Azure کلاؤڈ</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

اگر یہ ناکام ہو، تو `az login` چلائیں۔ پھر VS Code میں تصدیق کریں:

1. `Ctrl+Shift+P` → **Foundry Toolkit** ٹائپ کریں → کمانڈز ظاہر ہوں۔
2. **Foundry Toolkit** آئیکن دبائیں → آپ کا پروجیکٹ اور تعینات ماڈل **کامیاب** دکھائیں۔

![Foundry Toolkit سائڈبار جس میں My Resources کے تحت پروجیکٹ دکھا رہا ہے، سوئچ پروجیکٹ / نیا پروجیکٹ منتخب کنندہ کھلا ہوا](../../../../../translated_images/ur/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** آپ نے لیب 01 میں **Foundry User** اسائن کیا تھا۔ اگر دوبارہ اسائن کرنا ہو تو دیکھیے [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac)۔ یہ کردار پہلے **Azure AI User** کہلاتا تھا - وہی اجازتیں ہیں۔
