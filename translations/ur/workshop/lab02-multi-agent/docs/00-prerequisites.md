> [!WARNING]

## آپ کیا بنائیں گے

اس لیب میں، آپ لیب 01 سے سنگل ایجنٹ مہارتوں کو بڑھاتے ہوئے ایک **ملٹی ایجنٹ ورک فلو** بنائیں گے - ریزیومے → جاب فٹ ایویلیو ایٹر۔

آپ ایک **ریزیومے** اور ایک **جاب کی تفصیل** چسپاں کرتے ہیں۔ چار ماہر ایجنٹس ان پٹ کو ترتیب وار پروسیس کرتے ہیں، پھر واپس کرتے ہیں:
- ایک فٹ اسکور (0–100 اسکورنگ تفصیل کے ساتھ)
- مہارت اور سرٹیفیکیشن میں خلا کی فہرست
- ہر خلا کے لیے اصلی Microsoft Learn لنکس کے ساتھ ذاتی سیکھنے کا روڈ میپ

**ورک فلو استعمال کرتا ہے:**
- **Microsoft Agent Framework** - `WorkflowBuilder` ترتیب وار پائپ لائن آرکسٹریشن کے لیے
- **Foundry Toolkit for VS Code** - سکیفولڈ، لوکل ٹیسٹنگ، تعیناتی
- **ایک AI ماڈل** (مثلاً `gpt-4.1-mini`) - چاروں ایجنٹس کے ذریعے استعمال کیا جاتا ہے
- **Microsoft Learn MCP سرور** - ہر مہارت کے خلا کے لیے اصلی سیکھنے کے وسائل کے لنکس فراہم کرتا ہے

## لیب 01 کی جانچ

لیب 02 براہ راست لیب 01 پر مبنی ہے۔ پہلے لیب 01 مکمل کریں پھر یہاں شروع کریں۔

کیا آپ نے ابھی تک لیب 01 نہیں کی؟ یہاں سے شروع کریں: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ راستہ A - Azure کلاؤڈ</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

اگر یہ ناکام ہو تو، `az login` چلائیں۔ پھر VS Code میں تصدیق کریں:

1. `Ctrl+Shift+P` → **Foundry Toolkit** ٹائپ کریں → کمانڈز ظاہر ہونے کی تصدیق کریں۔
2. **Foundry Toolkit** آئیکن پر کلک کریں → آپ کا پروجیکٹ اور تعینات کیا ہوا ماڈل **Succeeded** دکھائیں۔

![Foundry Toolkit سائڈبار میں MY RESOURCES سیکشن دکھاتے ہوئے، پروجیکٹ سوئچر موڈل کھلا ہوا](../../../../../translated_images/ur/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** آپ نے لیب 01 میں **Foundry User** تفویض کیا تھا۔ اگر دوبارہ تفویض کرنا ہو تو دیکھیں [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac). یہ رول پہلے **Azure AI User** کہلایا کرتا تھا - ایک ہی اجازتیں۔

</details>

<details open>
<summary><strong>🅱️ راستہ B - Foundry لوکل</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

متوقع: `StatusCode: 200`۔ اگر نہیں، تو Foundry Toolkit سائڈبار سے Foundry لوکل دوبارہ شروع کریں۔

> تمام انفرنس آپ کے کمپیوٹر پر چلتی ہے۔ واحد آؤٹ باؤنڈ کال MCP ٹول سے `https://learn.microsoft.com/api/mcp` کو جاتی ہے۔

</details>
