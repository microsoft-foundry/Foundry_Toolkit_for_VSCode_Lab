# لیب 02 - کثیر الاجنٹ ورک فلو: رزومہ → جاب فٹ ایویلیوایٹر

## مکمل لرننگ پاتھ

یہ دستاویزات آپ کو ایک **کثیر الاجنٹ ورک فلو** بنانے، جانچنے، اور تعینات کرنے کے عمل سے گزارتی ہے جو چار مخصوص ایجنٹس کے ذریعے رزومے سے جاب کی مطابقت کا اندازہ لگاتی ہے جو **WorkflowBuilder** کے ذریعے ہم آہنگ کیے جاتے ہیں۔
