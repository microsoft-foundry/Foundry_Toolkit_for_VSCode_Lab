# Maabara 02 - Mtiririko wa Kazi wa Wakala Wengi: Mieza → Mkaguzi wa Ulinganifu wa Kazi

## Njia Kamili ya Kujifunza

Hati hii inaonyesha jinsi ya kujenga, kujaribu, na kuweka kwenye matumizi **mtiririko wa kazi wa mawakala wengi** ambao hukadiria ulinganifu wa miezi kuhusiana na kazi kwa kutumia mawakala wanne maalum walioratibiwa kupitia **WorkflowBuilder**.

> **Shtaka la awali:** Maliza [Maabara 01 - Wakala Mmoja](../../lab01-single-agent/README.md) kabla ya kuanza Maabara 02.
