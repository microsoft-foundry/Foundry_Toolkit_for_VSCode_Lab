# Supporto

## Come segnalare problemi e ottenere aiuto  

Questo progetto usa GitHub Issues per tracciare bug e richieste di funzionalità. Si prega di cercare 
i problemi esistenti prima di segnalare nuovi problemi per evitare duplicati. Per nuovi problemi, 
segnala il tuo bug o la richiesta di funzionalità come un nuovo Issue.

Per aiuto e domande sull’uso di questo progetto, per favore **RESPONSABILE DEL REPO: INSERISCI QUI LE ISTRUZIONI 
SU COME COINVOLGERE I PROPRIETARI DEL REPO O LA COMMUNITY PER OTTENERE AIUTO. POTREBBE ESSERE UN TAG STACK 
OVERFLOW O UN CANALE DIVERSO. DOVE AIUTERAI LE PERSONE?**.
