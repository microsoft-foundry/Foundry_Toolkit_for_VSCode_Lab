## Sicurezza

Microsoft prende sul serio la sicurezza dei nostri prodotti software e servizi, il che
include tutti i repository di codice sorgente nelle nostre organizzazioni GitHub.

**Per favore, non segnalare le vulnerabilità di sicurezza tramite issue pubbliche su GitHub.**

Per informazioni sulla segnalazione di sicurezza, posizioni, contatti e politiche,
ti invitiamo a consultare le ultime linee guida per i repository Microsoft su
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
