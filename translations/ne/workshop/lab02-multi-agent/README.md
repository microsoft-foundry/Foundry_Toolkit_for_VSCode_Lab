# ल्याब ०२ - बहु-एजेन्ट कार्यप्रवाह: रेजुमे → जागिर अनुकूल मूल्याङ्कनकर्ता

## अवलोकन

यस व्यावहारिक ल्याबमा, तपाईं VS कोडमा Foundry Toolkit प्रयोग गरी **वर्कफ्लो-प्रथम बहु-एजेन्ट एप्लिकेशन** निर्माण गर्नुहुनेछ र यसलाई Microsoft Foundry Agent Service मा तैनाथ गर्नुहुनेछ।

**तपाईंले कुन कुरा बनाउन सक्नुहुन्छ:** एक Resume → Job Fit Evaluator जसले रेजुमे र कामको विवरण पार्स गर्दछ, मेलखाताको स्कोर गर्दछ, र Microsoft Learn स्रोतहरू प्रयोग गरी व्यक्तिगत सिकाइ रोडम्याप उत्पादन गर्दछ।

**यो कसरी काम गर्छ:**
1. प्रयोगकर्ताले एक रेजुमे र काम विवरण पेस्ट गर्दछ।
2. **ResumeParser** ले रेजुमे पार्स गर्दछ र JD लाई शब्दशः `[JOB DESCRIPTION PASS-THROUGH]` खण्डमा प्रतिलिपि गर्दछ।
3. **JD Agent** ले पास-थ्रू बाट संरचित मागहरू निकाल्छ, त्यसपछि `[PARSED RESUME]` लाई अगाडि `[PARSED RESUME PASS-THROUGH]` को रूपमा पठाउँछ।
4. **MatchingAgent** ले `[PARSED RESUME PASS-THROUGH]` र `[JD REQUIREMENTS]` लाई तुलना गरेर फिट स्कोर उत्पादन गर्दछ।
5. **GapAnalyzer** ले ग्यापहरूलाई व्यावहारिक रोडम्यापमा परिवर्तन गर्छ र MCP मार्फत वास्तविक Microsoft Learn लिंकहरू ल्याउँछ।

## भाग २: वर्कफ्लो बनाउनुहोस् र परीक्षण गर्नुहोस्

1. Foundry Toolkit विजार्डको प्रयोग गरेर वर्कफ्लो-आधारित प्रोजेक्ट स्क्याफोल्ड गर्नुहोस्।
2. `PersonalCareerCopilot/main.py` बाट प्रॉम्प्ट ब्लकहरू र वर्कफ्लो ग्राफ कपी गरेर आफ्नो वर्कस्पेसमा राख्नुहोस्।
3. एजेन्ट इन्स्पेक्टरसँग स्थानीय रूपमा चलाउनुहोस् र सबै चार एजेन्टहरू तथा MCP उपकरणको जाँच गर्नुहोस्।
4. स्थानीय परीक्षण पास भएपछि होस्ट गरिएको एजेन्टलाई Foundry मा तैनाथ गर्नुहोस्।
