## पूर्ण सिकाइ मार्ग

यस दस्तावेजले तपाइँलाई चारवटा विशेषज्ञ एजेन्टहरूद्वारा सञ्चालित **WorkflowBuilder** मार्फत रिजुमे-देखि-रोजगार मिलानको मूल्याङ्कन गर्ने **बहु-एजेन्ट कार्यप्रवाह** निर्माण, परीक्षण, र परिनियोजन गर्ने प्रक्रिया देखाउँछ।

> **पूर्व-शर्त:** प्रयोगशाला 02 सुरु गर्नु अघि [प्रयोगशाला 01 - एकल एजेन्ट](../../lab01-single-agent/README.md) पूरा गर्नुहोस्।
