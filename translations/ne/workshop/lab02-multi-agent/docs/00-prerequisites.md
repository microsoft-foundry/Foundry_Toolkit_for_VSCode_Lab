## के बनाउने छन् तपाईँले

यस प्रयोगशालामा, तपाईंले Lab 01 का एकल एजेन्ट कौशलहरूलाई विस्तार गरेर **बहु-एजेन्ट वर्कफ्लो** बनाउनुहुन्छ - रिजुमे → जागिर फिट मूल्यांकनकर्ता।

तपाईंले एउटा **रिजुमे** र एउटा **जागिर विवरण** टाँस्नुहुन्छ। चार विशेषज्ञ एजेन्टहरूले इनपुटलाई क्रमशः प्रक्रिया गर्छन्, त्यसपछि फिर्ता गर्छन्:
- फिट स्कोर (०–१०० र स्कोरिङ विवरण सहित)
- सीप र प्रमाणपत्र अन्तरको सूची
- प्रत्येक अन्तरका लागि वास्तविक Microsoft Learn लिंक सहित निजीकरण गरिएको सिकाइ रोडम्याप

**वर्कफ्लोले प्रयोग गर्छ:**
- **Microsoft Agent Framework** - `WorkflowBuilder` को लागि अनुक्रमिक पाइपलाइन समन्वय
- **Foundry Toolkit for VS Code** - स्क्याफोल्ड, स्थानीय परीक्षण, परिनियोजन
- **एआई मोडेल** (उदाहरण, `gpt-4.1-mini`) - सबै चार एजेन्टहरूले प्रयोग गर्ने
- **Microsoft Learn MCP सर्भर** - प्रत्येक सीप अन्तरका लागि वास्तविक सिकाइ स्रोत लिंकहरू प्रदान गर्छ

## Lab 01 जाँच

Lab 02 सिधै Lab 01 मा आधारित छ। यहाँ सुरुवात गर्नु अघि Lab 01 पूरा गर्नुहोस्।

Lab 01 अझै गर्नुभएको छैन? यहाँबाट सुरु गर्नुहोस्: [Lab 01 - परिचय](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ बाटो A - Azure क्लाउड</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

यदि असफल भयो भने, `az login` चलाउनुहोस्। त्यसपछि VS Code मा जाँच गर्नुहोस्:

१. `Ctrl+Shift+P` → टाइप गर्नुहोस् **Foundry Toolkit** → कमाण्डहरू देखा पर्न सुनिश्चित गर्नुहोस्।
२. **Foundry Toolkit** आइकनमा क्लिक गर्नुहोस् → तपाईंको परियोजना र परिनियोजित मोडेलले **सफल भयो** देखाउँछ।

![Foundry Toolkit साइडबारमा My Resources अन्तर्गत परियोजना देखाउँदै, Switch project / Create project पिकर खुल्ला छ](../../../../../translated_images/ne/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** तपाईंले Lab 01 मा **Foundry User** असाइन गर्नुभएको थियो। पुनः असाइन गर्नुपर्ने भएमा [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac) हेर्नुहोस्। यस भूमिकालाई पहिले **Azure AI User** भनिन्थ्यो - समान अनुमति।

</details>

<details open>
<summary><strong>🅱️ बाटो B - Foundry Local</strong></summary>
