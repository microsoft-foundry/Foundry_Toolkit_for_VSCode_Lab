# मोड्युल ७ - सारांश र आगामी चरणहरू

⏱️ ~५ मिनेट

**बधाई छ!** तपाईले Microsoft Foundry र Foundry Toolkit for VS Code प्रयोग गरेर होस्ट गरिएको AI एजेन्ट बनाउनु, परीक्षण गर्नु, र (यदि पथ A मा हुनुहुन्छ भने) डिप्लोय गर्नुभयो।

---

## तपाईले के बनाउनु भयो

एक **"व्यवस्थापकझैं व्याख्या गर्नुहोस्"** एजेन्ट जुन:
- HTTP (`POST /responses`) मार्फत प्राविधिक घटना रिपोर्टहरू वा सञ्चालन अपडेटहरू प्राप्त गर्दछ
- तिनीहरूलाई सामान्य भाषा व्यवस्थापक सारांशहरूमा अनुवाद गर्दछ
- संरचित आउटपुट ढाँचा अनुसरण गर्दछ (के भयो / व्यवसाय प्रभाव / आगामी कदम)
- विषयवस्तु बाहिरका अनुरोधहरू र प्राँप्ट इन्जेक्शन प्रयासहरू अस्वीकार गर्दछ
- Microsoft Foundry Agent Service मा कन्टेनराइज्ड होस्ट गरिएको एजेन्टको रूपमा चल्छ

---

## प्रमुख अवधारणाहरु सिक्नुभयो

| अवधारणा | तपाईंले अभ्यास गर्नुभयो |
|---------|-------------------|
| **एजेन्ट फ्रेमवर्क वास्तुकला** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` पाइपलाइन |
| **होस्ट गरिएको एजेन्ट जीवनचक्र** | स्क्याफोल्ड → कन्फिगर → स्थानीय परीक्षण → डिप्लोय → क्लाउडमा प्रमाणित गर्नुहोस् |
| **प्रणाली प्राँप्ट इन्जिनियरिङ** | भूमिका, दर्शक, आउटपुट ढाँचा, नियमहरू, सुरक्षा प्रतिबन्धहरू, र उदाहरणहरू |
| **स्थानीय vs होस्ट गरिएको फरकहरू** | पहिचान (व्यक्तिगत प्रमाणपत्र बनाम व्यवस्थापित पहिचान), अन्तबिन्दु, नेटवर्क मार्ग |
| **सुरक्षा सीमा** | प्राँप्ट इन्जेक्शन रक्षा, भूमिका पालना, किनार अवस्था को राम्रो ह्यान्डलिङ |
| **Foundry Toolkit कार्यप्रवाह** | परियोजना सिर्जना, मोडेल डिप्लोयमेन्ट, एजेन्ट स्क्याफोल्डिङ, एजेन्ट इन्स्पेक्टर, एक-क्लिक डिप्लोय |

### आफ्नो एजेन्ट विस्तारका लागि विचारहरू

- **मिति उपकरण थप्नुहोस्** - एजेन्टले सारांशहरूमा "आजको मिति अनुसार" सन्दर्भ समावेश गर्न सक्छ
- **घटना डाटाबेससँग जडान गर्नुहोस्** - उपकरण फङ्क्शनमार्फत वास्तविक घटना विवरणहरू ल्याउनुहोस्
- **Bing आधार उपकरण थप्नुहोस्** - एजेन्टले अतिरिक्त सन्दर्भको लागि हालैका समाचारहरू खोज्न सक्छ
- **विभिन्न मोडेलहरू प्रयास गर्नुहोस्** - `gpt-4.1` र `gpt-4.1-mini` आउटपुट गुणस्तर तुलना गर्नुहोस्
- **Foundry सँग मूल्यांकन गर्नुहोस्** - एजेन्ट गुणस्तर मापन गर्न Evaluations सुविधा प्रयोग गर्नुहोस्

### पथ B प्रयोगकर्ताहरूका लागि: क्लाउड डिप्लोयमेन्टमा अपग्रेड गर्नुहोस्

जब तपाईं क्लाउडमा डिप्लोय गर्न तयार हुनुहुन्छ:
1. Azure सदस्यता प्राप्त गर्नुहोस् ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [मोड्युल ०१, सेटअप](01-setup.md#step-2-set-up-based-on-your-access) पूरा गर्नुहोस् (परियोजना सिर्जना, मोडेल डिप्लोय, RBAC असाइन)
3. Foundry परियोजना अन्तबिन्दु र मोडेल डिप्लोयमेन्ट नाम सहित आफ्नो `.env` अपडेट गर्नुहोस्
4. [मोड्युल ०५ - Foundry मा डिप्लोय गर्नुहोस्](05-deploy-to-foundry.md) बाट जारी राख्नुहोस्

## स्रोतहरू सफा गर्नुहोस् (वैकल्पिक)

यदि तपाईंले यो कार्यशाला अवधिको समयमा सिर्जना गरिएको Azure स्रोतहरू हटाउन चाहनुहुन्छ भने:

### विकल्प १: स्रोत समूह मेटाउनुहोस् (सबै केही मेटिन्छ)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### विकल्प २: केवल होस्ट गरिएको एजेन्ट मेटाउनुहोस्

१. [ai.azure.com](https://ai.azure.com) खोल्नुहोस् → आफ्नो परियोजना → **निर्माण** → **एजेन्टहरू**।
२. आफ्नो एजेन्ट क्लिक गर्नुहोस् → **मेटाउनुहोस्** क्लिक गर्नुहोस्।

### विकल्प ३: मोडेल डिप्लोयमेन्ट मेटाउनुहोस्

१. Foundry साइडबारमा, आफ्नो परियोजना विस्तार गर्नुहोस् → **मोडेलहरू**।
२. मोडेल डिप्लोयमेन्टमा राइट-क्लिक गर्नुहोस् → **मेटाउनुहोस्**।

> **लागत नोट:** होस्ट गरिएको एजेन्टहरूले मात्र चल्दा लागत लाग्छ। यदि तपाईं एजेन्ट रोक्नुहुन्छ वा मेटाउनुहुन्छ भने, कोई निरन्तर शुल्क हुँदैन। मोडेल डिप्लोयमेन्टले आरक्षित क्षमता लागि सानो शुल्क लिन सक्छ - तपाईंले काम पूरा गरेपछि यसलाई मेटाउनुहोस्।
