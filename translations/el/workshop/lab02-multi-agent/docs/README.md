# Εργαστήριο 02 - Ροή Πολλών Πρακτόρων: Αξιολογητής Αντιστοιχίας Βιογραφικού σε Θέση Εργασίας

## Πλήρης Διαδρομή Μάθησης

Αυτή η τεκμηρίωση σας καθοδηγεί στο να κατασκευάσετε, να δοκιμάσετε και να αναπτύξετε μια **ροή εργασίας πολλών πρακτόρων** που αξιολογεί την αντιστοιχία βιογραφικού σε θέση εργασίας χρησιμοποιώντας τέσσερις εξειδικευμένους πράκτορες που συντονίζονται μέσω του **WorkflowBuilder**.

> **Προαπαιτούμενο:** Ολοκληρώστε το [Εργαστήριο 01 - Μονός Πράκτορας](../../lab01-single-agent/README.md) πριν ξεκινήσετε το Εργαστήριο 02.

## Ενότητες

| 0 | [Εισαγωγή](00-prerequisites.md) | Τι θα κατασκευάσετε, επαλήθευση Εργαστηρίου 01, σύγκριση Εργαστηρίου 02 με Εργαστήριο 01 |
| 1 | [Κατανόηση Αρχιτεκτονικής Πολυ-Πρακτόρων](01-understand-multi-agent.md) | Μάθετε για τον WorkflowBuilder, τους ρόλους των πρακτόρων, το γράφημα ορχήστρωσης |
| 2 | [Δημιουργία Σκελετού για το Έργο Πολυ-Πρακτόρων](02-scaffold-multi-agent.md) | Χρήση του οδηγού επέκτασης Foundry για τη δημιουργία του βασικού έργου |
| 3 | [Διαμόρφωση Πρακτόρων & Περιβάλλοντος](03-configure-agents.md) | Γράψτε οδηγίες για 4 πράκτορες, διαμορφώστε το εργαλείο MCP, ορίστε περιβαλλοντικές μεταβλητές |
| 4 | [Μοτίβα Ορχήστρωσης](04-orchestration-patterns.md) | Αλληλουχία σε σειρά, αναμετάδοση περιεχομένου και OR-σημασιολογία του WorkflowBuilder |
| 5 | [Τοπικές Δοκιμές](05-test-locally.md) | Αποσφαλμάτωση F5 με Agent Inspector, εκτέλεση δοκιμών καπνού με βιογραφικό + JD |

| 7 | [Επαλήθευση στο Playground](07-verify-in-playground.md) | Δοκιμή του αναπτυγμένου πράκτορα στα playgrounds του VS Code και Foundry Portal |
| 8 | [Αντιμετώπιση Προβλημάτων](08-troubleshooting.md) | Επίλυση κοινών προβλημάτων πολυ-πρακτόρων (σφάλματα MCP, κομμένη έξοδος, εκδόσεις πακέτων) |
| 9 | [Περίληψη & Επόμενα Βήματα](09-summary.md) | Τι κατασκευάσατε, βασικές έννοιες που μάθατε, καθαρισμός και πού να κατευθυνθείτε στη συνέχεια |
