# Ενότητα 0 - Εισαγωγή

⏱️ ~10 λεπτά

> [!WARNING]
> **Προεπισκόπηση & Περιορισμοί:** [Hosted Agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) βρίσκονται αυτήν την περίοδο σε **δημόσια προεπισκόπηση** - δεν συνιστώνται για εργασίες παραγωγής. Ορισμένες λειτουργίες που παρουσιάζονται σε αυτό το εργαστήριο ενδέχεται να αλλάξουν καθώς η υπηρεσία προχωρά προς GA.

## Τι θα δημιουργήσετε

Σε αυτό το εργαστήριο, επεκτείνετε τις δεξιότητες του μεμονωμένου πράκτορα από το Lab 01 για να δημιουργήσετε ένα **πολυπράκτορα ροής εργασίας** - τον Αξιολογητή Εφαρμογής Βιογραφικού → Θέσης Εργασίας.

Επικολλάτε ένα **βιογραφικό** και μια **περιγραφή εργασίας**. Τέσσερις εξειδικευμένοι πράκτορες επεξεργάζονται την είσοδο διαδοχικά, και μετά επιστρέφουν:
- Ένα σκορ καταλληλότητας (0–100 με ανάλυση σκοραρίσματος)
- Μια λίστα με κενά σε δεξιότητες και πιστοποιήσεις
- Έναν εξατομικευμένο οδικό χάρτη μάθησης με πραγματικούς συνδέσμους Microsoft Learn για κάθε κενό

**Η ροή εργασίας χρησιμοποιεί:**
- **Microsoft Agent Framework** - `WorkflowBuilder` για διαδοχικό συντονισμό pipeline
- **Foundry Toolkit για VS Code** - πλαίσιο εργασίας, τοπικός έλεγχος, ανάπτυξη
- **Ένα μοντέλο AI** (π.χ., `gpt-4.1-mini`) - που χρησιμοποιείται από όλους τους τέσσερις πράκτορες
- **Διακομιστής Microsoft Learn MCP** - παρέχει πραγματικούς συνδέσμους εκπαιδευτικών πόρων για κάθε κενό δεξιότητας

## Έλεγχος Lab 01

Το Lab 02 χτίζεται απευθείας πάνω στο Lab 01. Ολοκληρώστε πρώτα το Lab 01 πριν ξεκινήσετε εδώ.

Δεν έχετε ολοκληρώσει το Lab 01; Ξεκινήστε εδώ: [Lab 01 - Εισαγωγή](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ Διαδρομή Α - Azure cloud</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

Αν αποτύχει, εκτελέστε `az login`. Μετά επιβεβαιώστε στο VS Code:

1. `Ctrl+Shift+P` → πληκτρολογήστε **Foundry Toolkit** → επιβεβαιώστε ότι εμφανίζονται οι εντολές.
2. Κάντε κλικ στο εικονίδιο **Foundry Toolkit** → το έργο και το αναπτυγμένο μοντέλο εμφανίζουν **Επιτυχία**.

![Foundry Toolkit sidebar showing the project under My Resources, with the Switch project / Create project picker open](../../../../../translated_images/el/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** Έχετε εκχωρήσει το ρόλο **Foundry User** στο Εργαστήριο 01. Εάν χρειάζεται να το επαναεκχωρήσετε, δείτε [Εργαστήριο 01, Ενότητα 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac). Ο ρόλος προηγουμένως ονομαζόταν **Azure AI User** - με τις ίδιες άδειες.

</details>

<details open>
<summary><strong>🅱️ Διαδρομή B - Foundry Local</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

Αναμενόμενο: `StatusCode: 200`. Αν όχι, επανεκκινήστε το Foundry Local από την πλαϊνή μπάρα του Foundry Toolkit.

> Όλες οι εκτελέσεις συμπερασμάτων γίνονται στον υπολογιστή σας. Η μόνη εξερχόμενη κλήση είναι το εργαλείο MCP προς `https://learn.microsoft.com/api/mcp`.

</details>
