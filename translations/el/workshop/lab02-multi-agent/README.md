# Εργαστήριο 02 - Ροή εργασίας πολλαπλών πρακτόρων: Αξιολόγηση Καταλληλότητας Βιογραφικού → Θέσης Εργασίας

## Επισκόπηση

Σε αυτό το εργαστήριο πρακτικής, θα δημιουργήσετε μια **εφαρμογή πολλαπλών πρακτόρων με προτεραιότητα στη ροή εργασίας** χρησιμοποιώντας το Foundry Toolkit στο VS Code και θα την αναπτύξετε στην υπηρεσία Microsoft Foundry Agent Service.

**Τι θα δημιουργήσετε:** μια Αξιολόγηση Καταλληλότητας Βιογραφικού → Θέσης Εργασίας που αναλύει ένα βιογραφικό και περιγραφή θέσης, βαθμολογεί την αντιστοιχία και παράγει ένα εξατομικευμένο οδικό χάρτη εκμάθησης χρησιμοποιώντας πόρους του Microsoft Learn.

---

## Αρχιτεκτονική

```mermaid
flowchart TD
    A["Είσοδος Χρήστη"] --> B["Αναλυτής Βιογραφικού"]
    B -->|"[ΑΝΑΛΥΜΕΝΟ ΒΙΟΓΡΑΦΙΚΟ] + [ΠΕΡΑΣΜΑ ΠΕΡΙΓΡΑΦΗΣ ΘΕΣΗΣ ΕΡΓΑΣΙΑΣ]"| C["Πράκτορας Περιγραφής Θέσης Εργασίας"]
    C -->|"[ΑΠΑΙΤΗΣΕΙΣ ΠΕΡΙΓΡΑΦΗΣ ΘΕΣΗΣ] + [ΠΕΡΑΣΜΑ ΑΝΑΛΥΜΕΝΟΥ ΒΙΟΓΡΑΦΙΚΟΥ]"| D["Πράκτορας Ταύτισης"]
    D -->|αναφορά καταλληλότητας + κενά| E["Αναλυτής Κενών + Microsoft Learn MCP"]
    E -->|βαθμολογία καταλληλότητας + οδικός χάρτης| F["Έξοδος"]

    style A fill:#4A90D9,color:#fff
    style B fill:#7B68EE,color:#fff
    style C fill:#7B68EE,color:#fff
    style D fill:#E67E22,color:#fff
    style E fill:#27AE60,color:#fff
    style F fill:#4A90D9,color:#fff
```

**Πώς λειτουργεί:**
1. Ο χρήστης επικολλά ένα βιογραφικό και μια περιγραφή θέσης εργασίας.
2. Ο **ResumeParser** αναλύει το βιογραφικό και αντιγράφει το JD αυτούσιο σε μια ενότητα `[JOB DESCRIPTION PASS-THROUGH]`.
3. Ο **JD Agent** εξάγει δομημένες απαιτήσεις από την ενότητα αυτή και στη συνέχεια προωθεί το `[PARSED RESUME]` ως `[PARSED RESUME PASS-THROUGH]`.
4. Ο **MatchingAgent** συγκρίνει το `[PARSED RESUME PASS-THROUGH]` με το `[JD REQUIREMENTS]` και παράγει μια βαθμολογία καταλληλότητας.
5. Ο **GapAnalyzer** μετατρέπει τα κενά σε πρακτικό οδικό χάρτη και αναζητά πραγματικούς συνδέσμους Microsoft Learn μέσω MCP.

## Μέρος 2: Δημιουργία και δοκιμή της ροής εργασίας

1. Χρησιμοποιήστε τον οδηγό Foundry Toolkit για να στήσετε το έργο με βάση τη ροή εργασίας.
2. Αντιγράψτε τα μπλοκ προτροπής και το γράφημα ροής εργασίας από το `PersonalCareerCopilot/main.py` στον χώρο εργασίας σας.
3. Εκτελέστε το τοπικά με τον Επιθεωρητή Πρακτόρων και επαληθεύστε και τους τέσσερις πράκτορες καθώς και το εργαλείο MCP.
4. Αναπτύξτε τον φιλοξενούμενο πράκτορα στο Foundry όταν περάσουν οι τοπικές δοκιμές.
