# Ενότητα 8 - Αντιμετώπιση προβλημάτων

Αυτή η ενότητα είναι ένας οδηγός αναφοράς για κοινά προβλήματα. Αποθηκεύστε τον στα αγαπημένα και επιστρέψτε όταν παρουσιαστεί κάτι λάθος.

---

## 1. Σφάλματα αδειών

### 1.1 `agents/write` άδεια απορρίφθηκε

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**Βασική αιτία:** Έλλειψη ρόλου `Azure AI User` στο επίπεδο του **έργου**. Πρόκειται για το #1 σφάλμα στο εργαστήριο.

**Επιδιόρθωση:**
1. Ανοίξτε το [portal.azure.com](https://portal.azure.com).
2. Αναζητήστε το όνομα του έργου Foundry → κάντε κλικ στο αποτέλεσμα τύπου **"Microsoft Foundry project"** (ΟΧΙ ο λογαριασμός γονέας).
3. **Έλεγχος πρόσβασης (IAM)** → **+ Προσθήκη** → **Προσθήκη ανάθεσης ρόλου**.
4. Ρόλος: **Azure AI User** → Επόμενο.
5. Μέλη: Επιλέξτε τον εαυτό σας → Ανασκόπηση + ανάθεση → Ανασκόπηση + ανάθεση.
6. **Περιμένετε 1–2 λεπτά** → δοκιμάστε ξανά.

> **Γιατί δεν αρκεί ο Ιδιοκτήτης/Συνεισφέρων:** Αυτοί οι ρόλοι παρέχουν μόνο ενέργειες *διαχείρισης*. Οι λειτουργίες αντιπροσώπου απαιτούν την `agents/write` *ενέργεια δεδομένων*, η οποία υπάρχει μόνο στους `Azure AI User`, `Azure AI Developer`, ή `Azure AI Owner`. Δείτε [Foundry RBAC docs](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry).

### 1.2 `AuthorizationFailed` κατά την παροχή

**Επιδιόρθωση:** Ζητήστε από τον διαχειριστή σας να αναθέσει **Contributor** στην ομάδα πόρων, ή να δημιουργήσει το έργο για εσάς και να σας παραχωρήσει **Azure AI User** σε αυτό.

### 1.3 `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# Wait until: "Registered"
```

## 2. Σφάλματα Docker

> Το Docker είναι **προαιρετικό**. Αυτά ισχύουν μόνο αν έχει εγκατασταθεί το Docker Desktop και η επέκταση επιχειρεί τοπική κατασκευή.

### 2.1 Ο δαίμονας Docker δεν τρέχει

**Επιδιόρθωση:** Ξεκινήστε το Docker Desktop → περιμένετε η κατάσταση να γίνει "running" → επαληθεύστε με `docker info` → δοκιμάστε ξανά.

### 2.2 Η κατασκευή αποτυγχάνει με σφάλματα εξαρτήσεων

**Επιδιόρθωση:** Επαληθεύστε την ορθογραφία του `requirements.txt`, δοκιμάστε πρώτα τοπικά: `pip install -r requirements.txt`.

### 2.3 Ασυμβατότητα πλατφόρμας (Apple Silicon)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

## 3. Σφάλματα πιστοποίησης

### 3.1 `DefaultAzureCredential` αποτυγχάνει

**Επιδιόρθωση (δοκιμάστε με τη σειρά):**
1. `az login` (επανεπιβεβαίωση ταυτότητας)
2. `az account set --subscription "<id>"` (σωστή συνδρομή)
3. VS Code → Λογαριασμοί → Έξοδος → Είσοδος ξανά
4. Επαληθεύστε: `az account get-access-token --resource https://cognitiveservices.azure.com`

### 3.2 Το διακριτικό λειτουργεί τοπικά αλλά όχι φιλοξενούμενο

**Αναμενόμενο:** Οι φιλοξενούμενοι αντιπρόσωποι χρησιμοποιούν σύστημα διαχειριζόμενης ταυτότητας, όχι τα διαπιστευτήριά σας. Αν ο φιλοξενούμενος αντιπρόσωπος λαμβάνει σφάλματα πιστοποίησης:
- Επαληθεύστε ότι `AZURE_AI_MODEL_DEPLOYMENT_NAME` στο `agent.yaml` αντιστοιχεί στο όνομα της ανάπτυξης του μοντέλου σας (`FOUNDRY_PROJECT_ENDPOINT` εισάγεται από το Foundry κατά το χρόνο εκτέλεσης - μη το δηλώσετε στο `agent.yaml`)
- Ελέγξτε ότι η διαχειριζόμενη ταυτότητα του έργου έχει πρόσβαση στο μοντέλο

## 4. Σφάλματα μοντέλου

### 4.1 Η ανάπτυξη μοντέλου δεν βρέθηκε

**Επιδιόρθωση:** Το όνομα είναι **ευαίσθητο σε πεζά-κεφαλαία**. Συγκρίνετε `.env` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` με το ακριβές όνομα στο πλαϊνό μενού Foundry → Μοντέλα.

### 4.2 Απρόσμενη έξοδος μοντέλου

**Επιδιόρθωση:** Επανεξετάστε `AGENT_INSTRUCTIONS` στο `main.py` (όχι συντομευμένο;). Δοκιμάστε διαφορετικό μοντέλο (`gpt-4.1` έναντι `gpt-4.1-mini`).

## 5. Σφάλματα ανάπτυξης

### 5.1 Μη εξουσιοδοτημένη ανάκτηση ACR

**Επιδιόρθωση:** Azure Portal → Container Registry → Έλεγχος πρόσβασης (IAM) → Προσθέστε τον ρόλο **AcrPull** στη διαχειριζόμενη ταυτότητα του έργου Foundry.

### 5.2 Ο αντιπρόσωπος δεν ξεκινά (παραμένει "Pending" ή "Failed")

Ελέγξτε τα αρχεία καταγραφής κοντέινερ στο πλαϊνό μενού. Συνήθεις αιτίες:

| Μήνυμα καταγραφής | Επιδιόρθωση |
|-------------|-----|
| `ModuleNotFoundError` | Προσθέστε το ελλείπον πακέτο στο `requirements.txt`, αναπτύξτε ξανά |
| `ValueError: Missing required environment variables` | Επιβεβαιώστε ότι `AZURE_AI_MODEL_DEPLOYMENT_NAME` δηλώνεται στο `agent.yaml` κάτω από `environment_variables` και έχει τιμή, μετά αναπτύξτε ξανά. `FOUNDRY_PROJECT_ENDPOINT` εισάγεται από το Foundry κατά το χρόνο εκτέλεσης |
| `Address already in use` | Βεβαιωθείτε ότι μόνο μία διαδικασία δένεται στην θύρα 8088 |

### 5.3 Η ανάπτυξη λήγει σε χρόνο αναμονής

**Επιδιόρθωση:** Ελέγξτε τη σύνδεση στο διαδίκτυο. Η πρώτη ανάπτυξη αποστέλλει >100MB. Εάν είστε πίσω από proxy, ρυθμίστε τις ρυθμίσεις proxy του Docker Desktop.

## 6. Διαδρομή Β - Foundry Local

### 6.1 Δεν ξεκινάει το Foundry Local

| Πρόβλημα | Επιδιόρθωση |
|-------|-----|
| `foundry: command not found` | Επανεγκατάσταση: `winget install Microsoft.FoundryLocal` |
| Ανεπαρκείς πόροι | Το Foundry Local χρειάζεται ~4GB RAM ελεύθερα. Κλείστε άλλες εφαρμογές. |
| Απέτυχε η λήψη μοντέλου | Ελέγξτε τον χώρο στο δίσκο (τα μοντέλα είναι 2–8 GB). Δοκιμάστε ξανά: `foundry local models pull <name>` |

### 6.2 Σφάλματα μοντέλου Foundry Local

| Πρόβλημα | Επιδιόρθωση |
|-------|-----|
| Αργές αποκρίσεις | Αναμενόμενο - τα τοπικά μοντέλα τρέχουν στην CPU εκτός αν έχετε GPU. Να είστε υπομονετικοί. |
| Κακή ποιότητα εξόδου | Δοκιμάστε μεγαλύτερο μοντέλο αν το hardware σας το επιτρέπει. Το `phi-4-mini` είναι μια καλή ισορροπία. |
| Η σύνδεση απορρίφθηκε | Επαληθεύστε ότι το Foundry Local τρέχει: `foundry local status`. Επανεκκινήστε αν χρειάζεται. |

## 7. Γρήγορη αναφορά: Ρόλοι RBAC

| Ρόλος | Εύρος | Παραχωρήσεις |
|------|-------|--------|
| **Azure AI User** | Έργο | Ενέργειες δεδομένων: `agents/write`, `agents/read` |
| **Azure AI Developer** | Έργο/Λογαριασμός | Ενέργειες δεδομένων + δημιουργία έργου |
| **Azure AI Owner** | Λογαριασμός | Πλήρης πρόσβαση + διαχείριση ρόλων |
| **Contributor** | Συνδρομή/Ομάδα πόρων | Μόνο ενέργειες διαχείρισης (**όχι** ενέργειες δεδομένων) |
| **Owner** | Συνδρομή/Ομάδα πόρων | Διαχείριση + ανάθεση ρόλων (**όχι** ενέργειες δεδομένων) |
