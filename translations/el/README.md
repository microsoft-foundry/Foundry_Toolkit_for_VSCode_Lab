> **Hosted Agents are currently in preview.** Οι υποστηριζόμενες περιοχές είναι περιορισμένες - δείτε [διαθεσιμότητα περιοχής](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability).

> Ο φάκελος `agent/` μέσα σε κάθε εργαστήριο **δημιουργείται αυτόματα** από την επέκταση Foundry - στη συνέχεια προσαρμόζετε τον κώδικα, δοκιμάζετε τοπικά και αναπτύσσετε.

## Γνωρίστε τον Executive Agent

Σε αυτό το εργαστήριο θα δημιουργήσετε τον **"Explain Like I'm an Executive" Agent** - έναν πράκτορα AI που παίρνει δύσκολη τεχνική ορολογία και τη μεταφράζει σε ήρεμες, έτοιμες για το διοικητικό συμβούλιο περιλήψεις. Γιατί, ας είμαστε ειλικρινείς, κανείς στην C-suite δεν θέλει να ακούσει για "thread pool exhaustion caused by synchronous calls introduced in v3.2."

Δημιούργησα αυτόν τον πράκτορα μετά από πάρα πολλά περιστατικά όπου το τέλεια διατυπωμένο post-mortem μου απέσπασε την απάντηση: *"Λοιπόν... η ιστοσελίδα είναι κάτω ή όχι;"*

### Πώς λειτουργεί

Του παρέχετε μια τεχνική ενημέρωση. Επιστρέφει μια εκτελεστική περίληψη - τρεις κουκκίδες, χωρίς ορολογία, χωρίς stack traces, χωρίς υπαρξιακό πανικό. Μόνο **τι συνέβη**, **επιπτώσεις στην επιχείρηση**, και **επόμενο βήμα**.

### Δείτε το σε δράση

**Εσείς λέτε:**
> "The API latency increased due to thread pool exhaustion caused by synchronous calls introduced in v3.2."

**Ο πράκτορας απαντά:**

> **Εκτελεστική Περίληψη:**
> - **Τι συνέβη:** Μετά την τελευταία έκδοση, το σύστημα επιβραδύνθηκε.
> - **Επιπτώσεις στην επιχείρηση:** Μερικοί χρήστες αντιμετώπισαν καθυστερήσεις κατά τη χρήση της υπηρεσίας.
> - **Επόμενο βήμα:** Η αλλαγή έχει επαναφερθεί και ετοιμάζεται μια διόρθωση πριν την εκ νέου ανάπτυξη.

### Γιατί αυτός ο πράκτορας;

Είναι ένας απλός, μονοσκοπικός πράκτορας - ιδανικός για να μάθετε τη ροή εργασίας hosted agents από άκρη σε άκρη χωρίς να μπλεχτείτε σε πολύπλοκες αλυσίδες εργαλείων. Και ειλικρινά; Κάθε ομάδα μηχανικών θα μπορούσε να χρησιμοποιήσει έναν από αυτούς.

## Ξεκινώντας

### 1. Κλωνοποιήστε το αποθετήριο

```bash
git clone https://github.com/microsoft-foundry/Foundry_Toolkit_for_VSCode_Lab.git
cd Foundry_Toolkit_for_VSCode_Lab
```

### 2. Ρυθμίστε ένα εικονικό περιβάλλον Python

```bash
python -m venv venv
```

Ενεργοποιήστε το:

- **Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
- **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

### 3. Εγκαταστήστε τις εξαρτήσεις

```bash
pip install -r workshop/lab01-single-agent/agent/requirements.txt
```

### 4. Διαμορφώστε τις μεταβλητές περιβάλλοντος

Αντιγράψτε το παράδειγμα `.env` αρχείο μέσα στο φάκελο του πράκτορα και συμπληρώστε τις τιμές σας:

```bash
cp workshop/lab01-single-agent/agent/.env.example workshop/lab01-single-agent/agent/.env
```

Επεξεργαστείτε `workshop/lab01-single-agent/agent/.env`:

```env
AZURE_AI_PROJECT_ENDPOINT=https://<your-account>.services.ai.azure.com/api/projects/<your-project>
AZURE_AI_MODEL_DEPLOYMENT_NAME=<your-model-deployment-name>
```

Κάθε εργαστήριο είναι αυτοτελές με τις δικές του ενότητες. Ξεκινήστε με το **Lab 01** για να μάθετε τα βασικά, και μετά προχωρήστε στο **Lab 02** για ροές εργασίας πολλαπλών πρακτόρων.

## Απαιτούμενες άδειες (σύντομη αναφορά)

| Σενάριο | Απαιτούμενοι ρόλοι |
|----------|---------------|
| Δημιουργία νέου έργου Foundry | **Azure AI Owner** στον πόρο Foundry |
| Ανάπτυξη σε υπάρχον έργο (νέοι πόροι) | **Azure AI Owner** + **Contributor** στη συνδρομή |
| Ανάπτυξη σε πλήρως διαμορφωμένο έργο | **Reader** στον λογαριασμό + **Azure AI User** στο έργο |

> **Σημαντικό:** Οι ρόλοι Azure `Owner` και `Contributor` περιλαμβάνουν μόνο *δικαιώματα διαχείρισης*, όχι *δικαιώματα ανάπτυξης* (ενέργειες δεδομένων). Χρειάζεστε **Azure AI User** ή **Azure AI Owner** για να δημιουργήσετε και να αναπτύξετε πράκτορες.
