# Υποστήριξη

## Πώς να υποβάλετε ζητήματα και να λάβετε βοήθεια  

Αυτό το έργο χρησιμοποιεί τα GitHub Issues για την παρακολούθηση σφαλμάτων και αιτημάτων λειτουργιών. Παρακαλώ αναζητήστε τα υπάρχοντα 
ζητήματα πριν υποβάλετε νέα ζητήματα για να αποφύγετε τα διπλά.  Για νέα ζητήματα, υποβάλετε το σφάλμα ή 
αίτημα λειτουργίας ως νέο Ζήτημα.

Για βοήθεια και ερωτήσεις σχετικά με τη χρήση αυτού του έργου, παρακαλώ **ΔΙΑΧΕΙΡΙΣΤΗΣ ΑΠΟΘΕΤΗΡΙΟΥ: ΕΙΣΑΓΕΤΕ ΟΔΗΓΙΕΣ ΕΔΩ

ΚΑΝΑΛΙ. ΠΟΥ ΘΑ ΒΟΗΘΑΤΕ ΤΟΥΣ ΑΝΘΡΩΠΟΥΣ;**.
