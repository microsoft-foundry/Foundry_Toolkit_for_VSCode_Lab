## Ασφάλεια

Η Microsoft αντιμετωπίζει σοβαρά την ασφάλεια των λογισμικών προϊόντων και υπηρεσιών μας, που
περιλαμβάνει όλα τα αποθετήρια πηγαίου κώδικα στις οργανώσεις μας στο GitHub.

**Παρακαλούμε να μην αναφέρετε ευπάθειες ασφαλείας μέσω δημόσιων ζητημάτων στο GitHub.**

Για πληροφορίες αναφοράς ασφάλειας, τοποθεσίες, στοιχεία επικοινωνίας και πολιτικές,
παρακαλούμε δείτε τις τελευταίες οδηγίες για τα αποθετήρια της Microsoft στο
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
