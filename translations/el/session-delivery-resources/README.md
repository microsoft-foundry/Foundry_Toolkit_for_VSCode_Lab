# Πώς να παρουσιάσετε αυτή τη συνεδρία

Ευχαριστούμε που παρουσιάζετε αυτή τη συνεδρία!

Πριν παρουσιάσετε το εργαστήριο, παρακαλώ:

1. Διαβάστε αυτό το έγγραφο και όλους τους περιλαμβανόμενους πόρους στο σύνολό τους.
2. Παρακολουθήστε την εγγραφή της παρουσίασης της συνεδρίας και την πλήρη περιήγηση του εργαστηρίου.
3. Πραγματοποιήστε πλήρη εκτέλεση και των δύο εργαστηρίων στον δικό σας υπολογιστή **τουλάχιστον μία φορά** πριν από την εκδήλωση.
4. Επαληθεύστε το έργο Microsoft Foundry, τις αναπτύξεις μοντέλων και τα όρια χρήσης σας.
5. Επικοινωνήστε με τον διαχειριστή αν κάτι δεν είναι σαφές.

## Ξεκινώντας

Αυτό το εργαστήριο διδάσκει στους προγραμματιστές πώς να δημιουργούν, να δοκιμάζουν και να αναπτύσσουν AI agents στο **Microsoft Foundry Agent Service** ως **Hosted Agents** εξολοκλήρου από το VS Code, χρησιμοποιώντας την επέκταση **Microsoft Foundry Toolkit**.

Το εργαστήριο χωρίζεται σε πολλές ενότητες, περιλαμβάνοντας διαφάνειες, **2 ζωντανές επιδείξεις** και **2 πρακτικά εργαστήρια**.

### Προαπαιτούμενα για εκπαιδευτές

Πριν παρουσιάσετε, βεβαιωθείτε ότι έχετε:

- Μια **εγγραφή Azure** με άδεια για δημιουργία πόρων (Owner ή Contributor σε ομάδα πόρων).
- Πρόσβαση σε ένα **Microsoft Foundry έργο** σε μια [περιοχή που υποστηρίζει hosted agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability).
- Όριο για **gpt-4.1** (ή **gpt-4.1-mini**) στο Foundry έργο σας.
- Τα παρακάτω εργαλεία εγκατεστημένα:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Επέκταση Microsoft Foundry Toolkit](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (Προαιρετικό)
  - Python 3.10 ή νεότερη έκδοση

Εκτελέστε το [Γρήγορο ξεκίνημα hosted agents με `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) τουλάχιστον μία φορά πριν από την παρουσίαση ώστε να έχετε ένα γνωστό καλό Foundry έργο, ανάπτυξη μοντέλου και Azure Container Registry ως αναφορά αν κάποιος συμμετέχων κολλήσει.

### Επίδειξη 1: Executive Agent

Ένας αυτόνομος agent στο [`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent). Χρησιμοποιήστε το ως επίδειξη 10 λεπτών πριν το Εργαστήριο 01.

1. Ανοίξτε το [`workshop/lab01-single-agent/agent/main.py`](../../../workshop/lab01-single-agent/agent/main.py) και περιηγηθείτε στον ορισμό του agent (system prompt, μοντέλο, πλαίσιο).
2. Πατήστε `F5` για να εκκινήσετε το **Agent Inspector** τοπικά.
3. Επικολλήστε το δείγμα προτροπής από το [README](../README.md#see-it-in-action) και δείξτε την απάντηση της εκτελεστικής περίληψης.
4. Δείξτε τα αρχεία [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) και [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile) για να εξηγήσετε τα αρχεία ανάπτυξης.
5. Επιδείξτε τη ροή ανάπτυξης (Docker build, ACR push, δημιουργία hosted agent) χωρίς να περιμένετε να ολοκληρωθεί.

### Επίδειξη 2: Resume to Job Fit Evaluator

Μια ροή εργασίας 4-agent στο [`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot). Χρησιμοποιήστε το ως επίδειξη 10 λεπτών πριν το Εργαστήριο 02.

1. Ανοίξτε το [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) και δείξτε πώς οι τέσσερις agents συνδέονται σε μια διαδοχική ορχήστρωση.
2. Πατήστε `F5` για να εκκινήσετε το **Agent Inspector** για τη ροή εργασίας multi-agent.
3. Επικολλήστε μια σύντομη περιγραφή θέσης και ένα δείγμα βιογραφικού στο chat του Inspector.
4. Περιηγηθείτε στη σωλήνωση των τεσσάρων agents: ανάλυση βιογραφικού, εξαγωγή απαιτήσεων εργασίας, βαθμολόγηση αντιστοιχίας, και συγγραφή σύστασης.
5. Τονίστε πώς η έξοδος κάθε υπο-agent γίνεται το πλαίσιο για τον επόμενο agent, αναδεικνύοντας το πρότυπο μεταβίβασης.
6. Δείξτε το [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) για σύγκριση με το ισοδύναμο μονοατ agent από την Επίδειξη 1.

## Συμβουλές παρουσίασης

- **Ορίστε τις προσδοκίες από νωρίς.** Τα hosted agents είναι σε προεπισκόπηση - αναφέρετε όρια περιοχής και όρια χρήσης εξαρχής για να μη υπάρξουν εκπλήξεις κατά τη διάρκεια του εργαστηρίου.
- **Τρέξτε πρώτα την εργασία προαπαιτούμενων.** Και τα δύο εργαστήρια παρέχουν εργασία VS Code `Validate prerequisites` - ζητήστε από τους συμμετέχοντες να την εκτελέσουν πριν γράψουν κώδικα.
- **Κρατήστε ορατό το Agent Inspector.** Οι περισσότερες “aha” στιγμές συμβαίνουν όταν οι συμμετέχοντες βλέπουν να ανάβει το τοπικό `/responses` round-trip.
- **Έχετε ένα εφεδρικό έργο.** Αν το Foundry έργο ενός συμμετέχοντα φτάσει σε όριο, μοιραστείτε ένα προ-εξοπλισμένο έργο για το βήμα ανάπτυξης αντί να μπλοκάρετε την ομάδα.
- **Συνδυάστε συμμετέχοντες σε ζεύγη.** Το Εργαστήριο 02 (multi-agent) είναι σημαντικά πιο εύκολο όταν οι συμμετέχοντες μπορούν να συζητήσουν την ορχήστρωση ανά δύο.
- **Χρησιμοποιήστε τα αρχεία docs ως σημεία στάσης.** Ο φάκελος `docs/` κάθε εργαστηρίου χωρίζεται σε 8 αριθμημένα modules - χρησιμοποιήστε τα ως φυσικά σημεία παύσης.
- **Κάντε προ-λήψη της βασικής εικόνας Docker** στους κοινόχρηστους υπολογιστές του εργαστηρίου για να αποφύγετε όρια ρυθμού του καταλόγου.

## Αντιμετώπιση προβλημάτων κατά την παρουσίαση

| Σύμπτωμα                                    | Πρώτο βήμα που πρέπει να δοκιμάσετε                                                  |
|---------------------------------------------|--------------------------------------------------------------------------------------|
| Δεν μπορεί το Agent Inspector να συνδεθεί     | Επιβεβαιώστε ότι η θύρα `8088` είναι ελεύθερη και τρέχει η εργασία `Run Lab01 HTTP Server` / `Run Lab02 HTTP Server`.   |
| Ο αποσφαλματωτής δεν συνδέεται                | Ελέγξτε αν η θύρα `5679` είναι ελεύθερη. Επανεκκινήστε το VS Code αν το `debugpy` είναι ήδη δεσμευμένο.                 |
| Το `azd up` αποτυγχάνει με σφάλμα εξουσιοδότησης | Τρέξτε `az login` και `azd auth login`, βεβαιωθείτε ότι έχει επιλεγεί ο σωστός ενοικιαστής (tenant).                      |
| Η ανάπτυξη σταματά κατά το ACR push       | Ελέγξτε αν το Docker Desktop τρέχει και ο χρήστης έχει δικαίωμα `AcrPush` στον κατάλογο.                                 |
| Το μοντέλο επιστρέφει 404 / deployment-not-found | Το όνομα ανάπτυξης μοντέλου στο `agent.yaml` πρέπει να ταιριάζει με την ανάπτυξη στο Foundry έργο.                    |

| Ο φιλοξενούμενος agent κολλάει στο `Provisioning`         | Επαληθεύστε ότι η περιοχή του έργου [υποστηρίζει φιλοξενούμενους agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) και ότι υπάρχει διαθέσιμο όριο. |
| Το Playground επιστρέφει 401                       | Επανασυνδεθείτε στην επέκταση Foundry από τη γραμμή δραστηριοτήτων του VS Code.                                     |

Για πιο βαθιά καθοδήγηση, κάθε εργαστήριο συνοδεύεται από το δικό του έγγραφο `08-troubleshooting.md` - στείλτε τους μαθητές εκεί:

## Προσαρμογή αυτής της συνεδρίας

Μπορείτε να προσαρμόσετε το εργαστήριο για το κοινό σας. Συνήθεις παραλλαγές:

- **Κοινό backend:** αφιερώστε περισσότερο χρόνο στο `agent.yaml`, στο Docker και στο ACR· μειώστε την επίδειξη playground.
- **Κοινό πολίτες-προγραμματιστές:** παραμείνετε στην UI της επέκτασης Foundry για τη σκελετοποίηση· μειώστε τα βήματα CLI.
- **Μονοδιάδρομο 60 λεπτών:** παρουσιάστε την εισαγωγή, την επίδειξη και μόνο το Εργαστήριο 01.
- **Μορφή μόνο εργαστηρίου (χωρίς διαφάνειες):** ανοίξτε και τα δύο README των εργαστηρίων και χρησιμοποιήστε τα ως κύριο σενάριο.

Εάν επεκτείνετε τα εργαστήρια, παρακαλώ συνεισφέρετε τις αλλαγές μέσω PR ώστε να ωφεληθούν και άλλοι εκπαιδευτές.
