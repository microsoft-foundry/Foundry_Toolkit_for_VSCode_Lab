# Πώς να παραδώσετε αυτή τη συνεδρία

Ευχαριστούμε που παραδίδετε αυτή τη συνεδρία!

Πριν παραδώσετε το εργαστήριο, παρακαλώ:

1. Διαβάστε αυτό το έγγραφο και όλους τους περιλαμβανόμενους πόρους στο σύνολό τους.
2. Παρακολουθήστε την εγγραφή παράδοσης της συνεδρίας και την παρουσίαση του εργαστηρίου από την αρχή ως το τέλος.
3. Πραγματοποιήστε και τα δύο εργαστήρια πρακτικής εξάσκησης πλήρως στο δικό σας μηχάνημα **τουλάχιστον μία φορά** πριν την εκδήλωση.
4. Επικυρώστε το έργο Microsoft Foundry, τις αναπτύξεις μοντέλων και τα όρια χρήσης σας.
5. Επικοινωνήστε με τον υπεύθυνο αν κάτι δεν είναι σαφές.

## Ξεκινήστε

Αυτό το εργαστήριο διδάσκει στους προγραμματιστές πώς να δημιουργούν, να δοκιμάζουν και να αναπτύσσουν πράκτορες AI στο **Microsoft Foundry Agent Service** ως **Hosted Agents** εξ ολοκλήρου από το VS Code, χρησιμοποιώντας την επέκταση **Microsoft Foundry Toolkit**.

Το εργαστήριο χωρίζεται σε πολλαπλές ενότητες που περιλαμβάνουν διαφάνειες, **2 ζωντανές επιδείξεις** και **2 πρακτικά εργαστήρια**.

### Προαπαιτούμενα εκπαιδευτή

Πριν παραδώσετε, βεβαιωθείτε ότι έχετε:

- Μια **συνδρομή Azure** με άδεια για δημιουργία πόρων (Ιδιοκτήτης ή Συνεργάτης σε ομάδα πόρων).
- Πρόσβαση σε ένα **έργο Microsoft Foundry** σε μια [περιοχή που υποστηρίζει φιλοξενούμενους πράκτορες](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability).
- Πόρο για **gpt-4.1** (ή **gpt-4.1-mini**) στο έργο Foundry σας.
- Τα ακόλουθα εργαλεία εγκατεστημένα:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Επέκταση Microsoft Foundry Toolkit](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (Προαιρετικό)
  - Python 3.12 ή νεότερο

Εκτελέστε το [Γρήγορο ξεκίνημα φιλοξενούμενων πρακτόρων με `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) τουλάχιστον μία φορά πριν την παράδοση ώστε να έχετε ένα γνωστό, καλά λειτουργικό έργο Foundry, ανάπτυξη μοντέλου και αποθετήριο Azure Container Registry για αναφορά αν ένας μαθητευόμενος κολλήσει.

### Επίδειξη 1: Εκτελεστικός Πράκτορας

Ένας αυτόνομος πράκτορας σε [`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent). Χρησιμοποιήστε το ως επίδειξη 10 λεπτών πριν το Εργαστήριο 01.

1. Ανοίξτε [`workshop/lab01-single-agent/agent/main.py`](../../../workshop/lab01-single-agent/agent/main.py) και περιηγηθείτε στον ορισμό του πράκτορα (σύστημα προτροπής, μοντέλο, πλαίσιο).
2. Πατήστε `F5` για να ξεκινήσετε τον **Επιθεωρητή Πράκτορα** τοπικά.
3. Επικολλήστε τη δείγμα προτροπής από το [README](../README.md#see-it-in-action) και δείξτε την απόκριση της εκτελεστικής σύνοψης.
4. Δείξτε [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) και [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile) για να εξηγήσετε τα αρχεία ανάπτυξης.
5. Επιδείξτε τη ροή ανάπτυξης (Docker build, ACR push, δημιουργία φιλοξενούμενου πράκτορα) χωρίς να περιμένετε την ολοκλήρωση.

### Επίδειξη 2: Αξιολογητής Εφαρμογής στη Θέση Εργασίας

Ροή εργασίας 4 πρακτόρων σε [`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot). Χρησιμοποιήστε το ως επίδειξη 10 λεπτών πριν το Εργαστήριο 02.

1. Ανοίξτε [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) και δείξτε πώς είναι συνδεδεμένοι οι τέσσερις πράκτορες σε διαδοχική ορχήστρωση.
2. Πατήστε `F5` για να ξεκινήσετε τον **Επιθεωρητή Πράκτορα** για τη ροή εργασίας πολλαπλών πρακτόρων.
3. Επικολλήστε μια σύντομη περιγραφή θέσης εργασίας και ένα δείγμα βιογραφικού στην συνομιλία του Επιθεωρητή.
4. Περιηγηθείτε στη διαδικασία των τεσσάρων πρακτόρων: αναλυτής βιογραφικού, εξαγωγέας απαιτήσεων θέσης, αξιολογητής καταλληλότητας και συγγραφέας σύστασης.
5. Επισημάνετε πώς η έξοδος κάθε υποπράκτορα γίνεται το πλαίσιο για τον επόμενο πράκτορα, τονίζοντας το πρότυπο παράδοσης.
6. Δείξτε [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) για σύγκριση με τον αντίστοιχο μονό πράκτορα της Επίδειξης 1.

## Συμβουλές Παράδοσης

- **Ορίστε προσδοκίες νωρίς.** Οι φιλοξενούμενοι πράκτορες είναι σε προεπισκόπηση - επισημάνετε τα όρια περιοχής και το ποσό από την αρχή ώστε οι συμμετέχοντες να μην εκπλαγούν στη μέση του εργαστηρίου.
- **Τρέξτε πρώτα την εργασία προαπαιτούμενων.** Και τα δύο εργαστήρια διαθέτουν μία `Validate prerequisites` εργασία VS Code - ζητήστε από τους συμμετέχοντες να την τρέξουν πριν γράψουν κώδικα.
- **Κρατήστε τον Επιθεωρητή Πράκτορα ορατό.** Τα περισσότερα «α-χα» στιγμιότυπα συμβαίνουν όταν οι μαθητές βλέπουν το τοπικό `/responses` να λειτουργεί.
- **Έχετε ένα εφεδρικό έργο.** Αν το έργο Foundry κάποιου μαθητή φτάσει σε όριο, μοιραστείτε ένα προετοιμασμένο έργο για το βήμα ανάπτυξης ώστε να μην μπλοκαριστεί η αίθουσα.
- **Ζευγαρώστε τους συμμετέχοντες.** Το Εργαστήριο 02 (πολλαπλοί πράκτορες) είναι σημαντικά ευκολότερο όταν οι μαθητές μπορούν να συζητήσουν την ορχήστρωση με έναν σύντροφο.
- **Χρησιμοποιήστε τις ενότητες εγγράφων ως σημεία ελέγχου.** Ο φάκελος `docs/` για κάθε εργαστήριο χωρίζεται σε αριθμημένες ενότητες - χρησιμοποιήστε αυτές ως φυσικά σημεία παύσης.
- **Προ-φόρτωση της βασικής εικόνας Docker** στα κοινόχρηστα εργαστηριακά μηχανήματα για να αποφευχθούν όρια ρυθμού εγγραφής στο registry.

## Αντιμετώπιση προβλημάτων κατά τη διάρκεια της παράδοσης

| Σύμπτωμα                                    | Πρώτο πράγμα για δοκιμή                                                                                  |
|----------------------------------------------|----------------------------------------------------------------------------------------------------------|
| Ο Agent Inspector δεν μπορεί να συνδεθεί     | Επιβεβαιώστε ότι το port `8088` είναι ελεύθερο και ότι τρέχει η εργασία `Run Agent HTTP Server`.              |
| Ο Debugger δεν καταφέρνει να συνδεθεί       | Ελέγξτε ότι το port `5679` είναι ελεύθερο· επανεκκινήστε το VS Code αν `debugpy` είναι ήδη δεσμευμένο.          |
| `azd up` αποτυγχάνει με σφάλμα πιστοποίησης | Εκτελέστε `az login` και `azd auth login`, βεβαιωθείτε ότι ο σωστός tenant έχει επιλεγεί.                     |
| Η ανάπτυξη κολλάει στο ACR push              | Ελέγξτε ότι το Docker Desktop τρέχει και ο χρήστης έχει `AcrPush` στο registry.                                   |
| Το μοντέλο επιστρέφει 404 / deployment-not-found  | Το όνομα ανάπτυξης του μοντέλου στο `agent.yaml` πρέπει να ταιριάζει με την ανάπτυξη στο έργο Foundry.                 |
| Ο Hosted agent έχει κολλήσει σε `Provisioning`       | Επιβεβαιώστε ότι η περιοχή του έργου [υποστηρίζει hosted agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) και ότι υπάρχει διαθέσιμο quota. |
| Το Playground επιστρέφει 401                 | Επανα-πιστοποιήστε την επέκταση Foundry από τη γραμμή δραστηριότητας του VS Code.                               |

Για πιο εμπεριστατωμένη καθοδήγηση, κάθε εργαστήριο έχει το δικό του έγγραφο `08-troubleshooting.md` - συνδέστε τους μαθητές εκεί:

- Εργαστήριο 02: [`workshop/lab02-multi-agent/docs/08-troubleshooting.md`](../workshop/lab02-multi-agent/docs/08-troubleshooting.md)

## Προσαρμογή αυτής της συνεδρίας

Μπορείτε να προσαρμόσετε το εργαστήριο στο κοινό σας. Συχνές παραλλαγές:

- **Για κοινό backend:** αφιερώστε περισσότερο χρόνο στο `agent.yaml`, Docker, και ACR· μειώστε τη demo στο playground.
- **Για κοινό citizen-developer:** παραμείνετε στο UI της επέκτασης Foundry για scaffolding· μειώστε τα βήματα CLI.
- **Για μονοδιάδρομη συνεδρία 60 λεπτών:** αποφύγετε εισαγωγή, demo, και μόνο το Εργαστήριο 01.
- **Μορφή μόνο για εργαστήριο (χωρίς διαφάνειες):** ανοίξτε και τα δύο αρχεία README των εργαστηρίων και χρησιμοποιήστε τα ως το κύριο σενάριο.

Αν επεκτείνετε τα εργαστήρια, παρακαλώ συνεισφέρετε τις αλλαγές μέσω PR ώστε να ωφεληθούν και άλλοι εκπαιδευτές.
