## Keamanan

Microsoft sangat serius dalam menjaga keamanan produk perangkat lunak dan layanan kami, yang
mencakup semua repositori kode sumber di organisasi GitHub kami.

**Harap jangan melaporkan kerentanan keamanan melalui masalah GitHub publik.**

Untuk informasi pelaporan keamanan, lokasi, informasi kontak, dan kebijakan,
silakan tinjau panduan terbaru untuk repositori Microsoft di
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
