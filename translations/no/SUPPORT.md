# Support

## Hvordan rapportere problemer og få hjelp  

Dette prosjektet bruker GitHub Issues for å spore feil og funksjonsforespørsler. Vennligst søk i eksisterende 
issues før du oppretter nye saker for å unngå duplikater. For nye saker, rapporter feilen din eller 
funksjonsforespørselen som en ny Issue.

For hjelp og spørsmål om bruk av dette prosjektet, vennligst **REPO-VEDLIKEHOLDER: SETT INN INSTRUKSJONER HER 
FOR HVORDAN MAN KONTAKTER REPO-EIERE ELLER FELLESSKAP FOR HJELP. KAN VÆRE EN STACK OVERFLOW-TAG ELLER ANNEN
KANAL. HVOR VIL DU HJELPE FOLK?**.
