# Makmal 02 - Aliran Kerja Pelbagai Ejen: Penilai Keserasian Resume ke Pekerjaan

## Laluan Pembelajaran Penuh

Dokumentasi ini membimbing anda melalui pembinaan, pengujian, dan penyebaran **aliran kerja pelbagai ejen** yang menilai keserasian resume ke pekerjaan menggunakan empat ejen khusus yang diatur melalui **WorkflowBuilder**.

> **Prasyarat:** Lengkapkan [Makmal 01 - Ejen Tunggal](../../lab01-single-agent/README.md) sebelum memulakan Makmal 02.
