# ห้องปฏิบัติการ 02 - การทำงานแบบ Multi-Agent: ตัวประเมินความเหมาะสมเรซูเม่กับงาน

## เส้นทางการเรียนรู้เต็มรูปแบบ

เอกสารนี้จะนำทางคุณผ่านการสร้าง ทดสอบ และปรับใช้ **การทำงานแบบ multi-agent** ที่ประเมินความเหมาะสมของเรซูเม่กับงานโดยใช้เอเย่นต์เฉพาะทางสี่ตัวที่ประสานงานกันผ่าน **WorkflowBuilder**

> **ข้อกำหนดเบื้องต้น:** ทำ [Lab 01 - Single Agent](../../lab01-single-agent/README.md) ให้เสร็จสิ้นก่อนเริ่ม Lab 02
