# โมดูล 7 - สรุป & ขั้นตอนถัดไป

⏱️ ~5 นาที

**ขอแสดงความยินดี!** คุณได้สร้าง ทดสอบ และ (ถ้าอยู่ในเส้นทาง A) นำตัวแทน AI ที่โฮสต์ใช้งานได้โดยใช้ Microsoft Foundry และ Foundry Toolkit สำหรับ VS Code

---

## สิ่งที่คุณสร้าง

ตัวแทน **"อธิบายเหมือนผมเป็นผู้บริหาร"** ที่:
- รับรายงานเหตุการณ์ทางเทคนิคหรืออัปเดตการดำเนินงานผ่าน HTTP (`POST /responses`)
- แปลเป็นบทสรุปภาษาเรียบง่ายสำหรับผู้บริหาร
- ปฏิบัติตามรูปแบบผลลัพธ์ที่มีโครงสร้าง (เกิดอะไรขึ้น / ผลกระทบทางธุรกิจ / ขั้นตอนถัดไป)
- ปฏิเสธคำขอที่ไม่เกี่ยวข้องและพยายามฉีดข้อมูลกระตุ้น
- ทำงานในฐานะตัวแทนโฮสต์แบบคอนเทนเนอร์ใน Microsoft Foundry Agent Service

---

## แนวคิดหลักที่ได้เรียนรู้

| แนวคิด | สิ่งที่คุณฝึกปฏิบัติ |
|---------|-------------------|
| **สถาปัตยกรรม Agent Framework** | ท่อ `FoundryChatClient` → `Agent` → `ResponsesHostServer` |
| **วัฏจักรชีวิตของ Hosted Agent** | สร้างโครงร่าง → กำหนดค่า → ทดสอบในเครื่อง → นำส่ง → ตรวจสอบในคลาวด์ |
| **การออกแบบ Prompt ของระบบ** | บทบาท, ผู้ชม, รูปแบบผลลัพธ์, กฎ, ข้อจำกัดความปลอดภัย และตัวอย่าง |
| **ความแตกต่างระหว่าง Local กับ Hosted** | ตัวตน (ข้อมูลประจำตัวส่วนบุคคล vs ตัวตนที่จัดการ), จุดสิ้นสุด, เส้นทางเครือข่าย |
| **ขอบเขตความปลอดภัย** | การป้องกันการฉีด prompt, การปฏิบัติตามบทบาท, การจัดการอย่างนุ่มนวลกับกรณีขอบเขต |
| **ขั้นตอนการทำงานของ Foundry Toolkit** | การสร้างโปรเจกต์, การ deploy โมเดล, การสร้าง agent, Agent Inspector, การ deploy ด้วยคลิกเดียว |

### ไอเดียขยายตัวแทนของคุณ

- **เพิ่มเครื่องมือวันที่** - ให้ตัวแทนสามารถรวมบริบท "ถึงวันที่วันนี้" ในบทสรุป
- **เชื่อมต่อกับฐานข้อมูลเหตุการณ์** - ดึงรายละเอียดเหตุการณ์จริงผ่านฟังก์ชันเครื่องมือ
- **เพิ่มเครื่องมือ Bing grounding** - ให้ตัวแทนค้นข่าวล่าสุดเพื่อบริบทเพิ่มเติม
- **ลองโมเดลแตกต่างกัน** - เปรียบเทียบคุณภาพผลลัพธ์ `gpt-4.1` กับ `gpt-4.1-mini`
- **ประเมินกับ Foundry** - ใช้ฟีเจอร์ Evaluations เพื่อวัดคุณภาพตัวแทนในระดับใหญ่

### สำหรับผู้ใช้เส้นทาง B: อัปเกรดเป็นการ deploy บนคลาวด์

เมื่อคุณพร้อมที่จะ deploy บนคลาวด์:
1. สมัครรับ Azure ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. ทำ [โมดูล 01, การตั้งค่า](01-setup.md#step-2-set-up-based-on-your-access) ให้เสร็จ (สร้างโปรเจกต์, deploy โมเดล, กำหนด RBAC)
3. อัปเดต `.env` ของคุณด้วยจุดสิ้นสุดโปรเจกต์ Foundry และชื่อการ deploy โมเดล
4. ดำเนินการต่อจาก [โมดูล 05 - Deploy ไปยัง Foundry](05-deploy-to-foundry.md)

## ล้างทรัพยากร (ไม่บังคับ)

หากคุณต้องการลบทรัพยากร Azure ที่สร้างขึ้นระหว่างเวิร์กช็อปนี้:

### ตัวเลือก 1: ลบกลุ่มทรัพยากร (ลบทุกอย่าง)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ตัวเลือก 2: ลบแค่ตัวแทนที่โฮสต์

1. เปิด [ai.azure.com](https://ai.azure.com) → โปรเจกต์ของคุณ → **Build** → **Agents**
2. คลิกตัวแทนของคุณ → คลิก **Delete**

### ตัวเลือก 3: ลบการ deploy โมเดล

1. ในแถบ Foundry ให้ขยายโปรเจกต์ของคุณ → **Models**
2. คลิกขวาที่การ deploy โมเดล → **Delete**

> **บันทึกราคา:** ตัวแทนที่โฮสต์จะมีค่าใช้จ่ายเมื่อทำงานเท่านั้น หากคุณหยุดหรือลบตัวแทน จะไม่มีค่าใช้จ่ายซ้ำ การ deploy โมเดลอาจมีค่าใช้จ่ายเล็กน้อยสำหรับความจุที่จองไว้ – ลบเมื่อใช้งานเสร็จแล้ว
