## ความปลอดภัย

Microsoft ให้ความสำคัญกับความปลอดภัยของผลิตภัณฑ์ซอฟต์แวร์และบริการของเราอย่างจริงจัง ซึ่ง
รวมถึงที่เก็บซอร์สโค้ดทั้งหมดในองค์กร GitHub ของเรา

**โปรดอย่ารายงานช่องโหว่ด้านความปลอดภัยผ่านประเด็นสาธารณะใน GitHub**

สำหรับข้อมูลการรายงานความปลอดภัย สถานที่ ข้อมูลติดต่อ และนโยบาย
โปรดดูคำแนะนำล่าสุดสำหรับที่เก็บ Microsoft ได้ที่
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md)
