# การสนับสนุน

## วิธีการรายงานปัญหาและขอความช่วยเหลือ  

โครงการนี้ใช้ GitHub Issues ในการติดตามบั๊กและคำขอฟีเจอร์ โปรดค้นหา 
issues ที่มีอยู่ก่อนการยื่น issue ใหม่เพื่อหลีกเลี่ยงการซ้ำซ้อน  สำหรับ issue ใหม่ ให้ยื่นบั๊กของคุณหรือ 
คำขอฟีเจอร์ของคุณเป็น Issue ใหม่.

สำหรับการขอความช่วยเหลือและคำถามเกี่ยวกับการใช้โครงการนี้ โปรด **ผู้ดูแลรีโพ: แทรกคำแนะนำที่นี่ 
เกี่ยวกับวิธีการติดต่อเจ้าของรีโพหรือชุมชนเพื่อขอความช่วยเหลือ อาจเป็นแท็กบน Stack Overflow หรือช่องทางอื่น
ช่องทาง. คุณจะให้ความช่วยเหลือผู้คนที่ไหน?**.

## นโยบายการสนับสนุนของ Microsoft  

การสนับสนุนสำหรับ **โปรเจกต์หรือผลิตภัณฑ์** ถูกจำกัดไว้เพียงทรัพยากรที่ระบุไว้ข้างต้น.
