magában foglalja az összes forráskód tárházat GitHub szervezeteinkben.

kérjük, tekintse át a Microsoft tárházak legfrissebb útmutatóját a
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md) címen.
