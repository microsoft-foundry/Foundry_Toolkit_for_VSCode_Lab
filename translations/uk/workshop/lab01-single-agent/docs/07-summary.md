# Модуль 7 - Підсумок та наступні кроки

⏱️ ~5 хв

**Вітаємо!** Ви створили, протестували та (якщо за Путем A) розгорнули розміщеного агента ШІ за допомогою Microsoft Foundry та Foundry Toolkit для VS Code.

---

## Що ви створили

Агент **"Поясни, наче я керівник"**, який:
- Приймає технічні звіти про інциденти або операційні оновлення через HTTP (`POST /responses`)
- Перекладає їх у виконавчі резюме зрозумілою мовою
- Дотримується структурованого формату виводу (Що сталося / Вплив на бізнес / Наступний крок)
- Відмовляється від запитів поза темою та спроб інжекції підказок
- Працює як контейнеризований розміщений агент у Microsoft Foundry Agent Service

---

## Основні вивчені концепції

| Концепція | Що ви практикували |
|---------|-------------------|
| **Архітектура Agent Framework** | конвеєр `FoundryChatClient` → `Agent` → `ResponsesHostServer` |
| **Життєвий цикл розміщеного агента** | Підготовка → Конфігурація → Локальне тестування → Розгортання → Перевірка в хмарі |
| **Інженерія системної підказки** | Роль, аудиторія, формат виводу, правила, обмеження безпеки та приклади |
| **Різниця між локальним і розміщеним** | Ідентичність (особисті облікові дані vs керована ідентичність), кінцева точка, мережевий шлях |
| **Межі безпеки** | Захист від інжекції підказок, дотримання ролі, коректна обробка граничних випадків |
| **Робочий процес Foundry Toolkit** | Створення проекту, розгортання моделей, підготовка агента, Agent Inspector, розгортання в один клік |

### Ідеї для розширення вашого агента

- **Додайте інструмент дати** - Дозвольте агенту включати контекст "на сьогодні" у резюме
- **Підключіться до бази інцидентів** - Отримуйте реальні деталі інцидентів через функцію інструмента
- **Додайте інструмент Bing Grounding** - Дозвольте агенту шукати свіжі новини для додаткового контексту
- **Спробуйте різні моделі** - Порівняйте якість виводу `gpt-4.1` та `gpt-4.1-mini`
- **Оцініть з Foundry** - Використовуйте функцію Evaluation для вимірювання якості агента в масштабі

### Користувачам Шляху B: Оновлення до розгортання в хмарі

Коли будете готові до розгортання в хмарі:
1. Отримайте підписку Azure ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. Виконайте [Модуль 01, Налаштування](01-setup.md#step-2-set-up-based-on-your-access) (створення проекту, розгортання моделі, призначення RBAC)
3. Оновіть свій `.env` з кінцевою точкою проекту Foundry та іменем розгортання моделі
4. Продовжуйте з [Модуль 05 - Розгортання в Foundry](05-deploy-to-foundry.md)

## Очищення ресурсів (за бажанням)

Якщо ви хочете видалити ресурси Azure, створені під час цього воркшопу:

### Варіант 1: Видалити групу ресурсів (видаляє все)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### Варіант 2: Видалити лише розміщеного агента

1. Відкрийте [ai.azure.com](https://ai.azure.com) → ваш проект → **Build** → **Agents**.
2. Клікніть вашого агента → натисніть **Delete**.

### Варіант 3: Видалити розгортання моделі

1. У бічній панелі Foundry розгорніть свій проект → **Models**.
2. Правий клік по розгортанню моделі → **Delete**.

> **Примітка щодо вартості:** Розміщені агенти стягують плату лише під час роботи. Якщо ви зупините або видалите агента, оплата припиняється. Розгортання моделі може спричиняти невелику плату за зарезервовану потужність – видаліть, якщо він більше не потрібен.
