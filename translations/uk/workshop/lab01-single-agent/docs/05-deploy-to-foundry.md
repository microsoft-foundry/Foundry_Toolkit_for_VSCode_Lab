# Модуль 5 - Розгортання в службу агента Foundry

⏱️ ~10 хв

> ⚠️ **Користувачі шляху B:** Цей модуль вимагає підписки Foundry. Якщо ви користуєтеся Foundry Local, перейдіть до [Модуль 07 - Підсумок](07-summary.md). Ви успішно завершили локальний робочий процес розробки!

У цьому модулі ви розгортаєте ваш локально протестований агент у Microsoft Foundry як **хостинговий агент**. Розгортання створює образ контейнера, відправляє його у Azure Container Registry і запускає агента в керованій інфраструктурі Foundry.

## Крок 1: Початок розгортання

### Варіант А: Розгортання з Agent Inspector (рекомендовано)

Якщо Agent Inspector відкритий (після тестування):
1. Натисніть кнопку **Deploy** у верхньому правому куті (значок хмари ↑).

### Варіант B: Розгортання з командної палітри

1. Натисніть `Ctrl+Shift+P` → **Foundry Toolkit: Deploy Hosted Agent**.

## Крок 3: Розгортання та моніторинг

1. Натисніть **Deploy**.
2. Слідкуйте за панеллю **Output** (виберіть **Microsoft Foundry** у спадному списку).
3. Розгортання проходить такі етапи:
   - **Створення Docker-образу** — створення контейнера з вашого Dockerfile
   - **Відправка Docker-образу** — відправка образу до ACR (1–3 хв при першому розгортанні)
   - **Реєстрація агента** — створення хостингового агента в Foundry
   - **Запуск контейнера** — запуск із системною керованою ідентичністю

4. По завершенню з’явиться повідомлення:
   > **executive-summary-agent успішно розгорнуто.** `View logs` `Run agent`

5. Натисніть **Run agent** для відкриття Agent Playground.

![Повідомлення про успішне розгортання, що показує Agent Playground зі статусом Running](../../../../../translated_images/uk/05-deployed-asset.b59e6a5eef31c0b1.webp)

### Значення статусів розгортання

| Статус | Значення |
|--------|---------|
| **Running** | Контейнер готовий, агент відповідає |
| **Pending** | Контейнер запускається - зачекайте 30–60 секунд |
| **Failed** | Перевірте логи (див. розділ усунення несправностей нижче) |

---

## Типові помилки розгортання

| Помилка | Основна причина | Вирішення |
|-------|-----------|-----|
| `agents/write` permission denied | Відсутня роль **Azure AI User** на рівні проекту | [Модуль 01, Призначення RBAC](01-setup.md#deploy-a-model--assign-rbac) |
| Docker не запущено | Docker Desktop не стартував | Запустіть Docker Desktop → перевірте `docker info` |
| Авторизація ACR | Системна керована ідентичність не може завантажити образ | Див. [Модуль 08 - Усунення несправностей](08-troubleshooting.md) |

### ✅ Контрольна точка

- [ ] Розгортання завершено без помилок
- [ ] Агент відображається на вкладці **Hosted Agent** при натисканні **Agents** у боковій панелі Foundry Toolkit вашого проекту
- [ ] Статус контейнера показує **Running**
- [ ] Відкрито вкладку Agent Playground з деталями агента та URL кінцевої точки
