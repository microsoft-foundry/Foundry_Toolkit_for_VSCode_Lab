# Модуль 0 - Вступ

⏱️ ~10 хв

> [!WARNING]
> **Перегляд та Обмеження:** [Hosted Agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) наразі перебувають у **публічному перегляді** - не рекомендуються для робочих навантажень у виробничому середовищі. Деякі функції, показані в цьому воркшопі, можуть змінитися у міру наближення сервісу до GA.

## Що ви створите

У цій лабораторній роботі ви розширите навички одного агента з Лабораторної роботи 01, щоб побудувати **багатоагентський робочий процес** - Оцінювач відповідності резюме до вакансії.

Ви вставляєте **резюме** та **опис вакансії**. Чотири спеціалізовані агенти послідовно обробляють введені дані, а потім повертають:
- Оцінку відповідності (0–100 з розбиттям за балами)
- Список відсутніх навичок та сертифікацій
- Персоналізовану дорожню карту навчання з реальними посиланнями Microsoft Learn для кожного пропуску

**Робочий процес використовує:**
- **Microsoft Agent Framework** - `WorkflowBuilder` для послідовної оркестрації конвеєра
- **Foundry Toolkit для VS Code** - каркас, локальне тестування, розгортання
- **Штучний інтелект** (наприклад, `gpt-4.1-mini`) - використовується усіма чотирма агентами
- **Microsoft Learn MCP server** - надає реальні посилання на навчальні ресурси для кожного пропуску навички

## Перевірка Лаб 01

Лаб 02 будується безпосередньо на Лаб 01. Спочатку завершіть Лаб 01, перш ніж починати тут.

Ще не робили Лаб 01? Почніть тут: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ Шлях A - хмара Azure</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

Якщо це не вдається, виконайте `az login`. Потім перевірте у VS Code:

1. `Ctrl+Shift+P` → введіть **Foundry Toolkit** → переконайтеся, що з’являються команди.
2. Натисніть піктограму **Foundry Toolkit** → ваш проект та розгорнута модель відображають статус **Succeeded**.

![Foundry Toolkit sidebar showing MY RESOURCES section with the project switcher modal open](../../../../../translated_images/uk/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** Ви призначили роль **Foundry User** в Лаб 01. Якщо потрібно переназначити, дивіться [Лаб 01, Модуль 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac). Роль раніше називалася **Azure AI User** — з тими ж правами.

</details>

<summary><strong>🅱️ Шлях B - Foundry Local</strong></summary>
