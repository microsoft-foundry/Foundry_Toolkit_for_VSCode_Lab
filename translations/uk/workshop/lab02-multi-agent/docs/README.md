# Лабораторна 02 - Багатофункціональний робочий процес: Резюме → Оцінка відповідності вакансії

## Повний навчальний шлях

Ця документація допоможе вам побудувати, протестувати та розгорнути **робочий процес з кількома агентами**, що оцінює відповідність резюме вакансії за допомогою чотирьох спеціалізованих агентів, організованих через **WorkflowBuilder**.

> **Передумова:** Завершіть [Лабораторну 01 - Одиночний агент](../../lab01-single-agent/README.md) перед початком Лабораторної 02.
