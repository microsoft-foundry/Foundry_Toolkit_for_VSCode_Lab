## آنچه خواهید ساخت

در این آزمایشگاه، مهارت‌های تک‌عامل را از آزمایشگاه ۰۱ گسترش می‌دهید تا یک **گردش کار چندعامله** بسازید - ارزیاب تناسب رزومه به شغل.

شما یک **رزومه** و یک **توصیف شغل** جای‌گذاری می‌کنید. چهار عامل تخصصی ورودی را به ترتیب پردازش می‌کنند و سپس بازمی‌گردانند:
- امتیاز تناسب (۰–۱۰۰ همراه با تجزیه امتیاز)
- فهرست شکاف مهارت و گواهینامه
- نقشه راه یادگیری شخصی‌سازی‌شده با لینک‌های واقعی Microsoft Learn برای هر شکاف

**گردش کار از موارد زیر استفاده می‌کند:**
- **چارچوب عامل مایکروسافت** - `WorkflowBuilder` برای هماهنگی به صورت متوالی خط لوله
- **Foundry Toolkit برای VS Code** - اسکافولد، تست محلی، استقرار
- **یک مدل هوش مصنوعی** (مثلاً `gpt-4.1-mini`) - استفاده شده توسط همهٔ چهار عامل
- **سرور MCP مایکروسافت لرن** - ارائه لینک‌های منابع واقعی یادگیری برای هر شکاف مهارتی

## بررسی آزمایشگاه ۰۱

آزمایشگاه ۰۲ مستقیماً بر روی آزمایشگاه ۰۱ ساخته شده است. ابتدا آزمایشگاه ۰۱ را تکمیل کنید سپس اینجا را شروع کنید.

هنوز آزمایشگاه ۰۱ را انجام نداده‌اید؟ از اینجا شروع کنید: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ مسیر A - ابر Azure</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

اگر ناموفق بود، `az login` را اجرا کنید. سپس در VS Code تأیید کنید:

۱. `Ctrl+Shift+P` → تایپ کنید **Foundry Toolkit** → تأیید کنید دستورات ظاهر شده‌اند.
۲. روی آیکون **Foundry Toolkit** کلیک کنید → پروژه شما و مدل مستقر شده نشان دهند **Succeeded** باشد.

![نوار کناری Foundry Toolkit که پروژه را در بخش منابع من نشان می‌دهد، با انتخابگر تعویض/ایجاد پروژه باز](../../../../../translated_images/fa/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** شما در آزمایشگاه ۰۱ نقش **Foundry User** را اختصاص دادید. اگر نیاز به اختصاص مجدد دارید، به [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac) مراجعه کنید. این نقش قبلاً **Azure AI User** نامیده می‌شد - با همان دسترسی‌ها.

</details>

<details open>
<summary><strong>🅱️ مسیر B - Foundry Local</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

انتظار می‌رود: `StatusCode: 200`. اگر نه، Foundry Local را از نوار کناری Foundry Toolkit دوباره راه‌اندازی کنید.

> همه پیش‌بینی‌ها روی دستگاه شما انجام می‌شود. تنها تماس خروجی ابزار MCP به `https://learn.microsoft.com/api/mcp` است.

</details>
