# آزمایشگاه ۰۲ - گردش کار چندعاملی: ارزیاب تطابق رزومه با شغل

## مسیر کامل یادگیری

این مستند شما را گام به گام در ساخت، آزمایش و استقرار یک **گردش کار چندعاملی** راهنمایی می‌کند که با استفاده از چهار عامل تخصصی و هماهنگ شده از طریق **WorkflowBuilder**، تطابق رزومه با شغل را ارزیابی می‌کند.

> **پیش‌نیاز:** قبل از شروع آزمایشگاه ۰۲، آزمایشگاه [۰۱ - عامل تک](../../lab01-single-agent/README.md) را تکمیل کنید.
