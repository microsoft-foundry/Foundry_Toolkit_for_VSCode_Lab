# ماژول ۷ - خلاصه و مراحل بعدی

⏱️ ~۵ دقیقه

**تبریک می‌گوییم!** شما یک عامل هوش مصنوعی میزبانی شده با استفاده از Microsoft Foundry و Foundry Toolkit برای VS Code ساخته، آزمایش و (اگر در مسیر A هستید) مستقر کرده‌اید.

---

## آنچه ساختید

یک عامل **"توضیح مانند یک مدیر اجرایی"** که:
- گزارش‌های فنی یا به‌روزرسانی‌های عملیاتی را از طریق HTTP (`POST /responses`) دریافت می‌کند
- آن‌ها را به خلاصه‌های ساده و قابل فهم برای مدیران ترجمه می‌کند
- از فرمت خروجی ساختاریافته (چه اتفاقی افتاد / تأثیر تجاری / گام بعدی) پیروی می‌کند
- درخواست‌های نامرتبط و تلاش‌های تزریق درخواست را رد می‌کند
- به عنوان عامل میزبانی شده کانتینری شده در سرویس عامل Microsoft Foundry اجرا می‌شود

---

## مفاهیم کلیدی که یاد گرفتید

| مفهوم | آنچه تمرین کردید |
|---------|-------------------|
| **معماری چارچوب عامل** | مسیر `FoundryChatClient` → `Agent` → `ResponsesHostServer` |
| **چرخه عمر عامل میزبانی شده** | ساختار اولیه → پیکربندی → تست محلی → استقرار → تأیید در ابر |
| **مهندسی درخواست سیستم** | نقش، مخاطب، فرمت خروجی، قوانین، محدودیت‌های ایمنی، و نمونه‌ها |
| **تفاوت‌های محلی و میزبانی شده** | هویت (مدرک شخصی در مقابل هویت مدیریتی)، نقطه پایان، مسیر شبکه |
| **مرزهای ایمنی** | دفاع در برابر تزریق درخواست، رعایت نقش، مدیریت مودبانه موارد حاشیه‌ای |
| **روند کاری Foundry Toolkit** | ایجاد پروژه، استقرار مدل، ساختار عامل، بازرس عامل، استقرار با یک کلیک |

### ایده‌هایی برای گسترش عامل شما

- **ابزار تاریخ اضافه کنید** - اجازه دهید عامل در خلاصه‌ها بافت «تا امروز» را لحاظ کند
- **اتصال به پایگاه داده حادثه** - جزئیات واقعی حادثه را از طریق تابع ابزار بکشید
- **ابزار زمینه‌بخشی Bing اضافه کنید** - اجازه دهید عامل برای زمینه بیشتر اخبار اخیر را جستجو کند
- **مدل‌های مختلف را امتحان کنید** - کیفیت خروجی `gpt-4.1` در مقابل `gpt-4.1-mini` را مقایسه کنید
- **با Foundry ارزیابی کنید** - از ویژگی ارزیابی برای اندازه‌گیری کیفیت عامل در مقیاس استفاده کنید

### برای کاربران مسیر B: ارتقا به استقرار ابری

وقتی آماده باشید برای استقرار در ابر:
1. یک اشتراک Azure دریافت کنید ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. ماژول ۰۱، راه‌اندازی را کامل کنید (ایجاد پروژه، استقرار مدل، تخصیص RBAC)
3. فایل `.env` خود را با نقطه پایان پروژه Foundry و نام استقرار مدل به‌روزرسانی کنید
4. ادامه دهید از [ماژول ۰۵ - استقرار در Foundry](05-deploy-to-foundry.md)

## پاکسازی منابع (اختیاری)

اگر می‌خواهید منابع Azure ایجاد شده در طول این کارگاه را حذف کنید:

### گزینه ۱: حذف گروه منابع (همه چیز را حذف می‌کند)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### گزینه ۲: فقط عامل میزبانی شده را حذف کنید

1. به [ai.azure.com](https://ai.azure.com) → پروژه خود → **ساخت** → **عامل‌ها** بروید.
2. روی عامل خود کلیک کنید → کلیک روی **حذف**.

### گزینه ۳: استقرار مدل را حذف کنید

1. در نوار کناری Foundry، پروژه خود را باز کنید → **مدل‌ها**.
2. روی استقرار مدل راست‌کلیک کنید → **حذف**.

> **توجه هزینه:** عوامل میزبانی شده فقط هنگام اجرا هزینه دارند. اگر عامل را متوقف یا حذف کنید، هزینه جاری نیست. استقرار مدل ممکن است هزینه کمی برای ظرفیت رزرو شده داشته باشد - اگر کارتان تمام شده است آن را حذف کنید.
