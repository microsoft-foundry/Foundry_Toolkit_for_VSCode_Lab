## امنیت

مایکروسافت امنیت محصولات نرم‌افزاری و خدمات خود را جدی می‌گیرد، که شامل
تمام مخازن کد منبع در سازمان‌های GitHub ما می‌شود.

**لطفاً آسیب‌پذیری‌های امنیتی را از طریق مسائل عمومی GitHub گزارش ندهید.**

برای اطلاعات گزارش امنیتی، مکان‌ها، اطلاعات تماس و سیاست‌ها،
لطفاً آخرین راهنمایی‌ها برای مخازن مایکروسافت را در
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md) مرور کنید.
