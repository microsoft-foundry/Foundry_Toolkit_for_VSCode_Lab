## ಭದ್ರತೆ

ಮೈಕ್ರೋಸಾಫ್ಟ್ ನಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್ ಉತ್ಪನ್ನಗಳು ಮತ್ತು ಸೇವೆಗಳ ಭದ್ರತೆಯನ್ನು ಗಂಭೀರವಾಗಿ ನಡೆಸುತ್ತದೆ, ಇದು
ನಮ್ಮ GitHub ಸಂಸ್ಥೆಗಳಲ್ಲಿ ಇರುವ ಎಲ್ಲ ಮೂಲ ಕೋಡ್ ಸಂಗ್ರಹಾಲಯಗಳನ್ನು ಒಳಗೊಂಡಿದೆ.

**ದಯವಿಟ್ಟು ಭದ್ರತಾ ದೌರ್ಬಲ್ಯಗಳನ್ನು ಸಾರ್ವಜನಿಕ GitHub ಸಮಸ್ಯೆಗಳ ಮೂಲಕ ವರದಿ ಮಾಡಬೇಡಿ.**

ಭದ್ರತಾ ವರದಿ ಮಾಹಿತಿಗಾಗಿ, ಸ್ಥಳಗಳು, ಸಂಪರ್ಕ ಮಾಹಿತಿ ಮತ್ತು ನೀತಿಗಳಿಗಾಗಿ,
ದಯವಿಟ್ಟು ಮೈಕ್ರೋಸಾಫ್ಟ್ ಸಂಗ್ರಹಾಲಯಗಳ ಇತ್ತೀಚಿನ ಮಾರ್ಗಸೂಚಿಗಳನ್ನು
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md) ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.
