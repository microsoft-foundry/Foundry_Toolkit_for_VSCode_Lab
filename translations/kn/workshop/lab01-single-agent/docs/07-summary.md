# ಭಾಗ 7 - ಸಾರಾಂಶ ಮತ್ತು ಮುಂದಿನ ಹಂತಗಳು

⏱️ ~5 ನಿಮಿಷಗಳು

**ಅಭಿನಂದನೆಗಳು!** ನೀವು ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರಿ ಮತ್ತು ಫೌಂಡ್ರಿ ಟೂಲ್ಕಿಟ್ ফর VS ಕೋಡ್ ಬಳಸಿ ಆತಿಥ್ಯ ನೀಡಲಾದ ಎಐ ಏಜೆಂಟ್ ರಚಿಸಿ, ಪರೀಕ್ಷಿಸಿ ಮತ್ತು (ಪಾತ್ A ನಲ್ಲಿ ಇದ್ದರೆ) ನಿಯೋಜಿಸಿದ್ದೀರಿ.

---

## ನೀವು ರಚಿಸಿದದ್ದು

**"ನಾನು ಎಕ್ಸಿಕ್ಯೂಟಿವ್ ಆಗಿದ್ದರೆ ವಿವರಿಸಿ"** ಎಂಬ ಏಜೆಂಟ್:
- ತಾಂತ್ರಿಕ ಘಟನೆ ವರದಿಗಳು ಅಥವಾ ಕಾರ್ಯಾಚರಣೆ ನವೀಕರಣಗಳನ್ನು HTTP (`POST /responses`) ಮೂಲಕ ಸ್ವೀಕರಿಸುತ್ತದೆ
- ಅವುಗಳನ್ನು ಸರಳ ಭಾಷೆಯ ಎಕ್ಸಿಕ್ಯೂಟಿವ್ ಸಾರಾಂಶಗಳಾಗಿ ಅನುವಾದಿಸುತ್ತದೆ
- ರಚನೆಗೊಳ್ಳುವ ಔಟ್ಪುಟ್ ಫಾರ್ಮ್ಯಾಟ್ (ಏನು ನಡೆಯಿತು / ವ್ಯವಹಾರ ಪರಿಣಾಮ / ಮುಂದಿನ ಹಂತ) ಅನುಸರಿಸುತ್ತದೆ
- ವಿಷಯದಿಂದ ಬೇರೆಯಾಗಿರುವ ವಿನಂತಿಗಳು ಮತ್ತು ಪ್ರಾಂಪ್ಟ್ ಇಂಜೆಕ್ಷನ್ ಯತ್ನಗಳನ್ನು ನಿರಾಕರಿಸುತ್ತದೆ
- ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರಿ ಏಜೆಂಟ್ ಸೇವೆಯಲ್ಲಿ ಕಾಂಟೈನರ್ ಆಗಿ ಆತಿಥ್ಯ ನೀಡಲ್ಪಟ್ಟ ಏಜೆಂಟ್ ಆಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ

---

## ಕಲಿತ ಮುಖ್ಯ ಕಲ್ಪನೆಗಳು

| ಕಲ್ಪನೆ | ನೀವು ಅಭ್ಯಾಸ ಮಾಡಿದದ್ದು |
|---------|-------------------|
| **ಏಜೆಂಟ್ ಫ್ರೇಮ್‌ವರ್ಕ್ ಸಾಂದರ್ಭಿಕತೆ** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` ಪೈಪ್ಲೈನ್ |
| **ಆತಿಥ್ಯ ನೀಡಲಾದ ಏಜೆಂಟ್ ಜೀವನಚರಿತ್ರೆ** | ಸ್ಕಾಫೋಲ್ಡ್ → ಸಂರಚಿಸಿ → ಸ್ಥಳೀಯವಾಗಿ ಪರೀಕ್ಷಿಸಿ → ನಿಯೋಜಿಸಿ → ಮেঘದಲ್ಲಿ ಖಚಿತಪಡಿಸಿ |
| **ಸಿಸ್ಟಮ್ ಪ್ರಾಂಪ್ಟ್ ಎಂಜಿನಿಯರಿಂಗ್** | ಪಾತ್ರ, ಪ್ರೇಾಕ್ಷ, ಔಟ್ಪುಟ್ ಫಾರ್ಮ್ಯಾಟ್, ನಿಯಮಗಳು, ಭದ್ರತಾ ನಿಯಂತ್ರಣೆಗಳು, ಮತ್ತು ಉದಾಹರಣೆಗಳು |
| **ಸ್ಥಳೀಯ ಮತ್ತು ಆತಿಥ್ಯ ನೀಡಲಾದ ವ್ಯತ್ಯಾಸಗಳು** | ಗುರುತಿಸಿಕೊಳ್ಳುವುದು (ವೈಯಕ್ತಿಕ ಪ್ರಮಾಣೀಕರಣ ವಿರುದ್ಧ ನಿರ್ವಹಿತ ಗುರುತಿಸಿಕೊಳ್ಳುವಿಕೆ), ಅಂತ್ಯಬಿಂದು, ಜಾಲ ಮಾರ್ಗ |
| **ಭದ್ರತಾ ಗಡಿಗಳು** | ಪ್ರಾಂಪ್ಟ್ ಇಂಜೆಕ್ಷನ್ ರಕ್ಷಣೆ, ಪಾತ್ರ ಅನುಸರಣೆ, ಅಂಚು ಪ್ರಕರಣಗಳನ್ನು ದಯಾಳುವಾಗಿ ನಿರ್ವಹಿಸುವುದು |
| **ಫೌಂಡ್ರಿ ಟೂಲ್ಕಿಟ್ ಕೆಲಸದ ಪ್ರಕ್ರಿಯೆ** | ಯೋಜನೆ ರಚನೆ, ಮಾದರಿ ನಿಯೋಜನೆ, ಏಜೆಂಟ್ ಸ್ಕಾಫೋಲ್ಡಿಂಗ್, ಏಜೆಂಟ್ ಇನ್ಸ್‌ಪೆಕ್ಟರ್, ಒನ್-ಕ್ಲಿಕ್ ನಿಯೋಜನೆ |

- [x] ಭದ್ರತಾ ನಿಯಮಗಳೊಂದಿಗೆ ರಚಿತ ಏಜೆಂಟ್ ಸೂಚನೆಗಳನ್ನು ಬರೆದಿದ್ದಾರೆ

### ನಿಮ್ಮ ಏಜೆಂಟ್ ವಿಸ್ತರಿಸಲು ಚಿಂತನೆಗಳು

- **ದಿನಾಂಕ ಉಪಕರಣ ಸೇರಿಸಿ** - ಏಜೆಂಟ್ ಅನ್ನು "ಇಂದು ದಿನಾಂಕ" ಸಾಂದರ್ಭಿಕತೆಯೊಂದಿಗೆ ಸೇರಿಸಲು ಅನುಮತಿಸಿ
- **ಘಟನೆ ಡೇಟಾಬೇಸ್‌ಗೆ ಸಂಪರ್ಕ ಮಾಡಿ** - ಉಪಕರಣ ಕಾರ್ಯ ಮೂಲಕ ನಿಜವಾದ ಘಟನೆ ವಿವರಗಳನ್ನು ಪಡೆದುಕೊಳ್ಳಿ
- **ಬಿಂಗ್ ಗ್ರೌಂಡಿಂಗ್ ಟೂಲ್ ಸೇರಿಸಿ** - ಹೆಚ್ಚುವರಿ ಸಾಂದರ್ಭಿಕತೆಯಿಗಾಗಿ ಏಜೆಂಟ್ ಇತ್ತೀಚಿನ ಸುದ್ದಿಗಳನ್ನು ಹುಡುಕಲು ಅನುಮತಿಸಿ
- **ವಿಭಿನ್ನ ಮಾದರಿಗಳನ್ನು ಪ್ರಯತ್ನಿಸಿ** - `gpt-4.1` ಮತ್ತು `gpt-4.1-mini` ಔಟ್ಪುಟ್ ಗುಣಮಟ್ಟವನ್ನು ಹೋಲಿಸಿ
- **ಫೌಂಡ್ರಿ ಬಳಸಿ ಮೌಲ್ಯಾಂಕನ ಮಾಡಿ** - ಏಜೆಂಟ್ ಗುಣಮಟ್ಟವನ್ನು ವ್ಯಾಪಕವಾಗಿ ಅಳೆಯಲು ಮೌಲ್ಯಾಂಕನ ವೈಶಿಷ್ಟ್ಯವನ್ನು ಬಳಸಿರಿ

### ಪಾತ್ B ಬಳಕೆದಾರರಿಗೆ: ಕ್ಲೌಡ್ ನಿಯೋಜನೆಗೆ ಅಪ್‌ಗ್ರೇಡ್ ಮಾಡಿ

ನೀವು ಕ್ಲೌಡ್‌ಗೆ ನಿಯೋಜಿಸಲು ಸಿದ್ಧರಾಗಿದ್ದಾಗ:
1. ಅಜೂರ್ ಚಂದಾದಾರಿಕೆಯನ್ನು ಪಡೆಯಿರಿ ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [ಮಾಡ್ಯೂಲ್ 01, ಸೆಟಪ್](01-setup.md#step-2-set-up-based-on-your-access) ಅನ್ನು ಪೂರ್ಣಗೊಳಿಸಿ (ಯೋಜನೆ ರಚಿಸಿ, ಮಾದರಿ ನಿಯೋಜಿಸಿ, RBAC ನೇಮಕ ಮಾಡಿ)
3. ನಿಮ್ಮ `.env` ಅನ್ನು ಫೌಂಡ್ರಿ ಯೋಜನೆಯ ಅಂತ್ಯಬಿಂದು ಮತ್ತು ಮಾದರಿ ನಿಯೋಜನೆಯ ಹೆಸರಿನಿಂದ ನವೀಕರಿಸಿ
4. [ಮಾಡ್ಯೂಲ್ 05 - ಫೌಂಡ್ರಿಗೆ ನಿಯೋಜಿಸಿ](05-deploy-to-foundry.md) ನಿಂದ ಮುಂದುವರಿಸಿ

## ಸಂಪನ್ಮೂಲಗಳನ್ನು ಸ್ವಚ್ಛಗೊಳಿಸಿ (ಆಪ್ಷನಲ್)

ನೀವು ಈ ಕಾರ್ಯಾಗಾರದ ವೇಳೆಯಲ್ಲಿ ರಚಿಸಿದ ಅಜೂರ್ ಸಂಪನ್ಮೂಲಗಳನ್ನು ತೆಗೆದುಹಾಕಲು ಇಚ್ಛಿಸಿದರೆ:

### ಆಯ್ಕೆ 1: ಸಂಪನ್ಮೂಲ ಗುಂಪನ್ನು ಅಳಿಸಿ (ಎಲ್ಲವನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ಆಯ್ಕೆ 2: ಆತಿಥ್ಯ ನೀಡಲಾದ ಏಜೆಂಟ್ ಅನ್ನು ಮಾತ್ರ ಅಳಿಸಿ

1. [ai.azure.com](https://ai.azure.com) → ನಿಮ್ಮ ಯೋಜನೆ → **ಬಿಲ್ಡ್** → **ಏಜೆಂಟ್‌ಗಳು** ತೆರಯಿರಿ.
2. ನಿಮ್ಮ ಏಜೆಂಟ್ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ → **ಅಳಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ.

### ಆಯ್ಕೆ 3: ಮಾದರಿ ನಿಯೋಜನೆಯನ್ನು ಅಳಿಸಿ

1. ಫೌಂಡ್ರಿ ಸೈಡ್ಬಾರ್‌ನಲ್ಲಿ ನಿಮ್ಮ ಯೋಜನೆಯನ್ನು ವಿಸ್ತರಿಸಿ → **ಮಾದರಿಗಳು**.
2. ಮಾದರಿ ನಿಯೋಜನೆಯನ್ನು ರೈಟ್ ಕ್ಲಿಕ್ ಮಾಡಿ → **ಅಳಿಸಿ**.

> **ವೆಚ್ಚದ ಟಿಪ್:** ಆತಿಥ್ಯ ನೀಡಲಾದ ಏಜೆಂಟ್‌ಗಳು ಚಾಲನೆ ಇಟ್ಟಾಗ ಮಾತ್ರ ವೆಚ್ಚವನ್ನುಂಟುಮಾಡುತ್ತವೆ. ನೀವು ಏಜೆಂಟ್ ಅನ್ನು ನಿಲ್ಲಿಸಿದರೂ ಅಥವಾ ಅಳಿಸಿದರೂ ಮುಂದುವರಿದ ಶುಲ್ಕವಿಲ್ಲ. ಮಾದರಿ ನಿಯೋಜನೆ ಸಂರಕ್ಷಿತ ಸಾಮರ್ಥ್ಯದ ಕೆಲವು ಕುಸಿತವನ್ನು ಹೊಂದಬಹುದು - ನೀವು ಮುಗಿಸಿದಾಗ ಅದನ್ನು ಅಳಿಸಿ.
