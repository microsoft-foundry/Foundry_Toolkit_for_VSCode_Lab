# ಅಧ್ಯಾಯ 9 - ಸಾರಾಂಶ ಮತ್ತು ಮುಂದಿನ ಹಂತಗಳು

⏱️ ~5 ನಿಮಿಷಗಳು

**ಅಭಿನಂದನೆಗಳು!** ನೀವು ಮಲ್ಟಿ-ಏಜೆಂಟ್ ವರ್ಕ್‌ಫ್ಲೋವನ್ನು Microsoft Foundry ಮತ್ತು Foundry Toolkit for VS Code ಬಳಸಿ ನಿರ್ಮಿಸಿ, ಪರೀಕ್ಷಿಸಿ, ಮತ್ತು (ಪಾಥ್ A ನಲ್ಲಿ ಇದ್ದರೆ) ನಿಯೋಜಿಸಿದ್ದೀರಿ.

## ನೀವು ನಿರ್ಮಿಸಿದದ್ದು

**ರೆಸ್ಯೂಮ್ → ಜಾಬ್ ಫಿಟ್ ಇವ್ಯುಯೇಟರ್** - ಒಂದು ಮಲ್ಟಿ-ಏಜೆಂಟ್ ಹೋಸ್ಟೆಡ್ ವರ್ಕ್‌ಫ್ಲೋ:
- ರೆಸ್ಯೂಮ್ ಮತ್ತು ಉದ್ಯೋಗ ವಿವರಣೆಯನ್ನು HTTP ಮೂಲಕ ಸ್ವೀಕರಿಸುತ್ತದೆ (`POST /responses`)
- ನಾಲ್ಕು ವಿಶೇಷ ಏಜೆಂಟ್‌ಗಳನ್ನು ಕ್ರಮೇಣ ಚಾಲನೆ ಮಾಡುತ್ತದೆ - ಪ್ರತಿ ಏಜೆಂಟ್ ತನ್ನ ಮುಂದಿನವರಿಗೆ ಅಗತ್ಯವಿರುವ ಡೇಟಾವನ್ನು ಪೂರೈಕೆ ಮಾಡುತ್ತದೆ
- ಫಿಟ್ ಸ್ಕೋರ್ (0–100 ಬ್ರೇಕ್‌ಡೌನ್ ಸಹಿತ), ಕೌಶಲ್ಯ ಮತ್ತು ಪ್ರಮಾಣಪತ್ರ ಗ್ಯಾಪ್ ಲಿಸ್ಟ್, ಮತ್ತು ಪ್ರತಿ ಗ್ಯಾಪ್‌ಗೆ ನೈಜ Microsoft Learn ಲಿಂಕ್‌ಗಳೊಂದಿಗೆ ವೈಯಕ್ತಿಕ ಪಾಠಯೋಜನೆ roadmap ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ
- ಗುರುತಿಸಿದ ಪ್ರತಿ ಕೌಶಲ್ಯ ಗ್ಯಾಪ್‌ಗೆ ಅಧಿಕೃತ ಪಾಠ ಸಾಮಗ್ರಿಗಳನ್ನು ಪಡೆಯಲು Microsoft Learn MCP ಸರ್ವರ್ (`https://learn.microsoft.com/api/mcp`) ಅನ್ನು ಕರೆ ಮಾಡುತ್ತದೆ
- Microsoft Foundry Agent Service ನಲ್ಲಿ ಒಂದು ಸಿಂಗಲ್ ಕಂಟೈನರೈಜ್ಡ್ ಹೋಸ್ಟೆಡ್ ಏಜೆಂಟ್ ಆಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ

## ಕಲಿತ ಪ್ರಮುಖ ಆಲೋಚನೆಗಳು

| ಆಲೋಚನೆ | ನೀವು ಅಭ್ಯಾಸ ಮಾಡಿದದ್ದು |
|---------|-------------------|
| **ಮಲ್ಟಿ-ಏಜೆಂಟ್ ಒರ್ಗನೈಜೆಷನ್** | `WorkflowBuilder` ಕ್ರಮೇಣ ಪೈಪ್ಲೈನ್ ಆಗಿ `add_edge()` ಬಳಸಿ |
| **ಏಜೆಂಟ್ ವಿಶೇಷತೆ** | ನಾಲ್ಕು ಕೇಂದ್ರೀಕೃತ ಏಜೆಂಟ್‌ಗಳು ಒಂದು ಸಾಮಾನ್ಯ ಉದ್ದೇಶ ಏಜೆಂಟ್ ಗಿಂತ ಉತ್ತಮ ಸಾಧನೆ ಮಾಡುತ್ತವೆ |
| **ಕಂಟೆಂಟ್ ರೌಟರ್ ಪ್ಯಾಟರ್ನ್** | ResumeParser ರೌಟರ್ ಆಗಿಯೂ ಕಾರ್ಯನಿರತವಾಗಿದೆ - ಅದು JD ಪಠ್ಯವನ್ನು `[JOB DESCRIPTION PASS-THROUGH]` ವಿಭಾಗದಲ್ಲಿ ಉಳಿಸುವ ಮೂಲಕ ಕೆಳಗಿನ ಏಜೆಂಟ್‌ಗಳು ಅದನ್ನು ಪ್ರವೇಶಿಸಬಹುದು (ಅಗತ್ಯ, ಏಕೆಂದರೆ `context_mode="last_agent"` ಇದ್ದರೆ ಕೇವಲ `start_executor` ಹಳೆಯ ಬಳಕೆದಾರ ಸಂದೇಶವನ್ನು ನೋಡುತ್ತಾನೆ) |
| **ಕಂಟೆಂಟ್ ರಿಲೇ ಪ್ಯಾಟರ್ನ್** | JD ಏಜೆಂಟ್ `[PARSED RESUME PASS-THROUGH]` ಅನ್ನು ಮುಂದಕ್ಕೆ ರಿಲೇ ಮಾಡುತ್ತದೆ ಆದ್ದರಿಂದ MatchingAgent ಇಬ್ಬರೂ ಪ್ರೊಫೈಲ್‌ಗಳನ್ನು ಪಡೆಯುತ್ತದೆ; ಫ್ಯಾನ್-ಇನ್ ಗ್ರಾಫ್‌ಗಳುಂಟುಮಾಡುವ OR-ಸೆಮ್ಯಾಂಟಿಕ್ಸ್ ಡಬಲ್-ಟ್ರಿಗರ್ ತಪ್ಪಿಸುತ್ತದೆ |
| **MCP ಉಪಕರಣ ಸಂಯೋಜನೆ** | `@tool` + `streamable_http_client` ಮೂಲಕ ಬಾಹ್ಯ MCP ಸರ್ವರ್ ಅನ್ನು ಕರೆ ಮಾಡುವುದು |
| **ಹೋಸ್ಟೆಡ್ ಏಜೆಂಟ್ ಜೀವನಚಕ್ರ** | Scaffold → ಕಾನ್ಫಿಗರ್ → ಸ್ಥಳೀಯವಾಗಿ ಪರೀಕ್ಷೆ → ನಿಯೋಜನೆ → ಕ್ಲೌಡ್‌ನಲ್ಲಿ ಪರಿಶೀಲನೆ |
| **`context_mode="last_agent"`** | ಪ್ರತಿಯೊಂದು ಎಕ್ಸಿಕ್ಯೂಟರ್ ತನ್ನ ನೇರ ಹಿಂದಿನವರ ಫಲಿತಾಂಶವನ್ನು ಮಾತ್ರ ನೋಡುತ್ತದೆ |
| **Foundry Toolkit ವರ್ಕ್‌ಫ್ಲೋ** | Scaffold ವಿಸರ್ಡ್, ಏಜೆಂಟ್ ಇನ್ಸ್‌ಪೆಕ್ಟರ್, ವರ್ಕ್‌ಫ್ಲೋ ವಿಸುವಲೈಜರ್, ಒನ್-ಕ್ಲಿಕ್ ನಿಯೋಜನೆ |

### ಈ ವರ್ಕ್‌ಫ್ಲೋವ್ ಅನ್ನು ವಿಸ್ತರಿಸಲು ಆಲೋಚನೆಗಳು

- **ಐದನೇ ಏಜೆಂಟ್ ಸೇರಿಸಿ** - ಗ್ಯಾಪ್ ವರದಿಯ ಆಧಾರದ ಮೇಲೆ ಸಂಭವನೀಯ ಸಂದರ್ಶನ ಪ್ರಶ್ನೆಗಳನ್ನು ಉಂಟುಮಾಡುವ ಸಂದರ್ಶನ ಕೋಚ್
- **Bing ನೆಲಹಿಡುವ ಉಪಕರಣ ಸೇರಿಸಿ** - JD ಏಜೆಂಟ್ ಸಮಾನ ಉದ್ಯೋಗ ಪೋಸ್ಟಿಂಗ್‌ಗಳನ್ನು ಹುಡುಕಲು ಅವಕಾಶ ನೀಡಿ, ಅವು Requirements ಅನ್ನು ಶ್ರೀಮಂತಗೊಳಿಸಲು
- **ರೆಸ್ಯೂಮ್ ಡೇಟಾಬೇಸಿಗೆ ಸಂಪರ್ಕಿಸಿ** - ಕಸ್ಟಮ್ `@tool` ಮೂಲಕ ಬೇಸ್‌ಮಾದರಿ ಪ್ರೊಫೈಲ್‌ಗಳನ್ನು ಡೇಟಾಬೇಸ್‌ನಿಂದ ಪಡೆಯಿರಿ
- **ವಿವಿಧ ಮಾದರಿಗಳನ್ನು ಪ್ರಯತ್ನಿಸಿ** - `gpt-4.1` ಮತ್ತು `gpt-4.1-mini` ಬಿಡುಗಡೆಯ ಗುಣಮಟ್ಟ ಮತ್ತು ವಿಳಂಬವನ್ನು ಹೋಲಿಸಿ
- **Foundry ಮೂಲಕ ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ** - ಮೌಲ್ಯಮಾಪನ ವೈಶಿಷ್ಟ್ಯವನ್ನು ಬಳಸಿಕೊಂಡು ಫಿಟ್ ವರದಿಗಳನ್ನು ಗೋಳ್ಡನ್ ಡೇಟಾಸೆಟ್‌ಗಳೊಂದಿಗೆ ಅಂಕಿಅಂಶ ನೀಡಿ

### ಪಾಥ್ B ಬಳಕೆದಾರರಿಗೆ: ಕ್ಲೌಡ್ ನಿಯೋಜನೆಗೆ ಅಪ್‌ಗ್ರೇಡ್ ಮಾಡಿ

ನೀವು ಕ್ಲೌಡ್‌ಗೆ ನಿಯೋಜಿಸಲು ಸಿದ್ಧರಾದಾಗ:
1. ಒಂದು Azure ಚಂದಾವನ್ನು ಪಡೆಯಿರಿ ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [Lab 01, Module 01](../../lab01-single-agent/docs/01-setup.md) ಪೂರ್ಣಗೊಳಿಸಿ (ಪ್ರಾಜೆಕ್ಟ್ ರಚಿಸಿ, ಮಾದರಿಯನ್ನು ನಿಯೋಜಿಸಿ, RBAC ನಿಯೋಜಿಸಿ)
3. ನಿಮ್ಮ `.env` ಅನ್ನು Foundry ಪ್ರಾಜೆಕ್ಟ್ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಮತ್ತು ಮಾದರಿ ನಿಯೋಜನೆ ಹೆಸರಿನಿಂದ ನವೀಕರಿಸಿ
4. [Module 06 - Foundry ಗೆ ನಿಯೋಜಿಸಿ](06-deploy-to-foundry.md) ಯಿಂದ ಮುಂದುವರಿಯಿರಿ

## ಸಂಪನ್ಮೂಲಗಳನ್ನು ಆರೈಸಿ (ಐಚ್ಛಿಕ)

ಈ ವರ್ಕ್‌ಶಾಪ್ ಸಮಯದಲ್ಲಿ ನಿರ್ಮಿಸಿದ Azure ಸಂಪನ್ಮೂಲಗಳನ್ನು ತೆಗೆದುಹಾಕಲು ಬಯಸಿದರೆ:

### ಆಯ್ಕೆ 1: ಸಂಪನ್ಮೂಲ ಗುಂಪನ್ನು ಅಳಿಸಿ (ಎಲ್ಲದನ್ನೂ ತೆಗೆದುಹಾಕುತ್ತದೆ)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ಆಯ್ಕೆ 2: ಕೇವಲ ಹೋಸ್ಟೆಡ್ ಏಜೆಂಟ್ ಅಳಿಸಿ

1. [ai.azure.com](https://ai.azure.com) → ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ → **Build** → **Agents** ತೆರಿ.
2. **PersonalCareerCopilot** ಅನ್ನು ಕಂಡು → **Delete** ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ.

### ಆಯ್ಕೆ 3: ಮಾದರಿ ನಿಯೋಜನೆಯನ್ನು ಅಳಿಸಿ

1. Foundry ಸೈಡ್‌ಬಾರ್‌ನಲ್ಲಿ ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ತೆರೆ → **Models**.
2. ಮಾದರಿ ನಿಯೋಜನೆಯನ್ನು ಬಲ-ನೋಡಿಸಿ → **Delete**.

> **ಖರ್ಚು ಟಿಪ್ಪಣಿ:** ಹೋಸ್ಟೆಡ್ ಏಜೆಂಟ್‌ಗಳು ಚಲಾಯಿಸುವಾಗ ಮಾತ್ರ ಖರ್ಚು ಆಗುತ್ತದೆ. ನೀವು ಏಜೆಂಟ್ ನಿಲ್ಲಿಸಿದರೂ ಅಥವಾ ಅಳಿಸಿದರೂ, ಯಾವುದೇ ಮುಂದುವರಿದ ಶುಲ್ಕ ಇಲ್ಲ. ಮಾದರಿ ನಿಯೋಜನೆ ರಿಸರ್ವ್ಡ್ ಸಾಮರ್ಥ್ಯಕ್ಕಾಗಿ ಸಣ್ಣ ಶುಲ್ಕವನ್ನು ಹೊಂದಬಹುದು - ನೀವು ಮುಗಿಸಿದರೆ ಅದನ್ನು ಅಳಿಸಿ.
