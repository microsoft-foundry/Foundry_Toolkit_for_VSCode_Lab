# ಮೋಡ್ಯೂಲ್ 0 - ಪರಿಚಯ

⏱️ ~10 ನಿಮಿಷಗಳು

> [!WARNING]
> **ಪೂರ್ವದೃಷ್ಟಿ ಮತ್ತು ನಿರ್ಬಂಧಗಳು:** [Hosted Agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) ಪ್ರಸ್ತುತ **ಸಾರ್ವಜನಿಕ ಪೂರ್ವದೃಷ್ಟಿಯಲ್ಲಿ** ಇದ್ದು - ಉತ್ಪಾದನಾ ಕೆಲಸಗಳಿಗೆ ಶಿಫಾರಸು ಮಾಡುತ್ತಿಲ್ಲ. ಈ ಕಾರ್ಯ ಶಾಲೆಯಲ್ಲಿ ತೋರಿಸಲಾದ ಕೆಲವು ವೈಶಿಷ್ಟ್ಯಗಳು ಸೇವೆ GA ತಲುಪುವಂತೆ ಬದಲಾಗಬಹುದು.

## ನೀವು 무엇 ನಿರ್ಮಿಸಬಹುದು

ಈ ಪ್ರಯೋಗಶಾಲೆಯಲ್ಲಿ, ನೀವು ಲ್ಯಾಬ್ 01 ನಿಂದ ಏಕರೂಪ ಏಜೆಂಟ್ ಕೌಶಲ್ಯಗಳನ್ನು ವಿಸ್ತರಿಸಿ **ಬಹು ಏಜೆಂಟ್ ವರ್ಕ್‌ಫ್ಲೋ** ಅನ್ನು ನಿರ್ಮಿಸಲಿದ್ದೀರಿ - ರೆಸ್ಯೂಮ್ → ಕೆಲಸ ಹೊಂದಾಣಿಕೆ ಮೌಲ್ಯಮಾಪಕ.

ನೀವು ಒಂದು **ರೆಸ್ಯೂಮ್** ಮತ್ತು ಒಂದು **ಕೆಲಸದ ವಿವರಣೆ** ಅನ್ನು ಪೇಸ್ಟ್ ಮಾಡುತ್ತೀರಿ. ನಾಲ್ಕು ವಿಶೇಷೀಕೃತ ಏಜೆಂಟ್‌ಗಳು ಕ್ರಮವಾಗಿ ಇನ್‌ಪುಟ್ ಅನ್ನು ಪ್ರಕ್ರಿಯೆ ಮಾಡುತ್ತವೆ, ನಂತರ ಹಿಂತಿರುಗಿಸುತ್ತವೆ:
- ಹೊಂದಾಣಿಕೆ ಅಂಕ (0–100 ಅಂಕಗಳ ವಿವರಣೆಯೊಂದಿಗೆ)
- ಕೌಶಲ್ಯ ಮತ್ತು ಪ್ರಮಾಣಪತ್ರ ವ್ಯತ್ಯಾಸ ಪಟ್ಟಿ
- ಪ್ರತಿ ವ್ಯತ್ಯಾಸಕ್ಕೆ ನಿಜವಾದ Microsoft Learn ಲಿಂಕ್‌ಗಳೊಂದಿಗೆ ವೈಯಕ್ತಿಕ ಕಲಿಕಾ ರೂಪರೇಖೆ

**ವರ್ಕ್‌ಫ್ಲೋ ಬಳCpuವಾಗಿಸುತ್ತದೆ:**
- **Microsoft Agent Framework** - ಕ್ರಮಾತ್ಮಕ ಪೈಪ್ಲೈನ್ ನಿರ್ವಾಹಕತೆಗಾಗಿ `WorkflowBuilder`
- **Foundry Toolkit for VS Code** - ಸ್ಕಾಫೋಲ್ಡ್ ಮಾಡುವುದು, ಸ್ಥಳೀಯವಾಗಿ ಪರೀಕ್ಷಿಸುವುದು, ನಿಯೋಜಿಸುವುದು
- **ಏಐ ಮಾದರಿ** (ಉದಾ. `gpt-4.1-mini`) - ನಾಲ್ಕು ಏಜೆಂಟ್‌ಗಳೆಲ್ಲರೂ ಬಳಸುವದು
- **Microsoft Learn MCP ಸರ್ವರ್** - ಪ್ರತಿ ಕೌಶಲ್ಯ ವ್ಯತ್ಯಾಸಕ್ಕೆ ನಿಜವಾದ ಕಲಿಕೆಯ ಸಂಪನ್ಮೂಲ ಲಿಂಕ್‌ಗಳನ್ನು ಒದಗಿಸುವದು

## ಲ್ಯಾಬ್ 01 ಪರಿಶೀಲನೆ

ಲ್ಯಾಬ್ 02 ನೇರವಾಗಿ ಲ್ಯಾಬ್ 01 ಮೇಲೆ ನಿರ್ಮಿಸಲಾಗುತ್ತದೆ. ಇಲ್ಲಿಗೆ ಶುರುಮಾಡುವ ಮೊದಲು ಲ್ಯಾಬ್ 01 ಮುಗಿಸಿ.

ಇನ್ನೂ ಲ್ಯಾಬ್ 01 ಮಾಡಿಲ್ಲವೇ? ಇಲ್ಲಿ ಪ್ರಾರಂಭಿಸಿ: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ ಮಾರ್ಗ A - ಅಜೂರ್ ಕ್ಲೌಡ್</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

ವಿಫಲವಾದರೆ, `az login` ಅನ್ನು ಚಲಾಯಿಸಿ. ನಂತರ VS Code ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ:

1. `Ctrl+Shift+P` → ಟೈಪ್ ಮಾಡಿ **Foundry Toolkit** → ಕಮಾಂಡ್‌ಗಳು ಪ್ರತ್ಯೇಕವಾಗಿವೆ ಎಂದು ದೃಢೀಕರಿಸಿ.
2. **Foundry Toolkit** ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ → ನಿಮ್ಮ ಯೋಜನೆ ಮತ್ತು ನೀಡಲಾದ ಮಾದರಿ **ಯಶಸ್ವಿಯಾಗಿದೆ** ಎಂದು ತೋರಿಸುತ್ತದೆ.

![Foundry Toolkit ಬದಿಪಡೆಯ ಭಾಗದಲ್ಲಿ MY RESOURCES ವಿಭಾಗ ಮತ್ತು ಯೋಜನಾ ಮಾರಾಟರ್ ಮಾಡಲ್ ತೆರೆದಿದೆ](../../../../../translated_images/kn/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** ನೀವು ಲ್ಯಾಬ್ 01 ನಲ್ಲಿ **Foundry User** ಹಂಚಿದ್ದೀರಿ. ಪುನಃ ಹಂಚಿಕೆಗೆ ಅಗತ್ಯವಿದ್ದರೆ, [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac) ನೋಡಿ. ಈ ಪಾತ್ರದ ಹೆಸರು ಹಳೆಯದಾಗಿ **Azure AI User** ಆಗಿತ್ತು - ಅದೇ ಅನುಮತಿಗಳು.

</details>

<details open>
<summary><strong>🅱️ ಮಾರ್ಗ B - Foundry ಲೋಕಲ್</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

ನಿರೀಕ್ಷಿತ: `StatusCode: 200`. ಇಲ್ಲದಿದ್ದರೆ, Foundry Toolkit ಬದಿಪಡೆಯಿಂದ Foundry Local ಅನ್ನು ಮರುಪ್ರಾರಂಭಿಸಿ.

> ಎಲ್ಲ ಇನ್‌ಫರೆನ್ಸ್ ನಿಮ್ಮ ಯಂತ್ರದಲ್ಲಿ ನಡೆಯುತ್ತದೆ. ಏಕೈಕ ಹೊರಬಂದ ಕರೆ MCP ಉಪಕರಣಕ್ಕೆ `https://learn.microsoft.com/api/mcp` ಗೆ.

</details>
