# ಘಟಕ 1 - ವಾಸ್ತುಶಿಲ್ಪವನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ

⏱️ ~5 ನಿಮಿಷಗಳು

ಯಾವುದಾದರೂ ಕೋಡ್ ಬರೆಯುವುದಕ್ಕೆ ಮುಂಚೆ, ನೀವು ಏನು ನಿರ್ಮಿಸುತ್ತಿದ್ದು ಅದು ಹೇಗೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ ಎಂಬುದರ ತುಳಿತಿಕೆ ಇರುತ್ತದೆ.

---

## ನೀವು ಏನು ನಿರ್ಮಿಸುತ್ತಿದ್ದೀರಿ

ನೀವು **ರಿಜ್ಯೂಮ್** ಮತ್ತು **ಉದ್ಯೋಗ ವಿವರಣೆ** ಅನ್ನು ಪೇಸ್ಟ್ ಮಾಡುತ್ತೀರಿ. ಕಾರ್ಯಪ್ರವಾಹವು ಹೀಗಿದೆ:

- ಒಂದು ಹೊಂದಾಣಿಕೆ ಸ್ಕೋರ್ (0–100 ವಿಶ್ಲೇಷಣೆಯೊಂದಿಗೆ)
- ಕೌಶಲ್ಯ ಮತ್ತು ಪ್ರಮಾಣಪತ್ರ ವ್ಯತ್ಯಾಸಗಳ ಪಟ್ಟಿ
- ಪ್ರತಿಯೊಂದು ವ್ಯತ್ಯಾಸಕ್ಕೂ Microsoft Learn ಲಿಂಕ್‌ಗಳೊಂದಿಗೆ ವೈಯಕ್ತಿಕ ಕಲಿಕೆ ರಸ್ತೆಪಟ್ಟಿ

---

## ನಾಲ್ಕು ಏಜೆಂಟುಗಳು

ಒಂದೇ ಏಜೆಂಟ್ ಸಾರಿ ಎಲ್ಲಾ ವಿವರಣೆಗಳನ್ನು ವಿಶ್ಲೇಷಿಸಿ, ಸ್ಕೋರ್ ಮಾಡಿ, ಯೋಜನೆ ರೂಪಿಸುವ ಪ್ರಯತ್ನ ಮಾಡುವುದು ವೇಗವಾಗಿ ಮತ್ತು ಮೇಲ್ಮೈ ಮಟ್ಟದ ಉತ್ಪಾದನೆಗೆ ಕಾರಣವಾಗುತ್ತದೆ. ಕಾರ್ಯವನ್ನು ನಾಲ್ಕು ವಿಶೇಷ ಏಜೆಂಟ್‌ಗಳಾಗಿ ವಿಭಜಿಸುವುದು ಉತ್ತಮ ಫಲಿತಾಂಶಗಳನ್ನು ನೀಡುತ್ತದೆ:

| ಏಜೆಂಟ್ | ಅದು ಏನು ಮಾಡುತ್ತದೆ |
|-------|-------------|
| **ResumeParser** | ರಿಜ್ಯೂಮೆಯನ್ನು ವಿಶ್ಲೇಷಿಸುತ್ತದೆ; JD'ಯನ್ನು ನಕಲಿಸಿ `[JOB DESCRIPTION PASS-THROUGH]`ಗೆ ಕುರಿತ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಕಳುಹಿಸುತ್ತದೆ |
| **JobDescriptionAgent** | ಪಾಸ್-ತ್ರೂದಿಂದ JD ಅಗತ್ಯಗಳನ್ನು_unsigned; `[PARSED RESUME]` ಅನ್ನು ಮುಂದಕ್ಕೆ `[PARSED RESUME PASS-THROUGH]` ಆಗಿ ಕಳುಹಿಸುತ್ತದೆ |
| **MatchingAgent** | ಇಬ್ಬರೂ ಲೇಬಲ್‌ಗಳಿಸಿದ ವಿಭಾಗಗಳನ್ನು ಹೋಲಿಸುತ್ತದೆ; 0–100 ಹೊಂದಾಣಿಕೆ ಸ್ಕೋರ್ ಮತ್ತು ವ್ಯತ್ಯಾಸ ಪಟ್ಟಿಯನ್ನು ಉಂಟುಮಾಡುತ್ತದೆ |
| **GapAnalyzer** | ಕಲಿಕೆ ರಸ್ತೆಪಟ್ಟಿಯನ್ನು ರೂಪಿಸುತ್ತದೆ; ಪ್ರತಿಯೊಂದು ವ್ಯತ್ಯಾಸಕ್ಕೆ Microsoft Learn ಅನ್ನು ಹುಡುಕುತ್ತದೆ |

---

## ಸಂಚಲನ ಗ್ರಾಫ್

ಕಾರ್ಯಪ್ರವಾಹವು ** ಕ್ರಮಾನುಕ್ರಮ पाइಪ್‌ಲೈನ್** ಆಗಿದ್ದು - ಪ್ರತಿ ಏಜೆಂಟ್ ತನ್ನ ಔಟ್‌ಪುಟ್ ಅನ್ನು ಮುಂದಿನದಿಗೆ ಕಳುಹಿಸುತ್ತದೆ:

```mermaid
flowchart LR
    A["ಬಳಕೆದಾರ ಇನ್ಪುಟ್"] --> B["ರಿಜ್ಯೂಮ್ ಪಾರ್ಸರ್"]
    B -- "ಪಾರ್ಸ್ಡ್ ರಿಜ್ಯೂಮ್ + JD ರಿಲೇ" --> C["ಕೆಲಸದ ವಿವರಣೆ ಏಜೆಂಟ್"]
    C -- "JD ಅಗತ್ಯಗಳು + ರಿಜ್ಯೂಮ್ ರಿಲೇ" --> D["ಮ್ಯಾಚಿಂಗ್ ಏಜೆಂಟ್"]
    D -- "ಹೊಂದಾಣಿಕೆಯ ವರದಿ + ಗ್ಯಾಪ್ಗಳು" --> E["ಗ್ಯಾಪ್ ವಿಶ್ಲೇಷಕ + MCP"]
    E --> F["ಕೊನೆಯ ಔಟ್ಪುಟ್"]

    style A fill:#4A90D9,color:#fff
    style B fill:#7B68EE,color:#fff
    style C fill:#7B68EE,color:#fff
    style D fill:#E67E22,color:#fff
    style E fill:#27AE60,color:#fff
    style F fill:#4A90D9,color:#fff
```

1. **ResumeParser** ಬಳಕೆದಾರ ಸಹಾಯವನ್ನು ಸ್ವೀಕರಿಸಿ ರಿಜ್ಯೂಮೆಯನ್ನು ವಿಶ್ಲೇಷಿಸಿ, JD'ಯನ್ನು `[JOB DESCRIPTION PASS-THROUGH]` ಗೆ ನಕಲಿಸುತ್ತದೆ.
2. **JD ಏಜೆಂಟ್** ರಚನಾತ್ಮಕ ಅಗತ್ಯಗಳನ್ನು ಹೊರತೆಗೆದು `[PARSED RESUME PASS-THROUGH]` ಅನ್ನು ಮುಂದಕ್ಕೆ ಕಳುಹಿಸುತ್ತದೆ.
3. **MatchingAgent** ಎರಡೂ ವಿಭಾಗಗಳನ್ನು ಹೋಲಿಸಿ ಹೊಂದಾಣಿಕೆ ಸ್ಕೋರ್ ಮತ್ತು ವ್ಯತ್ಯಾಸ ಪಟ್ಟಿಯನ್ನು ಉಂಟುಮಾಡುತ್ತದೆ.
4. **GapAnalyzer** ರಸ್ತೆಪಟ್ಟಿಯನ್ನು ರೂಪಿಸಿ ಪ್ರತಿಯೊಂದು ವ್ಯತ್ಯಾಸಕ್ಕೆ Microsoft Learn MCP ಉಪಕರಣವನ್ನು ಕರೆಸುತ್ತದೆ.

## ಇದು ಕೋಡ್‌ಗೆ ಹೇಗೆ ಹೊಂದಿಕೊಳ್ಳುತ್ತದೆ

`main.py` ನಲ್ಲಿ, ನೀವು ಈ ಗ್ರಾಫ್ ಅನ್ನು `WorkflowBuilder` ಉಪಯೋಗಿಸಿ ವರ್ಣಿಸುತ್ತೀರಿ:

```python
workflow_agent = (
    WorkflowBuilder(
        start_executor=resume_executor,       # ಬಳಕೆದಾರರ ಇನ್‌ಪುಟ್ ಅನ್ನು ಪಡೆಯುವ ಮೊದಲ ಏಜೆಂಟ್
        output_executors=[gap_executor],      # ಕೊನೆಯ ಏಜೆಂಟ್ - ಅದರ ಔಟ್‌ಪುಟ್ ಪ್ರತ್ಯುತ್ತರವಾಗಿದೆ
    )
    .add_edge(resume_executor, jd_executor)       # ರೆಸ್ಯೂಮ್ ಪಾರ್ಸರ್ → JD ಏಜೆಂಟ್
    .add_edge(jd_executor, matching_executor)     # JD ಏಜೆಂಟ್ → ಮ್ಯಾಚಿಂಗ್ ಏಜೆಂಟ್
    .add_edge(matching_executor, gap_executor)    # ಮ್ಯಾಚಿಂಗ್ ಏಜೆಂಟ್ → ಗ್ಯಾಪ್ ಅನಾಲೈಸರ್
    .build()
    .as_agent()
)
```

ಪ್ರತಿ `Agent` ಅನ್ನು `AgentExecutor` ನಲ್ಲಿ ಅಂಶಿಸಲಾಗಿದೆ. `add_edge()` ಕಳುಹಿಸುವಿಕೆ ಕ್ರಮಾನುಕ್ರಮ पाइಪ್‌ಲೈನ್ ಅನ್ನು ನಿರ್ದಿಷ್ಟಪಡಿಸುತ್ತದೆ - ಪ್ರತಿ ಏಜೆಂಟ್ ತನ್ನ ತಾತ્કಾಲಿಕ ಪೂರ್ವಸ್ಥಿತಿಯ ಔಟ್‌ಪುಟ್ ಮಾತ್ರ ಪಡೆಯುತ್ತದೆ.

> `context_mode="last_agent"` ಅರ್ಥವೇ ಪ್ರತಿ ಕಾರ್ಯಚಾಲಕ ತನ್ನ ತಾತ್ಕಾಲಿಕ ಪೂರ್ವಸ್ಥಿತಿಯ ಔಟ್‌ಪುಟ್ ಮಾತ್ರ ನೋಡಬಹುದು. ResumeParser ಮತ್ತು JD ಏಜೆಂಟ್ ಲೇಬಲ್ ಮಾಡಲಾದ ವಿಭಾಗಗಳಲ್ಲಿ ಡೇಟಾವನ್ನು ಮುಂದಕ್ಕೆ ಕಳುಹಿಸುವ ಮೂಲಕ ಪ್ರತಿಯೊಬ್ಬ ಡೌನ್‌ಸ್ಟ್ರೀಮ್ ಏಜೆಂಟ್‌ಗೆ ಅವಶ್ಯವಿರುವುದನ್ನು ಮಾತ್ರ ನೀಡುತ್ತದೆ.

## MCP ಸಾಧನ

GapAnalyzer ಗೆ ಒಂದೇ ಸಾಧನ ಇದೆ: `search_microsoft_learn_for_plan`. ಇದು `https://learn.microsoft.com/api/mcp` ಗೆ ಸಂಪರ್ಕಿಸಿ ಪ್ರತಿಯೊಂದು ಕೌಶಲ್ಯ ವ್ಯತ್ಯಾಸಕ್ಕೂ ನೈಜ Microsoft Learn ಲಿಂಕ್‌ಗಳನ್ನು ನೀಡುತ್ತದೆ.

ಈ ಸಾಧನ ಕಾರ್ಯನಿರ್ವಹಿಸುವಾಗ ನೀವು ಈ ಲಾಗ್‌ಗಳನ್ನು ಕಾಣುತ್ತೀರಿ - ಇವು ಎಲ್ಲಾ ನಿರೀಕ್ಷಿತವು:

```
GET  https://learn.microsoft.com/api/mcp → 405   ← connection probe, normal
POST https://learn.microsoft.com/api/mcp → 200   ← actual tool call
DELETE https://learn.microsoft.com/api/mcp → 405 ← cleanup probe, normal
```

`POST` ನಲ್ಲಿ ದೋಷ ಬರುವುದನ್ನು ಮಾತ್ರ ಗಮನಿಸಿ.
