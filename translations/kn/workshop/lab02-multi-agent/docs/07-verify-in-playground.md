# ಅಧ್ಯಾಯ 7 - ಪ್ಲೆಕಾರ್ಡ್‌ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ

⏱️ ~10 ನಿಮಿಷಗಳು

ಈ ಅಧ್ಯಾಯದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ನಿಯೋಜಿತ ಬಹು-ಏಜೆಂಟ್ ಕಾರ್ಯವಾಹಿಕೆಯನ್ನು VS ಕೋಡ್ ಮತ್ತು ಫೌಂಡ್ರೀ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಪರೀಕ್ಷಿಸುತ್ತೀರಿ, ಏಜೆಂಟ್ ಸ್ಥಳೀಯ ಪರೀಕ್ಷೆಯಂತಹ ವರ್ತನೆ ಬಾಗುತ್ತದೆ ಎಂದು ದೃಢೀಕರಿಸುತ್ತೀರಿ.

---

## ನಿಯೋಜನೆಯ ನಂತರ ஏಕೆ ಮರುಪರೀಕ್ಷೆ ಮಾಡಬೇಕು?

ಹೋಸ್ಟ್ ಮಾಡಿದ ಪರಿಸರವು ಸ್ಥಳೀಯದೊಂದಿಗೆ ಕೆಲವು ಪ್ರಮುಖ ರೀತಿಗಳಲ್ಲಿ ಭಿನ್ನವಾಗಿರುತ್ತದೆ:

| | ಸ್ಥಳೀಯ | ಹೋಸ್ಟ್ ಮಾಡಿದ |
|--|-------|--------|
| **ಗುರುತುಹೊರಡು** | ನಿಮ್ಮ ವೈಯಕ್ತಿಕ ಸೈನ್ ಇನ್ (`DefaultAzureCredential`) | ನಿಯೋಜನೆಯ ಸಮಯದಲ್ಲಿ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಒದಗಿಸಲಾದ ಪ್ರತಿ ಏಜೆಂಟ್‌ಗೆ ಅಚೇತ ಒಕ್ಕಣೆ |
| **എന്‍‍ഡ്പോയಿಂಟ್‌** | `http://localhost:8088/responses` | ಫೌಂಡ್ರೀ ಏಜೆಂಟ್ ಸೇವೆ ನಿರ್ವಹಿಸಿರುವ URL |
| **ನೆಟ್‌ವರ್ಕ್** | ನಿಮ್ಮ ಯಂತ್ರ → ಅಜೂರ್ ಓಪನ್‌ಎಐ + ಎಂಸಿಪಿ | ಅಜೂರ್ ಹಡಗು (ಕಡಿಮೆಯ_latency) |

ತಪ್ಪಾಗಿ ಗೊಂದಲ ಹೊಂದಿದ ಪರಿಸರ ಸ್ಥಿತಿಚಿಹ್ನೆ, RBAC ಸಮಸ್ಯೆ ಅಥವಾ ತಡೆಹಿಡಿದ ಎಂಸಿಪಿ ಹೊರಗಿನ ಕರೆ ಇಲ್ಲಿ ಮೊದಲಿಗೆ ಕಂಡುಬರಬಹುದು.

---

## ಆಯ್ಕೆಯು ಎ: VS ಕೋಡ್ ಪ್ಲೇಗ್ರೌಂಡ್‌ನಲ್ಲಿ ಪರೀಕ್ಷಿಸಿ (ಮುನ್ಸೂಚನೆ)

### ಹಂತ 1: ನಿಮ್ಮ ಹೋಸ್ಟ್ ಮಾಡಿದ ಏಜೆಂಟ್‌ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ

1. ಕ್ರಿಯೆ ಬಾರ್ನಲ್ಲಿ **Foundry Toolkit** ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ.
2. ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ವಿಸ್ತರಿಸಿ → **Hosted Agents (Preview)** → ನಿಮ್ಮ ಏಜೆಂಟ್ ಅನ್ನು ಕಂಡುಹಿಡಿಯಿರಿ.

![Foundry Toolkit sidebar showing Hosted Agents (Preview) with resume-job-fit-evaluator and its deployed versions](../../../../../translated_images/kn/06-foundry-sidebar-agent-status.a45994bfb5c21284.webp)

### ಹಂತ 2: ಒಂದು ಆವೃತ್ತಿಯನ್ನು ಆಯ್ಕೆಮಾಡಿ

1. ಏಜೆಂಟ್ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ ಅದರ ಆವೃತ್ತಿಗಳನ್ನು ವಿಸ್ತರಿಸಲು.
2. `v1` ಕ್ಲಿಕ್ ಮಾಡಿ → ಸ್ಥಿತಿ **ಕ್ರಿಯಾಶೀಲ** ಎಂದು ಪರಿಶೀಲಿಸಿ (ಸೈಡ್‌ಬಾರ್ "ಚಲಿಸಲಾಗುತ್ತಿದೆ" ಅಥವಾ "ಪ್ರಾರಂಭಗೊಂಡಿದೆ" ಎಂದು ತೋರಿಸಬಹುದು - ಎರಡೂ ಒಂದೇ ಸಿದ್ಧಸ್ಥಿತಿಯನ್ನು ಸೂಚಿಸುತ್ತದೆ).

### ಹಂತ 3: ಪ್ಲೇಗ್ರೌಂಡ್ ತೆರೆಯಿರಿ

1. **Playground** ಕ್ಲಿಕ್ ಮಾಡಿ (ಅಥವಾ ಆವೃತ್ತಿಯ ಮೇಲೆ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ → **Open in Playground**).
2. VS ಕೋಡ್ ಟ್ಯಾಬ್ನಲ್ಲಿ ಚಾಟ್ ವಿಂಡೋ ತೆರೆಯುತ್ತದೆ.

### ಹಂತ 4: ನಿಮ್ಮ ಸ್ಮೋಕ್ ಪರೀಕ್ಷೆಗಳನ್ನು ನಡೆಸಿ

[Module 5](05-test-locally.md) ನಿಂದ ಅದೇ 3 ಪರೀಕ್ಷೆಗಳನ್ನು ಬಳಸಿ. ಪ್ರತಿ ಸಂದೇಶವನ್ನು ಪ್ಲೇಗ್ರೌಂಡ್ ಇನ್‌ಪುಟ್ ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಟೈಪ್ ಮಾಡಿ ಮತ್ತು **Send** (ಅಥವಾ **Enter**) ಒತ್ತಿ.

#### ಪರೀಕ್ಷೆ 1 - ಪೂರ್ಣ ರೆಸ್ಯೂಮ್ + JD (ಸ್ಟ್ಯಾಂಡರ್ಡ್ ಫ್ಲೋ)

Module 5, ಟೆಸ್ಟ್ 1 (ಜೆನ್ ಡೋ + ಕಂಟೋಸೊ ಲಿಮಿಟೆಡ್‌ನಲ್ಲಿ ಹಿರಿಯ ಕ್ಲೌಡ್ ಎಂಜಿನಿಯರ್) ನಿಂದ ಪೂರ್ಣ ರೆಸ್ಯೂಮ್ + JD ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಪೇಸ್ಟ್ ಮಾಡಿ.

**ನಿರೀಕ್ಷಿತ:**
- ಫಿಟ್ ಅಂಕೆ ಇವುಗಳ ಪದವಿ ಸಹಿತ (100-ಪಾಯಿಂಟ್ ಮೌಲ್ಯಮಾನ)
- ಹೊಂದಿರುವ ಕೌಶಲ್ಯಗಳ ವಿಭಾಗ
- ಇಲ್ಲದ ಕೌಶಲ್ಯಗಳ ವಿಭಾಗ
- **ಪ್ರತಿ ಇಲ್ಲದ ಕೌಶಲ್ಯಕ್ಕೆ ಒಂದು ಗ್ಯಾಪ್ ಕಾರ್ಡ್** ಮೈಕ್ರೋಸಾಫ್ಟ್ ಲೆರ್ನ್ URLಗಳೊಂದಿಗೆ
- ಟೈಮ್‌ಲೈನ್‌ ಸಹಿತ ಅಧ್ಯಯನ ಮಾರ್ಗಸೂಚಿ

#### ಪರೀಕ್ಷೆ 2 - ಕ್ವಿಕ್ ಶಾರ್ಟ್ ಟೆಸ್ಟ್ (ಕನಿಷ್ಠ ಇನ್‌ಪುಟ್)

```
RESUME: 3 years Python developer, knows Django and PostgreSQL, no cloud experience.

JOB: Cloud DevOps Engineer requiring AWS, Kubernetes, Terraform, CI/CD. 5 years needed.
```

**ನಿರೀಕ್ಷಿತ:**
- ಕಡಿಮೆ ಫಿಟ್ ಅಂಕೆ (< 40)
- ಸಮರ್ಥನೀಯ ಮೌಲ್ಯಮಾಪನ ಮತ್ತು ಹಂತಬದ್ಧ ಅಧ್ಯಯನ ಮಾರ್ಗ
- ಅನೇಕ ಗ್ಯಾಪ್ ಕಾರ್ಡುಗಳು (AWS, ಕುಬರ್ನೇಟೀಸ್, ಟೆರೆಫಾರ್ಮ್, CI/CD, ಅನುಭವದ ಗ್ಯಾಪ್)

#### ಪರೀಕ್ಷೆ 3 - ಉನ್ನತ ಫಿಟ್ ಅಭ್ಯರ್ಥಿ

```
RESUME:
10 years Azure Cloud Architect. AZ-305 certified. Expert in AKS, Terraform, Azure DevOps, 
Azure Functions, Helm, Prometheus, Grafana, Python, Go. Led platform team of 8.

JOB:
Senior Cloud Engineer. Required: AKS, Terraform, Azure DevOps, Python. Preferred: Helm, Go.
5+ years experience. AZ-305 preferred.
```

**ನಿರೀಕ್ಷಿತ:**
- ಉನ್ನತ ಫಿಟ್ ಅಂಕೆ (≥ 80)
- ಸಂದರ್ಶನ ಸಿದ್ಧತೆಗೆ ಮತ್ತು ಸುಂದರಗೊಳಿಸುವಿಕೆಗೆ ಕೇಂದ್ರೀಕರಿಸಿ
- ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳು ಕಡಿಮೆ ಅಥವಾ ಇಲ್ಲ
- ಸಣ್ಣ ಸಮಯರೇಖೆ ಸಿದ್ಧತೆಗೆ ಕೇಂದ್ರೀಕೃತವಾಗಿದ್ದು

### ಹಂತ 5: ಸ್ಥಳೀಯ ಫಲಿತಾಂಶಗಳೊಂದಿಗೆ ಹೋಲಿಸಿ

ಸ್ಥಳೀಯ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಉಳಿಸಿಕೊಂಡಿರುವ Module 5 ನಿಂದ ನಿಮ್ಮ ನೋಟ್ಸ್ ಅಥವಾ ಬ್ರೌಸರ್ ಟ್ಯಾಬ್ ತೆರೆಯಿರಿ. ಪ್ರತಿ ಪರೀಕ್ಷೆಗೆ:

- ಪ್ರತಿಕ್ರಿಯೆಗೆ **ಒಂದೇ ರಚನೆ** ಇದೆಯಾ? (ಫಿಟ್ ಅಂಕೆ, ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳು, ಮಾರ್ಗಸೂಚಿ)?
- **ಒಂದೇ ಅಂಕೆ ಮೌಲ್ಯಮಾಪನ ನಿಯಮ** ಅನುಸರಿಸಲಾಗಿದೆಯೇ? (100-ಪಾಯಿಂಟ್ ವಿಧವಿಧಾನ)?
- ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳಲ್ಲಿ **ಮೈಕ್ರೋಸಾಫ್ಟ್ ಲರ್ನ್ URLಗಳು** ಇನ್ನೂ ಇದ್ದಾವೆಯೇ?
- **ಪ್ರತಿ ಇಲ್ಲದ ಕೌಶಲ್ಯಕ್ಕೂ ಒಂದೇ ಗ್ಯಾಪ್ ಕಾರ್ಡ್** ಇರುತ್ತದೆಯೇ (ಕಡಿದಿಲ್ಲ)?

> **ಸ್ವಲ್ಪ ಶಬ್ದಬದಲಾಗುವಿಕೆ ಸಹಜವಷ್ಟೇ** - ಮಾದರಿ ನಿರ್ದಿಷ್ಟವಲ್ಲ. ರಚನೆ, ಅಂಕೆ ಸಂಯೋಜನೆ ಮತ್ತು MCP ಉಪಕರಣ ಬಳಕೆ ಮೇಲೆ ಗಮನ ಹಿಡಿಯಿರಿ.

## ಆಯ್ಕೆಯು ಬಿ: ಫೌಂಡ್ರೀ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಪರೀಕ್ಷಿಸಿ

[Foundry Portal](https://ai.azure.com) ತಂಡದ ಸದಸ್ಯರು ಅಥವಾ ಹಿತಾಧಿಕಾರಿಗಳಿಗೆ ಹಂಚಿಕೊಳ್ಳಲು ಉಪಯುಕ್ತವೆಂಬ ವೆಬ್ ಆಧಾರಿತ ಪ್ಲೇಗ್ರೌಂಡ್ ಅನ್ನು ಒದಗಿಸುತ್ತದೆ.

### ಹಂತ 1: ಫೌಂಡ್ರೀ ಪೋರ್ಟಲ್ ತೆರೆಯಿರಿ

1. ನಿಮ್ಮ ಬ್ರೌಸರ್ ತೆಗೆಯಿರಿ ಮತ್ತು [https://ai.azure.com](https://ai.azure.com) ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ.
2. ಕೆಲಸಾಗೆ ಬಳಸಿದ ಅದೇ ಅಜೂರ್ ಖಾತೆಯಿಂದ ಸೈನ್ ಇನ್ ಆಗಿ.

### ಹಂತ 2: ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ

1. ಮನೆ ಪುಟದಲ್ಲಿ, ಎಡ ಸೈಡ್‌ಬಾರ್ ಮೇಲೆ **ಇತ್ತೀಚಿನ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು** ಹುಡುಕಿ.
2. ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಹೆಸರನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ (ಉದಾಹರಣೆ: `workshop-agents`).
3. ಕಾಣದಿದ್ದರೆ, **ಎಲ್ಲಾ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು** ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಹುಡುಕಿ.

### ಹಂತ 3: ನಿಯೋಜಿತ ಏಜೆಂಟ್ ಕಾಣಿಸಿ

1. ಪ್ರಾಜೆಕ್ಟ್ ಎಡ ನ್ಯಾವಿಗೇಷನ್‌ನಲ್ಲಿ **Build** → **Agents** ಕ್ಲಿಕ್ ಮಾಡಿ (ಅಥವಾ **Agents** ವಿಭಾಗವನ್ನು ನೋಡಿ).
2. ಏಜೆಂಟ್‌ಗಳ ಪಟ್ಟಿ ತೋರಿಸುತ್ತದೆ. ನಿಮ್ಮ ನಿಯೋಜಿತ ಏಜೆಂಟ್ (ಉದಾಹರಣೆ: `resume-job-fit-evaluator`) ಕಂಡುಹಿಡಿಯಿರಿ.
3. ಏಜೆಂಟ್ ಹೆಸರನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ ಅದರ ವಿವರ ಪುಟ ತೆರೆಯಿರಿ.

### ಹಂತ 4: ಪ್ಲೇಗ್ರೌಂಡ್ ತೆರೆಯಿರಿ

1. ಏಜೆಂಟ್ ವಿವರ ಪುಟದ ಮೇಲೆ, ಮೇಲಿನ ಟೂಲ್‌ಬಾರ್ ನೋಡಿ.
2. **Open in playground** (ಅಥವಾ **Try in playground**) ಕ್ಲಿಕ್ ಮಾಡಿ.
3. ಚಾಟ್ ಇಂಟರ್‌ಫೇಸ್ ತೆರೆಯುತ್ತದೆ.

### ಹಂತ 5: ಅದೇ ಸ್ಮೋಕ್ ಪರೀಕ್ಷೆಗಳನ್ನು ಮಾಡಿ

ಮೇಲಿನ VS ಕೋಡ್ ಪ್ಲೇಗ್ರೌಂಡ್ ವಿಭಾಗದಿಂದ ಎಲ್ಲಾ 3 ಪರೀಕ್ಷೆಗಳನ್ನು ಪುನರಾವರ್ತಿಸಿ. ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಸ್ಥಳೀಯ ಫಲಿತಾಂಶಗಳ (Module 5) ಮತ್ತು VS ಕೋಡ್ ಪ್ಲೇಗ್ರೌಂಡ್ ಫಲಿತಾಂಶಗಳ (ಮೇಲಿನ ಆಯ್ಕೆ ಎ) ಜೊತೆಗೆ ಹೋಲಿಸಿ.

|-------|---------------|----------------|

|-------|---------------|----------------|
| ಎಲ್ಲಾ 4 ಏಜೆಂಟ್‌ಗಳು ಚಲಿಸಲಾಗಿದೆ | ಔಟ್‌ಪುಟ್‌ನಲ್ಲಿ ಫಿಟ್ ಅಂಕೆ ಮತ್ತು ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳಿವೆ | ಅಂಕೆ MatchingAgent ನಿಂದ, ಕಾರ್ಡ್‌ಗಳು GapAnalyzer ನಿಂದ |
| ಕ್ರಮಬದ್ಧ ಕಾರ್ಯಾಚರಣೆ | ಪ್ರತಿಕ್ರಿಯೆ ಸಮಯ ಯುಕ್ತವಾಗಿದೆ (< 2 ನಿಮಿಷ) | 3 ನಿಮಿಷಕ್ಕಿಂತ ಹೆಚ್ಚು ಆದರೆ, ಟರ್ಮಿನಲ್ ಲಾಗ್‌ನಲ್ಲಿ ದೋಷಗಳನ್ನು ಪರಿಶೀಲಿಸಿ |
| ಡೇಟಾ ಹರಿವಿನ ಬೆರಗು | ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳು ಹೊಂದಾಣಿಕೆಯ ವರದಿ ಕೌಶಲ್ಯಗಳನ್ನು ಉಲ್ಲೇಖಿಸುತ್ತವೆ | ಜೇಡಿಯಲ್ಲಿ ಇಲ್ಲದ ತಮಾಷಾತ್ಮಕ ಕೌಶಲ್ಯಗಳಿಲ್ಲ |

## ಮಾನ್ಯತೆ ಮೌಲ್ಯಮಾಪನ

ನಿಮ್ಮ ಬಹು-ಏಜೆಂಟ್ ಕಾರ್ಯವಾಹಿಕೆಯ ಹೋಸ್ಟ್ ಮಾಡಿದ ವರ್ತನೆಯನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡಲು ಈ ಮೌಲ್ಯಮಾಪನ ಸಾಧನವನ್ನು ಬಳಸಿ:

| # | ಮಾನದಂಡ | ಉತ್ತೀರ್ಣ ಅಳತೆ | ಉತ್ತೀರ್ಣ? |
|---|----------|---------------|-------|
| 1 | **ಕಾರ್ಯಕ್ಷಮ ಸರಿಯಾದತೆ** | ಏಜೆಂಟ್ ರೆಸ್ಯೂಮ್ + JD ಗೆ ಫಿಟ್ ಅಂಕೆ ಮತ್ತು ಗ್ಯಾಪ್ ವಿಶ್ಲೇಷಣೆಯೊಂದಿಗೆ ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತದೆ | |
| 2 | **ಅಂಕೆ ಸಂಯೋಜನೆ** | ಫಿಟ್ ಅಂಕೆ 100-ಪಾಯಿಂಟ್ ಕಲ್ಲುಮಾನದೊಂದಿಗೆ ಉಪಯೋಗಿಸುತ್ತದೆ | |
| 3 | **ಗ್ಯಾಪ್ ಕಾರ್ಡ್ ಪೂರ್ಣತೆ** | ಪ್ರತಿ ಇಲ್ಲದ ಕೌಶಲ್ಯಕ್ಕೆ ಒಂದು ಕಾರ್ಡ್ (ಕಡಿತ ಅಥವಾ ಸಂಯೋಜನೆ ಇಲ್ಲ) | |
| 4 | **MCP ಉಪಕರಣ ಏಕೀಕರಣ** | ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳಲ್ಲಿ ನಿಜವಾದ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಲರ್ನ್ URLಗಳು ಇವೆ | |
| 5 | **ರಚನಾತ್ಮಕ ಅಖಂಡತೆ** | ಸ್ಥಳೀಯ ಮತ್ತು ಹೋಸ್‌ಟ್ಡ್ ಚಾಲನೆಗಳ ನಡುವೆ ಔಟ್‌ಪುಟ್ ರಚನೆ ಹೊಂದಿದೆ | |
| 6 | **ಪ್ರತಿಕ್ರಿಯೆ ಸಮಯ** | ಪೂರ್ಣ ಅಂದಾಜುಗಾಗಿ ಹೋಸ್ಟ್ ಮಾಡಿದ ಏಜೆಂಟ್ 2 ನಿಮಿಷಗಳಲ್ಲಿ ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತದೆ | |
| 7 | **ಯಾವುದೂ ದೋಷಗಳಿಲ್ಲ** | HTTP 500 ದೋಷಗಳು, ಟೈಮ್‌ಔಟ್‌ಗಳು ಅಥವಾ ಖಾಲಿ ಪ್ರತಿಕ್ರಿಯೆಗಳಿಲ್ಲ | |

> "ಉತ್ತೀರ್ಣ" ಎಂದರೆ ಕನಿಷ್ಠ ಒಂದೂ ಮೊದಲಿನ ಪ್ಲೇಗ್ರೌಂಡ್ (VS ಕೋಡ್ ಅಥವಾ ಪೋರ್ಟಲ್) ನಲ್ಲಿ ಎಲ್ಲಾ 3 ಸ್ಮೋಕ್ ಪರೀಕ್ಷೆಗಳಿಗಾಗಿ ಎಲ್ಲ 7 ಮಾನದಂಡಗಳು ಪೂರೈಸಲ್ಪಟ್ಟಾಗ.

## ಪ್ಲೇಗ್ರೌಂಡ್ ಸಮಸ್ಯೆ ಪರಿಹಾರ

| ಲಕ್ಷಣ | ಸಾಧ್ಯ ಕಾರಣ | ಪರಿಹಾರ |
|---------|-------------|-----|
| ಪ್ಲೇಗ್ರೌಂಡ್ ಲೋಡ್ ಆಗುವುದಿಲ್ಲ | ಕಾಂಟೈನರ್ `active` ಸ್ಥಿತಿಯಲ್ಲಿ ಇಲ್ಲ | [Module 6](06-deploy-to-foundry.md) ಗೆ ಹಿಂದಿರುಗಿ, ನಿಯೋಜನೆ ಸ್ಥಿತಿಯನ್ನು ಪರಿಶೀಲಿಸಿ. `creating` ಇದ್ದರೆ ಕಾಯಿರಿ |
| ಏಜೆಂಟ್ ಖಾಲಿ ಪ್ರತಿಕ್ರಿಯೆ ನೀಡುತ್ತಾನೆ | ಮಾದರಿ ನಿಯೋಜನೆಯ ಹೆಸರು ಹೊಂದಿಕೆಯಾಗಿಲ್ಲ | `agent.yaml` → `environment_variables` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` ನಿಮ್ಮ ನಿಯೋಜಿತ ಮಾದರಿಯ ಜೊತೆ ಹೊಂದಿಕೆಯಾಗುತ್ತದೆ ಎಂದು ಪರಿಶೀಲಿಸಿ |
| ಏಜೆಂಟ್ ದೋಷ ಸಂದೇಶ ನೀಡುತ್ತದೆ | [RBAC](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry) ಅನುಮತಿ ಇಲ್ಲ | ಪ್ರಾಜೆಕ್ಟ್ ವ್ಯಾಪ್ತಿಯಲ್ಲಿ **[Foundry User](https://aka.ms/foundry-ext-project-role)** (ಹಿಂದೆ Azure AI User) ಅನ್ನು ನಿಯೋಜಿಸಿ |
| ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ನಲ್ಲಿ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಲರ್ನ್ URLಗಳಿಲ್ಲ | MCP ಹೊರಗಿನ ಸಂಪರ್ಕ ತಡೆ ಹೊಂದಿದೆ ಅಥವಾ MCP ಸರ್ವರ್ ಲಭ್ಯವಿಲ್ಲ | ಕಾಂಟೈನರ್ `learn.microsoft.com` ಗೆ ಸಂಪರ್ಕ ಇರಬಹುದೇ ನೋಡಿರಿ. [Module 8](08-troubleshooting.md) ನೋಡಿ |
| ಒಂದೇ ಒಂದು ಗ್ಯಾಪ್ ಕಾರ್ಡ್ (ಕಡಿತವಾದದ್ದಾಗಿ) | GapAnalyzer ಸೂಚನೆಗಳಲ್ಲಿ "CRITICAL" ಬ್ಲಾಕ್ ಇಲ್ಲ | [Module 3, ಹಂತ 2.4](03-configure-agents.md) ಪರಿಶೀಲಿಸಿ |
| ಸ್ಥಳೀಯದೊಂದಿಗೆ ಫಿಟ್ ಅಂಕೆ ಬಹಳ ಭಿನ್ನವಾಗಿದೆ | ವಿಭಿನ್ನ ಮಾದರಿ ಅಥವಾ ಸೂಚನೆಗಳು ನಿಯೋಜಿಸಲಾಗಿದೆ | `agent.yaml` ಪರಿಸರ ಚರಗಳನ್ನು ಸ್ಥಳೀಯ `.env` ಜೊತೆ ಹೋಲಿಸಿ. ಅಗತ್ಯವಿದ್ದರೆ ಮರುನಿಯೋಜಿಸಿ |
| ಪೋರ್ಟಲ್‌ನಲ್ಲಿ "ಏಜೆಂಟ್ ಕಂಡುಬಂದಿಲ್ಲ" | ನಿಯೋಜನೆ ಇನ್ನೂ ಹರಡುತ್ತಿರುವುದು ಅಥವಾ ವಿಫಲವಾಗಿದೆ | 2 ನಿಮಿಷ ಕಾಯಿರಿ, ಪುನರಾಯ್ಕೆ ಮಾಡಿ. ಇನ್ನೂ ಇಲ್ಲದಿದ್ದರೆ [Module 6](06-deploy-to-foundry.md) ನಿಂದ ಮರುನಿಯೋಜನೆ ಮಾಡಿ |

### ಚೆಕ್‌ಪಾಯಿಂಟ್

- [ ] VS ಕೋಡ್ ಪ್ಲೇಗ್ರೌಂಡ್‌ನಲ್ಲಿ ಏಜೆಂಟ್ ಪರೀಕ್ಷಿಸಲಾಗಿದೆ - ಎಲ್ಲಾ 3 ಸ್ಮೋಕ್ ಪರೀಕ್ಷೆಗಳು ಹಾರಿದವು

- [ ] ಪ್ರತಿಕ್ರಿಯೆಗಳು ಸ್ಥಳೀಯ ಪರೀಕ್ಷೆಯೊಂದಿಗೆ ರಚನಾತ್ಮಕವಾಗಿ ಹೊಂದಿವೆ (ಫಿಟ್ ಅಂಕೆ, ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳು, ಮಾರ್ಗಸೂಚಿ)
- [ ] ಗ್ಯಾಪ್ ಕಾರ್ಡ್‌ಗಳಲ್ಲಿ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಲರ್ನ್ URLಗಳು ಕಂಡುಬರುತ್ತವೆ (ಹೋಸ್ಟ್ ಮಾಡಿದ ಪರಿಸರದಲ್ಲಿ MCP ಉಪಕರಣ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆ)
- [ ] ಪ್ರತಿ ಇಲ್ಲದ ಕೌಶಲ್ಯಕ್ಕೂ ಒಂದೇ ಗ್ಯಾಪ್ ಕಾರ್ಡ್ (ಕಡಿತವಿಲ್ಲ)
- [ ] ಪರೀಕ್ಷೆಯ ಸಮಯದಲ್ಲಿ ಯಾವುದೇ ದೋಷಗಳು ಅಥವಾ ಸಮಯಚ್ಯುತಿಗಳು ಇಲ್ಲ
- [ ] ಮಾನ್ಯತೆ ಮೌಲ್ಯಮಾಪನ ಪೂರ್ಣಗೊಂಡಿದೆ (ಎಲ್ಲಾ 7 ಮಾನದಂಡಗಳು ಉತ್ತೀರ್ಣ)
