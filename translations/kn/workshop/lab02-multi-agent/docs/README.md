# ಲ್ಯಾಬ್ 02 - ಬಹು-ಏಜೆಂಟ್ ವರ್ಕ್ಫ್ಲೋ: ರೆಸ್ಯೂಮ್ → ಉದ್ಯೋಗ ಹೊಂದಾಣಿಕೆ ಮೌಲ್ಯಮಾಪಕ

## ಸಂಪೂರ್ಣ ಕಲಿಕೆ ಮಾರ್ಗ

ಈ ದಾಖಲೆ ನಿಮಗೆ ನಾಲ್ಕು ವಿಶಿಷ್ಟ ಏಜೆಂಟ್‌ಗಳನ್ನು **WorkflowBuilder** ಮೂಲಕ ಸಂಯೋಜಿಸಿ ರೆಸ್ಯೂಮ್-ಉದ್ಯೋಗ ಹೊಂದಾಣಿಕೆಯನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡುವ **ಬಹು-ಏಜೆಂಟ್ workflows** ರಚಿಸುವುದು, ಪರೀಕ್ಷಿಸುವುದು ಮತ್ತು ನಿಯೋಜಿಸುವುದರ ಮೂಲಕ ಹಾದಿ ತೋರಿಸುತ್ತದೆ.

> **ಪೂರ್ವಾಪೇಕ್ಷಿತ:** ಲ್ಯಾಬ್ 02 ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು [ಲ್ಯಾಬ್ 01 - ಏಕ ಏಜೆಂಟ್](../../lab01-single-agent/README.md) ಅನ್ನು ಪೂರ್ಣಗೊಳಿಸಿ.
