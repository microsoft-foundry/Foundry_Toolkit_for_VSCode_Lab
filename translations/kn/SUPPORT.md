# ಬೆಂಬಲ

## ಸಮಸ್ಯೆಗಳು ಸಲ್ಲಿಸುವುದು ಮತ್ತು ಸಹಾಯ ಪಡೆಯುವುದು ಹೇಗೆ  

ಈ ಪ್ರಾಜೆಕ್ಟ್ ದೋಷಗಳು ಮತ್ತು ವೈಶಿಷ್ಟ್ಯ ವಿನಂತಿಗಳನ್ನು ಅನುಸರಿಸಲು GitHub Issues ಅನ್ನು ಬಳಸುತ್ತದೆ. ದ್ವಂದ್ವ ತಪ್ಪಿಸಲು ಹೊಸ ಸಮಸ್ಯೆ ಸಲ್ಲಿಸುವ ಮೊದಲು ಇತ್ತೀಚಿನ 
ಸಮಸ್ಯೆಗಳನ್ನು ಹುಡುಕಿ. ಹೊಸ ಸಮಸ್ಯೆಗಳಿಗಾಗಿ ನಿಮ್ಮ ದೋಷ ಅಥವಾ 
ವೈಶಿಷ್ಟ್ಯ ವಿನಂತಿಯನ್ನು ಹೊಸ Issue ಆಗಿ ಸಲ್ಲಿಸಿ.

ಈ ಪ್ರಾಜೆಕ್ಟ್ ಬಳಸುವುದರ ಬಗ್ಗೆ ಸಹಾಯ ಮತ್ತು ಪ್ರಶ್ನೆಗಳಿಗಾಗಿ, ದಯವಿಟ್ಟು **ರೆಪೊ ನಿರ್ವಹಕ: ಇಲ್ಲಿ ಸಹಾಯಕ್ಕಾಗಿ ರೆಪೊ ಮಾಲೀಕರು ಅಥವಾ ಸಮುದಾಯವನ್ನು ಎಲ್ಲಿ ಸಂಪರ್ಕಿಸುವ ಕುರಿತು ಸೂಚನೆಗಳನ್ನು ಸೇರ್ಪಡೆಮಾಡಿ. ಇದು Stack Overflow ಟ್ಯಾಗ್ ಅಥವಾ ಇತರ ಚಾನೆಲ್ ಆಗಿರಬಹುದಾಗಿದೆ. ನೀವು ಜನರಿಗೆ ಸಹಾಯ ಮಾಡಲಿರುವ ಸ್ಥಳ ಯಾವುದು?**.



## ಮೈಕ್ರೋಸಾಫ್ಟ್ ಬೆಂಬಲ ನೀತಿ  

ಈ **ಪ್ರಾಜೆಕ್ಟ್ ಅಥವಾ ಉತ್ಪನ್ನ** ಗೆ ಬೆಂಬಲ ಮೇಲ್ಕಂಡ ಸಂಪನ್ಮೂಲಗಳಿಗೆ ಮಾತ್ರ ಸೀಮಿತವಾಗಿದೆ.
