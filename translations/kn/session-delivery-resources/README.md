# ಈ ಸೆಷನ್ ಅನ್ನು ಹೇಗೆ ಪೂರೈಸುವುದು

ಈ ಸೆಷನ್ ಪೂರೈಸಿದಕ್ಕಾಗಿ ಧನ್ಯವಾದಗಳು!

ಕಾರ್ಯಾಗಾರವನ್ನು ಪೂರೈಸುವ ಮೊದಲು, ದಯವಿಟ್ಟು:

1. ಈ ಡಾಕ್ಯುಮೆಂಟ್ ಮತ್ತು ಅದರಲ್ಲಿ ಒಳಗೊಂಡಿರುವ ಎಲ್ಲ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಓದಿ.
2. ಸೆಷನ್ ಪೂರೈಸುವ ರೆಕಾರ್ಡಿಂಗ್ ಮತ್ತು ಕಾರ್ಯಾಗಾರದ ಆರಂಭದಿಂದ ಕೊನೆಯಲ್ಲಿ ವಾಕ್ತೃತ್ವವನ್ನು ನೋಡಿ.
3. ಸ್ವಂತ ಯಂತ್ರದಲ್ಲಿ ಎರಡೂ ಹ್ಯಾಂಡ್ಸ್-ಆನ್ ಲ್ಯಾಬ್‌ಗಳನ್ನು ಸರ್ವಸ್ವವಾಗಿ ಕನಿಷ್ಟ **ಒಂದು ಬಾರಿ** ನಡೆಯಿರಿ.
4. ನಿಮ್ಮ Microsoft Foundry ಪ್ರಾಜೆಕ್ಟ್, ಮಾದರಿ ನಿಯೋಜನೆಗಳು ಮತ್ತು ಕೊಟಾ ಮಾನ್ಯತೆ ಮಾಡಿ.
5. ಏನಾದರೂ ಅಸ್ಪಷ್ಟವಾದರೆ ನಿರ್ವಹಣಾಧಿಕಾರಿಯೊಂದಿಗೆ ಸಂಪರ್ಕಿಸಿ.

## ಪ್ರಾರಂಭಿಸುವುದು

ಈ ಕಾರ್ಯಾಗಾರವು ಡೆವಲಪರ್‌ಗಳಿಗೆ **Microsoft Foundry Agent Service** ಗೆ **Hosted Agents** ಆಗಿ AI ಏಜೆಂಟ್‌ಗಳನ್ನು ಸಂಪೂರ್ಣವಾಗಿ VS Code ನಿಂದ, **Microsoft Foundry Toolkit** ವಿಸ್ತರಣೆ ಬಳಸಿ ನಿರ್ಮಿಸಲು, ಪರೀಕ್ಷಿಸಲು ಮತ್ತು ನಿಯೋಜಿಸಲು ಕಲಿಸುತ್ತದೆ.

- ನಿಮ್ಮ Foundry ಪ್ರಾಜೆಕ್ಟ್ ನಲ್ಲಿ **gpt-4.1** (ಅಥವಾ **gpt-4.1-mini**) ಕೊಟಾ ಹೊಂದಿದಿರಿ.
- ಕೆಳಕಂಡ ಉಪಕರಣಗಳು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿಲಾದವು:

ಪೂರೈಸುವ ಮೊದಲು ಕನಿಷ್ಟ ಒಂದು ಬಾರಿ [Hosted agents quickstart with `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) ಅನ್ನು ನಡೆಸಿ, ಆದರಿಂದ ಉತ್ತಮ Foundry ಪ್ರಾಜೆಕ್ಟ್, ಮಾದರಿ ನಿಯೋಜನೆ ಮತ್ತು Azure ಕನ್ಟೈನರ್ ರೆಜಿಸ್ಟ್ರಿ ಇದ್ದು ಕಲಿಯುವವರು ಅडकಿದಾಗ ಸಹಾಯ ಮಾಡಲು ಲಭ್ಯವಿರುತ್ತದೆ.

## ವಿತರಣೆಯ ಸಲಹೆಗಳು

- **ನಿರೀಕ್ಷೆಗಳನ್ನು ಆರಂಭದಲ್ಲೇ ಸ್ಥಾಪಿಸಿ.** ಹೋಸ್ಟ್ ಮಾಡಲಾದ ಏಜೆಂಟ್‌ಗಳು ಪೂರ್ವ ದರ್ಶನದಲ್ಲಿವೆ - ಪ್ರದೇಶодержание ಮಿತಿ ಮತ್ತು ಕೊಟಾ ಹಂಚಿಕೆ ಮುಂಚಿನಿಂದವೇ ತಿಳಿಸಿ ಅದೆಂದ್ರೆ ಮಧ್ಯ ಲ್ಯಾಬ್ ವೇಳೆ ಕಲಿಯುವವರು ಆಶ್ಚರ್ಯचकಿತರಾಗಬೆಡ).
- **ಪೂರ್ವಶರತ್ತು ಕಾರ್ಯವನ್ನು ಮೊದಲು ನಡೆಸಿ.** ಇಬ್ಬರು ಲ್ಯಾಬ್ ಗಳು `Validate prerequisites` ಎಂಬ VS Code ಕಾರ್ಯವನ್ನು ಹೊಂದಿವೆ - ಯಾವುದೇ ಕೋಡ್ ಬರೆಯುವ ಮೊದಲು ಇದನ್ನು ಕಲಿಯುವವರು ನಡೆಸಲಿ.
- **Agent Inspector ಸ್ಪಷ್ಟವಾಗಿರಲಿ.** ಬಹುತೇಕ "ಆಹಾ" ಕ್ಷಣಗಳು ಕಲಿಯುವವರು ಸ್ಥಳೀಯ `/responses` ರೌಂಡ್-ಟ್ರಿಪ್ ಬೆಳಗುವುದು ನೋಡಿ ಬರುತ್ತವೆ.
- **ಬ್ಯಾಕಪ್ ಪ್ರಾಜೆಕ್ಟ್ ಒದಗಿಸಿ.** ಕಲಿಯುವವರ Foundry ಪ್ರಾಜೆಕ್ಟ್ ಕೊಟಾ ಸಮಸ್ಯೆ ಎದುರಿಸಿದಾಗ, ನಿಯೋಜನೆ ಹಂತದಲ್ಲಿ ಮುಂಬಾದ್ದಂತೆ ಪ್ರಾಜೆಕ್ಟ್ ಹಂಚಿ, ಕುತೂಹಲವನ್ನು ತಡೆಯಬೇಡಿ.
- **ಕಲಿಯುವವರನ್ನು ಜೋಡಿಸಿ.** ಲ್ಯಾಬ್ 02 (ಬಹು ಏಜೆಂಟ್) ಸಹಯೋಗದೊಂದಿಗೆ ಈ ಪ್ರಕ್ರಿಯೆ ಸುಲಭವಾಗುತ್ತದೆ.
- **ದಾಖಲೆ ಮಾಯಾಜಾಲಗಳನ್ನು ತಪಾಸಣಾ ಬಿಂದುಗಳಾಗಿ ಬಳಸಿ.** ಪ್ರತಿಯೊಂದು ಲ್ಯಾಬ್‌ನ `docs/` ಫೋಲ್ಡರ್ನಲ್ಲಿ 8 ಸಂಖ್ಯೆಗೊಳಿಸಿದ ಮಾಯಾಜಾಲಗಳಿವೆ - ಅವುಗಳನ್ನು ನೈಸರ್ಗಿಕ ವಿರಾಂತಿ ಬಿಂದುಗಳಾಗಿ ಉಪಯೋಗಿಸಿ.
- **ಹಂಚಿರುವ ಲ್ಯಾಬ್ ಯಂತ್ರಗಳಲ್ಲಿ ಬೇಸ್ ಡಾಕರ್ ಚಿತ್ರವನ್ನು ಮುಂಚಿತವಾಗಿ ಪಡೆದುಕೊಳ್ಳಿ** ರೆಜಿಸ್ಟ್ರಿ ದರ ಮಿತಿಯನ್ನು ತಪ್ಪಿಸಲು.

ನಿಮ್ಮ ಪ್ರೇಕ್ಷಕರಿಗೆ ಕಾರ್ಯಾಗಾರವನ್ನು ಹೊಂದಿಸಲು ಸ್ವಾಗತ. ಸಾಮಾನ್ಯ ಬದಲಾವಣೆಗಳು:

- **ಬ್ಯಾಕ್‌ಎಂಡ್ ಪ್ರೇಕ್ಷಣಾಕರರು:** `agent.yaml`, Docker ಮತ್ತು ACR ಮೇಲೆ ಹೆಚ್ಚು ಸಮಯ ಕಳೆಯಿರಿ; ಪ್ಲೇಗ್ರೌಂಡ್ ಡೆಮೋವನ್ನು ಕಡಿಮೆಮಾಡಿ.
- **ಪಟ್ಟಣ ಅಭಿವೃದ್ಧಿಪಡಿಸುವವರ ಪ್ರೇಕ್ಷಣಾಕರರು:** ಫೌಂಡ್ರಿ ವಿಸ್ತರಣೆಯ UI ಯಲ್ಲಿ ಸ್ಕ್ಯಾಫೋಲ್ಡಿಂಗ್‌ಗಾಗಿಯೇ ತಂಗಿ; CLI ಹಂತಗಳನ್ನು ಕಡಿಮೆ ಮಾಡಿ.
- **ಏಕ-ಟ್ರ್ಯಾಕ್ 60 ನಿಮಿಷದ ಸೆಷನ್:** ಪರಿಚಯ, ಡೆಮೋ ಮತ್ತು ಪ್ರಯೋಗಾಲಯ 01 ಮಾತ್ರ ನೀಡಿ.
- **ಕಾರ್ಯಾಗಾರ ಮಾತ್ರ (ಸ್ಲೈಡ್ಗಳು ಇಲ್ಲ)**: ಲ್ಯಾಬ್ READMEs ಎರಡನ್ನೂ ತೆರೆಯಿರಿ ಮತ್ತು ಅವುಗಳನ್ನು ಪ್ರಮುಖ ಲಿಪಿಯಾಗಿ ಬಳಸಿ.

ನೀವು ಪ್ರಯೋಗಾಲಯಗಳನ್ನು ವಿಸ್ತರಿಸಿದರೆ, ದಯವಿಟ್ಟು ಬದಲಾವಣೆಗಳನ್ನು PR ಮುಖೇನ ಹಿಂತಿರುಗಿಸಿ ಇದರಿಂದ ಇತರ ತರಬೇತುದಾರರು ಲಾಭ ಪಡೆಯುತ್ತಾರೆ.
