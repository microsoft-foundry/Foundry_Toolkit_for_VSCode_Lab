# Support

## Wie man Probleme meldet und Hilfe erhält  

Dieses Projekt verwendet GitHub Issues, um Fehler und Funktionsanfragen zu verfolgen. Bitte durchsuchen Sie die vorhandenen 
Issues, bevor Sie neue Issues erstellen, um Duplikate zu vermeiden.  Für neue Issues erstellen Sie bitte Ihren Fehlerbericht oder 
Feature-Anfrage als neues Issue.

Bei Fragen und für Hilfe zur Nutzung dieses Projekts, bitte **REPO MAINTAINER: FÜGEN SIE HIER ANWEISUNGEN EIN 
WIE SIE REPO-EIGENTÜMER ODER DIE COMMUNITY UM HILFE ANSPRECHEN KÖNNEN. KANN EIN STACK OVERFLOW TAG ODER EIN ANDERER
KANAL SEIN. WO WERDEN SIE LEUTEN HELFEN?**.
