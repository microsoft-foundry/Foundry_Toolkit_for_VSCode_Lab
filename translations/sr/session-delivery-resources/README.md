# Како одржати ову сесију

Хвала што ћете одржати ову сесију!

Пре одржавања радионице, молимо:

1. Прочитајте овај документ и све укључене ресурсе у целини.
2. Погледајте снимак одржавања сесије и презентацију радионице корак по корак.
3. Прођите оба практична лабораторијска вежба у целини на вашем рачунару **бар једном** пре догађаја.
4. Верификујте ваш Microsoft Foundry пројекат, имплементације модела и квоте.
5. Обратитe се одржавачу ако нешто није јасно.

## Започните

Ова радионица учи програмере како да граде, тестирају и имплементирају AI агенте у **Microsoft Foundry Agent Service** као **Hosted Agents** у потпуности преко VS Code, користећи екстензију **Microsoft Foundry Toolkit**.

Радионица је подељена на више секција укључујући слајдове, **2 живе демонстрације** и **2 практичне лабораторијске вежбе**.

### Предуслови за тренера

Пре одржавања, осигурајте да имате:

- **Azure претплата** са дозволом за креирање ресурса (Owner или Contributor на resource group).
- Приступ **Microsoft Foundry пројекту** у [региону који подржава hosted агенте](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability).
- Квоту за **gpt-4.1** (или **gpt-4.1-mini**) у вашем Foundry пројекту.
- Инсталиране следеће алате:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Microsoft Foundry Toolkit extension](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (опционо)
  - Python 3.10 или новији

Покрените [Hosted agents quickstart with `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) бар једном пре одржавања како бисте имали пројекат, имплементацију модела и Azure Container Registry који је проверен и спреман као референца ако неко од учесника заглави.

## Демонстрације

У презентацију су укључене две живе демонстрације. Одвојите око 10 минута за сваку.

| Демо                     | Лаб                | Фајлови                                                           | Шта показати                                         |
|--------------------------|--------------------|------------------------------------------------------------------|----------------------------------------------------|
| Executive Agent          | Лаб 01             | [`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent)       | Један hosted агент; превод техничког жаргона у извршни сажетак |
| Resume to Job Fit Evaluator | Лаб 02             | [`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot) | Оркестрација четири агента; оцењује подударање резимеа и посла, и генерише препоруку |

### Демо 1: Executive Agent

Самостални агент у [`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent). Користите ово као 10-минутну демонстрацију пре Лаб 01.

1. Отворите [`workshop/lab01-single-agent/agent/main.py`](../../../workshop/lab01-single-agent/agent/main.py) и прођите кроз дефиницију агента (системска порука, модел, рамворк).
2. Притисните `F5` да покренете **Agent Inspector** локално.
3. Налепите пример поруке из [README](../README.md#see-it-in-action) и покажите одговор као извршни сажетак.
4. Прикажите [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) и [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile) да бисте објаснили артефакте имплементације.
5. Прикажите ток имплементације (Docker build, ACR push, креирање hosted агента) без чекања да се заврши.

### Демо 2: Resume to Job Fit Evaluator

Четворо-агентски ток у [`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot). Користите ово као 10-минутну демонстрацију пре Лаб 02.

1. Отворите [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) и покажите како су четири агента повезана у секвенцијално оркестрирање.
2. Притисните `F5` да покренете **Agent Inspector** за мулти-агентски ток.
3. Налепите кратак опис посла и пример резимеа у Agent Inspector chat.
4. Прођите кроз четворо-агентски проток: анализатор резимеа, извлачење захтева посла, оцењивач подударања, и аутор препорука.
5. Укажите како излаз сваког под-агента постаје контекст следећег агента, наглашавајући образац препуштања.
6. Прикажите [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) да упоредите са одговарајућим фајлом за једног агента из Демо 1.

## Савети за одржавање

- **Ранo поставите очекивања.** Hosted агенти су у preview режиму - наведите ограничења по регионима и квоте одмах да учесници не буду изненађени током лабораторија.
- **Прво покрените задатак провере предуслова.** Обе лабораторијске вежбе имају VS Code задатак `Validate prerequisites` - нека учесници то покрену пре него што било шта кодирају.
- **Држите Agent Inspector видљивим.** Већина "аха" момената се догађа када учесници виде како светли локални `/responses` рунд-трип.
- **Имајте резервни пројекат.** Ако учесникев Foundry пројекат наиђе на квотни лимит, поделите им већ припремљени пројекат за фазу имплементације уместо да блокирате простор.
- **Парите учеснике.** Лаб 02 (мулти-агент) је значајно лакши ако учесници могу да разговарају о оркестрацији са партнером.
- **Користите `docs` модуле као контролне тачке.** Сваки `docs/` фолдер у лабораторији је подељен у 8 нумерисаних модула - користите их као природне полазне тачке.
- **Претходно преузмите основну Docker слику** на заједничким радним машинама да бисте избегли ограничења регистра.

## Решавање проблема током одржавања

| Симптом                                    | Прва ствар коју треба пробати                                                                     |
|--------------------------------------------|--------------------------------------------------------------------------------------------------|
| Agent Inspector не може да се повеже      | Потврдите да је порт `8088` слободан и да је задатак `Run Lab01 HTTP Server` / `Run Lab02 HTTP Server` покренут. |
| Debugger не успева да се повеже            | Проверите да је порт `5679` слободан; рестартујте VS Code ако је `debugpy` већ заузет.              |
| `azd up` не успева због грешке аутентификације | Покрените `az login` и `azd auth login`, осигурајте да је одабран исправан тенант.                   |
| Имплементација застаје при ACR push-у      | Проверите да ли Docker Desktop ради и да корисник има дозволу `AcrPush` на регистру.               |
| Модел враћа 404 / deployment-not-found      | Име имплементације модела у `agent.yaml` мора да одговара имплементацији у Foundry пројекту.         |

| Хостовани агент заглављен у `Provisioning`         | Проверите да ли регија пројекта [подржава хостоване агенте](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) и да ли је квота доступна. |
| Playground враћа 401                       | Поново се аутентификујте у Foundry екстензији са активности траке у VS Code-у.                                     |

За детаљније смернице, сваки лабораторијски вежба има свој `08-troubleshooting.md` документ – усмерите ученике тамо:

- Лабораторијска вежба 01: [`workshop/lab01-single-agent/docs/08-troubleshooting.md`](../workshop/lab01-single-agent/docs/08-troubleshooting.md)
- Лабораторијска вежба 02: [`workshop/lab02-multi-agent/docs/08-troubleshooting.md`](../workshop/lab02-multi-agent/docs/08-troubleshooting.md)

## Прилагођавање ове сесије

Слободно прилагодите радионицу за своју публику. Уобичајене варијације:

- **За публику из бекаенда:** посветите више времена `agent.yaml`, Докеру и ACR-у; скратите демонстрацију playground-а.
- **За публику од грађанских програмера:** останите у Foundry екстензији ради убрзања; смањите кораке у CLI-ју.
- **Једносатна сесија једне теме:** одржите само увод, демонстрацију и Лабораторијску вежбу 01.
- **Само радионички формат (без слајдова):** отворите оба лаб-README документа и користите их као главни сценарио.

Ако проширујете лабораторијске вежбе, молимо вас допринесите променама преко PR-а како би други тренери имали користи.
