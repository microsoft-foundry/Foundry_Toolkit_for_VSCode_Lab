# Модул 9 - Резиме и следећи кораци

⏱️ ~5 минута

**Честитамо!** Направили сте, тестирате и (ако сте на Путању А) имплементирали мулти-агентски радни ток користећи Microsoft Foundry и Foundry Toolkit за VS Code.

---

## Шта сте направили

**Resume → Job Fit Evaluator** - мулти-агентски хостовани радни ток који:
- Прима резиме и опис посла преко HTTP (`POST /responses`)
- Покреће четири специјализована агента у секвенцијалном конвејеру - сваки агент преноси податке које његов наследник треба
- Враћа резултат уклапања (0–100 са детаљним прегледом), листу недостатака вештина и сертификата и персонализовану карту учења са стварним Microsoft Learn линковима за сваки недостатак
- Позива Microsoft Learn MCP сервер (`https://learn.microsoft.com/api/mcp`) да преузме званичне ресурсе за учење за сваки идентификован недостатак вештине
- Ради као један контејнеризовани хостовани агент у Microsoft Foundry Agent Service

## Кључни појмови које сте научили

| Пojам | Шта сте вежбали |
|---------|-------------------|
| **Оркестрација мулти-агента** | `WorkflowBuilder` секвенцијални конвејер са `add_edge()` |
| **Специјализација агента** | Четири фокусирана агента боље функционишу од једног општег агента |
| **Образац Content Router** | ResumeParser такође функционише као рутер - чува JD текст у одељку `[JOB DESCRIPTION PASS-THROUGH]` тако да агенти низводно могу да му приступе (потребно јер `context_mode="last_agent"` значи да само `start_executor` види сирову корисничку поруку) |
| **Образац Content Relay** | JD Agent преноси `[PARSED RESUME PASS-THROUGH]` даље тако да MatchingAgent добија оба профила; избегава двоструко активирање OR семантике које фан-ин графови изазивају |
| **Интеграција MCP алата** | `@tool` + `streamable_http_client` који позива спољни MCP сервер |
| **Животни циклус хостованог агента** | Scaffold → Конфигурисање → Локално тестирање → Имплементација → Верификација у облаку |
| **`context_mode="last_agent"`** | Сваки извршилац види само излаз свог директног претходника |
| **Foundry Toolkit радни ток** | Чаробњак Scaffold-а, Agent Inspector, Workflow Visualizer, имплементација једним кликом |

| **[Foundry процене](https://learn.microsoft.com/azure/foundry/evaluations/overview)** | Мерите квалитет агента у великој скали са аутоматизованим проценитељима |

### Идеје за проширење овог радног тока

- **Додајте 5. агента** - Тренер за интервју који производи вероватна питања за интервју на основу извештаја о недостацима
- **Додајте Bing алат за утемељење** - Дозволите JD агенту да претражује сличне огласе за посао ради обогаћивања захтева
- **Повежите се са базом резимеа** - Преузмите профиле кандидата из базе преко прилагођеног `@tool`
- **Испробајте различите моделе** - Упоредите квалитет и латенцију излаза `gpt-4.1` и `gpt-4.1-mini`
- **Оцените уз Foundry** - Користите функцију Процена за бодовање извештаја уклапања у односну скупу златних података

### За кориснике путање Б: Надоградите на имплементацију у облаку

Када будете спремни да имплементирате у облаку:
1. Набавите Azure претплату ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. Завршите [Lab 01, Модул 01](../../lab01-single-agent/docs/01-setup.md) (креирање пројекта, имплементација модела, додељивање RBAC-а)
3. Ажурирајте свој `.env` са Foundry пројектном крајњом тачком и именом имплементације модела
4. Наставите са [Модул 06 - Имплементација у Foundry](06-deploy-to-foundry.md)

## Очистите ресурсе (опционо)

Ако желите да уклоните Azure ресурсе креиране током ове радионице:

### Опција 1: Обришите групу ресурса (уклања све)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### Опција 2: Обришите само хостованог агента

1. Отворите [ai.azure.com](https://ai.azure.com) → ваш пројекат → **Build** → **Agents**.
2. Пронађите **PersonalCareerCopilot** → кликните **Delete**.

### Опција 3: Обришите имплементацију модела

1. У Foundry-у са стране проширите ваш пројекат → **Models**.
2. Кликните десним тастером на имплементацију модела → **Delete**.

> **Напомена о трошковима:** Хостовани агенти наплаћују се само када раде. Ако зауставите или избришете агента, нема сталних трошкова. Имплементација модела може наплатити мали износ за резервисани капацитет - обришите је ако сте завршили.
