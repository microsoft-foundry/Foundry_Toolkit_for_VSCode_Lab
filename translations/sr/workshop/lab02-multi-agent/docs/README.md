# Лаб 02 - Вишеагентски ток рада: Оцена подударности CV-а и посла

## Комплетан пут учења

Ова документација вас води кроз креирање, тестирање и имплементацију **вишeагентског тока рада** који процењује подударност CV-а са описом посла користећи четири специјализована агента координирана преко **WorkflowBuilder**.

> **Прeдвaзeтнo:** Завршите [Лаб 01 - Један агент](../../lab01-single-agent/README.md) пре почетка Лаба 02.
