# Модул 0 - Увод

⏱️ ~10 мин

> [!WARNING]
> **Преглед и ограничења:** [Хостовани агенти](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) су тренутно у фази **јавне превиев** - нису препоручени за продукцијске радне оптерећења. Неки приказани елементи у овом радионичарском курсу могу се мењати како услуга буде напредовала ка генералној доступности.

## Шта ћете направити

У овом лабораторијском задатку проширујете вештине једног агента из Лабораторије 01 за прављење **вишенаменског тока рада** - Оцена прегледа и прилагођености послу.

Уносите **резиме** и **опис посла**. Четири специјализована агента обрађују унос секвенцијално, затим враћају:
- Оцена прилагођености (0–100 са детаљним разградњом оцене)
- Листу недостајућих вештина и сертификата
- Персонализовану путну мапу учења са стварним Microsoft Learn линковима за сваки недостатак

**Ток рада користи:**
- **Microsoft Agent Framework** - `WorkflowBuilder` за секвенцијалну организацију радног процеса
- **Foundry Toolkit за VS Code** - скелет, локално тестирање, деплој
- **AI модел** (нпр. `gpt-4.1-mini`) - користе га сва четири агента
- **Microsoft Learn MCP сервер** - обезбеђује стварне линкове ресурса учења за сваки недостатак вештина

## Провера Лаб 01

Лаб 02 се надовезује директно на Лаб 01. Прво завршите Лаб 01 пре него што кренете овде.

Још нисте радили Лаб 01? Почните овде: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ Пут А - Azure cloud</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

Ако ово не успе, покрените `az login`. Затим проверите у VS Code:

1. `Ctrl+Shift+P` → упишите **Foundry Toolkit** → потврдите да се команде појављују.
2. Кликните икону **Foundry Toolkit** → ваш пројекат и деплојовани модел показују **Succeeded**.

![Foundry Toolkit sidebar showing MY RESOURCES section with the project switcher modal open](../../../../../translated_images/sr/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** Доделили сте **Foundry User** у Лаб 01. Ако морате поново да доделите, погледајте [Лаб 01, Модул 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac). Улога је претходно била названа **Azure AI User** - исте дозволе.

</details>
