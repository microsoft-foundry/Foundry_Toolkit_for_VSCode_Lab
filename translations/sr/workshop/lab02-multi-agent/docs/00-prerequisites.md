# Модул 0 - Увод

⏱️ ~10 мин

> [!WARNING]
> **Преглед и ограничења:** [Хостовани агенти](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) су тренутно у фази **јавног прегледа** - не препоручује се за продукционе радне оптерећења. Неке функције приказане у овој радионици могу се мењати како услуга буде напредовала ка GA.

## Шта ћете направити

У овој лабораторији проширујете вештине једног агента из Лабораторије 01 да бисте направили **радни ток са више агената** - Оцењивач погодности резимеа за посао.

Налепите **резиме** и **опис посла**. Четири специјализована агента обрађују улаз секвенцијално, а затим враћају:
- Оцена погодности (0–100 са распадом бодова)
- Листу недостатака вештина и сертификата
- Персонализовану мапу учења са стварним линковима из Microsoft Learn за сваки недостатак

**Радни ток користи:**
- **Microsoft Agent Framework** - `WorkflowBuilder` за секвенцијалну оркестрацију процеса
- **Foundry Toolkit за VS Code** - скеле, тестирање локално, деплој
- **АИ модел** (нпр. `gpt-4.1-mini`) - користе сва четири агента
- **Microsoft Learn MCP сервер** - обезбеђује стварне ресурсе за учење за сваки недостајући део вештина

## Провера Лабораторије 01

Лабораторија 02 директно наставља Лабораторију 01. Прво завршите Лабораторију 01.

Још нисте обавили Лабораторију 01? Почните овде: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ Пут А - Azure облак</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

Ако ово не успе, покрените `az login`. Затим потврдите у VS Code:

1. `Ctrl+Shift+P` → укуцајте **Foundry Toolkit** → потврдите да се команде приказују.
2. Кликните на икону **Foundry Toolkit** → ваш пројекат и деплојовани модел показују **Succeeded**.

![Foundry Toolkit бочно мени који приказује пројекат у Моји Ресурси, са отвореним селектором Промени пројекат / Направи пројекат](../../../../../translated_images/sr/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** Доделили сте улогу **Foundry User** у Лабораторији 01. Ако је потребно поново доделити, видите [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac). Раније је улога била названа **Azure AI User** - иста права.

</details>

<details open>
<summary><strong>🅱️ Пут Б - Foundry Local</strong></summary>

