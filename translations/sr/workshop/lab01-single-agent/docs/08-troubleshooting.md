# Модул 8 - Решавање проблема

Овај модул је референтни водич за уобичајене проблеме. Обележите га и вратите се када нешто пође по злу.

---

## 1. Грешке у дозволама

### 1.1 Одбијена дозвола за `agents/write`

```
Error: lacks the required data action 
Microsoft.CognitiveServices/accounts/AIServices/agents/write
```

**Узрок:** Недостаје улога `Azure AI User` на нивоу **пројекта**. Ово је најчешћа грешка на радионици.

**Поправка:**
1. Отворите [portal.azure.com](https://portal.azure.com).
2. Претражите име вашег Foundry **пројекта** → кликните на резултат типа **"Microsoft Foundry project"** (НЕ родитељски налог).
3. **Контрола приступа (IAM)** → **+ Додај** → **Додај доделу улоге**.
4. Улога: **Azure AI User** → Следеће.
5. Чланови: Изаберите себе → Прегледај и додели → Прегледај и додели.
6. **Сачекајте 1–2 минута** → покушајте поново.

> **Зашто власник/сарадник није довољно:** Ове улоге дају само *управљачке* акције. Операције агента захтевају `agents/write` *акцију за податке*, која је доступна само у `Azure AI User`, `Azure AI Developer` или `Azure AI Owner`. Погледајте [Foundry RBAC документацију](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry).

### 1.2 `AuthorizationFailed` током провизије

**Поправка:** Затражите од администратора да вам додели **Contributor** на ресурсу групи, или нека он креира пројекат за вас и додели вам **Azure AI User**.

### 1.3 `SubscriptionNotRegistered`

```bash
az provider register --namespace Microsoft.CognitiveServices
az provider show --namespace Microsoft.CognitiveServices --query "registrationState"
# Сачекајте док не буде: "Регистрован"
```

## 2. Docker грешке

> Docker је **опционо**. Ово важи само ако је Docker Desktop инсталиран и ако екстензија покушава локалну градњу.

### 2.1 Docker демону није покренут

**Поправка:** Покрените Docker Desktop → сачекајте статус "покренуто" → проверите са `docker info` → покушајте поново.

### 2.2 Грешка у градњи због зависности

**Поправка:** Проверите правопис у `requirements.txt`, прво тестирајте локално: `pip install -r requirements.txt`.

### 2.3 Неслагање платформе (Apple Silicon)

```bash
docker build --platform linux/amd64 -t myagent:v1 .
```

## 3. Грешке при аутентификацији

### 3.1 Неуспех `DefaultAzureCredential`

**Поправка (покушајте по овом редоследу):**
1. `az login` (поновно аутентификовање)
2. `az account set --subscription "<id>"` (исправна претплата)
3. VS Code → Accounts → Одјави се → Пријави се поново
4. Проверите: `az account get-access-token --resource https://cognitiveservices.azure.com`

### 3.2 Токен ради локално али не и на host-у

**Очекује се:** Host-овани агенти користе системски управљан идентитет, не вашу акредитацију. Ако host-овани агент добије грешке при аутентификацији:
- Проверите да ли је `AZURE_AI_PROJECT_ENDPOINT` у `agent.yaml` исправно подешен
- Проверите да ли пројектни управљани идентитет има приступ моделу

## 4. Грешке моделирања

### 4.1 Дистрибуција модела није пронађена

**Поправка:** Име је **osетљиво на велика/мала слова**. Упоредите `.env` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` са тачним именом у бочној траци Foundry → Models.

### 4.2 Неочекивани излаз модела

**Поправка:** Прегледајте `AGENT_INSTRUCTIONS` у `main.py` (да ли је непотпуно?). Покушајте други модел (`gpt-4.1` против `gpt-4.1-mini`).

---

## 5. Грешке при дистрибуцији

### 5.1 Одузимано право на ACR pull

**Поправка:** Azure Portal → Container Registry → Контрола приступа (IAM) → Додај улогу **AcrPull** управљаном идентитету Foundry пројекта.

### 5.2 Агент не успева да почне (остаје "Pending" или "Failed")

Проверите логове контејнера у бочној траци. Чести узроци:

| Порука у логу | Поправка |
|-------------|-----|
| `ModuleNotFoundError` | Додајте недостајући пакет у `requirements.txt`, поново дистрибуирајте |
| `KeyError: 'AZURE_AI_PROJECT_ENDPOINT'` | Додајте променљиву окружења у `agent.yaml` испод `environment_variables` |
| `Address already in use` | Осигурајте да један процес везује порт 8088 |

### 5.3 Време дистрибуције истекло

**Поправка:** Проверите интернет конекцију. Прва дистрибуција шаље >100MB. Јесте ли иза проксија? Конфигуришите подешавања проксија у Docker Desktop.

## 6. Путања Б - Foundry Local

### 6.1 Foundry Local се не покреће

| Проблем | Поправка |
|-------|-----|
| `foundry: command not found` | Поново инсталирајте: `winget install Microsoft.FoundryLocal` |
| Недовољно ресурса | Foundry Local треба ~4GB слободне РАМ меморије. Затворите друге апликације. |
| Неуспех преузимања модела | Проверите простор на диску (модели су 2–8 GB). Поново покушајте: `foundry local models pull <name>` |

### 6.2 Грешке модела у Foundry Local

| Проблем | Поправка |
|-------|-----|
| Спори одговори | Очекује се - локални модели раде на CPU осим ако немате GPU. Будите стрпљиви. |
| Лош квалитет излаза | Покушајте већи модел ако хардвер то дозвољава. `phi-4-mini` је добар баланс. |
| Комуникација одбијена | Проверите да ли Foundry Local ради: `foundry local status`. Поново покрените ако треба. |

## 7. Брзи преглед: RBAC улоге

| Улога | Обим | Овлашћења |
|------|-------|--------|
| **Azure AI User** | Пројекат | Акције са подацима: `agents/write`, `agents/read` |
| **Azure AI Developer** | Пројекат/Налог | Акције са подацима + креирање пројекта |
| **Azure AI Owner** | Налог | Потпуни приступ + управљање улогама |
| **Contributor** | Претплата/РГ | Само управљачке акције (**без** акција са подацима) |
| **Owner** | Претплата/РГ | Управљање + додела улога (**без** акција са подацима) |
