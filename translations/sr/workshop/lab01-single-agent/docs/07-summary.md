# Модул 7 - Резиме и наредни кораци

⏱️ ~5 мин

**Честитамо!** Креирали сте, тестирали и (ако сте на Пути A) имплементирали хостованог AI агента користећи Microsoft Foundry и Foundry Toolkit за VS Code.

---

## Шта сте направили

**„Објасни као да сам извршни директор“** агента који:
- Прима техничка извештаје о инцидентима или оперативне извештаје преко HTTP (`POST /responses`)
- Преводи их у прегледне, једноставне резимеје намењене руководству
- Следи структуриран формат излаза (Шта се догодило / Пословни утицај / Следећи корак)
- Одбија захтеве који су ван теме и покушаје убацивања злобних команда
- Ради као контејнеризовани хостовани агент у Microsoft Foundry Agent Service

---

## Кључни концепти које сте савладали

| Концепт | Шта сте вежбали |
|---------|-------------------|
| **Архитектура Agent Framework-а** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` питавања |
| **Животни циклус хостованог агента** | Scaffold → Конфигурисање → Локално тестирање → Имплементација → Верификација у облаку |
| **Енгинеринг системског питања (system prompt)** | Улога, публика, формат излаза, правила, безбедносна ограничења и примери |
| **Локалне и хостоване разлике** | Идентитет (лични креденцијал против управљаног идентитета), крајња тачка, мрежни пут |
| **Безбедносне границе** | Одбрана од убацивања у питање, поштовање улоге, лепо руковање границама случајева |
| **Foundry Toolkit ток рада** | Креирање пројекта, имплементација модела, агенти scaffolding, Agent Inspector, имплементација једним кликом |

### Идеје за проширење вашег агента

- **Додајте алат за датум** - Нека агент укључи контекст „као од данас“ у резимее
- **Повежите базу инцидената** - Повлачите стварне детаље инцидената путем функције алата
- **Додајте алат за Bing претрагу** - Нека агент тражи најновије вести за додатни контекст
- **Испробајте различите моделе** - Упоредите излазну квалитету `gpt-4.1` и `gpt-4.1-mini`
- **Процените са Foundry-ом** - Користите функцију процена за мерење квалитета агента на великој скали

### За кориснике Пута B: Надоградите на имплементацију у облаку

Када будете спремни за имплементацију у облаку:
1. Набавите Azure претплату ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. Завршите [Модул 01, Постављање](01-setup.md#step-2-set-up-based-on-your-access) (креирајте пројекат, имплементирајте модел, доделите RBAC)
3. Ажурирајте свој `.env` са Foundry крајњом тачком пројекта и именом имплементације модела
4. Наставите са [Модул 05 - Имплементација у Foundry](05-deploy-to-foundry.md)

## Чишћење ресурса (опционо)

Ако желите да уклоните Azure ресурсе креиране током овог радионичарског рада:

### Опција 1: Обришите групу ресурса (уклања све)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### Опција 2: Обришите само хостованог агента

1. Отворите [ai.azure.com](https://ai.azure.com) → ваш пројекат → **Build** → **Agents**.
2. Кликните на свог агента → кликните **Delete**.

### Опција 3: Обришите имплементацију модела

1. У Foundry бочној траци, проширите ваш пројекат → **Models**.
2. Десни клик на имплементацију модела → **Delete**.

> **Напомена о трошковима:** Хостовани агенти наплаћују се само када раде. Ако зауставите или обришете агента, нема текућих трошкова. Имплементација модела може имати мали трошак за резервисани капацитет - обришите је ако сте завршили.
