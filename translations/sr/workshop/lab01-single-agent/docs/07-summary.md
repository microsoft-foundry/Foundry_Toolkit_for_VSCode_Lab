# Модул 7 - Резиме и наредни кораци

⏱️ ~5 мин

**Честитамо!** Направили сте, тестирали, и (ако сте на путу А) мећели у рад хостованог AI агента користећи Microsoft Foundry и Foundry Toolkit за VS Code.

---

## Шта сте направили

**„Објасни као да сам извршни директор“** агента који:
- Прима техничке извештаје о инцидентима или оперативне извештаје преко HTTP-а (`POST /responses`)
- Преводи их у сажетке на језику који је разумљив извршном тиму
- Прати структуиран формат излаза (Шта се десило / Бизнис утицај / Следећи корак)
- Одбија захтеве који нису у теми и покушаје убацивања опасних упита (prompt injection)
- Радује као контејнеризовани хостовани агент у Microsoft Foundry Agent Service-у

---

## Кључни појмови које сте научили

| Пojам | Шта сте вежбали |
|---------|-------------------|
| **Архитектура Agent Framework** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` линија обраде |
| **Животни циклус хостованог агента** | Scaffold → Конфигуриши → Тестирај локално → Објави → Потврди у облаку |
| **Инжењеринг системског упита (prompt engineering)** | Улога, публика, формат излаза, правила, безбедносна ограничења и примери |
| **Локалне и хостоване разлике** | Идентитет (личне акредитиве vs. управљани идентитет), крајња тачка, мрежни пут |
| **Безбедносне границе** | Одбрана од убацивања упита, придржавање улоге, љубазан одговор у ивичним случајевима |
| **Foundry Toolkit радни ток** | Креирање пројекта, објава модела, scaffolding агента, Agent Inspector, објава једним кликом |

### Идеје за проширење вашег агента

- **Додајте алат за приказ датума** - Дозволите агенту да укључи контекст „од данас“ у сажецима
- **Повежите се са базом инцидената** - Преузмите стварне детаље инцидената преко алата
- **Додајте алат за Bing претрагу** - Дозволите агенту да тражи најновије вести за додатни контекст
- **Испробајте различите моделе** - Упоредите квалитет излаза `gpt-4.1` и `gpt-4.1-mini`
- **Процените са Foundry** - Користите функцију процена за мерење квалитета агента у великом обиму

### За кориснике пута Б: Надоградња на облачну објаву

Кад будете спремни за објаву у облаку:
1. Добити Azure претплату ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. Завршити [Модул 01, Подешавање](01-setup.md#step-2-set-up-based-on-your-access) (креирати пројекат, објавити модел, доделити RBAC)
3. Ажурирати свој `.env` са крајњом тачком Foundry пројекта и именом објаве модела
4. Наставити из [Модул 05 - Објава на Foundry](05-deploy-to-foundry.md)

## Чишћење ресурса (опционо)

Ако желите да уклоните Azure ресурсе креиране током овог радионичког рада:

### Опција 1: Обришите групу ресурса (уклања све)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### Опција 2: Обришите само хостованог агента

1. Отворите [ai.azure.com](https://ai.azure.com) → ваш пројекат → **Build** → **Agents**.
2. Кликните на свог агента → кликните **Delete**.

### Опција 3: Обришите објаву модела

1. У Foundry бочном менију проширите свој пројекат → **Models**.
2. Десни клик на објаву модела → **Delete**.

> **Белешка о трошковима:** Хостовани агенти стварају трошкове само када раде. Ако зауставите или обришете агента, нема сталних трошкова. Објава модела може имати мали трошак за резервисани капацитет - обришите је ако сте завршили.
