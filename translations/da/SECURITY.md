## Sikkerhed

Microsoft tager sikkerheden for vores softwareprodukter og -tjenester alvorligt, hvilket
inkluderer alle kildekodeopbevaringssteder i vores GitHub-organisationer.

**Rapportér venligst ikke sikkerhedssårbarheder via offentlige GitHub-issues.**

For information om sikkerhedsrapportering, steder, kontaktinformation og politikker,
se venligst den seneste vejledning for Microsoft-opbevaringssteder på
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
