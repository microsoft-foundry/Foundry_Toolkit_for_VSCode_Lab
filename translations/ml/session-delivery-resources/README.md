# ഈ സെഷൻ എങ്ങനെ കൈകാര്യം ചെയ്യാം

ഈ സെഷൻ കൈകാര്യം ചെയ്തതിന് നന്ദി!

വർക്ക്‌ഷോപ്പ് കൈകാര്യം ചെയ്യുന്നതിന് മുൻപ്, ദയവായി:

1. ഈ ദസ്താവേജ് മുഴുവനും മറുപടി ഉൾപ്പെടെ വായിക്കുക.
2. സെഷൻ കൈകാര്യം ചെയ്യൽ റെക്കോർഡിംഗ്‍യും വർക്ക്‌ഷോപ്പ് തുടങ്ങി അവസാനിക്കുന്ന വരെ നടന്ന സംവാദവും കാണുക.
3. രണ്ട് ഹാൻഡ്‌സ്-ഓൺ ലാബുകളും നിങ്ങളുടെ യന്ത്രത്തിൽ **കുറഞ്ഞത് ഒരിക്കൽ** മുഴുവൻ നടത്തുക.
4. നിങ്ങളുടെ Microsoft Foundry പ്രോജക്റ്റ്, മോഡൽ ഡിപ്ലോയ്മെന്റുകൾ, ക്വോട്ടാസുകൾ പരിശോധിക്കുക.
5. എന്തെങ്കിലുമെന്തെങ്കിലും മനസ്സിലാകാതെയുണ്ടെങ്കിൽ, പരിപാലകനോട് ബന്ധപ്പെടുക.

## ആരംഭിക്കുക

ഈ വർക്ക്‌ഷോപ്പ് ഡെവലപ്പർമാർക്ക് **Microsoft Foundry Toolkit** എക്സ്റ്റെൻഷൻ ഉപയോഗിച്ച്, VS Code-ൽ നിന്നു മുഴുവൻ **Microsoft Foundry Agent Service**-ലേക്കുള്ള AI ഏജന്റുകൾ നിർമ്മിക്കാൻ, പരീക്ഷിക്കാൻ, ഡിപ്ലോയ് ചെയ്യാൻ പഠിപ്പിക്കുന്നു.

### പരിശീലകർക്കുള്ള മുൻ ആവശ്യകതകൾ

കൈകാര്യം ചെയ്യുന്നതിന് മുൻപ്, ഉറപ്പു വരുത്തുക:

- ഒരു **ആസൂർ സബ്സ്ക്രിപ്ഷൻ** വിഭവങ്ങൾ സൃഷ്ടിക്കാൻ അനുമതിയുള്ളത് (ഒരു റിസോഴ്സ് ഗ്രൂപ്പിലെ ഉടമ അല്ലെങ്കിൽ കോൺട്രിബ്യൂട്ടറായിരിക്കണം).
- [ഹോസ്റ്റുചെയ്യുന്ന ഏജന്റുകൾ സപ്പോർട് ചെയ്യുന്ന പ്രദേശത്ത്](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) ഉള്ള **Microsoft Foundry പ്രോജക്റ്റ്**-ലേക്ക് ആക്‌സസ്.
- നിങ്ങളുടെ Foundry പ്രോജക്റ്റിൽ **gpt-4.1** (അല്ലെങ്കിൽ **gpt-4.1-mini**) ക്വോട്ട.
- താഴെ പറയുന്ന ടൂളുകൾ ഇൻസ്റ്റാൾ ചെയ്തിരിക്കണം:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Microsoft Foundry Toolkit extension](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
  - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
  - [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
  - [Docker Desktop](https://www.docker.com/) (ഐച്ഛികം)
  - Python 3.10 അല്ലെങ്കിൽ അതിനുശേഷമുള്ള പതിപ്പ്

കൈകാര്യം ചെയ്യുന്നതിന് മുമ്പ് കുറഞ്ഞത് ഒന്നിക്കൽ [Hosted agents quickstart with `azd`](https://learn.microsoft.com/azure/foundry/agents/quickstarts/quickstart-hosted-agent?pivots=azd) നടത്തുക, അതിനാൽ നിങ്ങൾക്ക് അറിയപ്പെടുന്ന טובה Foundry പ്രോജക്റ്റ്, മോഡൽ ഡിപ്ലോയ്മെന്റ്, ആസ്യൂർ കണ്ടെയ്‌നർ രജിസ്ട്രി ഉണ്ടാവും, ഒരു പഠിക്കുന്നവൻ തടഞ്ഞുപോയാൽ ഉപയോഗിക്കാൻ.

### ഡെമോ 1: എക്‌സിക്യൂട്ടീവ് ഏജന്റ്

[`workshop/lab01-single-agent/agent/`](../../../workshop/lab01-single-agent/agent) എന്ന ഒറ്റനിലയുള്ള ഏജന്റ്. ലാബ് 01 മുന്‍പ് 10 മിനിറ്റ് ഡെമോയായി ഉപയോഗിക്കുക.

1. [`workshop/lab01-single-agent/agent/main.py`](../../../workshop/lab01-single-agent/agent/main.py) തുറന്ന് ഏജന്റ് നിർവചനങ്ങൾ (സിസ്റ്റം പ്രോംപ്റ്റ്, മോഡൽ, ഫ്രെയിംവർക്ക്) അവലോകനം ചെയ്യുക.
2. പ്രാദേശികമായി **Agent Inspector** ആരംഭിക്കാൻ `F5` അമർത്തുക.
3. [README](../README.md#see-it-in-action) നിൽ നിന്നുള്ള സാമ്പിൾ പ്രോംപ്‌റ്റ് പേസ്റ്റ് ചെയ്ത് എക്‌സിക്യൂട്ടീവ് സംഗ്രഹം കാണിക്കുക.
4. [`workshop/lab01-single-agent/agent/agent.yaml`](../../../workshop/lab01-single-agent/agent/agent.yaml) ಮತ್ತು [`workshop/lab01-single-agent/agent/Dockerfile`](../../../workshop/lab01-single-agent/agent/Dockerfile) ഡിപ്ലോയ്മെന്റ് വാര്‍ത്തകള്‍ വിശദീകരിക്കാൻ കാണിക്കുക.
5. പൂർത്തിയായതിന് കാത്തിരിക്കുന്നില്ലാതെ ഡിപ്ലോയ്മെന്റ് പ്രക്രിയ (Docker build, ACR push, hosted agent സൃഷ്ടി) പ്രദർശിപ്പിക്കുക.

### ഡെമോ 2: Resume to Job Fit Evaluator

[`workshop/lab02-multi-agent/PersonalCareerCopilot/`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot) ലെ 4-ഏജന്റ് വർക്‌ഫ്ലോ. ലാബ് 02 മുൻപായി 10 മിനിറ്റ് ഡെമോ ആയി ഉപയോഗിക്കുക.

1. [`PersonalCareerCopilot/main.py`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/main.py) തുറന്ന് നാലു ഏജന്റുകളും പരമ്പരാഗത ഓർക്കസ്ട്രേഷൻ ആയി എങ്ങനെ ബന്ധിച്ചിരിക്കുന്നു എന്ന് കാണിക്കുക.
2. മൾട്ടി-ഏജന്റ് വർക്‌ഫ്ലോയ്ക്കുള്ള **Agent Inspector** തുടങ്ങാൻ `F5` അമർത്തുക.
3. ഇൻസ്പെക്ടർ ചാറ്റിൽ ചെറിയ ജോബ് വിവരണം കൂടി ഒരു സാമ്പിൾ റീസ്യൂം പേസ്റ്റ് ചെയ്യുക.
4. നാല് ഏജന്റുകളും: റീസ്യൂം പാർസർ, ജോബ് ആവശ്യം എക്സ്ട്രാക്ടർ, ഫിറ്റ് സ്‌കോറർ, ശുപാർശ എഴുത്തുകാരൻ എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്ന് വിശദീകരിക്കുക.
5. ഓരോ ഉപ-ഏജന്റിന്റെ output അടുത്ത ഏജന്റിന്റെ context ആകുന്നത്, കൈമാറ്റ മാതൃക പരാമർശിക്കുക.
6. [`PersonalCareerCopilot/agent.yaml`](../../../workshop/lab02-multi-agent/PersonalCareerCopilot/agent.yaml) കാണിച്ച് ഡെമോ 1 ലെ സിംഗിൾ ഏജന്റ് സമാനമാണ് എന്ന് താരതമ്യം ചെയ്യുക.

## കൈകാര്യം ചെയ്യലിന് ഉപദേശം

- **ആശാസൂത്രണം തുടക്കത്തിൽ തന്നെ വ്യക്തമാക്കുക.** ഹോസ്റ്റുചെയ്യുന്ന ഏജന്റുകൾ ഇപ്പോൾ പ്രിവ്യൂവിലാണ് - മേഖല പരിധികളും ക്വോട്ടയും അർപ്പിച്ച് പഠിക്കുന്നവർ നിർഭാഗ്യപ്പെടാതിരിക്കാനായി മുൻകൂട്ടി അറിയിക്കുക.
- **ആവശ്യമായ മുൻശ്രുതി പരിശോധന ആദ്യമൊക്കുക.** രണ്ട് ലാബുകളും `Validate prerequisites` എന്ന VS Code ടാസ്‌ക് ഉൾപ്പെടുത്തുന്നു - പഠിക്കുന്നവർക്ക് കോഡ് തയാറാക്കുന്നതിനു മുൻപ് ഇത് നടത്തിപ്പ് ചെയ്യിക്കാൻ ലോകം നൽകുക.
- **Agent Inspector കാണിക്കുന്ന നിലയിലാണ് സൂക്ഷിക്കുക.** ഏറ്റവും കൂടുതൽ "ആഹാ" അനുഭവങ്ങൾ വിദ്യാർത്ഥികൾ പ്രാദേശിക `/responses` റൗണ്ട്-ട്രിപ്പ് ലൈറ്റുകൾ കാണുമ്പോഴാകും.
- **ബാക്കപ്പ് പ്രോജക്റ്റ് ഉണ്ടാക്കുക.** ഒരു വിദ്യാർത്ഥിയുടെ Foundry പ്രോജക്ട് ക്വോട്ട അവലിയേഷനിലെ തടസ്സം വന്നു എങ്കിൽ, ഡിപ്ലോയ്മെന്റ് ഘട്ടത്തിനു മുൻകൂട്ടി ഒരുക്കിയ പ്രോജക്റ്റ് പങ്കുവെക്കുക മുറി തടസ്സപ്പെടുത്താതെ.
- **പങ്കാളികളായി പഠിക്കുന്നവർ കൂട്ടിച്ചേർക്കുക.** ലാബ് 02 (മൾട്ടി-ഏജന്റ്) വളരെയധികം സുഗമമാണ് വിദ്യാർത്ഥികൾ ഓർക്കസ്ട്രേഷൻ പങ്കാളികളുമായി സംസാരിക്കുമ്പോൾ.
- **ഡോക്സിലെ മൊഡ്യൂളുകൾ checkpoint ആയി ഉപയോഗിക്കുക.** ഓരോ ലാബിന്റെയും `docs/` ഫോൾഡർ 8 നമ്പർ ചെയ്തിട്ടുള്ള മൊഡ്യൂളുകളിൽ വിഭജിച്ചിരിക്കുന്നു - അവ സ്വാഭാവിക ഇടവേള പോയിന്റുകളായി ഉപയോഗിക്കുക.
- **ബേസ് Docker ഇമേജ് പ്രീ-പുൾ ചെയ്യുക** പങ്കിട്ട ലാബ് യന്ത്രങ്ങളിൽ രജിസ്ട്രി നിരക്ക് പരിധികൾ ഒഴിവാക്കുന്നതിന്.

## ഈ സെഷൻ കസ്റ്റമൈസ് ചെയ്യൽ

നിങ്ങൾക്ക് നിങ്ങളുടെ പ്രേക്ഷകർക്ക് അനുയോജ്യമായ രീതിയിൽ വർക്ക്‌ഷോപ്പ് ക്രമീകരിക്കാൻ സ്വાગതം. രീതി മാറ്റങ്ങൾ സാധാരണ:

- **ബാക്ക്‌എൻഡ് പ്രേക്ഷകർ:** `agent.yaml`, Docker, ACR എന്നിവയിൽ കൂടുതൽ സമയം ചെലവിടുക; പ്ലേഗ്രൗണ്ട് ഡെമോ ചുരുക്കുക.
- **സിറ്റിസൺ-ഡെവലപ്പർ പ്രേക്ഷകർ:** ഫൗണ്ട്രി എക്സ്റ്റൻഷൻ UIയിൽ തന്നെ സ്‌കാഫോൾഡിംഗ് നടത്തുക; CLI ഘട്ടങ്ങൾ കുറയ്ക്കുക.
- **ഒറ്റ പാത 60-മിനിറ്റ് സ്ലോട്ട്:** മാത്രം ഇന്റ്രോ, ഡെമോ, ലാബ് 01 നൽകുക.
- **വർക്ക്‌ഷോപ്പ് മാത്രം (സ്ലൈഡുകൾ ഇല്ല) ഫോർമാറ്റ്:** രണ്ട് ലാബ് റീഡ്മി ഫയലുകളും തുറന്ന് പ്രധാന സ്‌ക്രിപ്റ്റായി ഉപയോഗിക്കുക.
