# സഹായം

## പ്രശ്നങ്ങൾ എങ്ങനെ ഫയൽ ചെയ്യാം, സഹായം എങ്ങനെ നേടാം  

ഈ പ്രോജക്ട് ബഗുകളും ഫീച്ചർ അഭ്യർത്ഥനകളും ട്രാക്ക് ചെയ്യാൻ GitHub Issues ഉപയോഗിക്കുന്നു. ദയവായി നിലവിലുള്ള 
ഇഷ്യൂകൾ പുതിയ ഇഷ്യൂകൾ ഫയൽ ചെയ്യുന്നതിന് മുമ്പ് ഇരട്ടതുണ്ടാകുന്നത് ഒഴിവാക്കാൻ തിരയുക.  പുതിയ ഇഷ്യൂകൾക്കായി, നിങ്ങളുടെ ബഗ് അല്ലെങ്കിൽ 
ഫീച്ചർ അഭ്യർത്ഥന ഒരു പുതിയ Issue ആയി ഫയൽ ചെയ്യുക.

പ്രോജക്ട് ഉപയോഗിക്കുന്നതിനെക്കുറിച്ചുള്ള സഹായത്തിനും ചോദ്യങ്ങള కోసం, ദയവായി **REPO MAINTAINER: ഇവിടെ നിർദ്ദേശങ്ങൾ 插入 ചെയ്യുക 
REPO ഉടമകളുമായി അല്ലെങ്കിൽ സഹായത്തിനായി സമൂഹവുമായി എങ്ങനെ ബന്ധപ്പെട്ടുക എന്നതിനെക്കുറിച്ച് അറിയിക്കുക. ഇത് ഒരു STACK OVERFLOW TAG അല്ലെങ്കിൽ മറ്റ്
ചാനൽ ആകാമെന്നു വ്യക്തമാക്കുക. നിങ്ങൾ എവിടെ ആളുകൾക്ക് സഹായം നൽകും?**.
