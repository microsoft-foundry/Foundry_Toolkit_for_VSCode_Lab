## സുരക്ഷ

മൈക്രോസോഫ്റ്റ് നമ്മുടെ സോഫ്റ്റ്വെയർ ഉൽപന്നങ്ങളും സേവനങ്ങളും ഉൾപ്പെടെയുള്ള
എല്ലാ സോഴ്‌സ് കോഡ് റിപോസിറ്ററികളും നമ്മുടെ GitHub സ്ഥാപനങ്ങളിലുള്‍പ്പെടെ സുരക്ഷ എതിപോലും കാര്യമായി കൈകാര്യം ചെയ്യുന്നു.

**സുരക്ഷാ അശക്തികൾ പൊതു GitHub പ്രശ്നങ്ങളിലൂടെ റിപ്പോർട്ട് ചെയ്യരുത്.**

സുരക്ഷാ റിപ്പോർട്ടിങ്ങിനുള്ള വിവരങ്ങൾ, സ്ഥിതികൾ, ബന്ധപ്പെടാനുള്ള വിവരങ്ങൾ, നയം എന്നിവയ്ക്ക്,
ദയവായി ഏറ്റവും പുതിയ മാർഗ്ഗനിർദ്ദേശം മൈക്രോസോഫ്റ്റ് റിപോസിറ്ററികളിൽ കാണുക
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
