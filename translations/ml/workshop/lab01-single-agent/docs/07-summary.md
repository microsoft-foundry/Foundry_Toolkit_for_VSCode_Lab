# മോഡ്യൂൾ 7 - സംഗ്രഹം & അടുത്ത ചുവടുകൾ

⏱️ ~5 മിനിറ്റ്

**അഭിനന്ദനങ്ങൾ!** Microsoft Foundry ഉം Foundry Toolkit for VS Code ഉം ഉപയോഗിച്ച് നിങ്ങൾ ഒരു ഹോസ്റ്റഡ് AI ഏജൻറ് നിർമ്മിച്ചു, പരിശോധന നടത്തി, (പാത A-യിൽ ആണെങ്കിൽ) വിന്യസിച്ചു.

---

## നിങ്ങൾ നിർമ്മിച്ചത്

ഒരു **"എനിക്ക് എക്സിക്യൂട്ടീവ് പോലെ വിശദീകരിക്കുക"** ഏജൻറ്:
- HTTP വഴി സാങ്കേതിക അപകട റിപ്പോർട്ടുകൾ അല്ലെങ്കിൽ പ്രവർത്തന അപ്‌ഡേറ്റുകൾ സ്വീകരിക്കുന്നു (`POST /responses`)
- അവയെ ലളിതഭാഷാ എക്സിക്യൂട്ടീവ് സംഗ്രഹങ്ങളായി വിവർത്തനം ചെയ്യുന്നു
- ഘടനയുള്ള ഔട്ട്പുട്ട് ഫോർമാറ്റ് പിന്തുടരുന്നു (എന്താണ് സംഭവിച്ചത് / ബിസിനസ് പ്രഭാവം / അടുത്ത ചുവട്)
- വിഷയം കഴിഞ്ഞ അഭ്യർത്ഥനകളും പ്രോപംറ്റ് ഇൻജെക്ഷൻ ശ്രമങ്ങളുമെല്ലാം നിരസിക്കുന്നു
- Microsoft Foundry Agent Service ൽ കണ്ടെയ്‌നർ മേധാവിയായ ഹോസ്റ്റഡ് ഏജൻറ് ആയി പ്രവർത്തിക്കുന്നു

## അഭ്യസിച്ച പ്രധാന ആശയങ്ങൾ

| ആശയം | നിങ്ങൾ അഭ്യസിച്ചത് |
|---------|-------------------|
| **Agent Framework കെട്ടിട കോളം** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` പൈപ്പ്ലൈൻ |
| **ഹോസ്റ്റഡ് ഏജൻറ് കാലചക്രം** | Scaffold → കോൺഫിഗർ → പ്രാദേശികമായി പരീക്ഷിക്കുക → വിന്യാസം → ക്ലൗഡിൽ സ്ഥിരീകരിക്കുക |
| **സിസ്റ്റം പ്രോപംറ് എഞ്ചിനീയറിംഗ്** | റോൾ, പ്രേക്ഷകർ, ഔട്ട്പുട്ട് ഫോർമാറ്റ്, നിയമങ്ങൾ, സുരക്ഷാ നിബന്ധനകൾ, ഉദാഹരണങ്ങൾ |
| **പ്രാദേശികവും ഹോസ്റ്റഡുമായ വ്യത്യാസങ്ങൾ** | ഐഡന്റിറ്റി (വ്യക്തിഗത ക്രെഡൻഷ്യൽ vs മാനേജ്ഡ് ഐഡന്റിറ്റി), എന്റ്പോയിന്റ്, നെറ്റ്വർക്ക് പാത |
| **സുരക്ഷാ അതിരുകൾ** | പ്രോപംറ് ഇൻജെക്ഷൻ പ്രതിരോധം, റോൾ പാലനം, എഡ്ജ് കേസുകളുടെ സൗമ്യ കൈകാര്യം |
| **Foundry Toolkit പ്രവൃത്തി പ്രവാഹം** | പ്രൊജക്റ്റ് സൃഷ്‌ടിക്കൽ, മോഡൽ വിന്യാസം, ഏജൻറ് സ്കാഫോൾഡിംഗ്, ഏജൻറ് ഇൻസ്പക്ടർ, ഒരെണ്ണം ക്ലിക്ക് വിന്യാസം |

### നിങ്ങളുടെ ഏജന്റിനെ വിപുലീകരിക്കാൻ ആശയങ്ങൾ

- **തീയതി ടൂൾ ഒരു ചേർക്കുക** - സമ്പൂർണങ്ങളിൽ "ഇന്ന് വരെയുള്ള" പ്രസക്തി ചേർക്കാൻ ഏജന്റിനെ അനുവദിക്കുക
- **അപകട ഡാറ്റാബേസ് ബന്ധിപ്പിക്കുക** - ടൂൾ ഫംഗ്ഷൻ വഴി യഥാർത്ഥ അപകട വിശദാംശങ്ങൾ പുള്ള് ചെയ്യുക
- **Bing അടിസ്ഥാനം ടൂൾ ചേർക്കുക** - ഏജന്റ് പുതിയ വാർത്തകൾ തേടാൻ സാധ്യമാക്കുക
- **വ്യത്യസ്ത മോഡലുകൾ പരീക്ഷിക്കുക** - `gpt-4.1` vs. `gpt-4.1-mini` ഔട്ട്പുട്ട് ഗുണമേന്മ താരതമ്യം ചെയ്യുക
- **Foundry ഉപയോഗിച്ച് മൂല്യനിർണ്ണയം** - വിസ്തൃതിയിൽ ഏജന്റ് ഗുണമേന്മ നേരിടാൻ ഇവല്യുവേഷൻസ് ഫീച്ചർ ഉപയോഗിക്കുക

### പാത B ഉപയോക്താക്കൾക്ക്: ക്ലൗഡ് വിന്യാസത്തിലേക്ക് അപ്‌ഗ്രേഡ് ചെയ്യുക

നിങ്ങൾ ക്ലൗഡിലേക്ക് വിന്യസിക്കാൻ തയ്യാറായാൽ:
1. ഒരു ആസ്യൂർ സബ്സ്ക്രിപ്ഷൻ നേടുക ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [മോഡ്യൂൾ 01, സജ്ജീകരണം](01-setup.md#step-2-set-up-based-on-your-access) പൂർത്തിയാക്കുക (പ്രോജക്റ്റ് സൃഷ്‌ടിക്കുക, മോഡൽ വിന്യസിക്കുക, RBAC അനുവദിക്കുക)
3. നിങ്ങളുടെ `.env`യിൽ Foundry പ്രോജക്റ്റ് എന്റ്പോയിന്റും മോഡൽ വിന്യാസ നാമവും അപ്‌ഡേറ്റ് ചെയ്യുക
4. [മോഡ്യൂൾ 05 - Foundry-ലേക്ക് വിന്യാസം](05-deploy-to-foundry.md) നിന്നു തുടരണം

## വിഭവങ്ങൾ അഴിച്ചു കളയുക (ഐച്ഛികം)

ഈ വർക്‌ഷോപ്പിൽ സൃഷ്‌ടിച്ച ആസ്യൂർ വിഭവങ്ങൾ നീക്കം ചെയ്യാൻ ആഗ്രഹിക്കുകയാണെങ്കിൽ:

### ഓപ്ഷൻ 1: റിസോഴ്‌സ് ഗ്രൂപ്പ് നീക്കംചെയ്യുക (എല്ലാം നീക്കംചെയ്യുന്നു)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ഓപ്ഷൻ 2: ഹോസ്റ്റഡ് ഏജൻറ് മാത്രമേ നീക്കംചെയ്യുക

1. [ai.azure.com](https://ai.azure.com) തുറക്കുക → നിങ്ങളുടെ പ്രോജക്റ്റ് → **Build** → **Agents**.
2. നിങ്ങളുടെ ഏജൻറ് ക്ലിക്ക് ചെയ്യുക → **Delete**- ക്ലിക്ക് ചെയ്യുക.

### ഓപ്ഷൻ 3: മോഡൽ വിന്യാസം നീക്കംചെയ്യുക

1. Foundry സൈഡ്ബാറിൽ നിങ്ങളുടെ പ്രോജക്റ്റ് വിപുലീകരിക്കുക → **Models**.
2. മോഡൽ വിന്യാസത്തെ റൈറ്റ്-ക്ലിക്ക് ചെയ്ത് → **Delete**.

> **ചെലവിന്റെ കുറിപ്പ്:** ഹോസ്റ്റഡ് ഏജന്റുകൾ മാത്രം പ്രവർത്തിക്കുന്നസമയം ചെലവ് ഉണ്ടാക്കി. നിങ്ങൾ ഏജന്റ് നിർത്തുകയോ നീക്കം ചെയ്യുകയോ ചെയ്‌താൽ തുടർച്ചയായ ചാർജ് ഇല്ല. മോഡൽ വിന്യാസത്തിൽ റിസർവ് ചെയ്ത ശേഷിക്ക് ചെറിയ ഒരു ചാർജ് ഉണ്ടാകാം - നിങ്ങൾ കഴിഞ്ഞാൽ അത് നീക്കംചെയ്യുക.
