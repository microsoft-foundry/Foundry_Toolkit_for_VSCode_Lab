# Module 5 - പ്രാദേശികമായി പരീക്ഷിക്കുക

⏱️ ~15 മിനിറ്റ്

ഈ മോദ്യൂളിൽ, നിങ്ങൾ മൾട്ടി-ഏജന്റ് വർക്‌ഫ്ലോ പ്രാദേശികമായി പ്രവർത്തിപ്പിക്കുകയും, ഏജന്റ് ഇൻസ്പക്ടർ ഉപയോഗിച്ച് പരീക്ഷിക്കുകയും, ഏആർ നാലു ഏജന്റുകളും MCP ടൂൾ ശരിയായി പ്രവർത്തിക്കുന്നുവെന്ന് deploy ചെയ്യുന്നതിനു മുൻപ് സ്ഥിരീകരിക്കുകയും ചെയ്യും.

---

## ഘട്ടം 1: ഏജന്റ് സർവർ ആരംഭിക്കുക

### ഓപ്ഷൻ A: VS കോഡ് ടാസ്‌ക് ഉപയോഗിച്ച് (ശുപാർശ ചെയ്യുന്നു)

1. `workshop/lab02-multi-agent/PersonalCareerCopilot/` നിങ്ങളുടെ VS കോഡ് ഫോൾഡറായി തുറക്കുക.
2. `Ctrl+Shift+P` അമർത്തുക → **Tasks: Run Task** ടൈപ്പ് ചെയ്യുക → **Run Agent HTTP Server** തിരഞ്ഞെടുക്കുക.
3. ടാസ്‌ക് പോർട്ട് `5679` ന് debugpy ചേർത്തും 8088 പോർട്ടിൽ ഏജന്റ് സർവർ ആരംഭിക്കും.
4. ഔട്ട്പുട്ട് താഴെ കാണിച്ചിരിക്കുന്നതുപോലെ വരേന്ന് കാത്തിരിക്കുക:

```
INFO:resume-job-fit:Starting Resume -> Job Fit Evaluator HTTP server...
INFO:resume-job-fit:Server running on http://localhost:8088
```

### ഓപ്ഷൻ B: F5 (ഡീബഗ് മോഡ്) ഉപയോഗിച്ച്

1. `F5` അമർത്തുക → **Debug Local Agent HTTP Server** തിരഞ്ഞെടുക്കുക.
2. സർവർ മുഴുവൻ ബ്രേക്ക്പോയിന്റ് പിന്തുണയോടെ ആരംഭിക്കും - MCP പ്രതികരണങ്ങൾ അല്ലെങ്കിൽ ഏജന്റ് ഔട്ട്പുട്ടുകൾ പരിശോധിക്കാൻ ഉപകാരപ്പെടും.

## ഘട്ടം 2: ഏജന്റ് ഇൻസ്പക്ടർ തുറക്കുക

1. `Ctrl+Shift+P` അമർത്തുക → **Foundry Toolkit: Open Agent Inspector** ടൈപ്പുചെയ്യുക.
2. ഏജന്റ് ഇൻസ്പക്ടർ ഒരു VS കോഡ് പാനലായി `http://localhost:8088`-നോടൊപ്പം തുറക്കും.
3. ഏജന്റ് സന്ദേശങ്ങൾ സ്വീകരിക്കാൻ_interface_ തയ്യാറായിരിക്കുന്നതായി കാണണം.

![Agent Inspector open and ready - Playground shows the welcome prompt](../../../../../translated_images/ml/04-debug-console-matching-input.ed5c06395e25aec0.webp)

> **ഏജന്റ് ഇൻസ്പക്ടർ തുറക്കാത്തപക്ഷം:** സർവർ പൂർണ്ണമായി തുടങ്ങി ("Server running" ലോഗ് കാണുക) എന്നത് ഉറപ്പാക്കുക. പോർട്ട് 5679 ബിസിയാണെങ്കിൽ, [Module 8 - Troubleshooting](08-troubleshooting.md) കാണുക.

## ഘട്ടം 2b: (ഐച്ഛികം) വർക്‌ഫ്ലോ വിസ്വലൈസർ തുറക്കുക

ഫൗണ്ട്രി ടൂൾകിറ്റ് ഒരു റിയൽ-ടൈം **Workflow Visualizer** ഉൾക്കൊള്ളുന്നു, ഇത് ഗ്രാഫ് പ്രവർത്തിക്കുന്നതിനൊപ്പം ഏജന്റുകൾ എങ്ങനെ അപ്രവർത്തിക്കുന്നുവെന്ന് കാണിക്കുന്നു. മൾട്ടി-ഏജന്റ് ഡീബഗിംഗിന് ഇത് പ്രത്യേകിച്ച് ഉപകാരപ്രദമാണ്.

1. `Ctrl+Shift+P` അമർത്തുക → **Foundry Toolkit: Open Visualizer for Hosted Agents** ടൈപ്പ് ചെയ്യുക.
2. ഒരു പുതിയ VS കോഡ് ടാബ് തുറക്കുകയും ലൈവ് എക്സിക്യൂഷൻ ഗ്രാഫ് കാണിക്കുകയും ചെയ്യും.
3. ഏജന്റ് ഇൻസ്പക്ടറിൽ സന്ദേശങ്ങൾ അയക്കുമ്പോൾ, വിസ്വലൈസർ സ്വയം അപ്ഡേറ്റ് ചെയ്യും - പൂർത്തിയായ ഏജന്റുകൾക്ക് പച്ച നിറമുള്ള നോട്ടുകൾ, ഡാറ്റ ഒഴുകുന്ന സജീവ എഡ്ജുകൾ കാണിക്കും.

> **പോർട്ട് തകരാർ:** വിസ്വലൈസർ പോർട്ട് ഉപയോഗത്തിലാണ് എങ്കിൽ, VS കോഡ് സെറ്റിംഗ്സിൽ → **Extensions** → **Microsoft Foundry Configuration** → **Hosted Agents: Visualizer Port**-ൽ മാറ്റുക.

## ഘട്ടം 4: നിങ്ങളുടെ സ്വന്തം ഡാറ്റയോടെ പരീക്ഷിക്കുക (ഐച്ഛികം)

നിങ്ങളുടെ സ്വന്തം റിസ്യൂം, യഥാർത്ഥ ജോലി വിവരണം പേസ്റ്റ് ചെയ്യാൻ ശ്രമിക്കുക. ഇത് ഉറപ്പാക്കാൻ സഹായിക്കും:

- ഏജന്റുകൾ വ്യത്യസ്ത റിസ്യൂം ഫോർമാറ്റുകൾ കൈകാര്യം ചെയ്യുന്നു (ക്രമാനുസൃതം, ഫംഗ്ഷണൽ, ഹൈബ്രിഡ്)
- JD ഏജന്റ് വ്യത്യസ്ത ജോബ് വിവരണം ശൈലികൾ കൈകാര്യം ചെയ്യുന്നു (ബുള്ളറ്റ് പോയിന്റുകൾ, പാരഗ്രാഫുകൾ, ഘടനാപരമായ)
- MCP ടൂൾ യഥാർത്ഥ നൈപുണ്യങ്ങൾക്ക് അനുയോജ്യമായ സ്രോതസ്സുകൾ തിരിച്ചു നൽകുന്നു
- ഗ്യാപ് കാർഡുകൾ നിങ്ങളുടെ വ്യക്തിഗത പശ്ചാത്തലത്തിന് അനുയോജ്യമായവയാണ്

> **സ്വകാര്യത - പാത A (Foundry ക്ലൗഡ്):** റിസ്യൂം, ജോബ് വിവരണം ടെക്സ്റ്റ് ഇൻഫറൻസ് നിർവഹണത്തിന് നിങ്ങളുടെ Azure OpenAI ഡെപ്ലോയ്മെന്റിലേക്ക് അയയ്ക്കുന്നു. വേർക്‌ഷോപ്പ് ഇൻഫ്രാസ്ട്രക്ചർ ഇത് ലോഗ് ചെയ്യുകയോ സൂക്ഷിക്കുകയോ ചെയ്യില്ല. നിങ്ങൾക്ക് ആഗ്രഹമുണ്ടെങ്കിൽ പ്ളേസ്ഹോൾഡർ പേരുകൾ (ഉദാ: "ജേൻ ഡോ") ഉപയോഗിക്കുക.
>
> **സ്വകാര്യത - പാത B (Foundry പ്രാദേശികം):** നാല് ഏജന്റുകളുടെ ഇൻഫറൻസുകൾ മുഴുവനായി നിങ്ങളുടെ ഉപകരണത്തിൽ പ്രവർത്തിക്കുന്നു. നിങ്ങളുടെ റിസ്യൂം, ജോബ് വിവരണ ടെക്സ്റ്റ് നിങ്ങളുടെ മെഷീൻ വിട്ട് പുറന്തളയുകയില്ല. മാത്രമ арналған MCP ടൂൾ `https://learn.microsoft.com/api/mcp` നിന്നുള്ള സ്രോതസ്സുകൾ സ്വീക്കാറ്കാനുള്ള പുറം വിളി ആണ്; ആ ക്വറി നൈപുണ്യത്തിന്റെ പേരും, നിങ്ങളുടെ വ്യക്തിഗത വിവരങ്ങളും ഉൾക്കൊള്ളുന്നില്ല.
