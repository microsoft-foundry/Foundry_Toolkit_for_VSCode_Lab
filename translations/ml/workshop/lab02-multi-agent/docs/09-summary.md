# മഡ്യൂള്‍ 9 - സംക്ഷിപ്തവും അടുത്ത പടികളും

⏱️ ~5 മിനിറ്റ്

**അഭിനന്ദനങ്ങൾ!** Microsoft Foundry-ഉം Foundry Toolkit for VS Code-ഉം ഉപയോഗിച്ച് നിങ്ങൾ ഒരു മൾട്ടി-എജന്റ് വർക്ക്‌ഫ്ലോ നിർമ്മിച്ചു, പരിശോധന നടത്തി, (പാത Aയിൽ ആയാൽ) വിന്യോജിപ്പിച്ചുവ।

---

## നിങ്ങൾ നിർമ്മിച്ചതെന്ത്

**Resume → Job Fit Evaluator** - ഒരു മൾട്ടി-എജന്റ് ഹോസ്റ്റഡ് വർക്ക്‌ഫ്ലോ:
- HTTP വഴി ഒരു റിസ്യൂമേ + ജോബ് വിവരണം സ്വീകരിക്കുന്നു (`POST /responses`)
- നാല് പ്രത്യേകഗുണമുള്ള എജന്റുകളെ ഒരു അനുക്രമ പൈപ്പലൈനിൽ ഓടിക്കുന്നു - ഓരോ എജന്റും തന്റെ പിന്‍ഗാമിക്ക് ആവശ്യമുള്ള ഡാറ്റ പകരുന്നു
- ഒരു ഫിറ്റ് സ്കോർ (0–100 ഉള്ള വിഭജനത്തോടെ), ഒരു സ്‌കിൽ-സേര്‍ട്ടിഫിക്കേഷൻ ഗ്യാപ് ലിസ്റ്റ്, ഓരോ ഗ്യാപിനും യഥാർത്ഥ Microsoft Learn ലിങ്കുകൾ കൂടിയവയാണ് വ്യക്തിഗത പഠന റോഡ്‌മാപ്പും മടങ്ങുന്നു
- തിരിച്ചറിയപ്പെട്ട ഓരോ കഴിവ് ഗ്യാപിനും ഔദ്യോഗിക പഠന വనറുകൾ ലഭിക്കുന്നതിന് Microsoft Learn MCP സെർവർ (`https://learn.microsoft.com/api/mcp`) വിളിക്കുന്നു
- Microsoft Foundry എജന്റ് സർവീസ്-ലിലെ ഒരേയൊരു കണ്ടെയ്‌നറൈസ്ഡ് ഹോസ്റ്റഡ് എജന്റായി പ്രവർത്തിക്കുന്നു

## പഠിച്ച പ്രധാന ആശയങ്ങൾ

| ആശയം | നിങ്ങൾ അഭ്യസിച്ചത് |
|---------|-------------------|
| **മൾട്ടി-എജന്റ് ഓർക്കസ്ട്രേഷൻ** | `WorkflowBuilder` അനുക്രമ പൈപ്പ്ലൈൻ `add_edge()` ഉപയോഗിച്ച് |
| **എജന്റിന്റെ വിദഗ്ധത** | നാല് കേന്ദ്രീകൃത എജന്റുകൾ ഒരു പൊതു ഉപയോഗ എജന്റിനെക്കാൾ മികച്ച പ്രകടനം കാഴ്ചവെക്കുന്നു |
| **കണ്ടന്റ് റൂട്ടർ പാറ്റേൺ** | ResumeParser ഒരു റൂട്ടറായും പ്രവർത്തിക്കുന്നു - അത് JD വാചകത്തെ `[JOB DESCRIPTION PASS-THROUGH]` സെക്ഷനിൽ സൂക്ഷിക്കുന്നു അതിനാൽ താഴെ ഉള്ള എജന്റുകൾ അതിലേക്ക് മുൻനം പകരാൻ കഴിയുന്നു (`context_mode="last_agent"` കാരണം മാത്രമാണ് അത് ആവശ്യമായത്; കാരണം `start_executor` മാത്രം യഥാർത്ഥ ഉപയോക്തൃ സന്ദേശം കാണുന്നു) |
| **കണ്ടന്റ് റീലേ പാറ്റേൺ** | JD എജന്റ് `[PARSED RESUME PASS-THROUGH]` മുന്നിലേക്ക് പകർന്നു നൽകുന്നു അതിനാൽ MatchingAgent- ഉം രണ്ടും പ്രൊഫൈലുകൾ ലഭിക്കുന്നു; ഫാൻ-ഇൻ ഗ്രാഫുകളും സൃഷ്ടിക്കുന്ന OR-സെമാന്റിക് ഡബിൾ-ട്രിഗർ ഒഴിവാക്കുന്നു |
| **MCP ടൂൾ ഇന്റഗ്രേഷൻ** | `@tool` + `streamable_http_client` ഉറച്ച് MCP സെർവർ വിളിക്കുന്നു |
| **ഹോസ്റ്റഡ് എജന്റ് ലൈഫ് സൈക്ല്‍** | Scaffold → ക്രമീകരിക്കുക → ലോക്കലായി പരീക്ഷിക്കുക → വിന്യോജിക്കുക → ക്ലൗഡിൽ സ്ഥിരീകരിക്കുക |
| **`context_mode="last_agent"`** | ഓരോ executor-ഉം തത്ഫലമായി നേരിട്ടുള്ള മുന്‍സഞ്ചാരിയുടെ output മാത്രം കാണുന്നു |
| **Foundry Toolkit workflow** | Scaffold വിജാർഡ്, എജന്റ് ഇൻസ്പെക്ടർ, Workflow Visualizer, ഒരു ക്ലിക്ക് വിന്യോജനം |

### ഈ വർക്ക്‌ഫ്ലോ വിപുലമാക്കുന്നതിന് ആശയങ്ങൾ

- **ഏഴാം എജന്റ് ചേർക്കുക** - ഗ്യാപ് റിപ്പോട്ടിന്റെ അടിസ്ഥാനത്തിൽ സാധ്യതയുള്ള ഇന്റർവ്യൂ ചോദ്യങ്ങൾ നിർമ്മിക്കുന്ന ഒരു ഇന്റർവ്യൂ കോച്ച്
- **ബിംഗ് ഗ്രൗണ്ടിംഗ് ടൂൾ ചേർക്കുക** - JD എജന്റ് സമാന ജോബ് പോസ്റ്റിംഗുകൾ ഉണ്ടോ എന്ന് തിരയാൻ അനുവദിക്കുക ആവശ്യകതകൾ സമ്പന്നമാക്കാൻ
- **റിസ്യൂമേ ഡാറ്റാബേസുമായി ബന്ധിപ്പിക്കുക** - ഒരു കസ്റ്റം `@tool` ഉപയോഗിച്ച് ഉദ്യോഗാർത്ഥി പ്രൊഫൈലുകൾ ഡാറ്റാബേസിൽ നിന്ന് എടുത്തു വരുക
- **വിവിധ മോഡലുകൾ പരീക്ഷിക്കുക** - `gpt-4.1` ഉം `gpt-4.1-mini` ഉം ഔട്ട്പുട്ട് ഗുണനിലവാരവും ലാറ്റൻസിയും താരതമ്യം ചെയ്യുക
- **Foundry ഉപയോഗിച്ച് വിലയിരുത്തുക** - ഗോൾഡൻ ഡാറ്റാസെറ്റോടുകൂടെ ഫിറ്റ് റിപ്പോട്ടുകൾ സ്കോർ ചെയ്യുന്നതിന് എവാലുവേഷൻസ് ഫീച്ചർ ഉപയോഗിക്കുക

### പാത B ഉപയോക്താക്കൾക്കായി: ക്ലൗഡ് വിന്യോജനത്തിലേക്ക് അപ്ഗ്രേഡ് ചെയ്യുക

നിങ്ങൾ ക്ലൗഡിലേക്ക് വിന്യോജിക്കാൻ തയ്യാറായപ്പോൾ:
1. ഒരു ആസ്യൂർ സബ്സ്ക്രിപ്ഷൻ നേടുക ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [Lab 01, Module 01](../../lab01-single-agent/docs/01-setup.md) പൂർത്തിയാക്കുക (പ്രോജക്ട് ഉണ്ടാക്കുക, മോഡൽ വിന്യോജിക്കുക, RBAC നൽകുക)
3. Foundry പ്രോജക്ട് എൻഡ്‌പോയിന്റ്, മോഡൽ വിന്യോജനം നാമം ഉപയോഗിച്ച് നിങ്ങളുടെ `.env` അപ്ഡേറ്റ് ചെയ്യുക
4. [Module 06 - Deploy to Foundry](06-deploy-to-foundry.md) മുതൽ തുടരുക

## സ്വത്ത് തഴവാക്കാനുള്ള നിർദ്ദേശങ്ങൾ (ഐച്ഛികം)

ഈ വർക്ക്ഷോപ്പ് നടക്കുന്നപ്പോൾ സൃഷ്ടിച്ച ആസ്യൂർ സ്വത്ത് നീക്കം ചെയ്യാൻ നിങ്ങൾ ആഗ്രഹിക്കുന്നുണ്ടെങ്കിൽ:

### ഓപ്ഷൻ 1: റിസോഴ്‌സ് ഗ്രൂപ്പ് നീക്കം ചെയ്യുക (എല്ലാം നീക്കം ചെയ്യുന്നു)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### ഓപ്ഷൻ 2: ഹോസ്റ്റഡ് എജന്റ് മാത്രം നീക്കം ചെയ്യുക

1. [ai.azure.com](https://ai.azure.com) തുറക്കുക → നിങ്ങളുടെ പ്രോജക്ട് → **Build** → **Agents**.
2. **PersonalCareerCopilot** കണ്ടെത്തുക → **Delete** ക്ലിക്ക് ചെയ്യുക.

### ഓപ്ഷൻ 3: മോഡൽ വിന്യേाजनo നീക്കം ചെയ്യുക

1. Foundry സൈഡ്ബാറിൽ നിങ്ങളുടെ പ്രോജക്ട് വിപുലീകരിക്കുക → **Models**.
2. മോഡൽ വിന്യോജനം റൈറ്റ്-ക്ലിക്ക് ചെയ്ത് → **Delete**.

> **ചെലവ് കുറിപ്പ്:** ഹോസ്റ്റഡ് എജന്റുകൾ പ്രവർത്തിക്കുമ്പോഴേ ചെലവ് വരിക. നിങ്ങൾ എജന്റ് നിർത്തുകയോ നീക്കം ചെയ്‌താലോ തുടർച്ചാർജ് ഉണ്ടാകില്ല. മോഡൽ വിന്യോജനം നേരത്തെ സംരക്ഷിച്ച ശേഷിയ്ക്ക് ചെറിയ ഒരു ചെലവ് ഉണ്ടാകാം - നിങ്ങൾക്ക് ആവശ്യമില്ലെങ്കിൽ നീക്കം ചെയ്യുക.
