# ലാബ് 02 - മൾട്ടി-ഏജന്റ് വർക്ക്‌ഫ്ലോ: റിസ്യൂം → ജോബ് ഫിറ്റ് ഇവാലുവേറ്റർ

## പൂർണ്ണ പഠന പഥം

ഈ ഡോക്യുമെന്റേഷൻ നിങ്ങളെ **മൾട്ടി-ഏജന്റ് വർക്ക്‌ഫ്ലോ** നിർമ്മിക്കാൻ, പരീക്ഷിക്കാൻ, և ഡിപ്ലോയ് ചെയ്യാൻ വഴി കാണിക്കുന്നു, ഇത് നാല് വിദഗ്ധ ഏജന്റുകൾ ഉപയോഗിച്ച് റിസ്യൂം-ജോബ് ഫിറ്റ് വിലയിരുത്തുന്നു, **WorkflowBuilder** മുഖേന ഓർക്കസ്ട്രേറ്റുചെയ്യുന്നു.

> **ആവശ്യമായത്:** ലാബ് 02 ആരംഭിക്കുന്നതിന് മുമ്പ് [ലാബ് 01 - സിങിൾ ഏജന്റ്](../../lab01-single-agent/README.md) പൂർത്തിയാക്കുക.
