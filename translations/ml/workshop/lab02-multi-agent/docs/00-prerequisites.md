# Module 0 - പരിചയം

⏱️ ~10 മിനിറ്റ്

> [!WARNING]
> **ഉപരിതലവും പരിധികളും:** [Hosted Agents](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) ഇപ്പോൾ **പബ്ലിക് പ്രിവ്യൂ** ഘട്ടത്തിലാണ് - പ്രൊഡക്ഷൻ വർക്ക്‌ലോഡുകൾക്ക് ശിപാർശ ചെയ്യില്ല. ഈ വർക്ക്‌ഷോപ്പിൽ കാണിച്ച ചില സവിശേഷതകൾ സർവീസ് GA ആയി മാറുന്നതിനൊപ്പം മാറാം.

## നിങ്ങൾ നിർമ്മിക്കുന്നതു

ഈ ലാബിൽ, ലാബ് 01 ലെ സിംഗിൾ-ഏജന്റ് കഴിവുകൾ എക്സ്റ്റെൻഡ് ചെയ്ത് **മൾട്ടി-ഏജന്റ് പ്രവർത്തനക്രമം** - റിസൂമെ → ജോലി ഫിറ്റ് മൂല്യനിർണ്ണയകാരൻ - നിർമ്മിക്കുന്നു.

നിങ്ങൾ ഒരു **റിസൂമെ**യും ഒരു **ജോലി വിവരണം**യും പേസ്റ്റ് ചെയ്യും. നാല് പ്രത്യേക ഏജന്റുകൾ ഇൻപുട്ട് ക്രമസമാനമായി പ്രോസസ്സ് ചെയ്തു, შემდეგ തിരിച്ചുനൽകരുന്നു:
- ഫിറ്റ് സ്കോർ (0–100യും സ്കോർ ബ്രീക്സ്ഡൗൺഉം)
- സ്കിൽ, സർട്ടിഫിക്കേഷൻ ഗ്യാപ് ലിസ്റ്റ്
- ഓരോ ഗ്യാപിനും യാഥാർത്ഥ്യ Microsoft Learn ലിങ്കുകളുള്ള വ്യക്തിഗത പഠന റോഡ്‌മാപ്പ്

**പ്രവൃത്തി ക്രമം ഉപയോഗിക്കുന്നു:**
- **Microsoft Agent Framework** - ക്രമസമാന പൈപ്പ്‌ലൈൻ ഓർകസ്ട്രേഷനിനുള്ള `WorkflowBuilder`
- **Foundry Toolkit for VS Code** - സ്കാഫോൾഡ്, ലൊക്കലി ടെസ്റ്റ്, ഡിപ്ലോയ്
- **ഒരു AI മോഡൽ** (ഉദാഹരണം, `gpt-4.1-mini`) - നാല് ഏജന്റുകൾക്കും    
- **Microsoft Learn MCP സർവർ** - ഓരോ സ്കിൽ ക്യാപിനും യഥാർത്ഥ പഠന റിസോഴ്‌സ് ലിങ്കുകൾ നൽകുന്നു

## ലാബ് 01 പരിശോധന

ലാബ് 02 നേരിട്ട് ലാബ് 01-ൽ അധിഷ്ഠിതമാണ്. ഇവിടെ തുടങ്ങുന്നതിനു മുമ്പ് ലാബ് 01 പൂർത്തിയാക്കുക.

ഇനി വരെ ലാബ് 01 ചെയ്തത് ഇല്ലേ? ഇവിടെ തുടങ്ങുക: [Lab 01 - Introduction](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ വഴി എ - Azure ക്ലൗഡ്</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

ഇത് പരാജയപ്പെട്ടാൽ, `az login` നടത്തുക. ശേഷം VS Code-ൽ സ്ഥിരീകരിക്കുക:

1. `Ctrl+Shift+P` → **Foundry Toolkit** ടൈപ്പ് ചെയ്യുക → കമാൻഡുകൾ കാണുന്നു എന്ന് ഉറപ്പാക്കുക.
2. **Foundry Toolkit** ഐക്കൺ അമർത്തുക → നിങ്ങളുടെ പ്രോജക്റ്റും ഡിപ്ലോയ്മെന്റ് മോഡലും **Succeeded** എന്ന് കാണിക്കും.

![Foundry Toolkit sidebar showing MY RESOURCES section with the project switcher modal open](../../../../../translated_images/ml/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** ലാബ് 01-ൽ നിങ്ങൾ **Foundry User** ആയി അസൈൻ ചെയ്തു. ആവശ്യമുണ്ടെങ്കിൽ പുനഃഅസൈൻ ചെയ്യാൻ [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac) കാണുക. റോളിന് മുമ്പ് പേരിട്ടത് **Azure AI User** ആണ് - അതേ അനുമതികൾ.

</details>

<details open>
<summary><strong>🅱️ വഴി ബി - Foundry Local</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

പ്രതീക്ഷിക്കുക: `StatusCode: 200`. അല്ലെങ്കിൽ, Foundry Toolkit സൈഡ്ബാറിൽ നിന്ന് Foundry Local വീണ്ടും തുടങ്ങുക.

> എല്ലാ ഇൻഫറൻസ് നിങ്ങളുടെ മെഷീനിലാണ് നടക്കുന്നത്. പുറത്തേക്കുള്ള ഏക വിളി MCP ടൂൾ വഴി `https://learn.microsoft.com/api/mcp` ആണ്.

</details>
