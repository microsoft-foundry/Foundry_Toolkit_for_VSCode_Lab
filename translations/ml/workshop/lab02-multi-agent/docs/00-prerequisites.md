## നിങ്ങൾ നിർമ്മിക്കുന്നത്

ഈ ലാബിൽ, നിങ്ങൾ Lab 01ൽ നിന്നുള്ള സിംഗിൾ-ഏജൻറ് കഴിവുകൾ വിപുലീകരിച്ച് **മൾട്ടി-ഏജൻറ് വർക്ക്‌ഫ്ലോ** നിർമ്മിക്കും - റിസ്യൂം → ജോബ് ഫിറ്റ് വാല്യുവേറ്റർ.

നിങ്ങൾ ഒരു **റിസ്യൂം**യും ഒരു **ജോബ് വിവരണം**യും പകർത്തിപ്പെസ്റ്റ് ചെയ്യുന്നു. നാല് പ്രത്യേകപ്പെടുത്തി സജ്ജമാക്കിയ ഏജൻറുകൾ ഇൻപുട്ട് അനുക്രമത്തിൽ പ്രോസസ്സ് ചെയ്ത്, പിന്നെ തിരികെ നൽകുന്നു:
- ഫിറ്റ് സ്കോർ (0–100 സ്ക്കോറിംഗ് ബ്രേക്ക്‌ഡൗൺ സഹിതം)
- ഒരു സ്കിൽ ആൻഡ് സർട്ടിഫിക്കേഷൻ ഗ്യാപ് ലിസ്റ്റ്
- ഓരോ ഗ്യാപിനും യഥാർത്ഥ Microsoft Learn ലിങ്കുകളോടടങ്ങിയ വ്യക്തിഗത പഠന റോഡ്‌മാപ്പ്

**വർക്ക്‌ഫ്ലോയിൽ ഉപയോഗിക്കുന്നത്:**
- **Microsoft Agent Framework** - അനുക്രമ പൈപ്പ്‌ലൈൻ ഓർക്കസ്ട്രേഷൻക്കായി `WorkflowBuilder`
- **Foundry Toolkit for VS Code** - സ്‌കാഫോൾഡ്, പ്രാദേശികമായി ടെസ്റ്റ് ചെയ്യുക, ഡിപ്പ്ലോയ് ചെയ്യുക
- **ഒരു AI മോഡൽ** (ഉദാഹരണത്തിന്, `gpt-4.1-mini`) - നാല് ഏജൻറുകളും ഉപയോഗിക്കുന്നത്
- **Microsoft Learn MCP സർവർ** - ഓരോ സ്കിൽ ഗ്യാപിനും യഥാർത്ഥ പഠന സ്രോതസ്സ് ലിങ്കുകൾ നൽകുന്നു

## Lab 01 പരിശോധന

Lab 02 നേരിട്ട് Lab 01 ൽ നിന്ന് നിർമ്മിക്കുന്നു. ഇവിടെ തുടങ്ങുന്നതിന് മുമ്പ് Lab 01 പൂർത്തിയാക്കുക.

Lab 01 ഇപ്പോഴും ചെയ്തിട്ടില്ലേ? ഇവിടെ തുടങ്ങുക: [Lab 01 - പരിചയം](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ വഴി A - Azure ക്ലൗഡ്</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

ഇതു പരാജയപ്പെട്ടാൽ, `az login` പ്രവർത്തിപ്പിക്കുക. തുടർന്ന് VS Codeൽ പരിശോധിക്കുക:

1. `Ctrl+Shift+P` → ടൈപ്പ് ചെയ്യുക **Foundry Toolkit** → കമാൻഡുകൾ കാണിക്കുന്നതായി സ്ഥിരീകരിക്കുക.
2. **Foundry Toolkit** ഐക്കൺ ക്ലിക്ക് ചെയ്യുക → നിങ്ങളുടെ പ്രോജക്റ്റും ഡിപ്പ്ലോയുചെയ്ത മോഡലും **സക്സീഡ്** ആയി കാണിക്കും.

![Foundry Toolkit സൈഡ്ബാർ, My Resourcesന്റെ കീഴിലുള്ള പ്രോജക്റ്റുമായി, Switch project / Create project പിക്കർ തുറന്നിരിക്കുന്ന ചിത്രം](../../../../../translated_images/ml/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** നിങ്ങൾ Lab 01ൽ **Foundry User** നിയമിച്ചു. വീണ്ടും നിയമിക്കേണ്ടത് ഉണ്ടെങ്കിൽ, [Lab 01, Module 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac) കാണുക. ഈ റോളിന് മുമ്പ് **Azure AI User** എന്ന പേരിൽ അറിയപ്പെടുന്നുവായിരുന്നു - അനുമതികൾ അത് പോലെ തന്നെ.

</details>

<details open>
<summary><strong>🅱️ വഴി B - Foundry Local</strong></summary>

Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
