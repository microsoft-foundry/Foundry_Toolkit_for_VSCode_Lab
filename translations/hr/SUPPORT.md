# Podrška

## Kako prijaviti probleme i dobiti pomoć  

Ovaj projekt koristi GitHub Issues za praćenje grešaka i zahtjeva za značajkama. Molimo pretražite postojeće 
probleme prije prijavljivanja novih kako biste izbjegli duplikate. Za nove probleme prijavite svoju grešku ili 
zahtjev za značajkom kao novi Issue.

Za pomoć i pitanja o korištenju ovog projekta, molimo **ODRŽAVATELJU REPOZITORIJA: UPIŠITE UPUTE OVDJE 
KAKO SE OBRATITI VLASNICIMA REPOZITORIJA ILI ZAJEDNICI ZA POMOĆ. MOŽE BITI STACK OVERFLOW TAG ILI NEKI DRUGI
KANAL. GDJE ĆETE POMOĆI LJUDIMA?**.

## Microsoft Pravila podrške
