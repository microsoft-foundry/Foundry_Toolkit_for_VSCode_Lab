# Support

## Comment signaler des problèmes et obtenir de l’aide  

Ce projet utilise GitHub Issues pour suivre les bugs et demandes de fonctionnalités. Veuillez rechercher les problèmes existants 
avant de soumettre de nouveaux problèmes afin d’éviter les doublons. Pour les nouveaux problèmes, soumettez votre bug ou 
demande de fonctionnalité comme une nouvelle Issue.

Pour obtenir de l’aide et poser des questions sur l'utilisation de ce projet, veuillez **MAINTENEUR DU DÉPÔT : INSÉREZ ICI LES INSTRUCTIONS
