## Sécurité

Microsoft prend la sécurité de nos produits et services logiciels au sérieux, ce qui
inclut tous les dépôts de code source dans nos organisations GitHub.

**Veuillez ne pas signaler les vulnérabilités de sécurité via des issues publiques GitHub.**

Pour les informations sur la déclaration de failles de sécurité, les lieux, les contacts et les politiques,
veuillez consulter les dernières directives pour les dépôts Microsoft à
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
