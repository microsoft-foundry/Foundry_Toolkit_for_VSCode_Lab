## Güvenlik

Microsoft, yazılım ürünlerimizin ve hizmetlerimizin güvenliğini ciddiye almaktadır,
bu, GitHub organizasyonlarımızdaki tüm kaynak kodu depolarını da içermektedir.

**Lütfen güvenlik açıklarını halka açık GitHub sorunları üzerinden bildirmeyin.**

Güvenlik raporlama bilgileri, yerleri, iletişim bilgileri ve politikalar için,
lütfen Microsoft depoları için en son rehberi inceleyin:
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
