# Podpora

## Jak podat problémy a získat pomoc  

Tento projekt používá GitHub Issues k sledování chyb a žádostí o funkce. Před podáním nových problémů prosím vyhledávejte v již existujících 
problémech, abyste předešli duplicitám. Pro nové problémy zadejte svou chybu nebo 
žádost o funkci jako nový Issue.

Pro pomoc a otázky ohledně používání tohoto projektu, prosím **SPRÁVCE REPOZITÁŘE: VLOŽTE SEM INSTRUKCE 
JAK KOMUNIKOVAT S VLASTNÍKY REPOZITÁŘE NEBO S KOMUNITOU PRO POMOC. MŮŽE TO BÝT TAG NA STACK OVERFLOW NEBO JINÝ
KANÁL. KDE BUDETE LIDEM POMÁHAT?**.
