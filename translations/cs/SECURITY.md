## Bezpečnost

Microsoft bere bezpečnost našich softwarových produktů a služeb vážně, což
zahrnuje i všechny repozitáře zdrojového kódu v našich organizacích na GitHubu.

**Prosím, nehlaste bezpečnostní zranitelnosti prostřednictvím veřejných GitHub issues.**

Pro informace o hlášení bezpečnostních problémů, umístění, kontaktní údaje a zásady,
si prosím přečtěte nejnovější pokyny pro repozitáře Microsoft na
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
