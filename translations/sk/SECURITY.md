## Bezpečnosť

Microsoft berie bezpečnosť našich softvérových produktov a služieb vážne, čo zahŕňa
všetky zdrojové kódy v našich GitHub organizáciách.

**Prosím, nehláste bezpečnostné zraniteľnosti cez verejné GitHub issues.**

Pre informácie o hlásení bezpečnostných problémov, miestach, kontaktoch a politikách,
prosím, pozrite si najnovšie pokyny pre Microsoft repozitáre na
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
