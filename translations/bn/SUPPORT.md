# সাপোর্ট

## কীভাবে ইস্যু ফাইল করবেন এবং সাহায্য পাবেন  

এই প্রকল্পটি বাগ এবং ফিচার রিকোয়েস্ট ট্র্যাক করতে GitHub Issues ব্যবহার করে। অনুলিপি এড়াতে নতুন ইস্যু করার আগে বিদ্যমান 
ইস্যুগুলো খুঁজুন। নতুন ইস্যু হিসেবে আপনার বাগ বা 
ফিচার রিকোয়েস্ট ফাইল করুন।

এই প্রকল্পটি ব্যবহার সংক্রান্ত সাহায্য ও প্রশ্নের জন্য, **রেপো রক্ষণশীল ব্যক্তি: এখানে নির্দেশিকা সংযোজন করুন 
কীভাবে রেপো মালিক বা কমিউনিটির সাথে যোগাযোগ করবেন সাহায্যের জন্য। এটি হতে পারে একটি স্ট্যাক ওভারফ্লো ট্যাগ বা অন্য কোনো
চ্যানেল। কোথায় আপনি মানুষজনকে সাহায্য করবেন?**।
