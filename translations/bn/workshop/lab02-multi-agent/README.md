# ল্যাব ০২ - মাল্টি-এজেন্ট ওয়ার্কফ্লো: রিজিউম → জব ফিট ইভ্যালুয়েটর

## ওভারভিউ

এই হ্যান্ডস-অন ল্যাবে, আপনি VS কোডে Foundry Toolkit ব্যবহার করে একটি **ওয়ার্কফ্লো-প্রথম মাল্টি-এজেন্ট অ্যাপ** তৈরি করবেন এবং এটি Microsoft Foundry Agent Service-এ ডিপ্লয় করবেন।

**আপনি যা তৈরি করবেন:** একটি রিজিউম → জব ফিট ইভ্যালুয়েটর যা একটি রিজিউম এবং জব বর্ণনা পার্স করে, ম্যাচ স্কোর করে এবং Microsoft Learn রিসোর্স ব্যবহার করে একটি ব্যক্তিগতকৃত লার্নিং রোডম্যাপ তৈরি করে।

**কিভাবে কাজ করে:**
1. ব্যবহারকারী একটি রিজিউম এবং জব বর্ণনা পেস্ট করেন।
2. **ResumeParser** রিজিউম পার্স করে এবং JD-কে একেবারে অনুলিপি করে `[JOB DESCRIPTION PASS-THROUGH]` সেকশনে রাখে।
3. **JD Agent** পাস-থ্রু থেকে স্ট্রাকচার্ড রিকোয়েরমেন্ট বের করে, তারপর `[PARSED RESUME]` কে সামনে পাঠিয়ে দেয় `[PARSED RESUME PASS-THROUGH]` হিসেবে।
4. **MatchingAgent** `[PARSED RESUME PASS-THROUGH]` বনাম `[JD REQUIREMENTS]` তুলনা করে এবং একটি ফিট স্কোর তৈরি করে।
5. **GapAnalyzer** গ্যাপগুলোকে একটি প্র্যাকটিক্যাল রোডম্যাপে রূপান্তর করে এবং MCP-এর মাধ্যমে আসল Microsoft Learn লিঙ্ক সংগ্রহ করে।

## পার্ট ২: ওয়ার্কফ্লো তৈরি ও পরীক্ষা করুন

1. Foundry Toolkit উইজার্ড ব্যবহার করে ওয়ার্কফ্লো ভিত্তিক প্রোজেক্ট স্ক্যাফোল্ড করুন।
2. `PersonalCareerCopilot/main.py` থেকে প্রম্পট ব্লক এবং ওয়ার্কফ্লো গ্রাফ আপনার ওয়ার্কস্পেসে কপি করুন।
3. Agent Inspector দিয়ে লোকালি চালিয়ে সব চার এজেন্ট এবং MCP টুল যাচাই করুন।
4. লোকাল টেস্ট পাস হলে হোস্ট এজেন্টটি Foundry-তে ডিপ্লয় করুন।
