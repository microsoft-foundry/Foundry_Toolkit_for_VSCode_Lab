## আপনি কি তৈরি করবেন

এই ল্যাবে, আপনি Lab 01 থেকে একক এজেন্ট দক্ষতা সম্প্রসারণ করে একটি **মাল্টি-এজেন্ট ওয়ার্কফ্লো** তৈরি করবেন - রিজিউম → চাকরির ফিট মূল্যায়ক।

আপনি একটি **রিজিউমে** এবং একটি **চাকরির বর্ণনা** পেস্ট করবেন। চারটি বিশেষায়িত এজেন্ট ক্রমানুসারে ইনপুট প্রক্রিয়া করবে, তারপর ফলাফল দিবে:
- একটি ফিট স্কোর (0–100 স্কোরিং ব্রেকডাউনসহ)
- একটি দক্ষতা এবং সনদপত্র ঘাটতির তালিকা
- প্রতিটি ঘাটতির জন্য বাস্তব Microsoft Learn লিঙ্ক সহ একটি ব্যক্তিগতকৃত শেখার রোডম্যাপ

**ওয়ার্কফ্লোটি ব্যবহার করে:**
- **Microsoft Agent Framework** - `WorkflowBuilder` ক্রমাগত পাইপলাইন অর্কেস্ট্রেশনের জন্য
- **Foundry Toolkit for VS Code** - স্ক্যাফোল্ড, লোকালি টেস্ট, ডিপ্লয়
- **একটি এআই মডেল** (যেমন, `gpt-4.1-mini`) - চারটি এজেন্টের দ্বারা ব্যবহৃত
- **Microsoft Learn MCP সার্ভার** - প্রতিটি দক্ষতা ঘাটতির জন্য বাস্তব শেখার রিসোর্স লিঙ্ক প্রদান করে

## Lab 01 যাচাইকরণ

Lab 02 সরাসরি Lab 01 এর উপর নির্মিত। এখানে শুরু করার আগে Lab 01 সম্পন্ন করুন।

এখনও Lab 01 করেননি? এখানে শুরু করুন: [Lab 01 - পরিচিতি](../../lab01-single-agent/docs/00-prerequisites.md)

<details open>
<summary><strong>🅰️ পথ A - Azure ক্লাউড</strong></summary>

```powershell
az account show --query "{name:name, id:id}" --output table
```

যদি এটি ব্যর্থ হয়, তাহলে `az login` চালান। এরপর VS Code এ যাচাই করুন:

1. `Ctrl+Shift+P` → টাইপ করুন **Foundry Toolkit** → নিশ্চিত করুন কমান্ড আসে।
2. **Foundry Toolkit** আইকনে ক্লিক করুন → আপনার প্রকল্প এবং ডিপ্লয়কৃত মডেল দেখায় **সফল**।

![Foundry Toolkit সাইডবারে My Resources এর অধীনে প্রকল্প দেখাচ্ছে, Switch project / Create project পিকার খোলা](../../../../../translated_images/bn/00-foundry-sidebar-project-model.51036e8b9386e1f4.webp)

> **RBAC:** আপনি Lab 01 এ **Foundry User** অ্যাসাইন করেছেন। আবার অ্যাসাইন করতে হলে দেখুন [Lab 01, মডিউল 1](../../lab01-single-agent/docs/01-setup.md#deploy-a-model--assign-rbac)। পূর্বে এই ভূমিকা ছিল **Azure AI User** নামে - একই অনুমতিসমূহ।

</details>

<details open>
<summary><strong>🅱️ পথ B - Foundry লোকাল</strong></summary>

```powershell
Invoke-WebRequest -Uri "http://localhost:5273/v1/health" -UseBasicParsing | Select-Object StatusCode
```

প্রত্যাশিত: `StatusCode: 200`। না হলে, Foundry Toolkit সাইডবার থেকে Foundry লোকাল রিস্টার্ট করুন।

> সমস্ত ইনফারেন্স আপনার মেশিনে চলে। একমাত্র আউটবাউন্ড কল MCP টুল থেকে `https://learn.microsoft.com/api/mcp`।

</details>
