# মডিউল ৭ - প্লেগ্রাউন্ডে যাচাই করুন

⏱️ ~১০ মিনিট

এই মডিউলে, আপনি VS Code এবং ফাউন্ড্রি পোর্টালে আপনার ডিপ্লয়কৃত মাল্টি-এজেন্ট ওয়ার্কফ্লো পরীক্ষা করবেন, নিশ্চিত করবেন যে এজেন্টটি স্থানীয় পরীক্ষার মতোই আচরণ করছে।

---

## ডিপ্লয়ের পর আবার পরীক্ষা কেন?

হোস্টেড পরিবেশ কয়েকটি গুরুত্বপূর্ণ দিক থেকে স্থানীয় থেকে ভিন্ন:

| | স্থানীয় | হোস্টেড |
|--|-------|--------|
| **পরিচয়** | আপনার ব্যক্তিগত সাইন-ইন (`DefaultAzureCredential`) | নির্দিষ্ট এজেন্টের জন্য সমর্পিত এন্ট্রা পরিচয় (ডিপ্লয়ের সময় স্বয়ংক্রিয়ভাবে প্রদানকৃত) |
| **এন্ডপয়েন্ট** | `http://localhost:8088/responses` | ফাউন্ড্রি এজেন্ট সার্ভিস পরিচালিত URL |
| **নেটওয়ার্ক** | আপনার মেশিন → Azure OpenAI + MCP | Azure ব্যাকবোন (কম ল্যাটেন্সি) |

একটি ভুল কনফিগার্ড এনভি ভ্যারিয়েবল, RBAC সমস্যা, বা ব্লককৃত MCP আউটবাউন্ড কল প্রথমে এখানে দেখা যাবে।

---

## বিকল্প A: VS Code প্লেগ্রাউন্ডে পরীক্ষা করুন (প্রথমে সিফারিশকৃত)

### ধাপ ১: আপনার হোস্টেড এজেন্টে যান

১. Activity Bar-এ **Foundry Toolkit** আইকনে ক্লিক করুন।
২. আপনার প্রকল্প সম্প্রসারণ করুন → **Hosted Agents (Preview)** → আপনার এজেন্ট খুঁজুন।

![Foundry Toolkit sidebar showing Hosted Agents (Preview) with resume-job-fit-evaluator and its deployed versions](../../../../../translated_images/bn/06-foundry-sidebar-agent-status.a45994bfb5c21284.webp)

### ধাপ ২: একটি সংস্করণ নির্বাচন করুন

১. এজেন্টে ক্লিক করে তার সংস্করণগুলি সম্প্রসারিত করুন।
২. `v1`-এ ক্লিক করুন → নিশ্চিত করুন স্ট্যাটাস **সক্রিয়** (sidebar-এ "Running" বা "Started" দেখাতে পারে - উভয়ই একই প্রস্তুত অবস্থান নির্দেশ করে)।

### ধাপ ৩: প্লেগ্রাউন্ড খুলুন

১. **Playground**-এ ক্লিক করুন (অথবা সংস্করণের উপর রাইট-ক্লিক → **Open in Playground**)।
২. একটি চ্যাট উইন্ডো VS Code ট্যাবে খুলবে।

### ধাপ ৪: আপনার স্মোক টেস্টগুলি চালান

[মডিউল ৫](05-test-locally.md) থেকে একই ৩টি টেস্ট ব্যবহার করুন। প্রতিটি বার্তা প্লেগ্রাউন্ড ইনপুট বাক্সে টাইপ করুন এবং **Send** (অথবা **Enter**) চাপুন।

#### টেস্ট ১ - সম্পূর্ণ রেজিউমে + JD (স্ট্যান্ডার্ড ফ্লো)

মডিউল ৫, টেস্ট ১ থেকে সম্পূর্ণ রেজিউমে + JD প্রম্প্ট পেস্ট করুন (জেন ডো + কন্টোসো লিমিটেডে সিনিয়র ক্লাউড ইঞ্জিনিয়ার)।

**প্রত্যাশিত:**
- ফিট স্কোর সহ বিশ্লেষণমূলক গণনা (১০০-পয়েন্ট স্কেল)
- ম্যাচ করা দক্ষতা অংশ
- অনুপস্থিত দক্ষতা অংশ
- **প্রতিটি অনুপস্থিত দক্ষতার জন্য একটি গ্যাপ কার্ড** Microsoft Learn ইউআরএল সহ
- সময়রেখাসহ শিক্ষার রোয়াডম্যাপ

#### টেস্ট ২ - দ্রুত সংক্ষিপ্ত টেস্ট (ন্যূনতম ইনপুট)

```
RESUME: 3 years Python developer, knows Django and PostgreSQL, no cloud experience.

JOB: Cloud DevOps Engineer requiring AWS, Kubernetes, Terraform, CI/CD. 5 years needed.
```

**প্রত্যাশিত:**
- নিম্ন ফিট স্কোর (< ৪০)
- ধাপে ধাপে শেখার পথসহ সৎ মূল্যায়ন
- একাধিক গ্যাপ কার্ড (AWS, কুবের্নেটিস, টেরাফর্ম, CI/CD, অভিজ্ঞতার ফাঁক)

#### টেস্ট ৩ - উচ্চ ফিট প্রার্থী

```
RESUME:
10 years Azure Cloud Architect. AZ-305 certified. Expert in AKS, Terraform, Azure DevOps, 
Azure Functions, Helm, Prometheus, Grafana, Python, Go. Led platform team of 8.

JOB:
Senior Cloud Engineer. Required: AKS, Terraform, Azure DevOps, Python. Preferred: Helm, Go.
5+ years experience. AZ-305 preferred.
```

**প্রত্যাশিত:**
- উচ্চ ফিট স্কোর (≥ ৮০)
- ইন্টারভিউ প্রস্তুতি এবং পালিশকরণের উপর ফোকাস
- কম বা কোনো গ্যাপ কার্ড নেই
- প্রস্তুতি কেন্দ্রিক সংক্ষিপ্ত সময়রেখা

### ধাপ ৫: স্থানীয় ফলাফলের সাথে তুলনা করুন

মডিউল ৫ থেকে আপনার নোট বা ব্রাউজার ট্যাব খুলুন যেখানে আপনি স্থানীয় প্রতিক্রিয়া সংরক্ষণ করেছিলেন। প্রতিটি টেস্টের জন্য:

- প্রতিক্রিয়ার **একই কাঠামো** আছে কি (ফিট স্কোর, গ্যাপ কার্ড, রোয়াডম্যাপ)?
- এটি একই **স্কোরিং রুব্রিক** অনুসরণ করে কি (১০০-পয়েন্ট বিশ্লেষণ)?
- গ্যাপ কার্ডগুলিতে এখনও কি **Microsoft Learn ইউআরএল** আছে?
- অনুপস্থিত দক্ষতার জন্য **একটি গ্যাপ কার্ড আছে কি** (সংক্ষিপ্ত নয়)?

> **স্বল্প বাক্যাংশ পার্থক্য স্বাভাবিক** - মডেলটি অ-নির্ধারিত। কাঠামো, স্কোরিং সঙ্গতি এবং MCP টুল ব্যবহারে মনোযোগ দিন।

## বিকল্প B: ফাউন্ড্রি পোর্টালে পরীক্ষা করুন

[Foundry Portal](https://ai.azure.com) একটি ওয়েব-ভিত্তিক প্লেগ্রাউন্ড সরবরাহ করে যা টিম মেম্বার বা স্টেকহোল্ডারদের সাথে শেয়ার করার জন্য উপযুক্ত।

### ধাপ ১: ফাউন্ড্রি পোর্টাল খুলুন

১. আপনার ব্রাউজার খুলুন এবং [https://ai.azure.com](https://ai.azure.com) তে যান।
২. একই Azure অ্যাকাউন্ট দিয়ে সাইন ইন করুন যা আপনি পুরো ওয়ার্কশপে ব্যবহার করছেন।

### ধাপ ২: আপনার প্রকল্পে যান

১. হোম পেজে, বাম পাশে **Recent projects** খুঁজুন।
২. আপনার প্রকল্পের নাম (যেমন `workshop-agents`) ক্লিক করুন।
৩. যদি না পাওয়া যায়, তাহলে **All projects** ক্লিক করুন এবং খুঁজুন।

### ধাপ ৩: আপনার ডিপ্লয়কৃত এজেন্ট খুঁজুন

১. প্রকল্পের বাম নেভিগেশনে, **Build** → **Agents** ক্লিক করুন (অথবা **Agents** বিভাগ দেখুন)।
২. এজেন্টের একটি তালিকা দেখতে পাবেন। আপনার ডিপ্লয়কৃত এজেন্টটি খুঁজুন (যেমন `resume-job-fit-evaluator`)।
৩. এজেন্টের নাম ক্লিক করে বিস্তারিত পৃষ্ঠা খুলুন।

### ধাপ ৪: প্লেগ্রাউন্ড খুলুন

১. এজেন্ট বিস্তারিত পৃষ্ঠায়, উপরের টুলবারে দেখুন।
২. **Open in playground** (অথবা **Try in playground**) ক্লিক করুন।
৩. একটি চ্যাট ইন্টারফেস খুলবে।

### ধাপ ৫: একই স্মোক টেস্টগুলি চালান

উপরের VS Code প্লেগ্রাউন্ড অংশ থেকে সব ৩টি টেস্ট পুনরাবৃত্তি করুন। প্রতিটি প্রতিক্রিয়া স্থানীয় ফলাফল (মডিউল ৫) এবং VS Code প্লেগ্রাউন্ড ফলাফল (উপরের বিকল্প A) এর সাথে তুলনা করুন।

## মাল্টি-এজেন্ট নির্দিষ্ট যাচাই

মৌলিক সঠিকতার বাইরে, এই মাল্টি-এজেন্ট-নির্দিষ্ট আচরণগুলি যাচাই করুন:

### MCP টুল কার্যসম্পাদন

| পরীক্ষা করুন | কীভাবে যাচাই করবেন | উত্তীর্ণ শর্ত |
|-------|---------------|----------------|
| MCP কল সফল | গ্যাপ কার্ডে `learn.microsoft.com` ইউআরএল রয়েছে | আসল ইউআরএল, ফলব্যাক বার্তা নয় |
| একাধিক MCP কল | প্রতিটি উচ্চ/মধ্যম অগ্রাধিকার গ্যাপে রিসোর্স আছে | শুধুমাত্র প্রথম গ্যাপ কার্ড নয় |
| MCP ফলব্যাক কাজ করে | যদি ইউআরএল অনুপস্থিত হয়, ফলব্যাক টেক্সট দেখুন | এজেন্ট এখনও গ্যাপ কার্ড উৎপাদন করে (ইউআরএলসহ বা ছাড়া) |

### এজেন্ট সমন্বয়

| পরীক্ষা করুন | কীভাবে যাচাই করবেন | উত্তীর্ণ শর্ত |
|-------|---------------|----------------|
| সব ৪টি এজেন্ট চালায় | আউটপুটে ফিট স্কোর এবং গ্যাপ কার্ড থাকে | স্কোর আসে MatchingAgent থেকে, কার্ড আসে GapAnalyzer থেকে |
| ক্রমাগত কার্যসম্পাদন | প্রতিক্রিয়া সময় যুক্তিযুক্ত (< ২ মিনিট) | যদি > ৩ মিনিট হয়, টার্মিনাল লগে ত্রুটি চেক করুন |
| তথ্য প্রবাহ অখণ্ডতা | গ্যাপ কার্ড দক্ষতাকে ম্যাচিং রিপোর্ট থেকে রেফারেন্স করে | JD-তে না থাকা কোনো মিথ্যা দক্ষতা নেই |

## যাচাইকরণ রুব্রিক

আপনার মাল্টি-এজেন্ট ওয়ার্কফ্লোর হোস্টেড আচরণ মূল্যায়নের জন্য এই রুব্রিক ব্যবহার করুন:

| # | মাপকাঠি | উত্তীর্ণ শর্ত | উত্তীর্ণ? |
|---|----------|---------------|-------|
| ১ | **কার্যকরী সঠিকতা** | এজেন্ট রেজিউমে + JD-র জন্য ফিট স্কোর এবং গ্যাপ বিশ্লেষণ দিয়ে প্রতিক্রিয়া দেয় | |
| ২ | **স্কোরিং সঙ্গতি** | ফিট স্কোর ১০০-পয়েন্ট স্কেল নিয়ে বিশ্লেষণ করে | |
| ৩ | **গ্যাপ কার্ড সম্পূর্ণতা** | অনুপস্থিত দক্ষতার জন্য একটি কার্ড (সংক্ষিপ্ত বা মিলিত নয়) | |
| ৪ | **MCP টুল ইন্টিগ্রেশন** | গ্যাপ কার্ডে আসল Microsoft Learn ইউআরএল অন্তর্ভুক্ত | |
| ৫ | **কাঠামোগত সঙ্গতি** | স্থানীয় এবং হোস্টেড রানগুলির আউটপুট কাঠামো মেলে | |
| ৬ | **প্রতিক্রিয়া সময়** | সম্পূর্ণ মূল্যায়নের জন্য হোস্টেড এজেন্ট ২ মিনিটের মধ্যে প্রতিক্রিয়া দেয় | |
| ৭ | **ত্রুটি নেই** | কোনো HTTP ৫০০ ত্রুটি, টাইমআউট বা শূন্য প্রতিক্রিয়া নেই | |

> "পাস" মানে সব ৩টি স্মোক টেস্টের জন্য কমপক্ষে এক প্লেগ্রাউন্ডে (VS Code বা পোর্টাল) সব ৭টি মাপকাঠি পূরণ হয়েছে।

| এজেন্ট ফাঁকা প্রতিক্রিয়া দেয় | মডেল ডিপ্লয়মেন্ট নাম মেলেনি | `agent.yaml` → `environment_variables` → `AZURE_AI_MODEL_DEPLOYMENT_NAME` আপনার ডিপ্লয়কৃত মডেলের সাথে মেলে তা যাচাই করুন |
| এজেন্ট ত্রুটি বার্তা দেয় | [RBAC](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry) অনুমতি অনুপস্থিত | প্রকল্প স্তরে **[Foundry User](https://aka.ms/foundry-ext-project-role)** (পূর্বে Azure AI User) বরাদ্দ দিন |
| গ্যাপ কার্ডে কোনো Microsoft Learn ইউআরএল নেই | MCP আউটবাউন্ড ব্লক করা হয়েছে বা MCP সার্ভার অনুপলব্ধ | কন্টেইনার `learn.microsoft.com` অ্যাক্সেস করতে পারে কিনা চেক করুন। দেখুন [মডিউল ৮](08-troubleshooting.md) |
| মাত্র ১টি গ্যাপ কার্ড (সংক্ষিপ্ত) | GapAnalyzer নির্দেশনায় "CRITICAL" ব্লক অনুপস্থিত | [মডিউল ৩, ধাপ ২.৪](03-configure-agents.md) পর্যালোচনা করুন |
| স্থানীয় থেকে ফিট স্কোর ব্যাপকভাবে ভিন্ন | ভিন্ন মডেল বা নির্দেশনাগুলো ডিপ্লয় হয়েছে | `agent.yaml` env vars স্থানীয় `.env` এর সাথে তুলনা করুন। প্রয়োজন হলে পুনরায় ডিপ্লয় করুন |
| পোর্টালে "Agent not found" | ডিপ্লয়মেন্ট এখনও ছড়াচ্ছে অথবা ব্যর্থ হয়েছে | ২ মিনিট অপেক্ষা করুন, রিফ্রেশ করুন। এখনও না থাকলে [মডিউল ৬](06-deploy-to-foundry.md) থেকে পুনরায় ডিপ্লয় করুন |
