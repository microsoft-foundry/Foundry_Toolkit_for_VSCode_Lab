# ল্যাব ০২ - মাল্টি-এজেন্ট ওয়ার্কফ্লো: রিজিউম → জব ফিট ইভ্যালুয়েটর

## সম্পূর্ণ লার্নিং পাথ

এই ডকুমেনটেশন আপনাকে চারটি বিশেষায়িত এজেন্ট দ্বারা পরিচালিত **WorkflowBuilder** এর মাধ্যমে রিজিউম-টু-জব ফিট মূল্যায়ন করা **মাল্টি-এজেন্ট ওয়ার্কফ্লো** তৈরী, পরীক্ষা এবং ডিপ্লয় করার ধাপগুলো দেখাবে।

> **প্রয়োজনীয়তা:** ল্যাব ০২ শুরু করার আগে [ল্যাব ০১ - সিঙ্গেল এজেন্ট](../../lab01-single-agent/README.md) সম্পন্ন করুন।
