# মডিউল ৯ - সারাংশ ও পরবর্তী ধাপ

⏱️ ~৫ মিনিট

**অভিনন্দন!** আপনি Microsoft Foundry এবং Foundry Toolkit for VS Code ব্যবহার করে একটি মাল্টি-এজেন্ট ওয়ার্কফ্লো তৈরি, পরীক্ষা এবং (যদি পাথ এ-তে থাকেন) স্থাপন করেছেন।

---

## আপনি যা তৈরি করেছেন

**রিজিউমে → চাকরি উপযুক্ততা মূল্যায়ক** - একটি মাল্টি-এজেন্ট হোস্ট করা ওয়ার্কফ্লো যা:
- HTTP (`POST /responses`) এর মাধ্যমে রিজিউমে + চাকরির বর্ণনা গ্রহণ করে
- ধারাবাহিক পাইপলাইনে চারটি বিশেষায়িত এজেন্ট চালায় - প্রতিটি এজেন্ট তার উত্তরসূরীর জন্য প্রয়োজনীয় ডেটা প্রেরণ করে
- একটি উপযুক্ততা স্কোর (০–১০০ সহ বিস্তারিত), দক্ষতা ও সার্টিফিকেশন ফাঁক তালিকা, এবং প্রতিটি ফাঁকের জন্য বাস্তব Microsoft Learn লিঙ্কসহ ব্যক্তিগতকৃত শিক্ষণ রাস্তা প্রদান করে
- প্রত্যয়িত দক্ষতা ফাঁকের জন্য Microsoft Learn MCP সার্ভার (`https://learn.microsoft.com/api/mcp`) থেকে অফিসিয়াল শেখার উপকরণ আনে
- Microsoft Foundry Agent Service-এ একটি একক কন্টেইনারাইজড হোস্টেড এজেন্ট হিসেবে চলমান

---

## শেখা মূল ধারণা

| ধারণা | আপনি কি অনুশীলন করেছেন |
|---------|-------------------|
| **মাল্টি-এজেন্ট অর্কেস্ট্রেশন** | `WorkflowBuilder` ধারাবাহিক পাইপলাইন `add_edge()` সহ |
| **এজেন্ট বিশেষায়ন** | চারটি বিশেষায়িত এজেন্ট এক সাধারণ-উদ্দেশ্য এজেন্টের থেকে ভালো পারফর্ম করে |
| **কন্টেন্ট রাউটার প্যাটার্ন** | ResumeParser একটি রাউটার হিসেবেও কাজ করে - এটি JD টেক্সট `[JOB DESCRIPTION PASS-THROUGH]` সেকশনে সংরক্ষণ করে যাতে নিচের এজেন্টেরা প্রবেশাধিকার পায় (প্রয়োজন কারণ `context_mode="last_agent"` মানে শুধুমাত্র `start_executor` প্রকৃত ব্যবহারকারীর বার্তা দেখে) |
| **কন্টেন্ট রিলে প্যাটার্ন** | JD Agent `[PARSED RESUME PASS-THROUGH]` ফরওয়ার্ড করে যাতে MatchingAgent উভয় প্রোফাইল পায়; ফ্যান-ইন গ্রাফের কারণে OR-সেমান্টিক দ্বিগুণ ট্রিগার এড়ায় |
| **MCP টুল ইন্টিগ্রেশন** | `@tool` + `streamable_http_client` একটি বহির্গামী MCP সার্ভার কল করে |
| **হোস্টেড এজেন্ট লাইফসাইকেল** | Scaffold → কনফিগার → স্থানীয়ভাবে পরীক্ষা → স্থাপন → ক্লাউডে যাচাই |
| **`context_mode="last_agent"`** | প্রতিটি executor শুধুমাত্র তার সরাসরি পূর্বসূরীর আউটপুট দেখবে |
| **Foundry Toolkit ওয়ার্কফ্লো** | Scaffold উইজার্ড, Agent Inspector, Workflow Visualizer, এক-ক্লিক স্থাপন |

## পরবর্তী ধাপ

### শেখা অব্যাহত রাখুন

| রিসোর্স | বর্ণনা |
|----------|-------------|
| **[Agent Framework SDK রেফারেন্স](https://learn.microsoft.com/agent-framework/)** | `agent-framework-foundry`, `WorkflowBuilder`, `AgentExecutor` এর API ডকুমেন্টেশন |
| **[MCP টুল ক্যাটালগ](https://learn.microsoft.com/azure/foundry/agents/how-to/tools/model-context-protocol)** | এজেন্টদের অন্যান্য MCP সার্ভার (Bing, GitHub, কাস্টম) সঙ্গে সংযুক্ত করুন |
| **[জ্ঞান যোগ করা (RAG)](https://learn.microsoft.com/azure/foundry/agents/concepts/knowledge)** | এজেন্টদের ডকুমেন্ট, ভেক্টর স্টোর, বা Bing অনুসন্ধানের মাধ্যমে ভূমিকা প্রদান করুন |
| **[Foundry মূল্যায়ন](https://learn.microsoft.com/azure/foundry/evaluations/overview)** | স্বয়ংক্রিয় মূল্যায়ন ব্যবহার করে স্কেলে এজেন্ট কোয়ালিটি মাপুন |
| **[Microsoft Foundry ডকুমেন্টেশন](https://learn.microsoft.com/azure/foundry/)** | পূর্ণ প্ল্যাটফর্ম রেফারেন্স |
| **[Foundry Toolkit - কি নতুন](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio&ssr=false#version-history)** | এক্সটেনশন রিলিজ নোট এবং পরিবর্তন ইতিহাস |

### এই ওয়ার্কফ্লো সম্প্রসারণের ধারণা

- **পাঁচতে এজেন্ট যোগ করুন** - একটি ইন্টারভিউ কোচ যে গ্যাপ রিপোর্টের উপর ভিত্তি করে সম্ভাব্য ইন্টারভিউ প্রশ্ন তৈরি করে
- **Bing গ্রাউন্ডিং টুল যোগ করুন** - JD Agent-কে অনুরূপ চাকরির পোস্ট খোঁজার অনুমতি দিন যাতে প্রয়োজনীয়তাগুলি সমৃদ্ধ হয়
- **রিজিউমে ডেটাবেসের সাথে সংযুক্ত করুন** - একটি কাস্টম `@tool` এর মাধ্যমে ডেটাবেস থেকে প্রার্থীর প্রোফাইল টেনে আনুন
- **ভিন্ন মডেল চেষ্টা করুন** - `gpt-4.1` বনাম `gpt-4.1-mini` আউটপুট গুণমান এবং ল্যাটেন্সি তুলনা করুন
- **Foundry দিয়ে মূল্যায়ন করুন** - স্বর্ণ dataset এর বিরুদ্ধে ফিট রিপোর্ট স্কোর করতে Evaluations ফিচার ব্যবহার করুন

### Path B ব্যবহারকারীদের জন্য: ক্লাউড স্থাপনায় আপগ্রেড করুন

যখন আপনি ক্লাউডে স্থাপন করতে প্রস্তুত:
1. একটি Azure সাবস্ক্রিপশন পান ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [Lab 01, মডিউল 01](../../lab01-single-agent/docs/01-setup.md) সম্পন্ন করুন (প্রজেক্ট তৈরি, মডেল স্থাপন, RBAC নির্ধারণ)
3. আপনার `.env` ফাইলে Foundry প্রজেক্ট এন্ডপয়েন্ট এবং মডেল ডিপ্লয়মেন্ট নাম আপডেট করুন
4. [Module 06 - Deploy to Foundry](06-deploy-to-foundry.md) থেকে চালিয়ে যান

## সংস্থান পরিষ্কার করুন (ঐচ্ছিক)

আপনি যদি এই কর্মশালার সময় নির্মিত Azure সংস্থানগুলি অপসারণ করতে চান:

### অপশন ১: রিসোর্স গ্রুপ ডিলেট করুন (সবকিছু সরিয়ে ফেলে)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### অপশন ২: শুধুমাত্র হোস্টেড এজেন্ট ডিলেট করুন

১. [ai.azure.com](https://ai.azure.com) → আপনার প্রজেক্ট → **Build** → **Agents** খুলুন।
২. **PersonalCareerCopilot** খুঁজুন → **Delete** ক্লিক করুন।

### অপশন ৩: মডেল ডিপ্লয়মেন্ট ডিলেট করুন

১. Foundry সাইডবারে আপনার প্রজেক্ট এক্সপান্ড করুন → **Models**।
২. মডেল ডিপ্লয়মেন্টে রাইট-ক্লিক করুন → **Delete**।

> **খরচ নোট:** হোস্টেড এজেন্ট শুধুমাত্র চলছে তখন খরচ হয়। আপনি যদি এজেন্ট বন্ধ বা ডিলেট করেন, তাহলে কোনো চলমান চার্জ নেই। মডেল ডিপ্লয়মেন্টে সংরক্ষিত ক্যাপাসিটির জন্য একটি ছোট খরচ হতে পারে - কাজ শেষ হলে এটি মুছে ফেলুন।
