# মডিউল ৭ - সংক্ষিপ্তসার ও পরবর্তী ধাপ

⏱️ ~৫ মিনিট

**অভিনন্দন!** আপনি Microsoft Foundry এবং Foundry Toolkit for VS Code ব্যবহার করে একটি হোস্ট করা AI এজেন্ট তৈরি, পরীক্ষা ও (যদি Path A তে থাকেন) ডিপ্লয় করেছেন।

---

## আপনি যা তৈরি করেছেন

একটি **"আমাকে একজন নির্বাহীর মতো ব্যাখ্যা করুন"** এজেন্ট যা:
- প্রযুক্তিগত দুর্ঘটনা প্রতিবেদন বা অপারেশনাল আপডেট HTTP (`POST /responses`) এর মাধ্যমে গ্রহণ করে
- সেগুলোকে সাধারণ ভাষায় নির্বাহী সারাংশে অনুবাদ করে
- একটি কাঠামোবদ্ধ আউটপুট ফরম্যাট অনুসরণ করে (কি ঘটেছে / ব্যবসায়িক প্রভাব / পরবর্তী পদক্ষেপ)
- অফ-টপিক অনুরোধ এবং প্রম্পট ইনজেকশন প্রচেষ্টা প্রত্যাখ্যান করে
- Microsoft Foundry Agent Service-এ কন্টেইনারাইজড হোস্টেড এজেন্ট হিসেবে চলে

---

## শেখা মূল ধারণাগুলো

| ধারণা | আপনি কি অনুশীলন করেছেন |
|---------|-------------------|
| **এজেন্ট ফ্রেমওয়ার্ক আর্কিটেকচার** | `FoundryChatClient` → `Agent` → `ResponsesHostServer` পাইপলাইন |
| **হোস্টেড এজেন্ট জীবনচক্র** | Scaffold → Configure → স্থানীয়ভাবে পরীক্ষা → ডিপ্লয় → ক্লাউডে যাচাই |
| **সিস্টেম প্রম্পট ইঞ্জিনিয়ারিং** | ভূমিকা, শ্রোতা, আউটপুট ফরম্যাট, নিয়ম, নিরাপত্তা সীমাবদ্ধতা এবং উদাহরণ |
| **স্থানীয় বনাম হোস্টেড পার্থক্য** | পরিচয় (ব্যক্তিগত ক্রেডেনশিয়াল বনাম ম্যানেজড আইডেন্টিটি), এন্ডপয়েন্ট, নেটওয়ার্ক পাথ |
| **নিরাপত্তা সীমানা** | প্রম্পট ইনজেকশন প্রতিরোধ, ভূমিকা অনুসরণ, প্রান্তিক ক্ষেত্রে সুশৃঙ্খল পরিচালনা |
| **Foundry Toolkit ওয়ার্কফ্লো** | প্রকল্প তৈরি, মডেল ডিপ্লয়মেন্ট, এজেন্ট স্ক্যাফোল্ডিং, এজেন্ট ইনস্পেক্টর, এক-ক্লিক ডিপ্লয় |

### আপনার এজেন্ট উন্নত করার আইডিয়া

- **একটি তারিখ টুল যোগ করুন** - এজেন্টকে সারাংশে "আজকের তারিখ অনুযায়ী" প্রেক্ষাপট দিতে দিন
- **একটি দুর্ঘটনা ডাটাবেসের সাথে সংযুক্ত করুন** - টুল ফাংশনের মাধ্যমে আসল দুর্ঘটনা বিবরণ আনুন
- **একটি Bing গ্রাউন্ডিং টুল যোগ করুন** - এজেন্টকে সাম্প্রতিক খবর খুঁজে দেখতে দিন অতিরিক্ত প্রেক্ষাপটের জন্য
- **বিভিন্ন মডেল পরীক্ষা করুন** - `gpt-4.1` বনাম `gpt-4.1-mini` আউটপুট গুণমান তুলনা করুন
- **Foundry ব্যবহার করে মূল্যায়ন করুন** - এজেন্টের গুণগত মান পরিমাপের জন্য Evaluation ফিচার ব্যবহার করুন

### পাথ B ব্যবহারকারীদের জন্য: ক্লাউড ডিপ্লয়মেন্টে আপগ্রেড করুন

যখন আপনি ক্লাউডে ডিপ্লয় করতে প্রস্তুত হবেন:
1. একটি Azure সাবস্ক্রিপশন নিন ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. [মডিউল ০১, সেটআপ](01-setup.md#step-2-set-up-based-on-your-access) সম্পন্ন করুন (প্রকল্প তৈরি, মডেল ডিপ্লয়, RBAC বরাদ্দ)
3. আপনার `.env` ফাইলে Foundry প্রকল্পের এন্ডপয়েন্ট এবং মডেল ডিপ্লয়মেন্ট নাম আপডেট করুন
4. [মডিউল ০৫ - Foundry-তে ডিপ্লয়](05-deploy-to-foundry.md) থেকে চালিয়ে যান

## রিসোর্স ক্লিন আপ (ঐচ্ছিক)

আপনি যদি এই ওয়ার্কশপ চলাকালীন তৈরি হওয়া Azure রিসোর্স মুছে ফেলতে চান:

### অপশন ১: রিসোর্স গ্রুপ মুছুন (সবকিছু মুছে ফেলে)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### অপশন ২: শুধুমাত্র হোস্টেড এজেন্ট মুছুন

১. [ai.azure.com](https://ai.azure.com) → আপনার প্রকল্প → **Build** → **Agents** এ যান।
২. আপনার এজেন্টে ক্লিক করুন → **Delete** এ ক্লিক করুন।

### অপশন ৩: মডেল ডিপ্লয়মেন্ট মুছুন

১. Foundry সাইডবারে আপনার প্রকল্প সম্প্রসারণ করুন → **Models**।
২. মডেল ডিপ্লয়মেন্টে রাইট-ক্লিক করুন → **Delete**।

> **খরচ নোট:** হোস্টেড এজেন্ট চলাকালীনই খরচ হয়। আপনি যদি এজেন্ট বন্ধ বা মুছে ফেলেন, কোনো ধারাবাহিক চার্জ নেই। মডেল ডিপ্লয়মেন্টের জন্য সংরক্ষিত ক্যাপাসিটির জন্য সামান্য খরচ হতে পারে - কাজ শেষ হলে এটি মুছে ফেলুন।
