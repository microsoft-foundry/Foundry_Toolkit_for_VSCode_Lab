# মডিউল 0 - পরিচিতি

⏱️ ~10 মিনিট

> [!WARNING]
> **পূর্বরূপ এবং সীমাবদ্ধতা:** [হোস্টেড এজেন্টস](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) বর্তমানে **পাবলিক পূর্বরূপে** আছে - প্রোডাকশন ওয়ার্কলোডের জন্য সুপারিশ করা হয় না। নিম্নলিখিত বিষয়গুলো বিবেচনায় রাখুন:
> - **সমর্থিত অঞ্চল সীমিত** - রিসোর্স তৈরি করার আগে [অঞ্চলের প্রাপ্যতা](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents#region-availability) পরীক্ষা করুন। যদি আপনি একটি অসমর্থিত অঞ্চল নির্বাচন করেন, তবে ডিপ্লয়মেন্ট ব্যর্থ হবে।
> - `azure-ai-agentserver-agentframework` প্যাকেজটি প্রি-রিলিজ - বিভিন্ন সংস্করণের মধ্যে এপিআই পরিবর্তিত হতে পারে।
> - স্কেল সীমা: হোস্টেড এজেন্টস ০–৫ রিপ্লিকা (স্কেল-টু-জিরোসহ) সমর্থন করে।
> - এই ওয়ার্কশপে প্রদর্শিত কিছু ফিচার সার্ভিস GA দিকে যাওয়ার সাথে সাথে পরিবর্তিত হতে পারে।

## আপনি যা তৈরি করবেন

এই ওয়ার্কশপে, আপনি একটি **"ব্যবস্থাপনা কর্মকর্তার মতো ব্যাখ্যা করুন"** এজেন্ট তৈরি করবেন - একটি হোস্টেড AI এজেন্ট যা জটিল প্রযুক্তিগত আপডেটগুলো গ্রহন করে সেগুলোকে সাধারণ ইংরেজি ব্যবস্থাপনা সারসংক্ষেপ হিসেবে পুনঃলিখন করে।

```mermaid
flowchart LR
    A["🧑‍💻 আপনি একটি\nপ্রযুক্তিগত আপডেট পাঠান"] --> B["🤖 নির্বাহী সারাংশ\nএজেন্ট"]
    B --> C["📝 সহজ-সরল ইংরেজিতে\nনির্বাহী সারাংশ"]
```

**এজেন্টটি ব্যবহার করে:**
- **মাইক্রোসফট এজেন্ট ফ্রেমওয়ার্ক** - এজেন্টের লজিক এবং কাঠামোর জন্য
- **ফাউন্ডরি টুলকিট ফর VS কোড** - স্ক্যাফোল্ডিং, স্থানীয়ভাবে টেস্ট এবং ডিপ্লয় করার জন্য
- **একটি AI মডেল** (যেমন, `gpt-4.1-mini/gpt-5-mini`) - সারসংক্ষেপ তৈরির জন্য

এই ল্যাবের শেষে, আপনার কাছে একটি কাজকর্মক্ষম এজেন্ট থাকবে যাকে আপনি Agent Inspector এর মাধ্যমে স্থানীয়ভাবে পরীক্ষা করতে পারবেন এবং ইচ্ছা করলে ক্লাউডে ডিপ্লয় করতে পারবেন।

## হোস্টেড এজেন্ট কী?

একটি **হোস্টেড এজেন্ট** হল একটি AI এজেন্ট যা মাইক্রোসফট ফাউন্ডরিতে একটি ম্যানেজড সার্ভিস হিসেবে চলে। নিজের অবকাঠামো পরিচালনা করার বদলে, আপনি আপনার এজেন্ট কোডকে একটি কন্টেইনারে আবদ্ধ করেন এবং ফাউন্ডরি স্কেলিং, হোস্টিং, এবং একটি স্ট্যান্ডার্ড HTTP এন্ডপয়েন্টের মাধ্যমে এক্সপোজ করা পরিচালনা করে।

| ধারণা | এর অর্থ |
|---------|--------------|
| **এজেন্ট** | আপনার পাইটন কোড যা একটি ব্যবহারকারীর মেসেজ গ্রহণ করে, একটি AI মডেল কল করে, এবং একটি কাঠামোবদ্ধ উত্তর প্রদান করে |
| **হোস্টেড** | ফাউন্ডরি আপনার কন্টেইনার চালায় - কোনও VM, Kubernetes, বা অবকাঠামো পরিচালনা করার প্রয়োজন নেই |
| **রেসপন্স প্রোটোকল** | একটি স্ট্যান্ডার্ড HTTP API (`POST /responses`) যা যে কোনো ক্লায়েন্ট আপনার এজেন্টের সাথে ইন্টারঅ্যাক্ট করতে কল করতে পারে |
| **এজেন্ট ইনস্পেক্টর** | একটি স্থানীয় টেস্টিং UI (ফাউন্ডরি টুলকিটের অংশ) যা আপনাকে ডিপ্লয় করার আগে এজেন্টের সাথে চ্যাট করতে দেয় |

এই ওয়ার্কশপে, আপনি শূন্য থেকে সম্পূর্ণ হোস্টেড এজেন্ট তৈরি করবেন - অথবা প্রয়োজনে স্থানীয় টেস্টিং এ থামতে পারেন।

## সকল পথের জন্য: প্রয়োজনীয় টুলস

নিচের প্রতিটি টুল ইন্সটল করুন। ইন্সটল করার পরে, চেক কমান্ড চালিয়ে কাজ করছে কিনা যাচাই করুন।

| # | টুল | সংস্করণ | ইন্সটল | যাচাই (প্রত্যাশিত আউটপুট) |
|---|------|---------|---------|---------------------------|
| 1 | **ভিজ্যুয়াল স্টুডিও কোড** | সর্বশেষ | [code.visualstudio.com](https://code.visualstudio.com/) | কোনো এরর ছাড়াই খোলে |
| 2 | **পাইথন** | 3.12 বা বেশি| [python.org/downloads](https://www.python.org/downloads/) | `python --version` $\rightarrow$ `Python 3.12.x` |
| 3 | **ফাউন্ডরি টুলকিট ফর VS কোড** | সর্বশেষ | এক্সটেনশন ID: `ms-windows-ai-studio.windows-ai-studio` | Activity Bar এ Foundry আইকন |
| 4 | **পাইথন এক্সটেনশন ফর VS কোড** | সর্বশেষ | এক্সটেনশন ID: `ms-python.python` | এক্সটেনশন প্যানেলে ইন্সটল হয়েছে |

> [!TIP]
> **ইন্সটলেশনের জন্য প্রো-টিপস:**
> - **Python PATH (Windows):** পাইথন ইন্সটলার এর প্রথম স্ক্রিনে সবসময় **"Add Python to PATH"** চেক করুন। এটা না থাকলে, টার্মিনালে `python` কমান্ড চিনতে পারবে না।
> - **একাধিক পাইথন ভার্সন:** যদি আপনার কাছে পাইথন 3.10 এবং 3.12 দুইটি থাকে, তাহলে ভার্চুয়াল এনভায়রনমেন্ট তৈরির জন্য `python3.12 -m venv .venv` ব্যবহার করুন যাতে সঠিক ভার্সন ব্যবহৃত হয়।
> - **ডকার WSL 2 (Windows):** ডকার ডেস্কটপ ইন্সটলেশনের সময়, নিশ্চিত করুন **WSL 2 backend** নির্বাচন করা হয়েছে। Hyper-V দিয়ে ডকার ধীরগতিতে চলে এবং ফাউন্ডরি কন্টেইনার বিল্ডে সমস্যা হতে পারে।
> - **ডকার কাজ করছেনা?** ডকার ডেস্কটপ চালু করার পর ৩০-৬০ সেকেন্ড অপেক্ষা করুন। `docker info` চালান - যদি "Cannot connect to the Docker daemon" দেখায়, তাহলে ডকার এখনও ইনিশিয়ালাইজ হচ্ছে।
> - **VS কোড এক্সটেনশন লোড হচ্ছেনা?** এক্সটেনশন ইন্সটল করার পর উইন্ডো রিলোড করুন: `Ctrl+Shift+P` → `Developer: Reload Window`।

> **উইন্ডোজ ব্যবহারকারীরা:** পাইথন ইন্সটলেশনের সময় অবশ্যই **"Add Python to PATH"** চেক করুন।
