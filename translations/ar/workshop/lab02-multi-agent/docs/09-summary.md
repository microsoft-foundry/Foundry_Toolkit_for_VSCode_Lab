# الوحدة 9 - الملخص والخطوات التالية

⏱️ ~5 دقائق

**تهانينا!** لقد قمت ببناء واختبار ونشر (إذا كنت على المسار أ) سير عمل متعدد الوكلاء باستخدام Microsoft Foundry وأدوات Foundry لـ VS Code.

---

## ما الذي بنيته

**مُقَيِّم السيرة الذاتية → ملاءمة الوظيفة** - سير عمل متعدد الوكلاء مستضاف يقوم بما يلي:
- استلام سيرة ذاتية + وصف الوظيفة عبر HTTP (`POST /responses`)
- تشغيل أربعة وكلاء متخصصين في خط معالجة متسلسل - يقوم كل وكيل بنقل البيانات التي يحتاجها الوكيل التالي
- إعادة درجة الملاءمة (0–100 مع تفصيل)، وقائمة بفجوات المهارات والشهادات، وخارطة طريق تعلم شخصية بروابط فعلية من Microsoft Learn لكل فجوة
- الاتصال بخادم Microsoft Learn MCP (`https://learn.microsoft.com/api/mcp`) لجلب الموارد التعليمية الرسمية لكل فجوة مهارية محددة
- العمل كوكيل مستضاف في حاوية واحدة داخل خدمة وكلاء Microsoft Foundry

---

## المفاهيم الرئيسية التي تعلمتها

| المفهوم | ما تمرّنت عليه |
|---------|-------------------|
| **تنسيق متعدد الوكلاء** | خط معالجة متسلسل باستخدام `WorkflowBuilder` مع `add_edge()` |
| **تخصص الوكلاء** | أداء أربعة وكلاء متخصصين أفضل من وكيل عام واحد |
| **نمط موزع المحتوى** | يعمل ResumeParser كموزع - يحفظ نص وصف الوظيفة في قسم `[JOB DESCRIPTION PASS-THROUGH]` حتى يتمكن الوكلاء اللاحقون من الوصول إليه (مطلوب لأن `context_mode="last_agent"` يعني أن فقط `start_executor` يرى رسالة المستخدم الخام) |
| **نمط توصيل المحتوى** | وكيل وصف الوظيفة ينقل `[PARSED RESUME PASS-THROUGH]` للأمام حتى يحصل MatchingAgent على كلا الملفين الشخصيين؛ لتجنب تنشيط المعنى OR المزدوج الذي تسببه الرسوم البيانية التجميعية |
| **تكامل أداة MCP** | `@tool` + `streamable_http_client` تستدعي خادم MCP خارجي |
| **دورة حياة الوكيل المستضاف** | إعداد أولي → تكوين → اختبار محلي → نشر → التحقق في السحابة |
| **`context_mode="last_agent"`** | يرى كل منفذ فقط مخرجات المنفذ السابق المباشر له |
| **سير العمل باستخدام Foundry Toolkit** | معالج الإعداد، مفتش الوكيل، عارض سير العمل، نشر بنقرة واحدة |

## الخطوات التالية

### استمر في التعلم

| المورد | الوصف |
|----------|-------------|
| **[مرجع Agent Framework SDK](https://learn.microsoft.com/agent-framework/)** | وثائق API لـ `agent-framework-foundry`، `WorkflowBuilder`، `AgentExecutor` |
| **[كتالوج أداة MCP](https://learn.microsoft.com/azure/foundry/agents/how-to/tools/model-context-protocol)** | ربط الوكلاء بخوادم MCP أخرى (Bing، GitHub، مخصصة) |
| **[إضافة المعرفة (RAG)](https://learn.microsoft.com/azure/foundry/agents/concepts/knowledge)** | تزويد الوكلاء بالوثائق، مخازن المتجهات، أو بحث Bing |
| **[تقييمات Foundry](https://learn.microsoft.com/azure/foundry/evaluations/overview)** | قياس جودة الوكلاء على نطاق واسع باستخدام المقيمين الآليين |
| **[وثائق Microsoft Foundry](https://learn.microsoft.com/azure/foundry/)** | مرجع كامل للمنصة |
| **[Foundry Toolkit - ما الجديد](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio&ssr=false#version-history)** | ملاحظات إصدار الإضافة وسجل التغييرات |

### أفكار لتوسيع هذا سير العمل

- **أضف وكيلًا خامسًا** - مدرب مقابلات ينتج أسئلة محتملة بناءً على تقرير الفجوات
- **أضف أداة بحث Bing** - دع وكيل وصف الوظيفة يبحث عن إعلانات وظيفية مشابهة لإثراء المتطلبات
- **اتصل بقاعدة بيانات للسير الذاتية** - جلب ملفات المرشحين من قاعدة بيانات عبر `@tool` مخصصة
- **جرّب نماذج مختلفة** - مقارنة جودة الإخراج والكمون بين `gpt-4.1` و `gpt-4.1-mini`
- **قيّم باستخدام Foundry** - استخدم ميزة التقييمات لتسجيل تقارير الملاءمة مقابل مجموعة بيانات ذهبية

### لمستخدمي المسار ب: الترقية للنشر في السحابة

عندما تكون جاهزًا للنشر في السحابة:
1. احصل على اشتراك Azure ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. أكمل [مختبر 01، الوحدة 01](../../lab01-single-agent/docs/01-setup.md) (إنشاء مشروع، نشر نموذج، تعيين RBAC)
3. حدّث ملف `.env` الخاص بك بنقطة نهاية مشروع Foundry واسم نشر النموذج
4. استمر من [الوحدة 06 - النشر إلى Foundry](06-deploy-to-foundry.md)

## تنظيف الموارد (اختياري)

إذا كنت تريد إزالة موارد Azure التي تم إنشاؤها خلال هذا الورشة:

### الخيار 1: حذف مجموعة الموارد (يحذف كل شيء)

```powershell
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### الخيار 2: حذف الوكيل المستضاف فقط

1. افتح [ai.azure.com](https://ai.azure.com) → مشروعك → **Build** → **Agents**.
2. ابحث عن **PersonalCareerCopilot** → انقر **Delete**.

### الخيار 3: حذف نشر النموذج

1. في شريط Foundry الجانبي، قم بتوسيع مشروعك → **Models**.
2. انقر بزر الماوس الأيمن على نشر النموذج → **Delete**.

> **ملاحظة تكلفة:** وكلاء الاستضافة يتكبدون التكاليف فقط أثناء التشغيل. إذا أوقفت الوكيل أو حذفته، فلن يكون هناك رسوم مستمرة. قد يتكبد نشر النموذج رسومًا صغيرة للسعة المحجوزة - احذفه إذا انتهيت منه.
