# المختبر 02 - سير عمل متعدد الوكلاء: تقييم الملاءمة بين السيرة الذاتية والوظيفة

## مسار التعلم الكامل

ترشدك هذه الوثائق في بناء واختبار ونشر **سير عمل متعدد الوكلاء** يقوم بتقييم مدى تطابق السيرة الذاتية مع الوظيفة باستخدام أربعة وكلاء متخصصين يتم تنظيمهم عبر **WorkflowBuilder**.

> **المتطلبات السابقة:** إكمال [المختبر 01 - وكيل واحد](../../lab01-single-agent/README.md) قبل بدء المختبر 02.
