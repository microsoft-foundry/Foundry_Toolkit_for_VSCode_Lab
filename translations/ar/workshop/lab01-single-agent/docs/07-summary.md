# الوحدة 7 - ملخص والخطوات التالية

⏱️ ~5 دقائق

**تهانينا!** لقد أنشأت، اختبرت، و(إذا كنت على المسار أ) نشرت وكيل ذكاء اصطناعي مستضاف باستخدام Microsoft Foundry وأداة Foundry Toolkit لـ VS Code.

---

## ما الذي أنشأته

وكيل **"اشرحها لي كأنني مدير تنفيذي"** الذي:
- يستقبل تقارير الحوادث الفنية أو التحديثات التشغيلية عبر HTTP (`POST /responses`)
- يترجمها إلى ملخصات تنفيذية بلغة بسيطة
- يتبع تنسيق إخراج منظم (ماذا حدث / تأثير العمل / الخطوة التالية)
- يرفض الطلبات الخارجة عن الموضوع ومحاولات حقن التعليمات
- يعمل كوكيل مستضاف في حاوية ضمن خدمة وكلاء Microsoft Foundry

---

## المفاهيم الرئيسية التي تعلمتها

| المفهوم | ما تدربت عليه |
|---------|-------------------|
| **هيكلية إطار عمل الوكيل** | خط أنابيب `FoundryChatClient` → `Agent` → `ResponsesHostServer` |
| **دورة حياة الوكيل المستضاف** | إنشاء القالب → التهيئة → اختبار محلي → النشر → التحقق في السحابة |
| **هندسة التعليمات البرمجية للنظام** | الدور، الجمهور، تنسيق الإخراج، القواعد، قيود الأمان، والأمثلة |
| **الاختلافات بين المحلي والمستضاف** | الهوية (بيانات الاعتماد الشخصية مقابل الهوية المُدارة)، نقطة النهاية، مسار الشبكة |
| **حدود الأمان** | الدفاع ضد حقن التعليمات، التزام الدور، التعامل الراقي مع الحالات الحدية |
| **سير عمل أداة Foundry** | إنشاء المشروع، نشر النموذج، إنشاء وكيل، مفحص الوكيل، النشر بنقرة واحدة |

### أفكار لتطوير وكيلك

- **أضف أداة تاريخ** - اسمح للوكيل بإضافة سياق "حتى اليوم" في الملخصات
- **اتصل بقاعدة بيانات الحوادث** - سحب تفاصيل الحوادث الحقيقية عبر دالة أداة
- **أضف أداة تدعيم Bing** - اسمح للوكيل بالبحث عن أخبار حديثة لمزيد من السياق
- **جرّب نماذج مختلفة** - قارن جودة الإخراج بين `gpt-4.1` و `gpt-4.1-mini`
- **قيم مع Foundry** - استخدم ميزة التقييمات لقياس جودة الوكيل على نطاق واسع

### لمستخدمي المسار ب: الترقية للنشر السحابي

عندما تكون جاهزًا للنشر على السحابة:
1. الحصول على اشتراك Azure ([azure.microsoft.com/free](https://azure.microsoft.com/free/))
2. إكمال [الوحدة 01، الإعداد](01-setup.md#step-2-set-up-based-on-your-access) (إنشاء المشروع، نشر النموذج، تعيين RBAC)
3. تحديث ملف `.env` بنقطة نهاية مشروع Foundry واسم نشر النموذج
4. المتابعة من [الوحدة 05 - النشر إلى Foundry](05-deploy-to-foundry.md)

## تنظيف الموارد (اختياري)

إذا أردت إزالة موارد Azure التي تم إنشاؤها خلال هذه الورشة:

### الخيار 1: حذف مجموعة الموارد (يحذف كل شيء)

```bash
az group delete --name rg-hosted-agents-workshop --yes --no-wait
```

### الخيار 2: حذف الوكيل المستضاف فقط

1. افتح [ai.azure.com](https://ai.azure.com) → مشروعك → **بناء** → **وكلاء**.
2. انقر على وكيلك → انقر **حذف**.

### الخيار 3: حذف نشر النموذج

1. في الشريط الجانبي لـ Foundry، قم بتوسيع مشروعك → **النماذج**.
2. انقر بزر الماوس الأيمن على نشر النموذج → **حذف**.

> **ملاحظة التكلفة:** الوكلاء المستضافون يكلفون فقط عندما يكونون في حالة تشغيل. إذا أوقفت أو حذفت الوكيل، لن يكون هناك رسوم مستمرة. قد ينشأ رسم صغير لنشر النموذج على السعة المحجوزة - احذفه إذا انتهيت.
