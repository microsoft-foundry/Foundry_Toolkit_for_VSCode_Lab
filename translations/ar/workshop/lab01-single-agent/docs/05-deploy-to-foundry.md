# الوحدة 5 - النشر إلى خدمة Foundry Agent

⏱️ ~10 دقائق

> ⚠️ **لمستخدمي المسار B:** تتطلب هذه الوحدة اشتراكًا في Foundry. إذا كنت تستخدم Foundry Local، تخطَّ إلى [الوحدة 07 - الملخص](07-summary.md). لقد أكملت بنجاح سير عمل التطوير المحلي!

في هذه الوحدة، تقوم بنشر العميل الذي تم اختباره محليًا إلى Microsoft Foundry كـ **عميل مستضاف**. يقوم النشر ببناء صورة حاوية، ودفعها إلى Azure Container Registry، وتشغيل العميل في البنية التحتية المدارة من Foundry.

## الخطوة 1: بدء النشر

### الخيار أ: النشر من Agent Inspector (موصى به)

إذا كان Agent Inspector مفتوحًا (من الاختبار):
1. انقر زر **النشر** في الزاوية العليا اليمنى (رمز السحابة ↑).

1. اضغط `Ctrl+Shift+P` → **Foundry Toolkit: Deploy Hosted Agent**.

يطالبك المعالج بـ:

## الخطوة 3: النشر والمراقبة

1. انقر **نشر**.
2. شاهد لوحة **المخرجات** (اختر **Microsoft Foundry** من القائمة المنسدلة).
3. يمر النشر بالمراحل التالية:
   - **بناء Docker** - يبني الحاوية من Dockerfile الخاص بك
   - **دفع Docker** - يدفع الصورة إلى ACR (1–3 دقائق في أول نشر)
   - **تسجيل العميل** - ينشئ العميل المستضاف في Foundry
   - **بدء الحاوية** - يبدأ باستخدام الهوية المُدارة من النظام

4. عند الانتهاء، تظهر إشعار:
   > **تنفيذ-agent-summary-نفذ النشر بنجاح.** `View logs` `Run agent`

5. انقر **تشغيل العميل** لفتح منطقة تجارب العميل.

![نجاح النشر يظهر منطقة تجارب العميل مع حالة تشغيل](../../../../../translated_images/ar/05-deployed-asset.b59e6a5eef31c0b1.webp)

### قيم حالة النشر

| الحالة | المعنى |
|--------|---------|
| **تشغيل** | الحاوية جاهزة، العميل يستجيب |
| **معلق** | الحاوية تبدأ - انتظر 30–60 ثانية |
| **فشل** | تحقق من السجلات (انظر استكشاف الأخطاء أدناه) |

## الأخطاء الشائعة في النشر

| الخطأ | السبب الجذري | الحل |
|-------|-----------|-----|
| `agents/write` تم رفض الإذن | فقدان دور **Azure AI User** على مستوى المشروع | [الوحدة 01، تعيين RBAC](01-setup.md#deploy-a-model--assign-rbac) |
| Docker غير شغّال | لم يتم بدء Docker Desktop | ابدأ Docker Desktop → تحقق `docker info` |
| ترخيص ACR | الهوية المُدارة لا تستطيع سحب الصورة | راجع [الوحدة 08 - استكشاف الأخطاء](08-troubleshooting.md) |
