> - حزمة `agent-framework-foundry-hosting` في إصدار ما قبل الإصدار - قد تتغير واجهات برمجة التطبيقات بين الإصدارات.

> - قد تتغير بعض الميزات المعروضة في هذا الورشة مع تقدم الخدمة نحو الإصدار العام.

## ماذا ستبني

في هذه الورشة، ستبني عاملًا **"اشرح لي كأنني مسؤول تنفيذي"** - عامل ذكاء اصطناعي مستضاف يأخذ تحديثات تقنية معقدة ويعيد كتابتها كملخصات تنفيذية بالإنجليزية البسيطة.

```mermaid
flowchart LR
    A["🧑‍💻 You send a\ntechnical update"] --> B["🤖 Executive Summary\nAgent"]
    B --> C["📝 Plain-English\nexecutive summary"]
```

**العامل يستخدم:**
- **إطار عمل العوامل من مايكروسوفت** - للمنطق والهيكلية
- **مجموعة Foundry لأدوات VS Code** - لإعداد الهيكل، والاختبار محليًا، والنشر
- **نموذج ذكاء اصطناعي** (مثلاً `gpt-4.1-mini/gpt-5-mini`) - لتوليد الملخصات

بحلول نهاية هذا المختبر، سيكون لديك عامل يعمل يمكنك اختباره محليًا عبر Agent Inspector، وبإمكانك اختياريًا نشره في السحابة.

## ما هي العوامل المستضافة؟

**العامل المستضاف** هو عامل ذكاء اصطناعي يعمل كخدمة مُدارة في Microsoft Foundry. بدلاً من إدارة البنية التحتية الخاصة بك، تقوم بتغليف كود العامل داخل حاوية ويتولى Foundry التعامل مع التدرج والاستضافة وتعريضه عبر نقطة نهاية HTTP قياسية.

| المفهوم | ما يعنيه |
|---------|--------------|
| **العامل** | كود بايثون الخاص بك الذي يستقبل رسالة المستخدم، يستدعي نموذج الذكاء الاصطناعي، ويرجع استجابة منظمة |
| **مستضاف** | Foundry يشغل الحاوية الخاصة بك نيابة عنك - لا أجهزة افتراضية، لا Kubernetes، لا إدارة للبنية التحتية |
| **بروتوكول الاستجابة** | API HTTP قياسي (`POST /responses`) يمكن لأي عميل استدعاؤه للتفاعل مع العامل الخاص بك |
| **Agent Inspector** | واجهة اختبار محلية (مدمجة في Foundry Toolkit) تتيح لك الدردشة مع العامل قبل النشر |

في هذه الورشة، ستنتقل من الصفر إلى عامل مستضاف بالكامل — أو تتوقف عند الاختبار المحلي إذا فضلت ذلك.

## جميع المسارات: الأدوات المطلوبة

ثبت كل أداة أدناه. بعد التثبيت، تحقق من عملها عن طريق تشغيل أمر التحقق.

| # | الأداة | الإصدار | التثبيت | التحقق (الناتج المتوقع) |
|---|------|---------|---------|---------------------------|
| 1 | **Visual Studio Code** | الأحدث | [code.visualstudio.com](https://code.visualstudio.com/) | يفتح بدون أخطاء |
| 2 | **Python** | 3.12 أو أعلى| [python.org/downloads](https://www.python.org/downloads/) | `python --version` $\rightarrow$ `Python 3.12.x` |
| 3 | **Foundry Toolkit for VS Code** | الأحدث | معرف الإضافة: `ms-windows-ai-studio.windows-ai-studio` | أيقونة Foundry في شريط النشاط |
| 4 | **إضافة Python لـ VS Code** | الأحدث | معرف الإضافة: `ms-python.python` | مثبتة في لوحة الإضافات |

> [!TIP]
> **نصائح احترافية للتثبيت:**
> - **مسار Python (ويندوز):** تحقق دائمًا من تحديد **"Add Python to PATH"** في الشاشة الأولى لمثبت Python. بدون هذا، لن يتعرف على `python` في الطرفية الخاصة بك.
> - **إصدارات Python متعددة:** إذا كان لديك Python 3.10 و 3.12 مثبتان، استخدم `python3.12 -m venv .venv` لضمان استخدام الإصدار الصحيح لبيئة العمل الافتراضية.
> - **Docker WSL 2 (ويندوز):** أثناء تثبيت Docker Desktop، تأكد من اختيار **WSL 2 backend**. Docker مع Hyper-V أبطأ وقد يسبب مشكلات في إنشاء حاويات Foundry.
> - **Docker لا يبدأ؟** انتظر 30–60 ثانية بعد تشغيل Docker Desktop. شغّل `docker info` - إذا ظهرت الرسالة "Cannot connect to the Docker daemon"، فهذا يعني أن Docker لا يزال يبدأ.
> - **ملحقات VS Code لا تعمل؟** بعد تثبيت الإضافات، أعد تحميل النافذة: `Ctrl+Shift+P` → `Developer: Reload Window`.

> **مستخدمو ويندوز:** تحقق من تحديد **"Add Python to PATH"** أثناء تثبيت Python.
